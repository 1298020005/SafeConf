## 2. 数据集“对不对”

### 对的地方

1. 都是公开、可引用、单细胞扰动常见数据。
2. gene：Cui / Frangieh / Lara / Adamson / Norman 覆盖 CRISPR 扰动主流场景。
3. chem：sciplex3、McFarland、Tahoe 方向正确；有失败数据集反而加可信度。
4. 双模型线用 Adamson–Norman–Frangieh，和 GEARS/scGPT 能力匹配。

### 问题不在“名字错了”，在“用法”

1. **两套故事还没合成一套**：7 主表是参考预测+冻结四特征；E60–E74 是真实深度模型+pair-risk。审稿人会问是不是同一方法。
2. **难 setting 不全**：周老师要的小矩阵、整行、跨数据集，没有用同一真实预测器全收口。
3. **化学短板**：McFarland 失败 + Santinha 弱 + Tahoe/OP 未上真药学模型。
4. **多样性偏 setting 而不是再堆名字**：三个 gene 都只做“整列未见基因”，不等于三类 generalization 都过了。
5. **每面板 24 任务偏小**：E74 合并后好看；单面板 CI 常穿 0，必须多 panel / 汇总，不能吹单次。

**数据集本身：够用、选对方向。**  
**当前组合+实验合同：还撑不起“稳定二区已达成”。**

## 3. 稳定二区？

**现在：否。**  
**补齐后：有机会，不是玄学。**

二区要站住，最少要同时满足：

1. 一个清楚 claim（task-risk 分诊 **或** pair-risk 证书，二选一主叙事）
2. ≥3 独立数据 + **≥2 类难 setting**（不只未见基因）
3. ≥2 真实不同模型家族，同 task/gene/split
4. 相对 **predicted magnitude** 的增量说得清（E74 有苗头，需复现面板钉死）
5. 化学单独闭环或明确降为补充/边界
6. 阴性全保留（McFarland、seed 无信号、跨域弱）
7. 可复现合同

周老师门槛更硬：小矩阵 + 行/列 + 跨数据集都过 → 小文章。  
**这三关没齐 = 二区也别自我感觉稳定。**

---

## 4. 一区？

**现在：否。补齐二区门槛后仍不等于一区。**

一区还要额外有：

- 明确方法创新（不只评估协议）
- 跨域稳定增益（E69 目前不稳）
- 选择性预测 vs 原生 uncertainty / PRESCRIBE 类竞品
- gene+chem 双模态真模型
- 机制/何时失败可解释
- 更强外部验证（最好有盲测/湿实验）

**数据集再多，也换不来一区。** 一区卡在方法和发现，不卡在再下一个 Tahoe。

## 5. 直接回答你的三句

1. **数据集对吗？**  
   对。主表和双模型三件套都是正经数据；问题是协议统一和化学闭环，不是“数据假/数据错”。

2. **能稳定二区吗？**  
   **现在不能。** 数据底座够；把 claim 锁死 + 老师三 setting 用真实预测器收口 + magnitude 增量钉死 + 化学边界写清楚后，**才谈得上冲稳二区**。

3. **能发一区吗？**  
   **现在不能。** 以后若 claim 升级成可辩护的方法贡献并跨过竞品/跨域，才有一区候选；别把“数据量大”当一区进度。
