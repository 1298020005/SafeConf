# 目录与架构

## 当前架构（2026-06-01 起）

```text
~/.codex/                      # 唯一数据：sessions、state_5.sqlite、当前 auth.json
~/.codex-profiles/
  qq3485725367/auth.json       # 348 登录快照
  qq3506725328/auth.json       # 350 登录快照
~/.codex-active                # 当前逻辑账号名
~/.codex-accounts/             # 历史分目录（只读归档，切换不再 symlink）

切号 = 用 profiles 里 auth 覆盖 ~/.codex/auth.json + 杀 app-server
```

## 脚本（`~/bin/`）

| 脚本 | 作用 |
|:-----|:-----|
| `codex-switch` | **日常切号** `348` / `350` |
| `codex-unify-data.sh` | **一次性** 合并 348+350 → `~/.codex` |
| `codex-cursor-proxy` | Cursor 入口：17897 代理 + `CODEX_HOME=~/.codex` |
| `codex-account` | 多账号管理；`use` 在统一模式下转调 `codex-switch` |
| `sync-codex-cursor-home.sh` | 统一模式仅提示用 `codex-switch`；旧模式才建 symlink |
| `sync-codex-auth.sh` | 已废弃，指向 `sync-codex-cursor-home.sh` |
| `proxy-healthcheck.sh` | 隧道 + Codex API 探活 |
| `codex-data-status.sh` | rollout 数、threads 数、login status |
| `codex-server-relogin.sh` | 设备码重登辅助 |

## Cursor 远程

- 扩展：`openai.chatgpt`（linux-x64）
- 代理：`~/.cursor-server/data/User/settings.json` 与 `Machine/settings.json` 中 **17897**
- 建议 Remote 范围设置：`chatgpt.cliExecutable` → `/home/yyf/.local/bin/codex-cursor-proxy`（若面板起不来 CLI，检查此项是否在 **Remote** 而非 Windows User）

- 工具：[Cockpit Tools](https://github.com/jlcodes99/cockpit-tools)

- 服务器：**统一目录 + `codex-switch`**，比 Cockpit 多了一步「数据合并」，切号方式类似
