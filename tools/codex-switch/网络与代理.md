# 网络与代理

## 拓扑

```text
Windows Clash          SSH RemoteForward           服务器
127.0.0.1:7897  ──────────────────────────►  127.0.0.1:17897
     ▲                                              │
     │                                              ▼
 Cursor 本机 User 用 7897              Extension Host / codex-cursor-proxy / bash
 Remote SSH 用 17897（勿写成 7897）
```

## Windows

### 1. Clash

- HTTP 代理：`127.0.0.1:7897` 常开

### 2. SSH `~/.ssh/config`（lab-168）

```sshconfig
Host lab-168
    HostName 10.11.52.168
    User yyf
    RemoteForward 17897 127.0.0.1:7897
    ServerAliveInterval 60
    ServerAliveCountMax 3
```

### 3. Cursor 设置分 scope

| Scope | `http.proxy` / SSH 代理 |
|:------|:------------------------|
| **User（本机）** | `http://127.0.0.1:7897` |
| **Remote [SSH: lab-168]** | `remote.SSH.httpProxy` / `httpsProxy` → `http://127.0.0.1:17897` |

**不要**在 Remote Extension Host 里写 `7897`（服务器上没有该端口 → `fetch failed`）。

### 4. `chatgpt.cliExecutable`

| Scope | 值 |
|:------|:---|
| User（本机 Windows） | 本机 `codex.exe` 或 wrapper |
| **Remote lab-168** | `/home/yyf/.local/bin/codex-cursor-proxy` |

日志若出现 `C:\...\codex.exe` 在远程执行 → Remote 未覆盖 User 设置。

### 5. 自检（PowerShell）

```powershell
ssh lab-168 "ss -ltnp | grep 17897"
ssh lab-168 "~/bin/proxy-healthcheck.sh"
```

`remote port forwarding failed for listen port 17897` 且 `ss` 已有 17897 → **正常**（Cursor 已建隧道，勿再手动 ssh -R）。

## 服务器

### `~/.bashrc`

```bash
export http_proxy="http://127.0.0.1:17897"
export https_proxy="http://127.0.0.1:17897"
# ... NO_PROXY=localhost,127.0.0.1,::1
```

### `~/.cursor-server/data/User/settings.json`（摘要）

```json
{
  "http.proxy": "http://127.0.0.1:17897",
  "http.proxySupport": "on",
  "remote.extensionHost.env": {
    "HTTP_PROXY": "http://127.0.0.1:17897",
    "HTTPS_PROXY": "http://127.0.0.1:17897",
    "NO_PROXY": "localhost,127.0.0.1,::1"
  }
}
```

### `codex-cursor-proxy`

- 固定 `http(s)_proxy` → `17897`
- `CODEX_HOME=$HOME/.codex`

### 已移除（勿加回）

- `remote.extensionHost.env` 里的 `NODE_OPTIONS=--require ...cursor-extension-fetch-proxy.js`
- Extension Host 使用 `7897` 或 Windows 注入的 `HTTP_PROXY=7897`

## 本机 Codex 数据路径（Windows，参考）

- 默认：`%USERPROFILE%\.codex\`
- Cockpit 账号索引：`%APPDATA%\cockpit-tools` 等（见 Cockpit 文档）
- **不与 lab-168 自动同步**；要把本机历史弄到服务器需手动打包 `sessions` / 登录同一号 backfill
