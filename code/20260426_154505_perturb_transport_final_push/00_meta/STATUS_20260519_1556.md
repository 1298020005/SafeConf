## 现在怎么看

阶段性好消息：

- 新的 `PolicySafeTransPT` 不是空壳。
- 它相对 `V2` 有比较稳定的小幅提升，尤其是 top20 / DEG / program consistency 这些 effect 指标。

阶段性风险：

- 目前还没有形成“全面压过强基线 `V0`”的结果。
- `TianKampmann2019` 外部验证刚开始，早期结果里 `PolicySafeTransPT` 更像安全回退到 `V0`，说明它偏保守，但还不能说外部已经明显提升。
