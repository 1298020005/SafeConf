Model-specific risk（模型特异风险）：同一道任务上，模型 A 和模型 B 哪个更可靠。这需要真实多模型的逐任务预测向量。

当前真正的问题

“还有问题”不等于“继续随便加实验”。下面六项是现在必须如实保留的技术边界。

1. 同一任务的模型选择

Frozen task score 对同一任务上的所有模型给出相同先验。

缺口：需要 model-specific residual 和 model-selection regret。

2. 真实多模型逐向量验证

GEARS 已有 strict-pass formal 证据包和 GEARS-only 风险分析；scGPT 已有 forward-only strict smoke；E28/E29 已证明 GEARS–scGPT 同任务/gene panel 合同和小样本风险审计可行；E30 说明现有 GEARS runs 不足以直接写 seed uncertainty；E31/E32 已打通 fixed-test 3-seed smoke；CPA 尚未接入。

下一步：把 fixed-test 3-seed 提升到正式 epochs、扩大 shared tasks/数据集，或推进 CPA 资产。

3. Magnitude 是强基线

七主表宏平均两者接近；Tahoe 中 magnitude 的 top-10 更强。

正确说法：两者捕获不同风险模式，SafeConf 不是普遍替代品。

4. McFarland 失败边界

Frozen partial ρ=-0.061，不允许用 learned 结果把它改写成成功。

价值：它说明简单冻结公式的适用边界真实存在。

5. E8b 不是完整外部验证

它是 perturbation-level 聚合方法错误关联，不是 15 个模型的逐预测风险校准。

必须带：sample-size、metric 和 DEG 选择 caveat。

6. Tahoe 已闭环，不应再扫参数

D1–D5 已回答 pair、cell-line、triage、threshold 和 fixed combination。

不再做：增加 shard、扫 875/925/950 门槛或在 test set 调组合权重。

老师的问题当前回答状态
1. 数据是跨数据集切吗？不是。七个数据集分别做 held-out pair，所有特征只读 fold-train。已回答
2. 三个指标怎么算？Control 最大余弦相似度、train 内历史支持量、两个固定参考预测向量的 RMSE 分歧。定义已固化
3. Context / perturbation 各有多少？七个主数据集结构差异很大；完整 data map 在汇报第 17 页。7 datasets
4. 是否使用现成大型数据？已完成 Tahoe 9,000-task sampled validation，覆盖 25 contexts 和 1,028 drug-dose perturbations。D0–D5 闭环
5. 应该用公式还是模型？Frozen 公式是可解释主协议；learned risk model 是扩展和敏感性分析，不能反向改写 Frozen 成功率。两层已分开
6. 任务难度有什么用？用于人工复核和湿实验优先级分诊；但同一任务上选择模型，还需要 model-specific residual。价值已答；模型层待补
