# 执行合同 v2.1

本目录执行用户批准的SafeConf v2.1。三个研究问题、10个反馈顺序、20个内容置乱、三个固定端点、50/25/25外部分区、资格门和Source一次修复保持。

机器配置见CONFIG.json。外部通过纯元数据哈希限定1500基因，采用按需Range接入官方原始聚合文件；原下载部分和所有费用保留。确认375基因，未按风险结果选样。

两项明确适配：PertEMA同时保留原CDF版本并补齐原始RMSE误差回归；严格DEV归因定位支持字段对象不一致后，补一个固定入选支持量对照。算法、数据、预算和参数保持；Source不增加其他特征。

主要不确定性以生物基因簇为单位，算法重复不充作独立样本。主误差为登记轴的delta RMSE；辅助为1-Pearson与EffectTop200 RMSE，Top200仅用于评分。

资格门使用误差比<=1.02、95%区间上界<=1.02、60%有效分层、80%分层覆盖和每有效状态预测方差/真实方差>=0.01。条件均值仅在上游训练区拟合。资格错误与风险训练标签分别计账。

所有普通故障由负责人修复并重跑受影响部分；方法修复有独立卡。正文、PDF、投稿包暂停。原始模型、结果、其他会话未提交修改与E208受保护进程保持。
