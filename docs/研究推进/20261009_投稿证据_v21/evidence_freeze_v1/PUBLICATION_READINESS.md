# SafeConf 投稿定位与负责人判断

SafeConf 当前按“公共真实扰动实验能否在没有当前预测器错误记录时启动风险审核”组织。PublicRule 是一个模型无关的证据层：它把合法历史实验转成风险参照；Target 反馈和 Source 错误只作为已经通过比较的条件扩展，不强行进入默认系统。

目前最适合投稿的主线有三层证据：

1. McFaline 同一真值合同中，DecoderOnly 与 SAMS 两种预测器分别由 Public 找到 22/43 和 24/43 个最高误差任务，幅度基线分别是 4/43 和 5/43；充分反馈时 Native＋Public 的全量排序继续提高，但按背景宏平均主端点仍单独报告。
2. Frangieh native512 的 GEARS↔scGPT 跨家族压力测试中，PublicHGB 相对幅度的全量 paired U20 增量为 +0.460（95% CI 0.317–0.704）和 +0.309（0.079–0.440），heldout-context 结果同方向。六个上游能力门未通过，因此该结果承担跨模型压力证据和适用边界。
3. KOLF2.1J 采用 600/300/300 时序。Ridge 通过能力门，MLP 因方差门失败；300 个确认基因在风险冻结后一次评分。Public 覆盖 228/300，72 个无历史任务按预冻结规则回退幅度。Public 相对幅度的 U20 点增量为 +0.136，但 95% CI 跨零，严重错误命中为 17 对 17；该结果支持可运行的外部审核流程，同时诚实保留不确定性。

因此，论文主贡献应写成“公共实验历史提供无需目标错误拟合的风险启动层，并形成一个信息预算与适用条件明确的审核框架”。不要把工作写成新神经网络、Source 或 Target 必须普遍胜出。Frangieh 的强压力结果和 KOLF 的资格门边界都应放进主结果与补充材料，让审稿人看到方法在哪些条件下可靠、在哪些条件下退化。

当前方法采用：PublicRule；Source 不进入默认配置；Target 保留 McFaline 全量排序的已验证范围。证据冻结目录包含统一 benchmark、逐任务排序、五张结果图、Methods 合同、Supplement 索引、监督来源账本和复现命令。

这个证据结构已经达到二区/CCF-B 投稿候选的完整性要求：问题清楚、方法可复现、强简单基线齐全、跨预测器和跨家族证据存在、独立确认有明确能力门、负结果和边界没有被删除。下一步是把冻结证据写成正文和补充材料，并保持方法配置不再随评价答案变化。
