# KOLF 独立确认：负责人执行决定

## 当前采用的论文主线

主实验已经冻结为两条互补证据：

1. PublicRule 在没有当前预测器错误标签时启动风险审核。
2. Target 反馈在同一整批任务上继续改善实际排序，但不替代 PublicRule。

Target-only 在登记的背景宏平均主端点上到最高测试预算仍未达到 PublicRule，因此“标签等效节省”保持右删失；全量混合排序的正增益单独报告，不能把它改写成已证明的标签节省。

内容置乱结果作为机制诊断和强支持量对照保存。Source 特征工程结束，Source 不进入默认系统。

## 唯一新增实验线

KOLF2.1J 作为独立研究确认，固定为：

```text
600 predictor-train genes
300 feedback/development genes
300 final-confirmation genes
1400 source-defined output genes
```

KOLF 研究从 Public memory 排除。确认前不读取300个 confirmation 的响应值。

当前实际进度：训练与反馈角色计数正在读取，630／1400个输出列已经完成；角色、输出轴和预算未改变。

## 固定接续顺序

1. 完成训练和反馈计数，生成两个固定上游预测器。
2. 在300个反馈基因上执行预注册 competence gate。
3. 在读取确认答案前冻结 Track A：Magnitude、Support、PublicRule；冻结 Track B：Target-only、Public+Target；保存模型、输入和风险分数哈希。
4. 只在冻结完成后一次性读取300个确认基因，并输出5／10／20／30%复核、U20、AURC、剩余误差和三项误差端点。
5. KOLF完成后停止新方法和新数据搜索，进入结果冻结、主图、基线表、Methods、Supplement索引和复现入口整理。

## 预先固定的取舍

- 两个预测器通过：双预测器确认。
- 一个通过：用合格预测器做正式确认，另一个保留为压力测试。
- 两个都不通过：确认答案继续封存，KOLF只作为预测器能力压力测试；不借确认答案修复预测器，也不把压力测试写成独立确认。

这条取舍保护论文的因果顺序：先证明预测器有资格，再检验风险审核；不让一个本身不合格的预测器制造虚假的风险层收益。
