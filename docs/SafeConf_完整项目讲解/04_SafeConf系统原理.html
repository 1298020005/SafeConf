CHAPTER 04

SafeConf 是怎样打分的

打分只使用测试前可观察的三类线索：背景熟悉程度、历史支持量和预测器分歧。测试真实误差只用于最终评价。

1. 三个核心特征

Context similarity

背景相似度。目标细胞背景的 control 表达向量，和训练参考背景最像的那个有多像。越像表示模型站在较熟悉的区域。

Support count

历史支持量。这个 perturbation 在 fold-train 中有多少可用历史任务。支持越多，通常证据越充足。

Model disagreement

预测器分歧。两个固定参考预测器给出的 effect vector 相差多大。分歧大常表示任务不稳定。

2. 为什么要先标准化

相似度大约在 -1 到 1，support count 可能是 0 到几百，RMSE 又是另一个尺度。不能把原始数字直接相加。

z(x) = (x - fold-train 中位数) / fold-train IQR IQR = 第75百分位 - 第25百分位
Robust z-score
稳健标准分

用中位数和四分位距进行缩放，比均值/标准差更不容被少数极端值拖走。参考统计只来自当前 fold 的 train 行。

3. 冻结公式

基因类任务

confidence = z(context_similarity) + z(log(1 + support_count)) - z(model_disagreement_rmse)

同时使用背景熟悉度、历史支持和预测分歧。

药物类任务

confidence = z(log(1 + support_count)) - z(model_disagreement_rmse)

冻结 chemical 公式不含 context similarity。该规则在正式测试前已经写入方法定义。

Frozen protocol
冻结协议

在正式测试前就确定特征、公式、方向和评价指标，看到失败数据集后不再为它单独改规则。

4. Frozen 与 learned 的用途不同

Frozen v0.2：三个核心特征的可解释固定公式，是主协议。
Learned risk model：用更多特征训练 HistGBT 等模型预测误差，用于扩展、消融和敏感性分析。

Learned 在 McFarland 上可以为正，但不能据此把 Frozen 的 McFarland 失败改写成成功。

5. 它最终如何帮助做决定

将所有预测按 risk 降序排列
取 top 10% 高风险预测
先做人工复核/湿实验
比较随机选择抓到多少坏预测
用途：SafeConf 对已有预测进行风险排序，预测效应仍由原预测器生成。
