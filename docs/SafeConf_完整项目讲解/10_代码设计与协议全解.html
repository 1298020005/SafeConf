2. 四层系统怎样连接

协议层 Protocol

Protocol 指预先写好的实验规则。它规定 control、effect、eligible task、fold 和泄漏检查。

预测层 Predictor

Predictor 指生成 predicted effect 的模型。SafeConf 把它当作黑盒，只要求输入输出符合接口。

打分层 Scoring

从测试前可见信息计算 confidence 或 risk。标准化参数只能来自当前 fold 的训练部分。

评估层 Evaluation

打分完成后读取真实误差，计算相关、风险—覆盖、富集倍数和置信区间。

3. PredictionRecord 的完整字段

字段组字段含义
唯一身份record_id, task_id追踪一条记录和它所属的生物任务。
实验身份dataset_name, fold_id, split指出数据集、交叉验证折和 train/val/test 归属。
生物任务context, perturbation细胞背景与施加的基因或药物干预。
模型身份predictor_name说明预测由哪个模型产生。
向量指针predicted_effect_key, true_effect_key表中保存键名；几千维数组放在 NPZ 文件。
评价标签true_error_rmse预测向量和真实向量之间的均方根误差，只能用于评价或训练允许读取标签的 learned risk。
n_genes：协议把基因维数写入配置。Silent change 指代码没有记录就把 5,000 改成 1,000；这种变化会破坏结果可比性。

4. Held-out pair 与 L1–L4

约束检查内容原因
L1测试 pair 不出现在 train 或 val防止目标组合重复。
L2测试 perturbation 在训练中有其他 context保证能够计算历史支持和迁移预测。
L3测试 context 在训练中有其他 perturbation保证背景有训练参考。
L4特征计算不读取测试 true effect 或 error防止标签泄漏。

5. 七类特征：设计全集与冻结公式子集

特征人话进入 frozen v0.2？其他角色
context similarity目标背景与训练背景有多相似gene：是；chemical：否learned 风险特征
support count同一扰动在训练折有多少有效历史是单特征基线
perturbation stability同一扰动跨背景的效应是否一致否；chemical 明确置零扩展诊断
model disagreement两个参考预测器的向量差异是消融中很重要，但贡献依数据集变化
prediction magnitude预测效应整体大小及偏离程度否强基线、混杂控制和 learned 特征
OOD distance目标任务距训练分布有多远否learned 特征组
historical residual训练内相似任务过去留下的误差模式否基线与 learned 特征
关键区分：“系统收集哪些特征”和“冻结公式使用哪些特征”是两个清单。当前 frozen v0.2 只组合 context、support、disagreement；learned risk 可使用更完整的特征组。

6. 预测器与适配器

V0StrongBaseline

强 lookup 基线。Lookup 指从历史任务中检索并组合可用效应，不依赖大型神经网络。

ContextSimBaseline

按细胞背景相似度迁移历史扰动效应，是 frozen disagreement 的另一个参考预测器。

GEARS / CPA

协议计划中的深度模型扩展。Adapter 是把模型原输出转换成统一 PredictionRecord 的薄接口。

Adapter 当前状态：E20 显示旧 GEARS formal 输出缺少 gene order / normalization 字段，无法 strict pass；E25 已从 processed GEARS h5ad 恢复 gene order，把 Adamson/Dixit/Norman 的 54 条真实 GEARS formal 输出升级为 strict-pass PredictionRecord 包；E26 已在该包上完成 GEARS-only 单模型风险审计；E27 已用归档 scGPT 源码和 whole-human checkpoint 生成 strict-pass forward smoke；E28 已把 GEARS 与 scGPT 放到 Adamson 3 个共享任务和 512-gene panel 下 strict 对齐；E29 已扩展到 Adamson 7 个共享任务并计算双模型 disagreement 风险；E30 已确认 E25 三个 GEARS runs 任务重叠太少，不能直接写 seed uncertainty；E31 已给 GEARS exporter 增加 fixed-test 清单和 smoke/formal run_type，并完成 7-task strict smoke；E32 已跑通 fixed-test 3-seed smoke，形成 21 条 strict records 和 seed disagreement 初步信号。E17 旧记录的 record-scoped true key 已由 E21/E22 修法验证。统一 GEARS–scGPT–CPA 多模型验证仍需把 fixed-test 3-seed 提升到正式 epochs、扩大共享任务数、固定 split 和 CPA adapter。

7. 分数清单与论文角色

分数类型用途

oracle不可部署上界使用真实标签构造，只作为理论参照。

8. 主指标、附录指标和禁用写法

主指标

aligned Spearman、partial rho、RC@80%、high-low ΔRMSE。结果按数据集报告。

补充指标

Pearson、AURC/AUGRC、AUROC、calibration buckets 和 top-k enrichment。

禁用口径

不把 pooled Spearman 当唯一 headline；不只报 learned；不省略 split 与泄漏检查。
