CHAPTER 02

从 h5ad 到一条 SafeConf 分数

这一章只追踪数据。每一步都问：输入是什么？输出是什么？一行代表什么？

1. h5ad 是一个单细胞数据包

experiment.h5ad ├── obs # 细胞说明表：一行 = 一个细胞 ├── var # 基因说明表：一行 = 一个基因 ├── X # 表达矩阵：行 = 细胞，列 = 基因 ├── layers # 可选的其他表达矩阵 ├── obsm # 可选的细胞坐标/嵌入 └── uns # 其他说明信息

obs

包含 cell line、perturbation、dose、time 等标签。它告诉电脑哪些细胞应该分在一组。

var

包含基因名和 Ensembl ID。它确定 X 矩阵每一列是哪个基因。

X

数值矩阵。单细胞数据中大量位置为 0，因此常用 sparse matrix（稀疏矩阵）只存非零值。

2. 整条数据流

阶段 典型文件 一行/一个 key 代表 作用
原始细胞 *.h5ad obs 一行=一个细胞 保存表达与实验标签
切分 HELDOUT_PAIR_SPLITS.csv 一个任务在某 fold 中的 train/val/test 归属 防止测试答案混入训练
效应向量 true_effects.npz
predicted_effects.npz 		一个 key=一条多基因向量 保存标准答案与预测答案
预测记录 PREDICTION_RECORDS.csv 一个预测器对一个 task 的一次预测 统一数据集和预测器
风险线索 CONFIDENCE_FEATURES.csv 与 PredictionRecord 对齐的一组质检特征 不看测试答案也能计算
风险分 CONFIDENCE_SCORES.csv 一条记录被某个 score 打一次分 排序高风险预测
数据集结果 FORMAL_MAIN_TABLE.csv 一行=一个数据集的总结果 论文/汇报级结论

3. PredictionRecord 是整个系统的中心接口

record_id = v2_rec_000930 dataset_name = McFarlandTsherniak2020 context = 22RV1 perturbation = Trametinib predictor = ContextSimPredictor fold_id = 2 split = test predicted_effect_key = ... true_effect_key = ... true_error_rmse = 1.42

这一行记录某个预测器对“22RV1 细胞背景接受 Trametinib 后的扰动效应”给出的一次预测。原始细胞表中的多行细胞已经汇总为一个任务。

NPZ

NumPy 的压缩数组容器。CSV 适合存一行一条记录，NPZ 适合存每条记录对应的几千维向量。

Schema / Contract
模式/数据契约

规定每条 PredictionRecord 必须有哪些列、向量的基因顺序如何核对、哪些字段禁止当作特征。

4. 为什么真实误差不能进特征

允许的输入：训练侧历史支持、对照细胞相似度、预测器之间的分歧、预测输出幅度。
禁止的输入： true_error_rmse、true_effect、failure label 等使用了测试真值的列。

如果把真实误差放进风险特征，就等于在考试前先看到了答案。这叫 label leakage（标签泄漏）。
