CHAPTER 06

实验如何证明结果可信

正式实验同时检查数据泄漏、强基线、随机性和数据集差异。单个正相关数值不足以形成结论。

1. Held-out pair 与 fold-safe

Held-out pair

把某个 context–perturbation 组合完整留到测试集，模拟“这道具体任务没有在训练中见过”。

Fold-safe

每个交叉验证 fold 都独立计算参考统计，不用其他 fold 的测试答案。

Leakage

测试信息以任何形式流入特征、标准化或模型训练，会让结果虚高。

2. 看哪些评价指标

Spearman ρ

比较两组排名是否一致。风险排名越靠前的预测，真实误差是否也越大。

Partial ρ

统计分析控制 prediction magnitude（预测效应幅度）后，计算 SafeConf 与误差的剩余相关。

Top-k enrichment

取高风险 top 10%，其中高错误预测是随机选择的多少倍。

AURC

风险—覆盖曲线下面积。逐步剔除高风险预测后，剩余预测的平均误差越低越好。

Bootstrap CI

按 task cluster 重采样很多次，得到 95% 置信区间，不把同一 task 的相关行错当独立样本。

Negative control

打乱标签或特征后应该失效。如果打乱后仍然很强，就要怀疑泄漏或管道伪影。

3. E1–E4 分别防什么

实验 问题 结果 解释
E1 特征组消融 哪类线索真在贡献？ 不同数据集贡献不同 没有一个特征组通吃所有数据
E2 magnitude-residual 是否只是幅度代理？ 7/7 residual CI lower>0 控制 magnitude 后仍有剩余信号
E3 负对照 是否来自随机或缺失模式？ shuffled 7/7；missing-only 0/7 排除最简单的伪影
E4 模型稳定性 是否只有一个参数配置有效？ HistGBT 7/7；ElasticNet 6/7 不同配置表现有差异；信号不依赖单一配置

4. E8b 与 Tahoe 各自补什么

E8b：多方法聚合关联

Frangieh 共享任务包含 74 个 perturbation 和 15 种方法，其中 14 种方法方向为正。该分析使用聚合误差，没有完整逐向量输入，证据级别属于方法—误差关联。

Tahoe：大型 chemical 抽样验证

补足原主表 chemical 证据规模，检查 pair、cell-line、top-k、gene threshold 和 fixed combination。

预注册（preregistration）：跑正式实验前写明数据、切分、指标、通过门槛和停止条件，减少看结果后改标准。
