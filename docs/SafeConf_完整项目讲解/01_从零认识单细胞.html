CHAPTER 01

从零认识单细胞组学

先不讲模型。先弄清数据里的“细胞”、“基因”、“表达”和“扰动”到底是什么。

1. 人体包含许多类细胞

细胞

生物体的基本单位。不同细胞虽然大多拥有相同 DNA，却会启用不同基因。

基因

DNA 上的功能片段，在细胞功能说明中对应一个条目。

RNA

基因被使用时产生的中间分子。单细胞 RNA 测序通过 RNA 量估计基因的活跃程度。

Single-cell transcriptomics
单细胞转录组学

在单个细胞粒度上测量大量 RNA，从而比较不同细胞的基因表达状态。“转录组”就是某个细胞当时全部 RNA 的集合。

单细胞数据保留了异质性：不同细胞可能对同一药物反应不同。

Heterogeneity
异质性

同一个样本内部的细胞并不相同。它们可能是不同类型、不同状态，也可能对扰动产生不同反应。

3. SafeConf 中的一道“预测题”

Context
细胞背景

扰动发生在哪种细胞或实验环境中。例如 McFarland 数据中的 22RV1 是一种前列腺癌细胞系。

Perturbation
扰动

人为对细胞施加的改变。例如加 Trametinib 药物，或用 CRISPR 敲除一个基因。

Control
对照

没有接受目标扰动的细胞。它是计算“变化了多少”的基准线。

Effect vector
效应向量

一长串数字，每个位置对应一个基因的变化量，信息量多于“有效/无效”标签。

4. 从对照到真实效应

Control 细胞 每个基因求平均
Perturbed 细胞 每个基因求平均
扰动平均 - 对照平均 对每个基因相减
True effect 实验给出的“标准答案”
control_mean = [10, 8, 3, 6] perturbed_mean = [13, 7, 4, 10] true_effect = [ 3,-1, 1, 4]

正数表示扰动后表达升高，负数表示降低。图中只画 4 个位置；项目配置可使用 5,000 个基因位置。

本章结论：SafeConf 处理“某个 context 下某个 perturbation 的效应预测”。输入已经从单个细胞汇总到任务层。
