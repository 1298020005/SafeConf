4. 四段关键代码，逐句看懂

A. 合并预测记录与特征

rec = read_csv("PREDICTION_RECORDS.csv") feat = read_csv("CONFIDENCE_FEATURES.csv") base = rec.merge(feat, on=MERGE_KEYS, how="left")

MERGE_KEYS 包含 record_id、dataset、fold、split、context、perturbation和 predictor。目的是确保“这组线索”真的属于“这次预测”。

B. 检查特征没有偷看答案

bad = set(feature_cols) & { "true_error_rmse", "true_effect", "failure_label", "score_value" } if bad: raise ValueError("label leakage")

C. 在每个 dataset/fold/predictor 内标准化

train = sub[sub["split"] == "train"] z_ctx = zscore_by_ref(sub.context_similarity_max, train.context_similarity_max) z_support = zscore_by_ref(log1p(sub.support_count), log1p(train.support_count)) z_dis = zscore_by_ref(sub.disagreement_rmse, train.disagreement_rmse)

测试行可以被转换，但转换使用的中位数和 IQR 只能从 train 得到。

D. 风险—覆盖曲线

order = argsort(risk) # 低风险先保留 sorted_errors = errors[order] selective_risk = cumsum(sorted_errors) / arange(1, n+1) coverage = arange(1, n+1) / n

如果低风险组的平均误差真的更低，说明排序有实用意义。
