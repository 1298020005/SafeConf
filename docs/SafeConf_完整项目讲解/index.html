阅读时抓住三件事

确认每一行代表什么

原始表中一行是细胞，PredictionRecord 中一行是一次预测，最终主表中一行是一个数据集。

区分预测与质检

预测器生成 predicted effect；SafeConf 根据可见线索估计这次任务的风险。

成功与失败放在同一张表

6/7 为正不能写成 7/7；Tahoe 有信号也不等于超过 magnitude。

2026-07-07 新增外部验证入口

E10 数据资产审计

服务器已有 83 个 h5ad、约 107.3 GiB；官方 scPerturBench/scPerturb metadata 覆盖 66/66。

E10 外部小型探针

KaggleCrossCell、Haber、Parekh 已跑通；disagreement 信号强，组合分数存在外部边界。

E12 外部面板探针

6 个外部候选中 3 个可按 held-out pair 评价；sciplex3 与 KaggleCrossPatient 值得继续正式化。

E13 官方 sciplex3 focused panel

A549/K562/MCF7 三细胞系 drug-dose 面板已跑通；learned 与 disagreement 信号接近。

E14 sciplex3 full-743 gene1000

官方三细胞系 743 个共享 drug-dose 全量任务，1,000 基因快速验证；learned ρ=0.862。

E15 sciplex3 full-743 gene2000

同一 full-743 面板提高到 2,000 基因；learned ρ=0.899，disagreement ρ=0.739。

E16 sciplex3 full-743 gene3000

同一 full-743 面板提高到 3,000 基因；learned ρ=0.903，80% coverage 改善 19.14%。

E17 sciplex3 full-743 gene5000

同一 full-743 面板提高到 5,000 基因；learned ρ=0.891，正式 5k 外部验证完成。

E18 真实模型向量资产审计

GEARS 有 54 条可读记录；scGPT/CPA 暂无 SafeConf 协议下的逐任务向量。

E19 GEARS-only supplement

整理 GEARS-only formal 与 Frangieh supplement；只作补充，不冒充多模型统一验证。

E20 adapter contract validator

检查现有预测输出是否能进入 strict 多模型合同；10 个 bundle 可审计，但 0 个 strict pass。

E21 strict contract remediation

把 E17 抽样包改成 task-scoped true effect，strict validator 通过；这是修法样例，不替换正式结果。

E22 generator strict smoke

修改后的生成器新跑 Haber 200-gene smoke，240 条记录 strict pass；这是工程合同验证。

E23 shared benchmark adapter

固定 120 个 task groups 的 shared manifest，让 GEARS/scGPT/CPA 后续对同一任务台面输出预测向量。

E24 model-family compatibility

指出 E23 是 stimulus 合同 smoke，不适合直接给 GEARS；后续转入 GEARS gene-perturbation strict 证据包。

E25 GEARS strict records

把 Adamson/Dixit/Norman 的真实 GEARS formal 输出补齐 strict provenance；54 records，issue_count=0。

E26 GEARS single-model risk

在 E25 strict 包上评估 GEARS-only 风险线索；predicted-effect abs mean ρ=0.679，native uncertainty 缺失。

E27 scGPT forward smoke

用归档 scGPT 源码和 whole-human checkpoint 生成 strict PredictionRecord smoke；3 records，issue_count=0。

E28 GEARS–scGPT shared smoke

Adamson 上 3 个任务 × 2 个 predictor，统一 512-gene panel 和 true effect key；strict issue_count=0。

E29 GEARS–scGPT risk audit

Adamson 上 7 个任务 × 2 个 predictor，新增 disagreement 风险排序；14 records，strict issue_count=0。

E30 GEARS seed overlap

审计 E25 三个 GEARS runs 是否足以支持 seed uncertainty；47 tasks 中只有 5 个重复 ≥2 次。

E31 GEARS fixed-test smoke

GEARS exporter 已支持固定 test perturbations；Adamson 7 个任务全部命中，strict issue_count=0。

E32 GEARS 3-seed smoke

固定 Adamson 7 个 test 任务跑通 GEARS 3 seeds；21 records，seed disagreement ρ=0.679。
