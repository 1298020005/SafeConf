# 周报（2026年7月19日）

一、本周内容

科研学习

● 回查 Frangieh 原始数据后确认其中包含 Control、IFNγ 和 Co-culture 三个细胞背景，按每个组合至少 50 个细胞得到 3×189 的完整遗传扰动矩阵。完成 25%、50%、75%、100% 四档训练子矩阵，以及随机缺失、整行新背景、整列新扰动和双未见四类测试，共形成 7,416 条严格预测记录。

● 在 Lara ex vivo 和 Santinha 两套独立遗传扰动数据上完成同协议外部复制，并对 Frangieh、Lara、Santinha 做等权元分析。冻结分数三数据集宏平均相关系数为 0.425，高于模型分歧的 0.341；相对模型分歧的保守区间稳定为正。相对预测幅度的宏平均增量为 0.067，但区间仍跨 0，Santinha 也出现轻微负增量，相关边界已保留。

● 增加 Cui 细胞因子刺激实验。86 个刺激中只选择 41 个可直接对应 scGPT 词表的标签，不猜测商品名和复合亚基。六个免疫细胞背景下共生成 5,664 条严格预测记录；风险分数可以排序误差，但相对预测幅度仍只有正趋势。

● 完成两批全新 Primary CD4 靶点确认。E168 的 200 个靶点和 E172 的 800 个互斥靶点均未证明 fixed SafeConf 稳定优于 predicted magnitude，因此停止该增量主张，没有根据测试结果继续修改权重。

● 将后续重点转到可核验的风险边界。E176 采用四供体轮换、每个模型五个随机种子和分阶段真值解封，在 640 个隐藏评价靶点、1,920 个任务上得到模型对误差下界零违例；供体专属 90% split-conformal 上界的三状态同时覆盖率为 90.31%。排序信号仍弱，相关负结果已保留。

二、下周计划

科研学习

● 复核多背景矩阵的训练输入、control 使用假设和测试真值锁定过程，整理一张统一结果表，分别报告遗传扰动与细胞因子刺激，不把两类任务混成一个总成绩。

● 用训练子矩阵内部的模拟整行、整列和双未见任务建立难度匹配的校准集，重点处理 Santinha 校准退化和双未见任务 q80 阈值失效。同时评估 context-aware GEARS 或端到端 scGPT 适配是否能保持同一任务合同。

● 对高风险任务补共同失准、单模型失准和细胞背景分组，整理哪些结论已经达到稳定证据，哪些仍受预测幅度、数据集数量和跨域失准限制。

● 不再继续增加同一 Primary CD4 研究内的靶点。下一轮优先冻结一项独立研究的证书与 conformal 复现实验，沿用 pretruth 稳定性门、独立校准集和隐藏评价集，检验覆盖能否跨研究保持。

● 按“确定性下界—校准上界—增量门失败即弃权”的新结构整理方法和结果，同时推进 E143 新背景湿实验的条件确认。旧 fixed SafeConf 优于 magnitude 的表述从汇报和论文草稿中清理。
