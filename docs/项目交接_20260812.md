## 当前正在进行的 E201

E201 是对周老师“整列/整个细胞背景留出”问题的直接补充。模型训练时只看三个
source 细胞背景中的扰动数据；target 背景只保留 control（对照）细胞，目标扰动后的
表达物理隔离。四个 target 是 K562、RPE1、HepG2、Jurkat，每个 target 固定四个
随机种子，共 16 个正式训练。

## E201 完成后唯一允许的顺序

不能提前打开目标真值，也不能根据前几项 source validation 调参数。全部 16 个训练
完成后，必须按以下顺序继续：

1. `seal_e201_txpert_checkpoint_family.py`：检查 16 个 checkpoint 是否完整、条件和
   哈希是否一致；
2. `run_e201_txpert_sealed_prediction.py`：在零真值预测视图生成 16 份预测；
3. `run_e201_pretruth_risk_features.py` 与
   `build_e201_official_general_baseline.py`：只用 source 信息、target control 和
   冻结预测生成风险量、强基线；
4. 将上述预测前产物和哈希提交并推送到 **Gitee 与 GitHub**；
5. `release_e201_target_truth.py`：只有前一步完成才可释放目标真值；
6. `run_e201_formal_core_evaluation.py`：计算每种子、family、worst-seed、
   predicted magnitude、简单基线和 bootstrap 区间。
