一条主线

h5ad 原始单细胞数据
  -> obs 细胞表 + var 基因表 + X 表达矩阵
  -> true_effect = perturbation_mean - control_mean
  -> predicted_effect = 预测器给出的答案
  -> true_error_rmse = 预测错得多远
  -> SafeConf risk score = 这条预测是否高风险
