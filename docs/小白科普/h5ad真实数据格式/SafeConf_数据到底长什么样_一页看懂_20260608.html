SafeConf 数据到底长什么样

不讲空话。只追一条真实数据：McFarland 数据集里的 22RV1 × Trametinib，看它从原始单细胞矩阵一路变成论文表格。

0. 先别管 HDF5 是什么，先看“你真正会看到什么”

.h5ad 不是你熟悉的一张 Excel。你可以先把它当成一个“大盒子”，盒子里主要装三样东西：

obs：细胞表
一行是一个细胞。写着这个细胞来自哪个 cell line、加了什么药、剂量多少。
X：表达矩阵
行是细胞，列是基因，格子里的数字是“这个细胞里这个基因表达多少”。
var：基因表
一行是一个基因。写着基因名、Ensembl ID、出现在哪些细胞里。
你现在不用懂 HDF5。先记住：h5ad = 细胞表 obs + 表达矩阵 X + 基因表 var。这就够开始看数据了。
我已经把真实 h5ad 拆成一组小 CSV 样例，可以直接用 Excel/Cursor 打开： h5ad可打开CSV样例/README_这些CSV怎么看.md

2. 数据第一步变化：很多细胞变成一个 effect 向量

我们追的真实任务是：

context = 22RV1
perturbation = Trametinib

原始 h5ad 里，这不是一行，而是两堆细胞：

组筛选条件真实细胞数
control 组cell_line = 22RV1, perturbation = control158
drug 组cell_line = 22RV1, perturbation = Trametinib84

2.1 这句话逐词解释

词怎么读人话
22RV1twenty-two R V one一个癌细胞系名字。你可以先理解成“实验用的一种细胞背景”。
control对照组没有加目标药物的细胞，用来当基准线。
Trametinib曲美替尼一种药物名字。这里表示“给 22RV1 细胞加了这个药”。
cells细胞一个 cell 就是一条单细胞测序记录。158 cells 就是 158 个单细胞。
22RV1 control: 158 cells22RV1 的对照组有 158 个细胞在 22RV1 这个背景下，没加 Trametinib 的细胞有 158 个。
22RV1 Trametinib: 84 cells22RV1 的 Trametinib 处理组有 84 个细胞在 22RV1 这个背景下，加了 Trametinib 的细胞有 84 个。
对应 CSV： 02_obs细胞表_22RV1_control和Trametinib样例.csv， 04_X表达矩阵小块_20个细胞x8个基因.csv， 06_22RV1_Trametinib这句话逐词解释.csv。

这一步的数据形状变化是：很多行单细胞 → 一个任务的一条 effect 向量。

3. 向量是什么：一串固定顺序的数字

正式 pipeline 保存的 effect 不是只看 5 个基因，而是 5000 个位置：

true_effect = [第0个基因变化, 第1个基因变化, 第2个基因变化, ..., 第4999个基因变化]

同一条记录 v2_rec_000930 有两个向量：

向量哪里来的打分时能不能看
true_effect真实实验算出来的标准答案不能
predicted_effectV0StrongBaseline 猜出来的预测答案能

RMSE 就是把全部 5000 个位置都这样算：

RMSE = sqrt(mean((predicted_effect - true_effect)^2)) = 0.5776326656

所以 PREDICTION_RECORDS.csv 里这一条的 true_error_rmse 是 0.5776。

对应 CSV： 11_true_effect_vs_predicted_effect_前20个位置.csv， 12_true_effect_vs_predicted_effect_误差最大30个位置.csv。

5. SafeConf 打分时看到什么

SafeConf 不能看 true_effect，也不能看 true_error_rmse。它只能看预测输出和训练集能提供的线索。

feature这条记录的值人话解释
context_similarity_max0.967722RV1 和训练集中最像背景的相似度很高。
perturbation_support_count121训练集中有 121 个 Trametinib 相关支持。
prediction_l2_norm47.92预测出来的效应向量整体幅度。
prediction_magnitude_deviation0.7474预测幅度偏离常见范围的程度。
model_disagreement_rmse0.3692V0 和 ContextSim 对这道题分歧多大。
historical_residual_risk2.213历史上类似情况的风险。

这些 feature 再变成多个 score：

score_namescore_typescore_value
context_similarity_scoreconfidence0.9677
support_count_scoreconfidence4.804
model_disagreement_riskrisk0.3692
simple_combined_confidenceconfidence-0.8523
learned_risk_scorerisk1.5918
confidence 越高越可信；risk 越高越危险。方向相反，所以最后评估时要做方向对齐。
对应 CSV： 09_ConfidenceFeatures_单条质检线索.csv， 10_ConfidenceScores_单条记录的多个分数.csv。

6. 最后怎么变成论文数字

一条记录看不出方法好坏。最后要把所有 test records 放一起，看分数和真实误差是否相关。

datasetn test recordsaligned rhomagnitude-only rhopartial rhoRC@80%
McFarlandTsherniak20202326-0.08590.7954-0.06093.951%

这说明 McFarland 上 frozen v0.2 没成功，是 failure boundary。

但这不是“所有数据都没信号”。它说明：McFarland 这个药物数据集里，提前冻结的 v0.2 组合没有抓对信号。这个失败要诚实报告。
