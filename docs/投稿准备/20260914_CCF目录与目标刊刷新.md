# SafeConf｜2026 CCF 目录与目标刊刷新

核对日期：2026-09-14

## 当前目录口径

中国计算机学会当前目录入口：<https://www.ccf.org.cn/Academic_Evaluation/By_category/>。该页可能触发访问验证；可读的第七版目录镜像为 <https://ccf.atom.im/>。投稿前仍须让学院按其认可的当年目录和分区系统书面确认。

2026-09-21 复核官方 CCF 页面后，当前“交叉/综合/新兴”页列出的与 SafeConf 直接相关条目是：

| 期刊 | 2026 CCF 类别 | 与当前工作的关系 |
|---|---|---|
| Bioinformatics | B | 计算生物方法高度匹配，但仍要求实质性方法创新和真实数据对照；不能把它写成 A 类 |
| Briefings in Bioinformatics | B | 最新投稿说明将其定义为综述期刊且不接收纯原创研究；不作为本文主投 |
| IEEE/ACM Transactions on Computational Biology and Bioinformatics | B | 最符合“计算机方法 + 计算生物应用”；需要算法、证书、复杂度和系统评测完整闭环 |
| PLOS Computational Biology | B | 需要明显的生物学或方法学洞察；仅有风险排序表不够 |
| BMC Bioinformatics | C | 可作后续备选，但不满足“CCF-B”硬条件 |

CCF 类别与 JCR Q1/Q2、中科院一区/二区是三套不同口径，不能互相替换。

## 当前首选路线

### 路线 1｜IEEE/ACM TCBB（CCF-B）

把文章写成一个通用的预测后风险审计方法：

1. 注册模型家族分歧带来的确定性错误下界；
2. 以预测幅度表示响应尺度；
3. 以 SafeConf 表示训练支持、背景覆盖和模型稳定性；
4. 用固定或受约束自适应规则排序，并在证据不足时拒绝给出结论；
5. 报告计算复杂度、运行时间、校准、跨预测结构和新外部数据结果。

这条路线最需要 E205、E208 和同合同强简单基线。只有内部单数据结果时，算法增量偏弱。

### 路线 2｜Information Sciences（CCF-B）

只有在补足通用回归任务上的跨领域验证，并把注册家族、证书、失败关闭与复杂度写成
一般计算方法后再考虑。当前工作主要服务单细胞扰动预测，TCBB 的主题匹配度更高；
Information Sciences 的方法普适性和算法创新门槛也更高。

### 路线 3｜PLOS Computational Biology（CCF-B）

只有在风险分数能进一步解释哪些通路、细胞状态或扰动机制导致跨背景失效时再考虑。当前证据主要是方法审计，生物学洞察不足，暂不列第一顺位。

## 截止当前的投稿门

已经具备：四背景盲测、八研究历史压力测试、预测幅度基线、幅度外增量、低复杂度自适应开发、确定性证书与失败关闭流程。

尚未闭合：

1. E205 的 16 个 Exphormer 正式模型尚未全部完成和揭盲；
2. E208 Jiang24 虽已确认 224 个正式任务，但上游预测尚未完成；
3. 自适应公式的增益目前只在历史开发数据上成立，实际 top-20% 效用提升很小；
4. 需要把 PRESCRIBE、预测幅度、原 SafeConf、固定融合、受约束自适应和同合同简单基线放入一张统一主表；
5. 软件包、最小复现实例、运行时间和内存表需要做发布级验收。

因此，当前可以说“形成了 CCF-B 目标的完整实验路线”，不能说“已经百分之百能录用”。决定性节点是 E205 与 E208 的事前冻结结果，而不是继续调整已经揭盲的数据。
