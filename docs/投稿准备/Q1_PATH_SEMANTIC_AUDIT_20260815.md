# 一区路径：语义审核（聊天、成果、文献）

日期：2026-08-15

这份文件不做脚本巡检。它只回答：你反复要的是什么、现在手里到底有什么、
2025–2026 年审稿人会拿什么打回来、下一阶段怎样把“想投一区”落成可执行的
实验和写作。期刊录用不能保证；能保证的是不再用错主张、不再漏必须补的对照。

## 1. 你和 Codex 全部聊天里，真正没变的要求

长会话 202 条用户发言，跨 2026-06-29 到 08-13。去掉课程论文、考试 HTML、
周报措辞之后，重复出现的只有五句：

1. **周老师的问题一个都不能少。** 分数跟谁的误差比、magnitude 有没有看真值、
   没见过的任务怎么打分；然后是小矩阵、整行整列、跨数据集。
2. **要结果，不要让我做选择。** 中间问题自己解决。
3. **最终要能投稿。** 先说稳定二区，后来说冲一区；8 月 13 日组会又问“能不能
   发表、汇报还缺什么”。
4. **不要空话、不要分区口号进周报。** 7 月 26 日明确：周报只写做了什么、
   解决了老师哪一句。
5. **图和留存要能给别人看。** 白底图、Git 双远程、另一台电脑能拉取。

中间插曲（课程模板、考试 300 字、HTML 复习页、全盘整理服务器）都已经结束。
它们不能再占用下一阶段。

老师原话仍是判断标准，不是“再调公式”：

> 如果这三个都解决了，感觉你写一个小文章应该可以了。

“解决了”在老师那里首先是**这三档 setting 都能算、输入没泄漏**。
“稳定一区”是你后来加上的更强目标。两者不自动相等。

## 2. 当前成果：能写进论文的，和还只是工程进度的

### 已经是科学结果（有真值、有边界）

| 成果 | 它实际证明了什么 | 不能写成什么 |
|---|---|---|
| E189 小矩阵 / 行列 / 双未见 | 随机缺格偏容易；双未见时经验排序可以变负 | 风险分在所有缺失模式下都好用 |
| E190 / E192 跨研究 | 合同和防泄漏成立；RPE1 按事前规则 `ABSTAIN` | 跨数据集已经成功迁移 |
| E84 / E87 / E89 chemical | 能算；多处 magnitude 更强 | gene 与 chemical 同一套成功 |
| E194 family 治理 | 证书依赖成员和权重，复制成员会灌水 | 分歧越大越好 |
| E198 协议校准 | 后续指标不是随便换的 | SafeConf 本身被外部验证了 |
| E199 公开 TxPert，K562 未见基因 | 家族分歧与误差相关 0.395，20% 复核有正收益；magnitude 区间跨 0 | 图模型上风险量已经普遍赢 |
| E200 K562 整背景留出 | 图模型优于 general baseline；**magnitude 的 20% utility 0.91，高于 transfer risk 0.36** | 整背景留出已经证明 SafeConf 更好 |
| E158 / E159 PRESCRIBE | 官方 combined / epistemic 在严格未见基因 OOD 上完全饱和，主统计不可估计 | “我们打赢了 PRESCRIBE” |

最后一行经常被当成“实验失败所以丢掉”。从一区审稿看，它其实是**竞品在老师
要的困难 setting 上退化**。这必须写进 Related Work / Comparison，不能再藏。

### 还不是科学结果（只有训练账）

E201：四个细胞背景 × 四个种子的整列留出。截至今晚 12/16 完成，K562 seed 4
在跑，target 真值仍是 0 行。source validation 只说明训练没崩。

旧稿 `submission/SafeConf_current/` 写的是 registered-family 证书 + conformal
上界。老师听的、也更接近一区方法刊的，是**预测后风险审计、困难 setting、
何时 abstain**。旧摘要数字不能再小修小补当投稿正文。

## 3. 联网之后：一区现在是什么门槛

### 3.1 “一区”先说清楚，否则会投错刊

不同口径不是一回事：

| 口径 | 和 SafeConf 最接近的刊 | 现在算不算一区 |
|---|---|---|
| 中科院大类生物学 1 区 | Genome Biology、Nature Methods | 是大类一区；方法文要软件、广验证或生物学用途 |
| 中科院小类 1 区 + JCR Q1 | **Briefings in Bioinformatics**（大类 2 区，计算生物学小类 1 区，JCR Q1，2026 新锐还标 TOP） | 这是方法文最现实的“一区” |
| JCR Q1、中科院大类 3 区 | Bioinformatics（IF 5.5，计算生物学 7/67） | 学校若认中科院大类，这不是一区 |
| JCR Q2 / 中科院 3–4 区 | NAR Genomics and Bioinformatics | 不能再把它说成一区候选 |

中科院文献情报中心已声明 2026 年起不再更新分区表。学校认哪一年、认大类还是
小类，必须你向学院确认。我按你说的“投一区稳定”默认两条并行：

- **主投：Briefings in Bioinformatics**（小类一区 / JCR Q1，方法综述和原创方法都收）
- **冲刺：Genome Biology**（大类一区；要可安装软件 + 多数据 + 一个说得清的生物学用途）

Nature Methods / Nature Biotechnology 需要新预测器或新生物学，不是当前主战场。

### 3.2 2025–2026 审稿人手里已经有的近邻

1. **PRESCRIBE**（NeurIPS 2025）：模型内部的 evidential 置信度，过滤低可靠
   预测。领域里已经有“逐预测置信度”，不能写 first。
2. **TxPert**（Nature Biotechnology 2026）：用 STRING/GO/专有图预测未见扰动，
   并做 leave-one-cell-line-out。E201 用的是它的公开 STRING-GAT，不是专有
   PxMap/TxMap，论文里必须写公开审计，不能写成复现作者最强模型。
3. **PerturBench / 27×29 Nature Methods 基准**：简单基线经常不输深模型；
   RMSE 单独不够。
4. **Ahlmann-Eltze 等 Nature Methods 2025**：线性基线仍强。magnitude 必须留。
5. **PerturbMap**（2026-07-30，E201 冻结之后才出现）：在“源细胞系见过该扰动、
   目标细胞系缺同一扰动”上做 **train-only reliability-weighted 效应迁移**。
   这和周老师的整列问题几乎同一句话，但 PerturbMap 是**补预测**，SafeConf 是
   **预测已经给出之后决定信不信、查不查**。审稿人会问二者区别，必须在正文
   里主动划清。
6. **HyperMap**（2026-04）：也是 leave-one-cell-line-out 的迁移预测。

所以一区方法文现在挤在三件事里：预测器（TxPert）、学习式 UQ（PRESCRIBE）、
跨背景迁移（PerturbMap/HyperMap）。SafeConf 还能站住的空位只有：

> 不改现有预测器，只使用部署时能拿到的输出和元数据，对已经给出的预测做
> 可审计的任务风险合同：哪些 setting 可以排序复核，哪些必须明确 abstain。

这和“分数永远比 magnitude 高”不是同一篇文章。后一句目前证据不支持，
硬写会被一区审稿直接拒。

## 4. 缺什么：不是缺“再跑一个模型”，是缺三块审稿零件

### 阻断 A — 主张过宽

现在仓库里同时活着三套说法：family 证书、任务风险路由、稳定一区。
一区稿只能留一个主主张：

**预测后、真值前的 fail-closed 风险合同。**

证书是方法零件，abstain 是产品行为，分区是投稿策略。三者不能并列当贡献。

### 阻断 B — 竞品对照不完整

PRESCRIBE 的公平头对头没有写成论文表。已有事实是：官方分数在严格未见基因
OOD 上饱和（E158/E159）。这本身可以是比较结果，但还缺一张**同一任务合同**
上的对照表：

- PRESCRIBE 自信度（能算的时候）
- predicted magnitude
- 冻结家族分歧 / SafeConf
- 20% 复核效用、是否退化、是否该 abstain

没有这张表，Briefings / Genome Biology 都会问：和 2025 年那篇 NeurIPS 比呢？

### 阻断 C — 多背景整列还没开真值

E200 只有 K562。E201 才是老师和 TxPert 论文都承认的四背景。
它没评完之前，主结果不能写“跨细胞系成立”。

### 不必再开、一区也帮不上忙的

- 再下载一堆数据却不改主张
- 把 chemical 塞进 gene 成功主表
- 重跑已经有负结果的 Tahoe 去“赢 magnitude”
- 湿实验：有用，但是 Genome Biology 冲刺项，不是 Briefings 的最低门槛
- 课程稿、考试页、7 月组会旧图

## 5. 下一阶段：怎样把一区缺口补上

原则：E201 占着 GPU1，在 16/16 评完前**不新开占卡训练**。能补的对照先用
已经解盲的数据做成论文表。

### 阶段 I（现在到 E201 训练结束，约 2–3 天）

1. 锁主张：本文只写 fail-closed 风险合同。
2. **E202a（不占 GPU）**：把 E158/E159、E199、E200、E189/E192 收成一张
   “竞品与基线在何种 setting 退化”的论文表。饱和写成 `undefined / ABSTAIN`，
   不写成 ρ=0。
3. 正文里写清 SafeConf ≠ PRESCRIBE ≠ PerturbMap ≠ TxPert。
4. 旧稿只抽数学定义；摘要和结果按新主张重写提纲，不含 E201 数字。

### 阶段 II（16 个 checkpoint 齐了之后，硬顺序）

封存 → 零真值预测 → 风险和 general baseline → 双远程 → 开真值 → 正式评价。
三个门分开判：证书、路由、相对 magnitude 的增量。四个细胞系全报。

### 阶段 III（E201 数字出来后立刻分叉，不另开讨论会）

- 多数背景过路由门：主文写多背景审计；Briefings 可进入正文。
- 只有部分过：异质性就是结果；abstain 规则是贡献。
- 全不过或 magnitude 全面主导：停掉“排序优于幅度”，主文改成
  “困难 setting 下何时必须停用经验排序”，仍可投 Briefings。
  Genome Biology 则要再加软件包和一个独立队列。

### 阶段 IV（只在 III 需要冲大类一区时才开）

1. **E202b**：新的、尚未解封的数据上，预注册非饱和的 PRESCRIBE 官方分数，
   与 SafeConf / magnitude 同任务比较。E158 的 P3/P4 不能重跑当确认。
2. 一个可 `pip install` 的最小审计包 + 一条复现命令。
3. 若学院认定必须中科院大类 1 区：再考虑独立细胞系或一项扰动前冻结的
   小规模湿实验。这是加码，不是现在的主路径。
