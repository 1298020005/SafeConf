# SafeConf-Cert：TCBB 方法主线与执行门

更新时间：2026-09-15

## 一句话定位

SafeConf-Cert 不重新预测扰动后的表达，而是接收一组已经冻结的预测，给出：

1. 不读取目标真值也成立的家族误差下界；
2. 在明确校准条件下成立的边际上界；
3. 证据不足时的拒绝输出；
4. 作为附加功能的高风险任务排序。

论文主次固定为“证书为主、排序为辅”。五特征等权分数不再作为最终算法。

## 核心误差对象与公式

预先登记成员、权重、基因轴与预处理后，令第 \(i\) 个预测器输出 \(p_i\)，权重为
\(w_i\)，真实结果为 \(y\)：

\[
\bar p=\sum_i w_i p_i,\qquad
D_F^2=\sum_i w_i\lVert p_i-\bar p\rVert^2.
\]

家族均方根误差满足经典 ambiguity decomposition：

\[
R_F^2=\sum_iw_i\lVert p_i-y\rVert^2
=\lVert\bar p-y\rVert^2+D_F^2.
\]

因此在不知道 \(y\) 时仍有确定性下界：

\[
L_F=D_F\le R_F.
\]

这里的被保证对象是**预先注册的模型家族均方根误差** \(R_F\)，不是质心预测
\(\bar p\) 的误差，也不是某一个指定 TxPert 成员的误差。因为
\(R_F^2=\lVert\bar p-y\rVert^2+D_F^2\)，很大的成员分歧足以证明该家族不能作为
一致预测整体直接放行；它不能定位究竟哪一个成员出错。论文中的实际动作因此是
“该任务停止自动放行并进入复核”，不能写成“SafeConf 已证明某个上游模型错误”。

如果目标研究与校准研究之间的质心误差分位数为 \(q_\alpha\)，已冻结的质心迁移代价
为 \(s\)，则使用：

\[
U_F=\sqrt{(q_\alpha+s)^2+D_F^2}.
\]

\(L_F\) 是代数下界；\(U_F\) 是在预先说明的可交换性和校准合同下的边际
conformal 上界。后者不能解释为每一个被挑选任务都必然安全。

## 计算机方法贡献写什么

1. **注册家族**：成员、架构、训练谱系、随机种子、权重、输出基因轴和预处理先登记
   并哈希；结果出来后不能换成员。
2. **防复制治理**：同一架构复制更多随机种子不能增加该架构的话语权；先在架构内
   聚合，再在架构之间分配平衡权重。
3. **真值无关下界**：仅根据预测器之间的分歧计算 \(L_F\)。给定允许误差阈值
   \(\tau\)，若 \(L_F>\tau\)，则记为 `CERTIFIED_HIGH`；其余为 `UNKNOWN`，不冒充
   安全。
4. **条件上界**：按扰动靶点聚类校准并搬移质心上界；覆盖不足时输出
   `ABSTAIN`。
5. **盲态协议**：预测、成员表、证书和哈希先写入版本库，再允许读取目标表达。
6. **可复算实现**：一条命令从冻结预测重算证书、图表和审计清单，报告时间复杂度、
   CPU 时间和峰值内存。

输出语义固定为：

- \(L_F>\tau\)：`CERTIFIED_HIGH`，确定性地确认注册家族的 \(R_F>\tau\)；
- \(U_F\le\tau\)：仅在已声明的 conformal 条件下记为 `CONFORMAL_LOW`；该结论是
  边际覆盖，不得改写成每个被选任务的点态安全保证；
- 其余情况：`UNKNOWN`；
- 合同、校准或数值门失败：`ABSTAIN`。

由于 \(U_F\ge L_F\)，同一任务不会同时进入 `CERTIFIED_HIGH` 和
`CONFORMAL_LOW`。外部验证如果没有产生 `CONFORMAL_LOW`，仍须如实报告，不能放宽
\(\tau\) 或改校准单位制造放行量。

经典恒等式和 conformal prediction 本身不写成新理论。创新落在单细胞扰动预测中的
误差对象、注册治理、跨研究搬移、失败关闭和可审计实现。

## 排序模块的进入条件

经验排序只能使用预先冻结的单一候选。预测幅度 \(M\) 作为锚点，附加分数只能增加
风险警报，例如：

\[
R_{\mathrm{rank}}=M+\lambda\max(S-M,0).
\]

这只保证分数不低于幅度，不保证排序效用一定更好。只有在 E208 中同时满足以下两条，
排序模块才进入正文：

1. 相对幅度的 Spearman 差值之扰动簇自举 95% 区间下限大于 0；
2. 预设 20% 预算下的复核效用差不小于 0。

未通过时，排序结果放补充材料；证书主线不受影响。

## TCBB 投稿 GO 门

| 门 | 必须达到的状态 |
|---|---|
| G1 盲态完整 | E205、E208 均完成预测/证书封存，真值访问审计 0 违例 |
| G2 下界有效 | 新外部异构家族下界 0 违反，按尺度设置的数值恒等式门通过 |
| G3 上界校准 | 新外部研究 90% 目标簇上界覆盖至少 85%，且 95% 区间包含 90% |
| G4 下界可用 | 新外部异构家族的下界紧致度中位数至少 0.15，且高误差证书覆盖非零 |
| G5 比较完整 | 报告普通分歧、幅度、标准 centroid split-conformal、原 SafeConf、证书；所有研究和负结果保留 |
| G6 工程完整 | 可安装 CLI、固定环境、一键复算、单元测试、复制攻击测试、运行时间与内存表通过 |

G1–G4 任一失败，不改阈值、不删研究。先补另一个未参与开发的外部数据；不能把增加
随机种子或事后合并当成新外部确认。

## 执行顺序

1. E205 继续双卡训练；并行完成风险/证书生成和评价程序。
2. 在读取 E208 表达数值前补充证书副协议：成员、权重、误差几何、校准簇、
   \(\tau\) 网格、主指标和数值容差全部冻结。
3. CPU 复算 E176/E177/E180/E182 的阈值—证书召回曲线、上下界宽度与按研究分层结果。
4. E205 训练完成后封存 checkpoint，生成盲预测、跨结构证书并推送，之后一次性评价。
5. E208 完成同样的封存—推送—揭盲链，作为决定性外部结果。
6. 将散脚本收为 `safeconf-audit` 的证书子命令并做发布级验收。
