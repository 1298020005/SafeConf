# SafeConf｜2026-09-21 当前 CCF-B / 计算机二区审稿判断

## 先给结论

**现在不能把 SafeConf 写成“已经稳定 CCF-B”或“计算机二区稳录”。**
截至2026-09-22，E208外部确认仍无成绩；E205已经发布，E220已使用该表完成同口径复核。本文原先“E205等待揭盲”的状态过时，现更正。新增开发结果见[三轮执行记录](../方法设计/20260922_条件风险模型/EXPERIMENTS.md)。

目前更准确的状态是：

- 研究问题和方法身份已经清楚：SafeConf 是上游扰动预测后的风险排序/停止放行层，
  不承担表达预测本身；
- 四背景 E201 证明幅度与误差有强关系，SafeConf 还有剩余排序信息，但原分数不应
  宣称超过幅度；
- E220 用同一背景内百分位重新对齐基线后，固定组合的 Spearman 增量仍为正，但
  20% 复核效用区间跨 0；
- E221 的嵌套留一研究自适应分数点估计为 ΔSpearman `+0.04499`、
  Δutility@20% `+0.02693`，但 utility 的研究簇 95% 区间为
  `[-0.01476, +0.06259]`。它支持“跨研究有排序增量的迹象”，还不支持“稳定提高实际
  复核收益”。

因此，当前可以准备一篇以“预测后风险审计、证书和适用边界”为核心的 CCF-B 方向方法稿，
但不能用当前状态承诺录用，也不能通过删掉不利研究来制造通过。

## 为什么这项工作仍然有 CCF-B 潜力

CCF 当前“交叉/综合/新兴”官方页面把 IEEE-ACM Transactions on Computational
Biology and Bioinformatics（TCBB）列为 B 类，也列出 Bioinformatics、Briefings in
Bioinformatics 等 B 类期刊；这只是目录类别，不等于 JCR Q2、中科院二区或学院毕业认定。
来源：<https://www.ccf.org.cn/Academic_Evaluation/Cross_Compre_Emerging/>。

TCBB 类型的计算机方法稿可围绕以下可复算贡献组织：

1. 预测器家族、成员权重和数据处理先注册并哈希，防止事后换模型；
2. 用预测幅度表示响应尺度，用跨成员分歧、历史支持和背景覆盖表示证据缺口；
3. 提供真值未读取时仍成立的分歧下界；超过容忍阈值就停止自动放行；
4. 在固定复核预算下评估风险排序，同时报告幅度强、SafeConf 弱或失效的场景；
5. 用跨结构、外部数据、强简单基线和一键复算脚本检验方法边界。

这套贡献比“把几个指标相加并在一个数据集上提高一点”更完整，但是否够 CCF-B 取决于
外部结果和主张收窄后的审稿判断。

类别代替分区要求。

## 审稿人会重点追问的五件事

1. 真正的评价对象是哪个预测器或预测器家族的误差；
2. 风险分数是否在读取测试真值前完全封存；
3. 幅度基线是否与 SafeConf 使用同一背景内排名口径；
4. 结果是否被某个细胞背景、研究或单一架构主导；
5. 当幅度或 SafeConf 在双未见、化学扰动等场景失效时，系统是否会明确输出
   `UNKNOWN/ABSTAIN` 而不是继续放行。

这五点全部有可追溯实验记录后，才适合进入 TCBB 型正文。期刊录用仍由编辑和审稿人
决定，任何内部 gate 都不能改写成百分之百保证。
