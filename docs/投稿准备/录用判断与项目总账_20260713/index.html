PROJECT AUDIT / PUBLICATION READINESS

实验闭环以后，为什么仍不能承诺期刊录用？

把周老师的每个追问、七套正式数据、两类误差风险、失败复制和投稿风险放到同一张账上。这里不估算虚假的“录用概率”，只说明已经解决什么、哪些边界经实验仍然存在。

当前判断：七套正式 scGPT–GEARS 数据、32 个 folds 和 3,209 个测试任务形成较强二区投稿主干。原 SafeConf 的 absolute RMSE 排序稳定超过 disagreement，但相对 magnitude 的七数据区间跨 0；Directional-SafeConf 已在冻结后的 Nadig 第七数据确认通过。可以投稿和冲击一区，不能承诺“稳定录用二区”。
01 / ADVISOR QUESTIONS

周老师的问题，逐项回答

老师关心的不是“数据够不够多”这一句话，而是预测错误来自谁、输入有没有偷看真值、容易和困难的缺失方式是否分开、结论能否跨背景和数据集成立。

风险分数和什么相关？
主终点是每个任务上 scGPT 与 GEARS 的平均预测 RMSE；另报告最大 RMSE 和模型别 RMSE。风险先冻结，测试真实表达后解封。
E108 主审计E111 模型别误差
实际错误来自什么模型？
来自按外层 fold 正式训练的 scGPT 与 GEARS。scGPT 加载 whole-human 权重再微调；GEARS 的共表达图只读训练背景 control。
E106 scGPTE107 GEARS
未见组合输入什么？
目标背景的未扰动 control 表达、扰动标签和训练子矩阵。目标 pair 的受扰动表达不进入预测器，也不进入 SafeConf。
E97 冻结合同
随机挖 pair 是否太容易？
正式测试拆为随机缺失 pair、整行新背景、整列新扰动、背景与扰动双未见。四种 setting 单独报告，不用随机缺失代表全部泛化。
E108 FrangiehE112 外部复制
训练矩阵很小时怎样？
25%、50%、75%、100% 嵌套子矩阵已冻结并测试。正式主证据使用完整训练量，小矩阵作为压力测试保留。
E98 敏感性
能否跨行、跨列、跨数据集？
七套正式数据、32 个 context-holdout folds、3,209 个测试任务；每折另有约 20% 扰动整列留出和双未见任务。Nadig 增加 HepG2/Jurkat 跨细胞系确认。
E140 七数据元分析
RMSE 是否过于单一？
已按 Systema 的训练受扰动表达质心增加 Pearson/cosine 方向误差。原 SafeConf 不适合直接排序方向误差；新方向风险头冻结后在 Nadig 确认通过。
E139 第七数据确认
能否节约复核预算？
六数据集 normalized AURC 稳定优于 disagreement；top-20% 错误捕获点估计更高，但区间仍跨 0，不能承诺固定预算收益。
E132 分诊效用
分歧是不是依赖模型？
是。SafeConf 对 GEARS 误差排序较强，对 scGPT 误差证据弱。论文对象必须写成“预测器/任务级风险”，不能写通用置信度。
E111 机制审计
有没有风险保证？
E114 的 90% split-conformal 上界经验覆盖 98.0%，但偏宽；E117 收紧后覆盖降到 72.6%，已经否决。
E114 保守上界E117 失败紧化
老师说“三个设置解决后可以写一个小文章”，说明研究问题达到了可写作的最低闭环。原话没有指定期刊、新颖性门槛或审稿结果，不能扩写成“期刊一定接收”。

05 / EDITORIAL FUNNEL

为什么实验通过，仍可能被拒

期刊决定不是“指标达到阈值就自动接收”。每一道关口回答的问题不同，其中一部分是独立专业判断。

01 范围
主题、文章类型、读者是否匹配期刊
不匹配可直接退稿
02 编辑初筛
新颖性、优先级、完整度是否值得送审
没有统一量化阈值
03 同行评审
方法、基线、统计、解释、复现是否可信
专家可以有不同判断
04 修回
能否逐条补实验、改主张、澄清争议
大修后仍可拒稿
05 决定
编辑综合稿件与评审意见作出决定
接收不是代码输出
“一区/二区”是期刊在某套评价体系、某个年份和学科中的相对位置，不是投稿系统的及格线；分区变化也不受作者控制。
06 / PROJECT-SPECIFIC REVIEW RISKS

放到 SafeConf 身上，最可能被追问什么

方法新颖性是否足够仍有判断空间
正式风险层、任务合同、元分析和 conformal 构成完整方法；高门槛期刊仍可能把它视为可靠性协议，而非重大算法突破。
是否适用于所有预测器不能泛化
GEARS 证据强、scGPT 证据弱。限定为预测器/任务级风险路由，能守住结论。
跨数据集是否稳定分指标回答
absolute 对 disagreement 稳定，对 magnitude 的七数据 CI 跨 0；方向风险在冻结后的第七数据确认通过。
是否带来实际筛选收益部分闭环
AURC 相对 disagreement 稳定改善；固定 top-20% 捕获增益仍未稳定。
上界是否够紧偏保守
98.0% 经验覆盖可靠，但平均上界为真实平均误差的 1.86 倍。
是否跨扰动模态正式负边界
chemical 合同中 magnitude 更强，不能合并冒充跨模态成功。
是否有生物学解释部分闭环
背景新颖度是明确线索；通路富集未显著，尚无湿实验因果证据。
是否真正独立验证冻结后复制
E135 方向模型先冻结，E136 再固定 Nadig 双细胞系合同，E139 预注册 gate 通过；尚无前瞻湿实验。
07 / CONTROL BOUNDARY

我们能提高什么，不能承诺什么

可以继续提高

  • 目标期刊与文章类型匹配

无法预先控制

  • 具体编辑与审稿人分配
  • 专家对“足够新”的判断阈值
  • 同期出现的竞争工作
  • 期刊当期方向、版面和政策
  • 不同审稿意见能否一致
  • 下一年度期刊分区变化

11 / GLOSSARY

这页出现的名词

task / 任务一个细胞背景与一个扰动的组合，例如某细胞系接受某基因敲除。
control / 对照同一细胞背景未受到目标扰动时的表达状态。
pair背景 × 扰动矩阵中的一个格子。
fold一次独立的数据划分；训练、验证和测试来源在该划分中固定。
RMSE预测效应和真实效应逐基因差异的均方根；越大表示错误越大。
Spearman ρ两套排序的一致程度；这里衡量风险排序能否把高错误任务排在前面。
magnitude预测效应幅度。效应越大往往越难预测，因此是必须比较的强基线。
disagreement两个预测器输出的差异；差异大可能意味着其中一个模型不可靠。
PredictionRecord记录一次预测的输入来源、拆分、基因顺序、预测数组和真值数组键的审计合同。
truth lock / 真值锁测试真实受扰动表达在预测和风险冻结前不可读取。
95% CI对统计量不确定性的区间估计；增量区间跨 0 时，不能声称稳定优于比较对象。
cluster bootstrap按 fold、扰动或数据集等相关单元整体重采样，避免把相关任务当成完全独立样本。
macro average / 宏平均每个数据集先算结果，再等权平均，避免任务多的数据集独占结论。
split-conformal用独立校准集的残差分位数构造预测误差上界；保证依赖可交换性条件。
exchangeability / 可交换性校准任务和未来任务在统计上可看作同一机制产生；严重分布偏移时不一定成立。
RC80保留 80% 低风险任务后的误差改善，用来衡量风险排序的实际筛选价值。
