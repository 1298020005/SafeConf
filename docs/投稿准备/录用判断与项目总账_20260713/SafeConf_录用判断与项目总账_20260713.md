# SafeConf 录用判断与项目总账（更新至 E140）

## 一、严肃结论

SafeConf 现在有 7 套正式 scGPT–GEARS 数据、32 个外层 folds、3,209 个测试任务和 6,418 条 strict PredictionRecord，严格检查问题数为 0。项目已具备**较强二区稿件的投稿水准**，也可以按匹配范围冲击一区；不能把它说成“稳定录用二区”。

论文方法需要改成两个明确风险头：

- 原 SafeConf：排序 control-referenced absolute RMSE；
- Directional-SafeConf：排序 Systema 训练受扰动表达质心下的 Pearson/cosine 方向误差。

原 SafeConf 七数据总体稳定超过 disagreement，未稳定超过 magnitude。Directional-SafeConf 在六数据探索与 LODO 后冻结，并在 Nadig HepG2/Jurkat 第七数据通过预注册确认。

## 二、核心数字

### Absolute RMSE

| 数据集 | SafeConf | magnitude | disagreement |
|---|---:|---:|---:|
| Frangieh | 0.253 | 0.148 | 0.137 |
| Lara ex vivo | 0.387 | 0.148 | 0.176 |
| Santinha | 0.065 | -0.089 | -0.127 |
| Shifrut | 0.173 | 0.209 | 0.051 |
| Liang | 0.212 | 0.074 | 0.075 |
| Tian CRISPRi | 0.134 | 0.067 | -0.018 |
| Nadig HepG2/Jurkat | 0.231 | 0.403 | 0.230 |

- 相对 disagreement：七数据 Δρ=0.133，dataset-population 95% CI `[0.045, 0.223]`。
- 相对 magnitude：七数据 Δρ=0.071，dataset-population CI `[-0.056, 0.186]`。

Nadig 是 absolute RMSE 的明确反例，不能删除，也不能用方向风险成功覆盖。

### Systema 方向误差

- 原 SafeConf：六数据 centered Pearson ρ=-0.039，cosine ρ=-0.032；不适合直接用于方向误差。
- E135 Directional-SafeConf 探索性 LODO：Pearson ρ=0.346，cosine ρ=0.336；六个留出数据集均为正。
- E139 Nadig 冻结确认：Pearson ρ=0.748，cosine ρ=0.757；复合方向 rank 的 perturbation-cluster bootstrap 95% CI `[0.693, 0.801]`。
- 冻结模型未在 Nadig 重拟合；E136 记录模型哈希，E139 先写风险分数再计算方向真值。

## 三、老师的问题

| 周老师追问 | 当前回答 |
|---|---|
| 风险和什么错误相关 | absolute 与 direction 分开定义；两者均来自真实 scGPT/GEARS 预测向量 |
| 错误来自什么模型 | 每 fold 正式微调 scGPT、训练 GEARS；不是代理模型 |
| 未见组合输入什么 | 训练子矩阵、目标背景 control、扰动标签；目标受扰动表达只事后评价 |
| 随机缺失是否太容易 | 随机 pair、整背景、整扰动、背景与扰动双未见分开报告 |
| 数据是否太少 | 7 数据、32 folds、3,209 tasks；含生物背景、跨细胞系和技术批次 |
| 简单基线是否比较 | magnitude、disagreement、training perturbed centroid 全部比较 |
| 能否节省复核预算 | 六数据 AURC 对 disagreement 稳定，固定 top-20% 增益仍不稳定 |
| 是否有误差保证 | E114 覆盖充分但偏宽；E117 紧化失败 |
| 是否跨 chemical | 没有；E118 中 magnitude 更强 |

## 四、为什么第七数据重要

```text
E133/E134 发现方向误差缺口
          │
          ▼
E135 五候选透明探索 + 六数据 LODO
          │
          ▼
Ridge 四特征、系数、截距冻结
          │
          ▼
E136 Nadig 标签合同与模型哈希冻结
          │
          ▼
E137 读取表达并构建组合资产
          │
          ▼
E138 scGPT/GEARS 正式预测，strict issues=0
          │
          ▼
E139 风险先落盘，再计算方向误差
          │
          ▼
预注册 gate 通过
```

E135 看过候选结果，所以只算探索；E139 才是确认。该顺序避免把在六数据上挑出的最好模型伪装成独立验证。

## 五、简单质心基线

Systema 的训练受扰动表达质心在训练 fold 内构造，不使用验证或测试真值。原六数据中 scGPT/GEARS ensemble 在 5 套上优于简单质心，Tian 例外；Nadig 中 ensemble RMSE=0.1315，质心 RMSE=0.4007，79.7% 测试任务胜出。

这个结果说明上游模型总体不只是复现系统性平均变化，但不等于每套数据都领先。

## 六、仍未解决的边界

1. absolute RMSE 相对 magnitude 的七数据总体 CI 跨 0。
2. 固定 top-20% 复核预算收益没有稳定闭环。
3. split-conformal 上界偏宽，紧化版本覆盖失败。
4. chemical 模态没有独立增量。
5. 通路富集未显著，没有湿实验因果验证。
6. 方向风险只有一个真正冻结后的新数据确认。

## 七、当前投稿定位

- 研究闭环：完成。
- 较强二区投稿水准：达到。
- 一区尝试：有实验基础，主要风险在方法不可替代性、生物学推动作用和 absolute-vs-magnitude 边界。
- 稳定录用或百分百录用：不能承诺。编辑初筛、审稿人判断、同期竞争和期刊政策不由实验控制。

稿件不能再写“一个分数对所有误差普适”。更合理的主张是：**单细胞扰动预测风险依赖评价目标；SafeConf 提供 metric-aware 的任务风险路由，并用严格合同、简单基线和冻结外部确认界定适用范围。**

## 八、下一步

1. 以 E140 为 absolute 主表，E139 为 direction 确认表，E132 为分诊效用表。
2. Methods 明写 E133/E134 的负结果、E135 的探索性质、E136–E139 的冻结顺序。
3. 不在 Nadig 真值上修改方向模型后重复宣称确认。
4. 冲更高门槛时，优先争取湿实验或另一项真正独立研究验证。
5. 转入稿件图表、伪代码、统计计划和一键复现，不再在七套已解封数据上无休止换模型。
