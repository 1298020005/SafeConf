# E235 预测与评分执行实现（测试真值读取前）

本文件只记录如何实现已冻结的 `ANALYSIS_CONTRACT.md`，**不更改任务、公式、指标或通过门**。实现代码是 `tools/scripts/run_e235_pretruth_supervisor.py` 和 `tools/scripts/run_e235_pretruth_scores.py`。

执行顺序：

1. 监管器等 E233 阶段 1 和阶段 2 的验证能力均为 `PASS`。若任一门失败，写 `BLOCKED_UPSTREAM_COMPETENCE` 并停止。
2. 从已选定的同一 E233 变体取四个完整随机种子的最佳 checkpoint，验证每个预测 checkpoint 的 SHA-256 确实属于相应训练记录。调用 E208 已有的**仅目标对照**预测程序，两张 GPU 并行运行四次；每次输出 224×15,473 的预测质心与同一目标状态对照质心。此时不访问测试受扰动表达。
3. 读取 E208 已封存的训练来源效应缓存。每个任务计算四种子平均预测的 `M`；同一基因的训练来源效应之间的离散度 `H`。同状态按秩转百分位，固定 `0.8·rank(M)+0.2·rank(H)`；同时计算 `M`、`M+D/G/N/C` 和原五分量组合，不在测试集搜索权重。
4. 输出 `E235_PRETRUTH_SCORES.csv`、输入哈希和 `E235_PRETRUTH_SCORE_STATUS.json` 后，监管器**停止**在 `SCORES_READY_AWAITING_REMOTE_SEAL`。下一步必须先提交并推送分数，再经单独授权读取测试真值并评价。此监管器不运行评价程序。

固定输入：E208 的 224 任务清单、目标状态对照缓存、训练来源效应缓存；E233 四种子训练状态、验证能力门及其 checkpoint。缺来源、输入哈希不符、种子任务顺序或基因轴不一致时停止，不补齐、不删任务。手动检查所有来源状态的 `test_perturbed_expression_rows_read` 字段必须为 0。目标受扰动表达未进入该程序的参数列表。

本程序本身不是成绩单。只有 E233 能力门通过、预测/评分封存完成后，才有 E235 外部结果可谈。E233 训练可能被早停或算力速度影响；不能按估计时间宣称外部验证已经完成。
