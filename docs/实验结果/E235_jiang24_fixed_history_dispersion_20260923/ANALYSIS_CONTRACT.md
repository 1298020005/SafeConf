# E235｜Jiang24 上固定 `M+H` 的独立确认协议

登记时间：2026-09-23；E233 阶段1尚未完成，Jiang24 正式测试扰动表达读取0行。E234 已显示 `M+H` 是四背景开发数据上的最强简单组合，本协议将它视为**已经通过开发数据挑出的候选**，在新外部数据中一次性检验。E235 不是 E208 原冻结主分析的替代品，两套结果须并列报告。

## 进入门与固定范围

只有 E233 预登记修复变体的阶段1和四种子平均的阶段2验证能力门均通过，才允许使用该上游预测器生成 Jiang24 测试预测。未通过时本实验为 `BLOCKED_UPSTREAM_COMPETENCE`，不打开测试真值补结果。

任务范围严格沿用 E208 D0 清单：K562、MCF7、HT29、HAP1 四个细胞系，各在 IFNG、INS、TGFB 三个状态，共12状态、224个单基因扰动任务、53个扰动基因。全部进入报告；不依预测误差删任务、基因或状态。训练来源仅来自 Jiang24 官方 `train` 层，当前目标状态和所有测试受扰动表达禁止进入来源证据。

## 固定的三类输入与评分

四个合格 E233 种子等权平均预测表达向量，目标状态对照表达来自允许的对照缓存。对任务 `t=(c,g)`：

- `M_t` = 四种子平均预测与目标状态对照的全基因均方根差，表示**预测响应幅度**；
- `H_t` = 同一基因在其他训练来源状态上的平均扰动效应向量的跨来源均方根离散度，使用已冻结 E208 训练来源效应缓存的全部合格来源；
- 若来源少于2个或任务/基因轴/向量不一致，该状态记 `ABSTAIN`，不从测试真值补数据。

每个目标状态内按全部预定任务平均秩转百分位；固定候选

`R_MH = 0.8 × rank_c(M) + 0.2 × rank_c(H)`。

系数不搜索、不按验证或测试错误调整。对照必须用同一预测家族和同一任务，包括单幅度 `M`、`M+D`、`M+G`、`M+N`、`M+C`、原五分量固定 `80/20` 及随机排序；`D/G/N/C` 按 E208 已冻结的特征定义。E232 复杂相似性方法若未能按源数据合同无损实现，只报告为未评估，不拿旧数据分数冒充跨数据结果。

## 先封存，再评价

评分阶段只能读取训练来源、测试对照和四种子预测，产出任务级全部方法分数、来源元数据、基因轴、checkpoint、输入与脚本哈希；确认无真实误差字段后提交并推送 GitHub/Gitee。只有在该封存完成后，单独的评价阶段才可一次性读取224任务的测试受扰动表达。此前和未通过进入门时读取数保持0。

真实误差固定为四种子**平均预测质心**对测试受扰动表达质心的共同基因轴 RMSE；不临时更换为效果更好的输出空间。每状态各选最高风险的20%任务，主要指标为12状态等权的归一化错误捕获效用。Spearman、错误总量抓取率、10%/30%预算、12状态及4细胞系逐项表为辅助。按53个扰动基因做跨状态簇重采样，固定种子20260923、2,000次，报告配对95%区间。

预设“实际增益”门：`R_MH−M` 的20%效用宏平均至少+0.02、簇重采样95%区间下限大于0、至少9/12状态为正。若任一失败，写 `NOT_SUPPORTED`；无论结果如何全部对照与状态保留。即便通过，也只支持这个基因扰动范围与此上游预测家族，不能推出化学扰动通用或期刊录用保证。
