# E235 正式评价与自动留存：实现记录

记录时间：2026-09-24。本文件补充已冻结的 `ANALYSIS_CONTRACT.md`，不更改 224 任务、`M+H` 公式、20% 主指标、2,000 次基因簇重采样或三项通过门。截至本记录，E233 仍在训练；**这里没有 E235 测试成绩**。

## 范围和对照

只研究 Jiang24 官方切分中的 224 个单基因扰动任务：4 个细胞系 × 3 种处理状态、53 个目标基因。输入为通过验证能力门的 E233 四随机种子平均预测、目标状态未扰动对照、官方训练来源的同基因历史效应。所有 224 个任务进入结果。`M` 为预测表达相对对照的均方根变化；`H` 为同一基因训练来源效应的跨背景离散度。主要候选固定为每个状态内的 `0.8·rank(M)+0.2·rank(H)`。

同一批预测、同一任务和同一真实误差上比较：`M`、`M+D/G/N/C`、原五分量固定组合和固定哈希随机排序。随机排序由 `SHA256(E235_RANDOM_V1\0task_id)` 在解封前确定，不通过测试真值选择种子。PertEMA 一类需要同筛查误差标签训练的评分器属于不同信息预算，见 `RELATED_METHODS_CONTRACT.md`；其演示模型不能直接硬套 Jiang24 充当公平负对照。

| 代码 | 作用 | 测试受扰动表达 |

| `audit_e235_formal_results.py` | 用任务级结果独立重算主指标、逐状态、2,000 次重采样和通过门 | 不重读 H5；**仅指标审计** |

在 Git 评分封存和授权这两个阶段若有网络推送失败、仓库不干净、文件哈希变化或上游验证未通过，程序停止，**不会跳到真值读取**。正式评价先检查授权提交与两个远程当前分支完全一致，再打开 H5。完整 H5 与官方切分分别核对 SHA-256；评分任务顺序、四个预测文件及其 checkpoint 哈希也重新核对。

主指标：每个状态取预测高风险的前 20% 任务，效用定义为 `(选中任务平均真实 RMSE－该状态全部任务平均 RMSE)/(真实 RMSE 最高的前 20% 平均 RMSE－该状态全部任务平均 RMSE)`；12 状态等权平均。辅助指标有 10%/30% 预算、Spearman、原始错误捕获比例、逐状态和逐细胞系表。按 53 个目标基因整簇重采样 2,000 次，固定种子 `20260923`，报告 `M+H－M` 的配对 95% 区间。

预设三项门同时满足才标 `SUPPORTED_IN_FIXED_SCOPE`：20% 宏平均效用差至少 `+0.02`、基因簇区间下限大于 0、至少 9/12 状态的效用差为正；否则标 `NOT_SUPPORTED`。这只是**固定范围内方法增益的证据门**，不是 CCF B／二区录用门。任何负结果、全部对照与状态均留在正式 CSV 中。
