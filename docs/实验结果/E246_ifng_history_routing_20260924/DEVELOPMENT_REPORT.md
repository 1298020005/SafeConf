# E246 开发结论：IFNG 上游可行，H 风险增益不成立

执行时间：2026-09-24。只看 Jiang24 官方验证集 IFNG 状态的 80 个合格任务（四细胞系各20个、20个扰动基因），使用 `α=0.10` 的训练来源效应迁移预测；**测试受扰动表达读取0行**。上游相对无变化的全基因验证 MSE 降低约 2.82%，四细胞系均正向，这是选择这一局部范围的依据。

然而风险排序已经被最简单的预测幅度 `M` 做得很强：20%预算下，四细胞系等权的 oracle 归一化效用为 **0.9464**。历史离散度 `H` 加20%权重后的前20%名单完全没有变化，效用仍为0.9464；加到40%、60%或单独用H，效用均降到约0.8125，只有1/4细胞系相对M正向。权重选择协议要求至少`+0.03`效用增益、至少3/4细胞系正向，故状态为 `NO_RISK_CANDIDATE`。

结论很具体：**IFNG 数据可能适合研究历史来源效应迁移预测，但不适合把 `M+H` 包装成比 `M` 更好的高误差优先复核方法。** E246 不进入测试真值阶段；80 个验证任务的全表及五权重结果保存在 `development_results/`。不能为了得到漂亮图而把 `H` 的负结果藏起来，也不能把 `M` 改名成 SafeConf 的新方法。

下一步若仍追求预测后风险方法，应优先寻找“上游预测确实有用、同时简单幅度尚未接近 oracle”的任务族，先用验证数据证明这两项均成立，再在独立任务上一次性确认。E233 的 Jiang24 全域模型仍在正式能力门流程中；它若失败，E235 会自动停在上游门，不读测试真值。若考虑其他数据集，也要先查训练来源质量和现有 PertEMA 等方法的公平信息预算。
