# E126 设计冻结｜跨数据集风险路由器

冻结时间：2026-07-14（E124/E125 解封后）。因此 E126 属于方法改进与探索性验证，不能冒充事前确认性结果。

## 要解决的问题

E125 显示固定 SafeConf 在五数据集上的 normalized AURC 稳定优于单独的模型分歧，但 top-20% 错误捕获增益仍不稳定。E126 检验：能否把已有数据集作为历史标注库，学到一套可迁移到整套新数据集的风险路由器。

## 冻结协议

1. 五套正式数据每次整套留出一套；被留出数据集的任务真值不得参与训练、特征变换、超参数选择或阈值选择。
2. 训练输入只有部署前可得的六个风险特征：原 SafeConf、模型分歧、预测幅度、背景新颖度、扰动新颖度和负对数支持数。
3. 为减少不同数据集量纲差异，每个特征只在各自 dataset × outer-fold 内转为百分位秩；该变换不读取任务真值。
4. 训练目标为来源数据集各 outer-fold 内的任务误差百分位秩。
5. 唯一模型为正系数 Ridge，`alpha=10`；不搜索模型和超参数。来源数据集及其 folds 等权。
6. 主比较为原 SafeConf、predicted magnitude 和 model disagreement。报告 fold 内 Spearman、normalized AURC、top-20% error capture，并保留所有留出数据集，包括失败数据集。

## 解释边界

E126 使用的是其他数据集已经揭示的任务真值，适合“已有历史项目后部署到新项目”的情境。它不能代替未来第六套未见数据的确认性复现；若结果好，后续必须冻结 E126 后再做真正的新数据验证。
