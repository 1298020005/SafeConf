# E144｜STRING 知识距离与靶基因自身恢复失败

## 预注册主 gate：未通过

原 SafeConf 对被扰动基因自身绝对预测误差的七数据等权 ρ=0.015；bootstrap 中位数 0.013，95% CI [-0.065, 0.099]。

相对 predicted magnitude 的 Δρ=+0.017 [-0.078, +0.106]；相对 disagreement 的 Δρ=-0.001 [-0.094, +0.086]。

## 网络知识距离

训练未见目标中，STRING 最短距离与全向量 RMSE 的 fold→dataset 等权 ρ=-0.095。折内基因标签置换的中位数为 -0.001，双侧经验 P=0.0080。

该结果只说明网络知识位置与错误存在统计联系；STRING 是功能关联网络，不能据此宣称直接调控或因果机制。
