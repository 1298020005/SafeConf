# E258 第二次开发追加：分半噪声审计改变了判断

记录：2026-09-25。接续[第一份开发追加](DEV_AMENDMENT_20260925_历史距离候选.md)，并保留其中的原候选及其提出时间；**本文件的证据优先级更高**。只使用原始计数的训练/验证靶向细胞和允许的对照；四位测试供体靶向扰动真值仍没有打开。

## 为什么必须加这一步

在同一验证面板上，历史离散度 `H_disp` 控制预测幅度 `M` 的偏秩相关宏平均为 `0.572`，再控制历史来源的中位靶向细胞数降为 `0.169`。同时，用训练供体折外错误标签训练的 `M+来源数+来源细胞量` 小风险对照，宏 `Utility@20% = 0.24195`；原始历史距离为 `0.24178`。因此“生物学效应离散度本身提供独立收益”的解释还不成立，必须把测量波动拆出来。

## 数据边界与分半方法

把原始映射中每个允许读取的细胞组按原始列顺序交替分为两半；被排除的测试供体靶向细胞仍保持 `-1`，原始计数扫描器跳过其数值转换。每个半组最少 15 个细胞，两半最多差 1 个。第二次扫描的**所有 6,517 个原始基因行、所有 5,616 个原始组**均满足半组计数相加精确等于原完整组，整转录组文库 UMI 总数亦精确相等；日志显示测试靶向数值转换数 `0`。分半效果以原来相同的 6,515 个符号轴、相同对照批次加权重新计算。

扫描器运行摘要：总原始基因行 `36,518`，命中固定符号轴的原始行 `6,517`；解析允许的计数 token `32,639,605,810` 个，跳过而不做数字转换的 token `9,789,380,260` 个，测试供体靶向数值解析 `0`。这组计数可用下方命令复核，不包含任何最终测试误差。

对每位训练供体的同靶基因历史效应，估计全组采样波动方差为两半效应之差的逐基因平方平均再除以 4；在来源间方差中扣除 `(1−1/来源数)×平均来源波动方差`，负值截为零。此换算假定两半近似独立、均衡；对 `log1p` 归一化和混合批次只是**近似诊断**，不能将剩余方差称作“纯生物学变异”。完整组效应与两半效应均值的中位 RMS 差为 `0.00169`，低于半组估计的来源采样波动 RMS 中位数 `0.03221`；132/1,530 个验证任务的校正后来源间方差截为零。

## 同一验证任务上的结果

四条细胞系等权、每条取 20% 任务，误差和基因轴完全不变：

| 风险信息 | 宏 `Utility@20%` | 宏 Spearman |
|---|---:|---:|
| 当前预测幅度 `M` | 0.23429 | 0.63738 |
| 原始来源间离散度 `H_disp` | 0.23807 | 0.71142 |
| 扣除分半采样波动后的 `H_disp` | 0.22626 | 0.22441 |
| 原始历史距离 `sqrt(H_gap²+H_disp²)` | 0.24178 | 0.75209 |
| **只用分半采样波动代替来源间离散度的距离** | **0.24201** | 0.75017 |
| 扣除波动后的历史距离 | 0.23394 | 0.57532 |

校正后 `H_disp` 同时控制 `M` 与来源细胞量的偏秩相关，四条线为 `−0.011、+0.035、+0.014、−0.007`，宏 `+0.008`。校正后历史距离相对 `M` 的 2,000 次靶基因聚类 bootstrap 95% 区间为 `[−0.00249,+0.00149]`，穿零；原始历史距离相对“只用分半采样波动的距离”的效用差区间 `[−0.00101,+0.00083]`，也穿零。区间都只条件于现有两位验证供体。**这表示本验证集的原始历史距离增益，可以被采样波动/测量支持度解释；不支持将其写作“跨供体真实生物效应差异的已确认增量”。**它不证明生物历史在所有研究、所有模型中都无用，也不证明上述近似校正完全正确。

此处的上游是“训练历史均值乘一个固定收缩系数”。所以“当前预测到历史均值的距离”与 `M` 数学同序；噪声对照仍使用历史均值向量，但它没有提供一个独立于 `M` 的新生物特征。这里针对的是**历史来源间真实效应差异有没有额外价值**，不能从结果推断历史均值本身完全没用。

训练侧历史效应 RMS 与分半噪声 RMS 的比值，其中位阈值为 `0.58078`。高比值组 779 个验证任务，原始历史距离仍比 `M` 高约 `+0.00607`；**但扣噪后的历史距离不再高于 `M`**。低比值组 751 任务，原始历史距离也没有稳定收益。因此先前“高历史信噪比可作为有效适用域”的想法仍是待验证假设，不能拿这批数据直接定为论文适用门。

## 更新后的研究决策

1. 原[开发报告](DEV_REPORT_20260925_历史何时有用.md)中的原始历史距离数值保留，但主解释改为“混合了真实来源差异与测量不确定性”，不得只写成生物学历史增量。
2. 原合同的学习型上游能力门仍失败；**不解封 E258 最终四位测试供体**。分半诊断不是降低门槛的理由。
3. 不继续在两位验证供体上为生物历史反复调权重；这只会把噪声学成漂亮数字。下一项高价值工作是事前固定、在另一套独立研究或合格上游预测器上比较：`M`、`M+来源细胞量`、原始历史距离、只用分半采样波动的距离、扣噪后的历史距离。同任务、同误差、同预算，必须同时报告所有数据和供体。
4. 如果真实效应向量相对“幅度+测量支持度/波动”持续没有增量，就把**生物学历史作为主创新**这条假设淘汰；可以另行评估“计数质量感知的预测风险排序”，但须先核对现有工作和独立验证，不能把这次后验转向写成预注册成功。
