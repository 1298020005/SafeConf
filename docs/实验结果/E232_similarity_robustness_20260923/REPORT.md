# E232 背景相似性历史路由压力测试

## 结果

预登记机制门通过。固定候选始终保留80%预测幅度，只用20%相似背景历史证据作校正；没有搜索新的混合系数。

| 检验 | 结果 | 预登记方向 |
|---|---:|---|
| 干净历史候选 − 幅度 | +0.016760，4/4目标为正 | ≥0.01，至少3/4正向 |
| 干净历史 − 100%标签破坏 | +0.031152，4/4目标为正 | >0，至少3/4正向 |
| 每增加1%标签破坏的效用趋势 | -0.000304 | <0 |
| 双来源 − 单来源 | +0.009549 | >0 |

干净历史下，K562、RPE1、HepG2、Jurkat的候选效用依次为0.943297、0.627974、0.822239、0.748774；相对单幅度分别提高0.009527、0.019524、0.025959、0.012028。

标签破坏比例为0%、10%、25%、50%、100%时，候选四目标平均效用依次为0.785571、0.779704、0.771595、0.762400、0.754419。单幅度不使用历史，始终为0.768811。标签完全破坏后候选低于幅度，符合“错误历史应当伤害历史校正”的可证伪预期。

## 可以形成的方法逻辑

历史数据库的作用不是简单累加样本数。E231已经显示，按估计精度或细胞数加权没有稳定帮助；E232进一步显示，有效信息来自扰动名称正确对应、且来源细胞背景与目标对照背景接近的历史效应。可固定为：

\[
R=(1-0.2q)\,\operatorname{rank}(M)+0.2q\,\operatorname{rank}(S_{sim}),
\]

其中，`M`是上游模型预测变化的幅度；`S_sim`是使用来源—目标对照背景相似权重后得到的五项风险分；`q`是历史均值效应相对估计噪声的收缩量。`q=0`时退回幅度，历史证据最多占20%。

当前证据支持“相似背景历史含有任务特异的增量信息”和“来源背景覆盖有价值”。它不支持“历史越多必然越好”，也不支持把20%固定系数写成普适最优值。

## 证据边界

E232使用的是E201相同四个目标和相同冻结预测，属于开发机制实验。它比单个最好数字更可信，因为全部目标、全部破坏率、三个种子和全部来源子集均保留；但它仍不能替代新数据或新预测器家族的独立确认。E208外部数据的两个模型家族未通过验证能力门，测试扰动表达仍读取0行，因此没有拿E208测试真值补故事。
