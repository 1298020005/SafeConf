# SafeConf 公式收拢决定

决定时间：2026-09-12

## 1. 不再把五个经验特征等权和当成全部方法

当前证据支持把 SafeConf 分成两个层次：第一层是与真实答案无关的预测家族误差
证书；第二层是在特定部署场景中安排复核顺序的经验路由。二者回答的问题不同，论文
中不能再混成一个“万能风险分”。

## 2. 数学核心：冻结预测家族的误差证书

设同一任务有 `K` 个已登记预测向量
\(\hat y_1,\ldots,\hat y_K\)，权重 \(w_k\geq0\)、
\(\sum_k w_k=1\)，加权质心为

\[
\bar y=\sum_{k=1}^{K}w_k\hat y_k.
\]

对 `G` 个输出基因，定义预测家族内部离散度

\[
D^2=\sum_{k=1}^{K}w_k\frac{\lVert\hat y_k-\bar y\rVert_2^2}{G}.
\]

由平方误差分解，对未知真实向量 \(y\) 恒有

\[
\sum_{k=1}^{K}w_k\,\operatorname{RMSE}(\hat y_k,y)^2
=\operatorname{RMSE}(\bar y,y)^2+D^2\geq D^2.
\]

因此 `D` 是登记预测家族均方误差的真值无关下界。它不声称知道每个单模型的误差，
也不等于“预测正确概率”。若使用两成员最大距离，还可由三角不等式得到至少一个成员
误差不小于成员距离的一半。这个确定性关系是方法的理论骨架。

在有独立校准任务且交换性条件合理时，再用 split conformal 给参考质心误差构造上界。
把参考质心移到当前家族质心时，必须显式加入两者的距离；校准失败或分布条件不成立时
输出 `ABSTAIN`，不宣称覆盖。

## 3. 经验路由：只在有证据的场景使用

对于“整个细胞背景未见过”的遗传扰动，保留 E206 冻结候选式：

\[
R_{\mathrm{SCM}}=\frac{4\,\operatorname{rank}(M)+
\operatorname{rank}(S)}{5N}
=0.80Q(M)+0.20Q(S),
\]

其中 `M` 是预测向量相对未扰动对照的 RMS 幅度，`S` 是原 SafeConf，`N` 是同一
部署批次任务数，`Q` 是批次内百分位秩。整数比写法只为保持理论并列，不改变
0.80/0.20。该式输出复核顺序，不输出新的表达预测。

E207 给出的边界很明确：

- 八个遗传研究中，相对幅度的宏平均 Spearman 增量为 0.0182，95% 簇自举区间
  `[0.0089, 0.0231]`，7/8 研究为正；
- 三个遗传难度数据中增量为 0.0051，区间 `[0.0009, 0.0070]`，2/3 为正；
- 两组遗传数据的 20% 复核效用区间均跨 0；
- SafeConf 单项在 E153/E187 的宏平均 Spearman 分别为 0.2034/0.3892，仍高于
  融合式 0.1648/0.3857。融合式只证明“对幅度有小修正”，没有全面超过两个单项；
- 细胞因子没有确认增量；化学扰动缺少同定义融合输入。

所以，`SafeConf-M` 暂时只作为**整背景未见遗传扰动的冻结候选路由**，等待 E205
第二模型结构验证。它不升级成全遗传、全细胞因子、全化学扰动的统一公式。

## 4. 暂定部署表

| 场景 | 当前输出 | 证据状态 |
|---|---|---|
| 同一输出合同的多模型家族 | 确定性下界 `D`；条件允许时再给校准上界 | 理论恒等式与既有四研究证书 |
| 已知背景、未见遗传扰动 | 优先报告家族分歧/下界；经验排序作为辅助 | E199 支持，仍需与更多模型家族核对 |
| 整个背景未见、遗传扰动 | `SafeConf-M` 复核排序 | E206 开发；E207 回顾性压力测试；E205 待确认 |
| 双未见 | `ABSTAIN` 或只报告未经部署授权的诊断量 | 已有困难切分显示不稳定 |
| 细胞因子 | 单独报告，不启用 SafeConf-M | E207 区间跨 0 |
| 化学扰动 | 幅度基线优先，SafeConf-M 不适用 | E118 中幅度强于分歧，且缺完整 `S` |

## 5. 论文主张的最窄可守版本

SafeConf 的主贡献应写成：对预先登记、满足共同输出合同的单细胞扰动预测家族进行
预测后审计，输出真值无关的家族误差下界、条件校准上界和失败关闭状态；在整背景
未见的遗传扰动中，用幅度锚定的经验路由安排复核顺序。

`0.80/0.20` 不是理论定理，也不是全文唯一卖点。若 E205 未确认其相对幅度的增量，
该路由降为开发性补充，证书主线保持不变。
