# E207 分析合同｜固定融合公式的跨研究、跨难度、跨扰动压力测试

冻结日期：2026-09-12

## 1. 目的和证据身份

E206 在 E201 已解封结果上开发出固定候选式：

\[
R_{\mathrm{SCM}}=0.80\,Q(M)+0.20\,Q(S),
\]

其中，`M` 是预测幅度，`S` 是原 SafeConf，`Q` 是一次实际排序批次内的百分位秩。E207 不再搜索权重、特征、数据子集或端点，直接把这个固定公式放到既有历史任务表中做压力测试。

E207 的输入真值早已解封，项目人员也已经看过这些数据的历史总结。因此，它是**回顾性稳健性检查**，不是独立外部确认。无论结果好坏，都不得改写为 E207 前瞻性验证通过。

## 3. 固定分析

每个排序批次分别计算：

1. `magnitude = Q(M)`；
2. `safeconf = Q(S)`；
3. `disagreement = Q(D)`；
4. `safeconf_m = 0.80 × Q(M) + 0.20 × Q(S)`。

不允许根据数据集、扰动类型、训练量或测试设置改 0.80/0.20。所有任务和所有失败方向均保留。

主描述指标：

- Spearman：风险排序与误差排序的一致性；
- 20% 复核效用：固定复核预算下，高风险集合的平均误差相对随机和理想选择的位置；
- `safeconf_m − magnitude` 的配对差。

次要预算固定为 5%、10%、20%、30%。遇到 cutoff 分数并列时，使用并列组的期望误差，不按 CSV 行顺序任意打破并列。

## 4. 聚合和不确定性

- 先在每个排序批次计算指标；
- 同一数据集内对 folds 等权；
- 跨数据集对研究等权，禁止让大数据集凭行数支配总结果；
- 以 perturbation 为簇重抽样，同一扰动的全部 context、fold、训练量和 setting 同步出现；
- 固定 2,000 次 bootstrap；第 `i` 次重抽样的随机种子由 `202609207`、分析名称和 `i` 唯一确定，使串行与并行运行得到完全相同的抽样；
- 分别报告 E153、E187 遗传子集、E187 细胞因子子集，不能把不同扰动类型混成一个主效应。

## 5. 解释规则

- 某场景配对差区间下界大于 0：只写“历史压力测试中固定融合式相对幅度有稳定增量”。
- 区间跨 0：写“没有确认增量”，不得删除该场景。
- 区间上界小于 0：写“该场景保留幅度基线，融合式停用”。
- 双未见场景即使点估计为正，也不自动获得部署授权；它还必须通过上游预测有效性、分数分辨率和新的冻结确认。
- E205 完成前，不得写固定公式已经跨模型结构验证。

## 6. 与最终方法的关系

E207 只负责检查公式能否简化和界定适用范围。最终候选协议暂时收成三层：

1. 已知细胞背景、未见遗传扰动：使用模型家族分歧证书；
2. 整个细胞背景未见、遗传扰动：使用冻结的 SafeConf-M，并等待 E205 第二结构确认；
3. 双未见、化学或证据不足场景：保留单独结果并允许停用，不强行纳入同一个加权式。

这个分层由部署时已知的场景定义决定，不能查看真实误差后再选分支。
