# E264b｜排除目标背景后的基础历史质量复核

本轮修正了 E264 的合同判断。原脚本把训练来源中出现目标背景直接判为污染；冻结协议实际要求的是：计算历史支持时排除目标背景，排除后仍至少有两个独立来源才可评估。

## 结果

修正后仍只有三个研究满足基础元数据合同：Cui、Lara ex vivo、Santinha。Lara in vivo 在排除目标背景后来源不足，继续标记为 `CONTRACT_FAILED`；Frangieh、McFarland、SciPlex3 仍需先完成背景/剂量/时间字段审计。

三项已对齐研究的主要变化与旧 E264 一致：

- Cui 的 ContextSim 预测器加入基本历史质量后，原始历史离散度相对 `M+Qbasic` 的平均效用变化为 `+0.027742`；但其他预测器为负，且该结果缺少来源内 split-half 测量变化。
- Lara ex vivo 的 ContextSim 变化为 `+0.199965`，但这是已公开结果上的回顾性开发，不能当外部确认。
- Santinha 的三种预测器方向不一致。

因此本次修正没有把研究数量或胜负方向改成有利结果，只修正了来源合同的逻辑。完整逐折表见 `FOLD_RESULTS.csv`，机器状态见 `STATUS.json`。

## 口径

这是 `Ridge(alpha=10)` 在已有 E256 外层测试折之间轮换训练的回顾性检查；效用仍沿用 E256 的 oracle-adjusted Utility@20%。它不是新的盲测，不能和 E201/E205 的最终测试混写。
