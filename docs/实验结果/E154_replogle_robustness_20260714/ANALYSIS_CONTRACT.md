## 固定分析

只分析 256 个预先标记的 held-out-context 唯一任务。绝对误差排序报告 SafeConf、predicted magnitude、模型分歧与两模型平均 RMSE 的两折等权 Spearman。方向排序使用 E135 冻结 Ridge（不在 Replogle 重拟合），报告其与 magnitude 对 E134 Systema exact centered-Pearson、centered-cosine 及二者折内百分位复合终点的两折等权 Spearman。同时报告 scGPT、GEARS、ensemble 和训练受扰动表达质心的 RMSE。

全量三种子按每项指标报告均值、最小值、最大值与范围。训练量分析报告四个固定点、25% 到 100% 的差以及训练比例与指标的 Spearman；四个点只作描述，不作新显著性声明。

## 边界

该实验考察计算随机性和既有训练样本量选择的敏感性。两个细胞系仍来自同一研究，目标细胞系 control 可见；结果不能扩展为跨研究、完全 zero-shot 或湿实验验证。
