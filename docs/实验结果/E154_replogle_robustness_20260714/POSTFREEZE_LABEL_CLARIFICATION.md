# E154 冻结标签说明

记录时间：2026-07-14。

E149 在读取表达值与预测误差之前，用固定 SHA-256 哈希阈值生成了
`in_train_fraction_25/50/75/100` 四列。列名中的 25/50/75/100 表示哈希阈值，
并未按固定数量强制抽取训练对。

对 140 个全量训练对，四列实际选中 18、58、105、140 对，分别占
12.9%、41.4%、75.0%、100%。成员关系严格嵌套，两个 fold 分别为
10+8、27+31、56+49、70+70 对。

本说明不改变冻结成员、模型运行、端点、结果或推断。报告和图继续保留原标签以便与
E149 manifest 一一对应，同时并列给出实际数量和比例。训练量结果只能解释为四个冻结
嵌套子集的描述性敏感性，不能表述为精确的 25%/50% 等量抽样实验。

逐项核对见 `tables/E154_TRAIN_FRACTION_SIZE_AUDIT.csv`。
