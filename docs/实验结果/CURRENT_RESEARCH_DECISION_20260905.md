# SafeConf 当前判断与下一步实验

日期：2026-09-05

## 当前已经得到什么

E201 已完成四个细胞系、四个随机种子的盲预测与正式评价。训练和打分先封存到 GitHub、Gitee，随后才释放四个 target 的真实扰动表达。主分析包含 1,808 个任务，另有 200 个小样本敏感性任务；bootstrap 以扰动条件为簇运行 5,000 次。

SafeConf 风险分与 family RMS error 的合并 Spearman 为 0.4082，95% CI 为 [0.3506, 0.4621]。四个 target 均为正：K562 0.4803、RPE1 0.2868、HepG2 0.5633、Jurkat 0.4453。固定检查 20% 任务时，SafeConf 的复核效用为 0.3200 [0.2456, 0.3929]。这回答了周老师所说的第一种用途：预测出来以后，风险信息可以把较可能出错的任务提前挑出来。

预测幅度的排序更强：合并 Spearman 为 0.6189，20% 复核效用为 0.5943。SafeConf 相对幅度的直接效用差为 -0.2743，不能写成优于幅度。控制预测幅度后，SafeConf 仍与误差相关，partial Spearman 为 0.2503 [0.2021, 0.2980]，四个 target 的区间下限都大于 0。准确表述是：SafeConf 提供幅度之外的信息，但目前作为单独排序器不如幅度。

## 需要保留的负结果

1. 四种子 family 的恒等式残差为 3.61×10^-10，高于事前写死的 1×10^-10，因此正式证书门记为 FAIL；下界违反数为 0。这个失败更像 float32 数值精度问题，但不能事后改阈值再写成通过。
2. K562 上 family centroid 的平均 RMSE 为 0.0540，优于 official general baseline 的 0.0584，却差于 batch-matched control 的 0.0523。深模型不是每个 target 都胜过“不预测变化”的强基线。
3. RPE1 上单独的四种子分歧与误差相关只有 0.0397，区间跨 0。组合风险仍为正，不能据此声称模型分歧在四个 target 上单独稳定。
4. E199/E200 已证明同一信号会随考法翻转，固定加权不可能在所有场景都占优。

## 对周老师最新意见的回答

第一条“把不可信结果挑出来”已经有了四 target 盲测证据，但部署时应把预测幅度作为强基线，SafeConf 用来补充，而不是替代幅度。

第二条“训练时更强调不容易预测对的任务”还没有正式效果结果。E204 已在解盲前固定训练权重公式、λ 和停止规则；第一版清单覆盖不足，完整 profile 有 304,158 个样本退回单位权重，因此该作业作废。修正版已经覆盖实际 source 训练条件：K562 1,365、RPE1 1,298、HepG2 1,241、Jurkat 1,308，共 5,212 个条件。旧清单现在会被训练程序拒绝。

## 接下来按这个顺序做

### 1. 先完成 E204 工程验收

用修正版清单对四个 target 各跑一次单 epoch profile。验收项：所有非对照训练条件均命中权重，未知条件回退数为 0；controls 固定权重 1；loss 有限；训练行数、validation 行数和 E201 一致。任何一项失败就停，不开始正式队列。

### 2. 跑风险指导训练的主比较

E201 的 16 个 uniform 模型直接作为成对基线，不重复训练。新增：

- `risk_weighted`：四个 target × 四个 seed，共 16 个模型；
- `dispersion_only`：四个 target × 四个 seed，共 16 个模型。

合计新增 32 个模型。模型结构、split、epoch、batch size、优化器与 E201 完全一致。主比较按同一 target、同一 seed 成对进行，报告全任务 RMSE、source-only difficulty 最高 20% 任务的 RMSE、Pearson delta 和 rank。高难任务改善但整体 RMSE 相对恶化超过 5% 时，只能写成训练取舍，不能写成模型整体变好。

### 3. 将预测后筛错变成可执行策略

E201 表明 magnitude 更强、SafeConf 有独立信息。下一版路由不再比较“二选一谁更好”，而是开发“magnitude 主排序 + SafeConf 补充”的二阶段策略。开发只使用 E201；公式、阈值和停止规则封存后，必须在一个未参与开发的新数据集或新模型家族上一次性评价。不能回到 E201 上调到最好再称为前瞻结果。

### 4. 补模型家族和外部确认

E201 只有 TxPert-GAT 的四个随机种子。E205 用相同任务合同增加一个结构不同的预测器家族，区分“初始化敏感性”与“跨架构分歧”。最终确认还需要一个没有参与当前排错的新外部数据集；已有 Frangieh、Lara、Santinha 和 Replogle 已参与过方法开发，只能作既有支持，不能再次包装成全新确认。

## 当前投稿判断

现在已经形成一条完整、可复核的主结果：在一个大规模公开 CRISPRi 数据中，四个整背景留出 target 都完成了预测先封存、真值后释放，风险排序和幅度调整后的独立信息均稳定为正。这比此前单一 K562 结果强很多。

仍不宜说“稳定二区”：最关键的实际增益尚未闭合——SafeConf 单独排序弱于 magnitude，风险指导训练还没有正式结果，跨模型家族和真正新的外部确认仍缺。若 E204 能在不损害整体性能的情况下改善难任务，再加一套冻结后的外部确认，论文会从“可靠性审计现象”推进到“能改变训练和复核决策的方法”。这是目前最值得投入的路线。
