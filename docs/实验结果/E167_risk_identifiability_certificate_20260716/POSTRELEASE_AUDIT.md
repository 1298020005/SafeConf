# E167 正式结果后的独立审计

审计日期：2026-07-16

## 结论

E167 v1 的正式结果保持 `FAIL`，不覆盖、不重跑成通过。真实塌缩、合成常数、微小抖动、预测塌缩、magnitude 同序复制和 Wessels 跨 seed 不稳定均按合同被拦截。失败只来自预设条件“12 个非塌缩参考必须全部通过 G2/G3”：Replogle 和 Santinha 没有通过 G2。

这不是 runner 算错，也不能靠降低数字门槛后把 v1 改成通过。审计发现，合同把两个不同命题混在了一起：

1. 上游预测向量是否随任务变化；
2. 风险分数是否有足够分辨率支持某个具体 coverage 的唯一选择。

预测不塌缩不能推出风险分数一定高分辨率，因此原成功条件第 4 条没有逻辑保证。

## 修正规则的边界

后续 E167a 只能作为公开的协议修正，不能冒充独立确认。修正前先提交新合同和 runner，E167 v1 的目录及结果保持不动。

- `G2a 分数非退化`：逐部署批次检查全部有限、至少 2 个唯一值且 population std 大于 `1e-6`。失败才记为分数饱和，相关与选择性评价均停止。
- `G2b coverage 分辨率`：对预先登记的 coverage，记录阈值上方任务数、边界并列组大小和待填位置。并列组大于待填位置时，top-k 集合不唯一；只能报告 tie-aware 期望或上下界，不能给出唯一部署名单。
- `G3a 预测非塌缩`：量化预测向量只有 1 个唯一值或所有坐标变化不超过 `1e-6` 时硬拒绝。
- `G3b 预测分辨率`：保留唯一向量比例作为诊断量；低于原半数阈值记为低分辨率，不再与“完全塌缩”使用同一原因码。
- G4 跨重复稳定性和 G5 与 magnitude 的 weak-order 等价规则不变。

修正后的状态必须区分 `ABSTAIN`、`ASSOCIATION_ONLY`、`TOPK_TIE_AWARE_ONLY` 和 `TOPK_EXACT_ELIGIBLE`。它不会把 Replogle K562 或 Santinha 四个低分辨率批次包装成可唯一选择 top-20%，也不会漏掉 Norman P3/P4 与 Wessels 的预测塌缩。

## 数据边界

本次审计只读取 E167 已发布表和已登记的 E153 任务表；没有打开 TianKampmann2019、DatlingerBock2021 或其他候选确认数据的表达矩阵。修正规则冻结后，仍需在全新数据上一次性确认。
