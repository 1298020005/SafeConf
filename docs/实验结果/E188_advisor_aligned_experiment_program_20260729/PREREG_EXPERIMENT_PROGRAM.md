# E188｜周老师问题对应的正式实验计划

冻结日期：2026-07-29  
性质：实验总计划与停止规则；不读取新的评价结果，不修改 SafeConf 公式。

## 一、周老师原始问题

根据 2026-07-09 组会原始记录，验收对象不是“再多下载几个数据集”，而是下面六件事：

1. 风险最终与哪个预测器、哪一种误差比较；
2. 打分输入能否在目标扰动真值未知时计算，尤其是预测幅度；
3. 随机缺失 pair 是否过于简单；
4. 只给一小部分训练矩阵时是否仍可计算；
5. 整行、整列和背景—扰动双未见时怎样表现；
6. 在一个数据集训练、到另一个数据集直接预测时怎样表现，并分别检查基因和化学扰动。

## 二、现有证据不能代替什么

E187 汇总了 8,196 个矩阵任务实例和 581 个跨数据集任务，但矩阵部分使用两个归纳式参考预测器。它可以验证切分、输入边界和确定性下界，不能写成“端到端 scGPT 与 GEARS 已经在完整难度矩阵中重训”。

E176 已用五个 scGPT 和五个 GEARS 随机种子完成四位供体整行留出，并包含背景与扰动同时未见的靶点；E77 完成单背景下整列未见基因；E84 用 CPA–RDKit 完成化学四象限和不同训练子矩阵；E87/E89 完成化学跨数据集预测。仍缺：

- 同一多背景遗传数据、同一 scGPT–GEARS 合同下的随机 pair、整行、整列、双未见和训练量梯度；
- 基因预测器从一个独立研究直接迁移到另一个研究，而不是只迁移风险分数；
- 证书在这些 setting 中的紧致度、覆盖、预测器有效性和零效应基线同时报告。

## 三、E189：正式遗传扰动笛卡尔实验

### 3.1 数据与模型

- 数据：Primary CD4 Perturb-seq 的四个供体轮换面板 H01–H04；
- 输出空间：冻结 512 基因面板，背景内 log1p 表达差；
- 模型家族：scGPT 与 GEARS，各三个随机种子 3407–3409，共六个成员；
- 训练、验证和查询图沿用 E176 实现与超参数；
- E189 是已经公开真值上的回顾性压力测试，不冒充新的前瞻确认。

### 3.2 每个面板的矩阵

每个面板有两个训练供体、一个验证供体和一个测试供体，每个供体含 Rest、Stim8hr、Stim48hr 三种状态。

从 E176 的 160 个可训练靶点中，只按冻结 SHA-256 顺序划分：

- 120 个 `SEEN_PERTURBATION`；
- 40 个 `UNSEEN_PERTURBATION`。

对每个 seen perturbation，在六个训练背景中固定保留一个 pair 作为 `RANDOM_PAIR` 测试，其余五个背景形成候选训练矩阵。训练支持量依次为每个扰动 1、2、3、5 个背景，构成四级小矩阵。

固定评价集合：

| setting | 背景 | 扰动 | 每面板任务数 |
|---|---|---|---:|
| random pair | 训练中见过 | 训练中见过 | 120 |
| unseen context row | 完整留出测试供体 | 训练中见过 | 360 |
| unseen perturbation column | 训练背景 | 完全未参与拟合 | 240 |
| double unseen | 完整留出测试供体 | 完全未参与拟合 | 120 |

每个支持量、每个面板固定 840 个评价任务；四面板共 3,360 个任务。四种支持量合计 13,440 个任务实例。

### 3.3 真值隔离

数据准备程序根据任务身份拆出两类物理目录：

1. `model_assets/`：只含当前支持量允许的训练效应、验证效应、control、基因面板和训练背景构建的图；
2. `evaluation_truth/`：只含四类固定评价任务的效应向量。

训练程序只接受 `model_assets/`，拒绝包含 `evaluation_truth`、h5ad、loom 或 zarr 的目录。预测文件、模型审计和输入哈希落盘后，评价程序才读取 `evaluation_truth/`。

### 3.4 主终点

每个任务同时报告：

- scGPT RMSE；
- GEARS RMSE；
- 六成员家族 RMS error；
- 六成员最坏误差；
- 家族多样性确定性下界；
- 家族直径下界；
- predicted magnitude；
- zero-effect RMSE；
- 下界紧致度。

按 `(panel, perturbation)` 整簇 bootstrap。主要比较：

1. 四种 setting 下确定性下界违例必须为 0；
2. 随训练支持量增加，模型准确率和证书紧致度怎样变化；
3. row、column、double-unseen 是否比 random pair 产生更多共享错误；
4. scGPT/GEARS 是否至少在有意义比例的任务上优于 zero-effect；
5. 分歧和预测幅度只作诊断，不再以“必须超过幅度”作为方法存亡门槛。

### 3.5 停止规则

- 任一任务下界违反超过 `1e-10`：先判实现失败，不解释生物结果；
- 查询图包含 `y` 或模型目录出现评价真值：整次运行作废；
- 两个架构在某 setting 中均不优于 zero-effect：保留为预测器失准边界；
- 小分歧不得解释为预测安全；
- 不根据 E189 结果更换模型、靶点、基因面板或 setting。

## 四、E190：基因侧直接跨研究预测

E190 在 E189 完成后执行，优先采用 E176 Primary CD4 与 E177 Sunshine 的公共 512 基因轴：

1. 源研究训练 scGPT/GEARS；
2. 目标研究只开放 control、扰动身份和预先规定的基因轴；
3. 目标 prediction release 落盘并提交 Git；
4. 最后打开目标扰动表达；
5. 报告模型与 zero-effect、训练均值基线的胜负比例；
6. 只要缺少目标域校准，就不报告跨研究 conformal 上界。

若两个研究的扰动类型、归一化或基因轴无法形成可审计的共同合同，E190 不做数值拼接，转为使用同实验系列或同技术平台的两个公开研究。

## 五、化学扰动线

化学线不重跑不适用的 scGPT/GEARS。E84、E87 和 E89 已形成 CPA–RDKit 合同：

- 小训练矩阵：25%、50%、75%；
- random pair、unseen context、unseen drug、double unseen；
- sciPlex3→OpenProblems；
- sciPlex3→sciPlex4。

需要新增的只是统一审计表：模型是否胜过 zero-effect、下界紧致度、分歧相对 magnitude 的增量及其失败边界。E87 中两个源域模型对 OpenProblems 的胜出率均为 0，必须作为跨域失败保留。

## 六、投稿门槛

### 可进入方法类二区目标的最低证据

- E189 四面板正式模型笛卡尔实验完成；
- E190 至少一个基因侧直接跨研究预测合同完成，成功或失败均保留；
- 化学 E84/E87/E89 与遗传 E189/E190 分开报告；
- PRESCRIBE、GEARS uncertainty、普通 disagreement 和 conformal 的对象差异写清；
- 全部任务表、模型输入、哈希、失败 setting 和重建脚本公开。

### 冲击更高门槛需要的增量

- 新研究或新实验的事前冻结确认，而不是继续切已经解封的数据；
- 以实验重复噪声或生物学容忍度定义可解释的误差阈值；
- 用证书决定复核任务后，获得真实的后续实验或机制验证；
- 证明方法带来的决策收益，而不只报告相关系数和零违例。

期刊录用不是实验字段。这里的门槛表示可控制的证据完整性，不写成“保证录用”。
