# SafeConf 下一阶段实验矩阵

更新时间：2026-09-12

目标是用较少的重复计算关闭真正影响方法论文可信度的问题。实验数量按
“扰动类型 × 分布偏移 × 模型结构 × 随机种子 × 评价端点”展开，所有负结果保留。

## P0｜正在执行

### E205：第二模型结构冻结验证

- 数据：K562、RPE1、HepG2、Jurkat；
- 设置：每次完整留出一个细胞背景；
- 模型：TxPert-Exphormer；
- 重复：4 个背景 × 4 个随机种子，共 16 个正式模型；
- 对照：已完成的 TxPert-GAT 四种子；
- 冻结路由：0.80 幅度秩 + 0.20 SafeConf 秩；
- 主要端点：任务级 family RMSE 的 Spearman 和 20% 复核效用；
- 关键检验：跨结构分歧在控制幅度后是否仍提供信息，SafeConf-M 是否相对幅度有
  一致增量；
- 当前状态：两张 GPU 同时训练 K562/seed1 与 RPE1/seed1，其余 14 项自动排队。

### E207：固定公式历史压力测试

- 遗传扰动：E153 八研究 + E187 三研究难度阶梯；
- 细胞因子：E187-Cui；
- 化学边界：E118 三来源；
- 结果：遗传排序有稳定但较小的增量，固定预算效用未确认；细胞因子和化学不进入
  统一公式。实验已完成并独立复核。

## P1｜E205 完成后立即执行

### E205-A：预测前封存与泄漏审计

1. 16 个 checkpoint 逐一检查轮数、模型结构、状态张量、有限数和 SHA-256；
2. 只对零化目标表达的 blind view 推理；
3. 先写出并哈希 16 份预测、每个背景的 matched controls 和任务顺序；
4. 计算幅度、同家族分歧、跨家族质心分歧、原 SafeConf 和 SafeConf-M；
5. 将全部预测侧文件推送留痕后，才调用已释放的 E201 真值做 E205 评价。

### E205-B：跨结构和逐背景评价

完整报告：

- GAT、Exphormer 各自误差；
- 同结构跨种子分歧、跨结构质心分歧、预测幅度、原 SafeConf、SafeConf-M；
- RMSE、Pearson-delta、rank/方向误差；
- 5%、10%、20%、30% 复核预算；
- 四背景宏平均与逐背景结果；
- perturbation-cluster bootstrap；
- 控制幅度后的偏相关；
- 任何结构冲突和负增量。

### E206 数值并列复核

E207 已发现线性浮点运算可能伪拆理论并列。E206 需要在不改变 0.80/0.20 和输入的
前提下，使用 `4:1` 平均秩表达式重算权重曲线、留一背景结果和 5,000 次簇自举；
旧文件哈希和变化量必须登记。

## P2｜外部性与直接竞品

### 新外部遗传扰动确认

选择一个没有参与 E206 权重选择、没有用于 E207 压力测试、且能提供对照细胞、明确
单基因扰动标签和可复现上游预测的数据。下载后先做字段与任务可用性审计，再冻结：

- 训练/校准/测试的扰动簇边界；
- 上游模型与随机种子；
- 0.80/0.20 公式和停止规则；
- 主误差和复核预算；
- 真值访问时点。

若候选数据只有调控元件、多基因组合或没有未扰动对照，则登记为不兼容，不把它改名
成单基因验证。

### 同合同强基线

在同一任务、同一预测、同一误差上比较：

1. 随机排序；
2. 预测幅度；
3. 同结构 seed 分歧；
4. 跨结构质心分歧；
5. 原 SafeConf；
6. SafeConf-M；
7. 可合法接入时的模型原生不确定性或 PRESCRIBE/CPA uncertainty。

不同方法若审计的是不同预测器，必须标成 system-level comparison，不能写成同一预测
上的直接胜负。

## P3｜投稿前压力测试

- 输出基因空间：全共同基因、差异表达基因、通路活性三种端点；
- 误差定义：RMSE、相关性损失、方向/rank 和分布距离；
- 复核预算：5%–30% 完整曲线与 AURC；
- 数据量：25%、50%、75%、100% source 数据；
- 缺失方式：随机缺 pair、未见扰动、未见背景、双未见；
- 稳定性：逐数据集、逐背景、逐种子、leave-one-dataset-out；
- 效率：特征计算时间、显存/内存、相对上游训练成本；
- 失败关闭：分数常数、成员输出合同不一致、校准覆盖失败、跨结构冲突。

这些项目中已有结果的直接复用现有冻结表，不重新训练；缺少的再补。完成很多相似
实验不会自动提高证据等级，新的模型结构和真正未用过的外部数据优先级最高。

## 投稿充分性门槛

进入正式写作前至少满足：

1. E205 16 个模型、预测封存和评价全部完成；
2. E206 数值并列修正不改变 0.80/0.20 的基本判断，或如实降级；
3. 一个真正未参与方法开发的外部遗传数据完成冻结确认；
4. 同合同强基线与直接竞品比较完整；
5. 理论证书、经验路由和适用边界明确分开；
6. 所有主数字可由提交的 CSV、哈希和复现入口重算。

满足这些条件只能说明方法论文证据链达到可投稿水平，不能保证某个分区期刊录用。
