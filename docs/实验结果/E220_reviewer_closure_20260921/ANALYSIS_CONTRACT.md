# E220：同口径基线、实际预测误差和分量消融

登记日期：2026-09-21。此时 E205 结果已经公开。本实验属于事后稳健性分析，不是新的盲测，也不能重新选择 E205/E208 主公式。

## 要解决的问题

1. E205 固定组合先在每个目标背景内计算百分位，原汇总基线却使用原始幅度。跨背景合并时，增益可能同时包含尺度处理收益。增加同背景百分位幅度基线，分离这两部分。
2. 家族均方根误差包含成员分歧项。另以四种子平均预测、跨结构平均预测自身的误差评价，检查实际采用的预测结果是否也能更好地筛选。
3. 与简单的“幅度＋单项特征”比较，逐项删除分量，明确五项证据是否都必要。
4. 分别报告背景等权和全部任务合并的结果，避免跨背景分配复核预算的收益冒充同背景筛选收益。

## 输入和隔离

唯一数据输入为已公开的 `../E205_cross_family_disagreement_20260830/formal_evaluation/E205_TASK_METRICS.csv`；程序记录文件 SHA-256。

不读取原始表达矩阵、E208 测试数据或在训模型。统计仅使用 CPU。来源数据的风险分、模型误差、任务清单不修改。

全部 2,008 个任务先计算背景内排名；主分析沿用原来的 `primary_ge30`（1,808 个任务），低细胞数任务保留在全任务敏感性分析中。每个背景的任务数从 CSV 读取，不写死为 502。

## 固定比较

Exphormer 组使用原 Exphormer 幅度与五项标准化分量。比较：原始幅度、背景内幅度百分位、原 SafeConf、封存的 4:1 组合、幅度与每个单分量的 4:1 组合、五项逐一删除后的 4:1 组合、历史证据组、预测侧证据组、来源平均效应幅度基线。

跨结构组使用注册家族幅度，与封存的整背景路由、架构感知路由、非负学习路由、证书优先路由比较；额外报告幅度与跨结构分歧的简单 4:1 组合。

敏感性权重预列为 0、0.05、0.10、0.20、0.35、0.50，全部公开。不得挑最好的权重作为新主方法。新方法如需采用其他权重，须在开发资料上固定后另找独立验证。

## 评价口径

- Exphormer 组：`family_rms_error` 与 `family_centroid_rmse`。
- 跨结构组：`registered_family_rms_error` 与 `registered_family_centroid_rmse`。
- 主解释为四背景等权平均；合并结果单列，表示跨背景统一分配预算的不同问题。
- 指标：Spearman、20% 预算归一化复核效用、20% 预算错误总量抓取率、剩余 80% 预测的平均误差、归一化风险—覆盖曲线面积。
- 比较基线统一为对应模型家族的背景内幅度百分位；另外保留原始幅度行以复现尺度差异。
- 2,000 次配对扰动条件簇自助法，同一扰动在不同背景一起抽样。报告四背景各自、背景等权、合并三类区间。这些区间只描述当前四背景与观察到的扰动集合，不能当成随机新背景的总体保证。
- 主要解释对象预先固定为封存 SafeConf-M 相对同口径幅度的宏平均增量。消融和多公式的区间属于探索性区间，不进行“任一显著即成功”的筛选。
- 分数并列采用任务 ID 哈希打破，同一重复抽样中的副本采用相同抽样编号保证所有方法使用同一规则。

## 完成条件

输出全部比较、各背景分解、配对区间、参数敏感性和三张白底图；独立检查正式分数能复算、原始幅度与其百分位在单背景内排序相同、簇抽样保留跨背景关系、质心误差恒等式正确。结果无论正负都提交。
