# E217 架构感知路由开发合同

冻结时间：2026-09-20，E205 目标真值打开之前。

## 目的

解释既有实验中修正权重为何不一致，并把“模型家族结构”作为预先可观察的分层因素。

## 开发数据

- E153：八研究、3,465 行、34 个 fold；scGPT/GEARS 跨结构模型对；
- E201：四个整背景留出目标、1,808 个主任务；同一 TxPert-STRING-GAT 结构的四个随机种子。

两者均已解封，只能用于方法开发。E205 与 E208 的目标真值不允许参与选参。

## 候选公式

所有信号先在部署批次内转成百分位：预测幅度为 \(m\)，SafeConf 为 \(s\)，模型分歧为 \(d\)。

\[
R=m+\lambda_s[s-m]_+ +\lambda_d[d-m]_+,
\qquad [x]_+=\max(x,0).
\]

参数网格固定为 \(\{0,0.125,0.25,0.50,0.75,1.0\}^2\)。跨结构参数依次按以下规则选择：

1. Spearman 正向研究数最多；
2. 5%、10%、20%、30% 四个预算下正向“研究×预算”单元最多；
3. 四预算平均效用增量最高；
4. 平均 Spearman 增量最高；
5. 仍并列时取修正较小的参数。

同结构种子家族使用 E212 已登记的弱修正 \(\lambda_s=0.125,\lambda_d=0\)。

## 验证纪律

- E217 的全部结果标为开发结果；
- E205 解封前把跨结构公式写入风险表和评价脚本；
- E205 逐目标和宏平均同时报告，不能删除表现差的目标；
- E205 后不得重新调整 \(\lambda_s\) 或 \(\lambda_d\)；
- 排序结果与 SafeConf-Cert 证书结果分别报告，不能互相替代。
