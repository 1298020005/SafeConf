# E218｜多假设统一验证
本实验在 E153 八研究上每次留出整个研究，学习型方法只用其余七个研究选参。E201 只用于检查跨结构规则误用到同结构种子时会发生什么。E205/E208 真值未读取。
## 关键结果
- 候选方法：12 类；E153：3465 任务、8 研究、34 个 fold。
- 最好的留一研究方法：`lodo_nonnegative`，平均 ΔSpearman=+0.0247，95% 研究自举区间 [+0.0140, +0.0338]。
- 冻结跨结构规则：平均 ΔSpearman=+0.0234，95% 区间 [+0.0149, +0.0311]。
- 同结构 E201 弱修正：平均 ΔSpearman=+0.0072；误用跨结构强修正：-0.0107。
