# E214 基准合同｜风险路由计算开销与规模扩展

冻结日期：2026-09-18

E214 只测 SafeConf 风险路由层，不把上游 TxPert、GEARS 或湿实验耗时算入方法耗时。
基准过程包含五个已经在内存中的任务级输入、批内标准化、平均秩转换、固定 4∶1 融合和
单向 0.25 修正。它回答“预测结果已经存在后，额外质检层需要多少时间和内存”。

## 固定规模

- 单批任务数：1,000、10,000、100,000、1,000,000、5,000,000；
- 每个规模重复 5 次，报告中位数与四分位范围；
- 并行吞吐：固定 32 个批次，每批 250,000 个任务，worker 数为 1、2、4、8、16、32；
- 随机种子：20260918；
- 机器信息、CPU、内存、Python、NumPy 与 SciPy 版本全部写入状态文件。

## 输出

- 单批延迟、每秒任务数和输入/输出数组理论字节数；
- 多进程端到端吞吐和相对单 worker 加速比；
- 白底 SVG、PDF、300 dpi PNG；
- 不把本机吞吐外推为其他硬件的保证，不与未实测方法比较速度。
