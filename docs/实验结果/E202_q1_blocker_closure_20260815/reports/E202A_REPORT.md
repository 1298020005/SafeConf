## 总表

见 [`../tables/E202A_SETTING_COMPARISON.csv`](../tables/E202A_SETTING_COMPARISON.csv)。

用一句话读：

1. **严格未见基因 + PRESCRIBE 官方分数**：分数没有任务间方差，统计不可估计。
   论文里应写官方置信度在该 OOD 上退化，系统应 abstain。不能写“我们赢了
   PRESCRIBE”，也不能把未定义相关写成 0。
2. **K562 内未见基因 + 公开 TxPert 家族**：分歧可以排序，magnitude 的区间跨 0。
   这是目前最干净的正结果，但只有一个细胞系、一种未见方式。
3. **K562 整背景留出**：风险量仍与误差相关，但固定 20% 预算上 magnitude
   明显更强。这是必须保留的负结果，也是 E201 存在的理由。
4. **双未见 / 跨研究 RPE1**：经验排序不能当默认开启。RPE1 按事前相关门槛
   已经是 ABSTAIN，尽管 20% utility 点估计为正。
5. **四背景整列**：还没有数字。

## 这对一区主张的直接约束

主句只能是：

> 在已验证的 setting 里，预测后风险合同可以辅助有限预算复核；在分数退化、
> 相关门槛未过、或 magnitude 稳定更强的 setting 里，必须明确停用经验排序。

任何“SafeConf 普遍优于学习式不确定性和幅度基线”的句子，都会被这张表证伪。
