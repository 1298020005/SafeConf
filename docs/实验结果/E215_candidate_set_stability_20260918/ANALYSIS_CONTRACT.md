# E215 分析合同｜候选任务集合变化下的路由稳定性

冻结日期：2026-09-18

证据身份：已解封八研究数据上的部署稳定性审计，不是新的外部确认。

SafeConf-M 使用同一部署批次内的百分位秩。当待排序任务清单改变时，幅度秩和 SafeConf
秩的相对间距也会改变。E215 检查这种“候选集合依赖”是否会显著改变最终排序。

## 冻结设计

- 输入与哈希同 E213：3,465 个任务、8 个研究、34 个 outer folds；
- 公式：固定 4∶1 SafeConf-M、单向 0.25 修正；
- 每个 fold 按扰动条件无放回抽取 25%、50%、75%；
- 每个比例 1,000 次，固定种子 20260918；
- 在抽样任务上重新计算批内秩，与完整候选集合计算后再限制到同一抽样任务的分数比较；
- 24 个 CPU worker 并行；原始抽样结果只保存在数据盘，仓库保存汇总、哈希、报告和图。

## 指标

- 重算分数与完整集合分数的 Spearman；
- 两种分数 top-20% 任务集合的 Jaccard；
- 重算前后与真实误差 Spearman 的差；
- 重算前后 20% 复核效用的差。

排序稳定性和 top-20% 重合度越高越好；后两项接近 0 表示候选集合变化没有系统性改变
评价。所有研究和抽样比例完整报告，不根据结果寻找新的比例或公式。
