# 人工识别记录：Tahoe 之外还有哪些数据真的能用

这份不是自动清单，是按字段逐个看过后的判断。重点看四件事：有没有扰动标签、有没有细胞背景、有没有跨域维度、能不能变成 SafeConf 后续实验。

## 1. 已经完整在本地的数据

本地现有 83 个可读 h5ad，来源分三块：

- scPerturb Zenodo：54 个文件，RNA / protein / multimodal 都有。
- scPerturBench perturbation generalization：17 个文件，偏“扰动泛化”。
- scPerturBench cellular context generalization：12 个文件，偏“细胞背景泛化”。

这三块已经完整，不需要重新下载。它们已经覆盖：

- 基因单扰动：45 个文件。
- 基因组合扰动：18 个文件。
- 化学单扰动：8 个文件。
- 化学组合扰动：6 个文件。
- 调控元件/增强子相关扰动：6 个文件。

## 2. 字段核对后，最值得马上用的非 Tahoe 数据

### 2.1 KaggleCrossCell / KaggleCrossPatient

位置：

- `extra_official/cellular_context_generalization/KaggleCrossCell.h5ad`
- `extra_official/cellular_context_generalization/KaggleCrossPatient.h5ad`

字段情况：

- `donor_id`：3 个 donor。
- `cell_type`：KaggleCrossCell 有 5 类，KaggleCrossPatient 有 6 类。
- `perturbation`：11 类，包括 control 和多种小分子。
- `dose_uM`：1.0 与 14.1 两个剂量。
- `batch / plate_name`：有批次信息。

判断：

这组非常适合回答老师说的“跨细胞类型、跨病人/供体”。它的任务结构清楚，体量不大，适合作为 OpenProblems 下载完成前的快速验证集。

可做实验：

- cell-type holdout：留出 B cells / Myeloid / CD8 等细胞类型。
- donor holdout：留出 Pat0 / Pat1 / Pat2。
- compound holdout：留出某几个小分子。
- dose-aware audit：同一小分子不同剂量下，风险分数是否更容易识别高误差任务。

### 2.2 crossPatient

位置：

- `extra_official/cellular_context_generalization/crossPatient.h5ad`

字段情况：

- `patient`：6 个病人。
- `perturbation`：control、Etoposide、Panobinostat。
- `batch`：9 个 patientBatch。

判断：

这是很干净的“病人域泛化”数据。虽然扰动种类少，但病人差异明确，适合检查 SafeConf 的 context support 是否能识别跨病人的不稳定预测。

可做实验：

- patient holdout：每次留一个 patient。
- drug transfer：Etoposide 与 Panobinostat 分开看。
- batch sensitivity：看高风险是否被 batch 混淆。

### 2.3 crossSpecies

位置：

- `extra_official/cellular_context_generalization/crossSpecies.h5ad`

字段情况：

- `condition1`：mouse、rabbit、rat、pig。
- `condition2`：LPS / control。
- `condition3`：0、2、4、6 小时。

判断：

这是域偏移最强的一组。它不一定适合直接和 gene/drug 扰动放进同一个主表，但很适合作为“SafeConf 是否能发现超出训练分布的任务”的补充实验。

可做实验：

- species holdout：训练三种物种，测试第四种。
- time holdout：留出 LPS 某个时间点。
- domain shift stress test：专门作为失败边界实验。

### 2.4 TCDD

位置：

- `extra_official/cellular_context_generalization/TCDD.h5ad`

字段情况：

- `celltype`：6 类肝脏相关细胞。
- `perturbation`：TCDD / control。
- `dose`：9 个剂量。

判断：

这组是很好的剂量反应数据。扰动只有 TCDD 一个，但 dose 和 cell type 很完整，适合做“同一化合物在不同剂量/细胞类型下，风险为什么变化”的解释型实验。

可做实验：

- dose holdout：留出某些剂量。
- celltype holdout：留出某个肝细胞类型。
- monotonicity audit：剂量升高时误差和风险是否同步变化。

### 2.5 sciplex3 / sciplex3_A549 / K562 / MCF7

位置：

- `extra_official/cellular_context_generalization/sciplex3.h5ad`
- `official_generalization/sciplex3_A549.h5ad`
- `official_generalization/sciplex3_K562.h5ad`
- `official_generalization/sciplex3_MCF7.h5ad`
- `official_scperturb/SrivatsanTrapnell2020_sciplex3.h5ad`

字段情况：

- `cell_line`：A549、K562、MCF7。
- `perturbation`：上百个药物。
- `target / pathway`：药物靶点和通路。
- `dose_value`：多剂量。
- `SMILES`：部分 benchmark 文件有化学结构。

判断：

这是目前 chemical 方向最稳的一组。它比 Tahoe 小很多，字段也更容易读。适合作为 OpenProblems 和 Tahoe 之间的桥：先在 sciplex3 上把逻辑跑通，再扩大到 Tahoe / OpenProblems。

可做实验：

- drug holdout：留出某些药物。
- target holdout：留出某类药物靶点。
- cell-line holdout：A549 / K562 / MCF7 互相外推。
- dose holdout：低剂量训练，高剂量测试。

### 2.6 Norman

位置：

- `official_generalization/Norman.h5ad`

字段情况：

- `perturbation`：227 类。
- 包含单基因和组合基因扰动，例如 `CEBPE+RUNX1T1`。

判断：

这是组合基因扰动的核心数据。它不解决 chemical 问题，但能回答“SafeConf 在组合扰动上是否只会看 support，还是能识别模型分歧和组合外推风险”。

可做实验：

- single-to-combo：单基因训练，组合测试。
- combo holdout：留出特定组合。
- gene overlap split：训练集中出现过 A 和 B，但没出现过 A+B。

### 2.7 Replogle

位置：

- `official_generalization/Replogle_RPE1essential.h5ad`
- `official_generalization/Replogle_K562essential.h5ad`
- `official_scperturb/ReplogleWeissman2022_K562_gwps.h5ad`

字段情况：

- RPE1essential：约 17.4 万细胞，1331 个扰动。
- K562 gwps：约 198.9 万细胞，是大规模基因扰动压力测试。

判断：

Replogle 是基因扰动方向的大规模支撑。它适合做规模、support 稀疏性、低频扰动失败这些问题。K562 gwps 很大，适合后面做扩展，不适合作为今天就跑的第一批。

可做实验：

- low-support perturbation audit。
- essential gene vs non-targeting control。
- K562 / RPE1 跨细胞系泛化。

### 2.8 Papalexi / Frangieh

位置：

- `official_generalization/Papalexi.h5ad`
- `official_generalization/Frangieh.h5ad`
- `official_scperturb/PapalexiSatija2021_*`
- `official_scperturb/FrangiehIzar2021_*`

字段情况：

- Papalexi：基因扰动，有 RNA 和 protein 文件。
- Frangieh：基因扰动，`condition` 包含 IFNγ、Co-culture、Control。

判断：

这两组适合做 multimodal / immune context 的补充说明。主线不必一开始放太重，因为 SafeConf 当前主任务还是预测误差质检。但它们能证明项目不只盯 RNA 单一输出。

可做实验：

- RNA-only risk 与 protein-side phenotype 是否一致。
- immune condition holdout。
- IFNγ / Co-culture 条件下的失败边界。

### 2.9 Gasperini / JoungZhang

位置：

- `official_scperturb/GasperiniShendure2019_atscale.h5ad`
- `official_scperturb/GasperiniShendure2019_highMOI.h5ad`
- `official_scperturb/GasperiniShendure2019_lowMOI.h5ad`
- `official_scperturb/JoungZhang2023_atlas.h5ad`
- `official_scperturb/JoungZhang2023_combinatorial.h5ad`

字段情况：

- Gasperini：CRISPR 调控元件/增强子相关，K562，guide 信息很丰富。
- JoungZhang：字段里 `perturbation_type` 显示 ORF overexpression，不能简单说成“增强子扰动”。

判断：

Gasperini 可作为 regulatory/enhancer 主代表。JoungZhang 更适合放在 regulatory/overexpression 扩展，不要在汇报里硬说成增强子。

可做实验：

- regulatory perturbation holdout。
- guide-level vs target-level risk。
- highMOI / lowMOI 差异。

## 3. 新补的 OpenProblems / NeurIPS 2023

位置：

- `mega_external/OpenProblems_NeurIPS2023_single_cell_perturbations/`

已经确认的官方资源：

- OpenProblems task repository。
- NeurIPS 2023 / Kaggle single-cell perturbations。
- S3 公开目录共约 53.1 GB。

内容包括：

- processed DGE：`de_train.h5ad`、`de_test.h5ad`、`id_map.csv`。
- 原始 Kaggle DGE。
- 单细胞表达训练集。
- scRNA counts：原始、processed、reannotated。
- multiome：RNA + ATAC。
- pseudobulk / pseudobulk_by_cell_type。
- MoA annotations：小分子作用机制注释。

当前识别到的 `de_test.h5ad` 字段：

- 151 个任务。
- `cell_type`：B cells、Myeloid cells。
- `sm_name / SMILES / sm_lincs_id`：小分子信息。
- `split`：private_test。
- layers 包含 `logFC`、`P.Value`、`adj.P.Value`、`is_de` 等差异表达信息。

判断：

OpenProblems 是 Tahoe 之外最值得补的新数据。它能把 chemical setting 从 Tahoe 扩展到 PBMC、多供体、多细胞类型、多模态 baseline，并且有比赛式 held-out 任务。

等下载完整后，优先做：

- chemical held-out smoke：先用 processed DGE。
- cell-type holdout：B cells / Myeloid 等。
- donor holdout：需要 raw 或 single-cell obs 完整后确认。
- compound/MoA holdout：按药物或 MoA 类别留出。
- multiome context：用 baseline ATAC/RNA 解释不同 cell type 对药物反应的差异。

## 4. 当前不急着再找的数据

目前不建议再盲目扩到 CMap / LINCS L1000、Cell Painting、RxRx 这类数据。原因很简单：

- 它们和单细胞转录组扰动预测的接口不直接一致。
- 加进去会变成新课题，不会马上回答老师的问题。
- 当前 scPerturb + scPerturBench + Tahoe + OpenProblems 已经覆盖基因、组合、药物、剂量、细胞类型、病人、物种、多模态、调控元件。

下一步更有价值的是把现有数据拆成清楚的实验，而不是继续堆数据名。
