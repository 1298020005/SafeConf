# 数据线总览：现在手里到底能讲多少条线

这里的“数据线”指能独立支撑一个实验问题的方向，不是简单数文件。判断标准很朴素：字段里必须真的有对应信息，能拆 split，能解释 SafeConf 为什么有用或为什么失效。

## 1. 第一层：已经能立刻开跑的主线

### 1.1 OpenProblems / NeurIPS 2023 PBMC 小分子预测线

位置：

- `mega_external/OpenProblems_NeurIPS2023_single_cell_perturbations/data/workflow_resources/neurips-2023-kaggle/`
- `mega_external/OpenProblems_NeurIPS2023_single_cell_perturbations/data/workflow_resources/neurips-2023-data/`

已经完整的关键文件：

- `de_train.h5ad`：614 个训练任务，18211 个基因。
- `de_test.h5ad`：255 个测试任务，18211 个基因。
- `id_map.csv`：测试任务映射。
- `pseudobulk.h5ad`：3318 个 pseudobulk 样本，21265 个基因。
- `prediction.h5ad / score.h5ad`：官方 workflow 的参考输出，可用于理解 benchmark 接口。

字段：

- `cell_type`：训练有 6 类，包括 NK、CD4、Treg、CD8、B、Myeloid；测试主要是 B cells 和 Myeloid cells。
- `sm_name / sm_lincs_id / SMILES`：小分子名称、LINCS 编号和化学结构。
- `dose_uM`：主要是 1.0，也有 0.1。
- `split`：train、control、public_test、private_test。
- `donor_id`：在 pseudobulk 和 single_cell_obs 中可见 3 个 donor。

能回答的问题：

- SafeConf 在独立 PBMC 小分子 benchmark 上是否还能筛出高误差任务。
- cell type 外推是否比普通随机划分更难。
- chemical structure / SMILES / MoA 信息能不能作为风险解释的一部分。
- 官方 public/private split 下，风险分数是否能提前指出不可靠任务。

建议实验：

1. OpenProblems chemical smoke：mean baseline、magnitude、SafeConf-style risk 三组先跑通。
2. B cells / Myeloid test：看未充分覆盖 cell type 时风险是否升高。
3. compound holdout：按 `sm_name` 留出药物。
4. MoA holdout：等 `moa_annotations.csv` 完整后按机制类别留出。
5. donor holdout：等 raw/single-cell 层稳定后做。

## 9. 数据线怎样落到实验问题

这部分给汇报用。不要把数据集名字堆给老师，按问题讲会更清楚。

| 实验问题 | 可用数据 | 能形成的结果 |
| --- | --- | --- |
| 换药物后还能不能判断风险 | OpenProblems、Tahoe、sciplex3、McFarland | compound holdout、MoA holdout、drug-level error enrichment |
| 换细胞类型/细胞系后是否失效 | OpenProblems、sciplex3、KaggleCrossCell、Tahoe、McFarland | cell-type / cell-line holdout，检验 context support |
| 换病人/供体后是否失效 | OpenProblems pseudobulk、KaggleCrossPatient、crossPatient、Shifrut | donor/patient holdout，检验真实个体差异 |
| 剂量改变后是否还能稳 | sciplex3、TCDD、McFarland、KaggleCrossCell | dose holdout、dose-stratified error |
| 组合扰动是否更难 | Norman、Wessels、Lotfollahi、Sunshine | single-to-combo、single vs dual、多扰动复杂度 |
| 调控元件/标签稀疏会不会更难 | Gasperini、XieHon、JoungZhang | guide-level / target-level risk、batch audit |
| RNA 之外的表型能不能互相验证 | Papalexi、Frangieh、OpenProblems multiome | RNA-protein consistency、multiome context |
| 时间、物种、疾病背景是否造成 domain shift | crossSpecies、Lara、Tian、Santinha、McFarland | species/time/disease/neuron transfer |
| 原始单细胞层是否支持 pseudobulk 结论 | Tahoe raw、OpenProblems raw | shard / plate / cell-cycle / donor audit |

## 10. 最适合给老师汇报的顺序

我建议汇报时不要把 20 条线全铺开，会散。可以这样讲：

   - Tahoe raw：100M 原始层，drug、cell line、MoA、SMILES、cell cycle、plate。
4. 接下来不盲目堆数据，按 6 个实验问题推进：
   - chemical independent benchmark：OpenProblems + sciplex3 + Tahoe。
