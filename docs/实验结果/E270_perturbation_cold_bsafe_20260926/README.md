# E270｜按扰动留出下的 Bsafe 与监督错误历史

E270 是 E267 的干净特征版本。每个扰动整体按固定哈希放入五个桶，评估桶中的扰动在风险训练集中没有历史错误标签；比较 `Bsafe`（支持数、背景相似度）以及加入同一预测器过去错误历史 `E` 的监督风险层。

## 汇总线索

- `P+Bsafe`：三项研究×三种预测器共 9 个组合均高于 `M`，宏平均 Utility@20 差值约 `+0.3921`。
- `P+Bsafe+E`：9/9 组合为正，宏平均差值约 `+0.5745`。
- `P+Bsafe+E_dynamic`：9/9 组合为正，宏平均差值约 `+0.6269`。

这些是回顾性开发结果，B 字段仍沿用旧折合同，不能当全新的盲测。E 需要同类任务的过去错误标签，因此是监督风险层，不是冷启动分数。
