# E216 正式评价实现修正 01

## 发生了什么

首次授权运行在读取正式测试表达后、写出任何结果文件前，于基因簇自举阶段停止。原实现从全部基因中整体重抽；在确定性随机序列的某一次抽样中，至少一个“细胞状态 × 刺激条件”分组缺失或只剩常数排名，因此该组 Spearman 无定义，程序按失败退出。

首次运行没有生成任务结果、状态结果、自举结果、证书曲线或正式状态文件，也没有据此查看或筛选效应方向。

## 修正内容

1. 仍以扰动基因为整簇重抽，保留同一基因在四个细胞状态中的关联。
2. 在 IFNG、INS、TGFB 三个刺激条件内分别进行有放回抽样，保持每次重抽都覆盖全部 12 个评价状态。
3. 极少数仍产生常数排名或无定义效用的抽样直接作废，继续使用同一固定随机种子，直到获得预注册的 10,000 个有效重复。
4. 输出同时记录有效重复编号 `draw` 和原始尝试编号 `attempt`，便于复核跳过次数。

## 未改变的内容

- 224 个任务及 4,000 个基因不变。
- 五个上游预测成员和跨结构权重不变。
- SafeConf、预测幅度、SafeConf-M 4:1 组合及证书阈值不变。
- 主指标、20% 复核预算、置信区间、通过门槛和 10,000 次有效重复不变。
- 没有根据正式结果增删数据、改分数、改权重或改终点。

本修正处理的是自举抽样的可计算性，不改变待检验科学假设。修正代码和本说明须先提交并推送到双远程，再重新运行正式评价。
