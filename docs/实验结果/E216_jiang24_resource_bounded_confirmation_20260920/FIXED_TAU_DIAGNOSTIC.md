# E216 固定阈值证书诊断

## 证据身份

本诊断在 E216 正式结果释放后运行，因此不改变 E216 的预注册主检验：SafeConf-M 相对预测幅度的外部排序增量仍为 `NOT_SUPPORTED`。

这里使用的绝对 RMSE 阈值不是根据 E216 结果挑选。完整阈值网格来自 2026-09-15 已提交的 E211：`0.01, 0.015, 0.02, 0.025, 0.03, 0.04, 0.05, 0.06, 0.07, 0.08, 0.10, 0.15, 0.20, 0.30`。本诊断回答的是另一个问题：当外部上游模型整体失格时，真值不可见的跨结构分歧下界能否正确触发停止。

## 结果

| 误差容忍度 τ | 提前确认高风险 | 解盲后真实高风险 | 假证书 | 召回率 |
|---:|---:|---:|---:|---:|
| 0.05 | 224/224 | 224/224 | 0 | 100% |
| 0.10 | 224/224 | 224/224 | 0 | 100% |
| 0.15 | 224/224 | 224/224 | 0 | 100% |
| 0.20 | 142/224 | 224/224 | 0 | 63.39% |
| 0.30 | 0/224 | 224/224 | 0 | 0% |

在 `τ≤0.15` 的既有阈值下，系统在不读取测试扰动真值的情况下拒绝全部 224 个任务；解盲后这些任务的注册家族 RMS 误差确实全部高于阈值。`τ=0.20` 时下界只签发 142 个高风险证书，剩余 82 个应保持 `UNKNOWN`，不能解释为安全。

## 数值复核

从封存的五个 float32 成员预测重新计算家族质心、分歧下界和家族 RMS 误差，并使用 long double 完成恒等式复核：

- 最大绝对恒等式残差：`1.2875×10⁻¹⁹`；
- 下界越过真实家族 RMS 误差：0/224；
- 下界紧致度中位数：0.61875；
- 固定 E211 阈值网格上的假证书总数：0。

原正式状态中的 200 个恒等式失败来自 float32 家族质心与 float64 分歧之间约 `10⁻¹⁰` 的序列化残差，以及过严的 `10⁻¹¹` 量级容差。高精度重算确认数学恒等式和下界均未失败；预注册的排序与效用判定不作改判。

## 可以写入的结论

E216 支持 SafeConf-Cert 的失败关闭用途：当多个不同结构的上游预测器相互分歧已经超过应用容忍度时，可以在没有目标真值的情况下确定“注册模型家族的 RMS 误差必然超过该容忍度”，从而停止自动放行。

它不支持以下表述：

- SafeConf-M 在 Jiang24 上比预测幅度更会排序；
- 任一指定单模型的误差被下界直接证明；
- 未签发证书的任务已经安全；
- 本次资源受限模型具备合格的扰动预测能力。
