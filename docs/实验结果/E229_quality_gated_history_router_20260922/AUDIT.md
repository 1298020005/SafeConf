# E229暂停与E228解释更正

2026-09-22。本轮没有E229有效结果；首次运行因未把`n_source_contexts`纳入输入列而失败。后续修补又会重复`dispersion_imputed`列；检查中还发现：

1. MDH输出为拟合的误差百分位，M为原始表达变化幅度，不能直接拼接。已改成同批次百分位分支并增加实际单元测试；旧的“字符串等于自身”测试不能作为验收证据，已替换。
2. 更重要的是E228只隔离了评分器误差列。训练评分器时使用的其他目标背景特征，其历史来源包括外层目标背景；其上游预测器也可能在该背景训练。仅删除外层误差列，不足以保证整个系统从未见过外层背景的扰动表达。
3. E228协议写相对M，执行门用原始幅度；本次二者排序恰相同，因此数字未改变，但仍记录协议偏差。协议文件在运行前写出、与结果一起提交，没有单独预运行Git提交；不能称为外部注册。

E228的数值保留，只能称“固定历史表上的评分器层目标留出诊断”。不能当作无泄漏跨背景结果，更不能新增一个有效外部数据集。E201原先每个目标自己的盲态协议不因这个后续评分器错误而自动失效，两层问题须分开。

E229运行器现明确拒绝运行，等待全局外层目标隔离数据。可测试的门函数不意味着性能已验证。

可执行替代：E230不训练跨目标误差评分器；在每个目标自己的已冻结源数据视图内，真实抽样历史细胞和来源背景，保持预测/误差/任务不变。它检验历史库容量机制，仍属于开发实验。未来训练评分器时需要按全局外层切分重建上游和参考库，或明确只验证同研究内本地校准场景。
