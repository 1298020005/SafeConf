# E229：历史证据质量门控

登记：2026-09-22，在读取E229结果前固定。E229不重训上游预测器，沿用E201目标背景留出。

## 目的

E228显示历史字段在RPE1/hepg2方向有帮助、在K562/jurkat方向可能伤害排序。E229检验一个不读取测试误差的明确规则：只有历史来源完整时才启用历史补充，否则退回幅度基线。

## 固定规则

每个外层目标背景使用另外三个背景的已知误差训练同一MDH岭回归（与E228完全相同，alpha=10）。留出任务满足下列两个条件才用MDH预测分数：

1. `n_source_contexts == 3`（三个可用来源背景均覆盖）；
2. `dispersion_imputed == False`（跨背景离散度是实际观察值，不是预设中位数填补）。

否则使用原始预测幅度M。规则只看任务输入的历史覆盖字段，不使用留出误差、效用或结果后调阈值。全部四个目标背景和全部任务保留。

## 评价

报告M、无门控MDH、门控分数三者的Spearman和10%/20%/30%复核效用。主门控结果在20%预算下相对M平均提高至少0.02、至少3/4目标为正，目标簇描述性95%区间下限大于0；相对无门控MDH也完整报告，不以门控后结果替代E228。

这是历史开发验证，不是E208外部确认；门控规则通过也不能声称录用或节省湿实验。
