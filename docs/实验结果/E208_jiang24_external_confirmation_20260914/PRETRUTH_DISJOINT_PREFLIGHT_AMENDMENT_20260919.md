# E208｜空闲 GPU 的独立工程预检补充登记

登记时间：2026-09-19。登记时 E205 已完成 15/16 个模型，最后一个模型只占用 GPU0；E205 目标真值与 E208 测试真值均未授权读取。

## 调度调整

允许在 GPU1 上先运行一次 E208 H5 工程预检。预检只读取 Jiang24 的训练集与验证集，强制 `test=false`，每个架构各运行一个训练批次和一个验证批次，并检查 checkpoint 恢复。它不读取测试扰动表达，不生成任务误差，不选择特征、阈值、模型或超参数。

只有同时满足下列条件时才允许启动：

1. E205 状态仍为盲态，永久失败为空；
2. E205 已无等待任务，且指定 GPU 不在 E205 活跃任务列表中；
3. E208 测试真值访问保持 `NOT_AUTHORIZED`，读取行数为 0；
4. 预检输出写入独立目录，并标记 `DISJOINT_ENGINEERING_PREFLIGHT`；
5. 此结果不得释放 E208 正式训练队列。正式队列仍等待原定的 E205 完成后 smoke 门。

## 目的与结论边界

本调整只提前发现 H5 延迟读取、显存、checkpoint 和恢复流程的问题，减少 E205 完成后的空等时间。预检成功不属于模型效果，不进入论文结果表，也不改变 E205 或 E208 的正式端点。
