# E233 提前验证诊断与 E245 启动理由

记录时间：2026-09-24。以下只使用 Jiang24 官方验证集 216 个任务；**不是测试成绩**。E233 正式阶段1需等两变体训练完成并由原监管器输出，不能用此诊断替代最终状态。

| 预测 | 验证平均全基因 MSE | 相对无变化 | 不劣于无变化的状态 |
|---|---:|---:|---:|
| 无变化（目标状态对照原样输出） | 0.000440907 | 基线 | 12/12 |
| E233 softplus，种子1正式最佳 checkpoint（第28轮） | 0.004553496 | 差约 9.33 倍基线误差 | 0/12 |
| E233 linear，种子1第58轮最佳 checkpoint 的**提前诊断** | 0.000595906 | 高约 35.2% | 0/12 |

两个预测均按原 E208 验证缓存中的目标状态对照生成，checkpoint 和输出留在 `/home/yyf/data/perturbench_e233/early_*_validation_20260924/`；验证受扰动质心来自已允许的验证缓存，测试受扰动表达读取 0 行。softplus 训练已完成，linear 当时仍在训练，因此后者只是当时最佳 checkpoint 的诊断。

对 linear 提前预测用验证集做纯数学缩放 `x_ctrl+α(预测−x_ctrl)` 的诊断：全基因最小二乘 `α≈0.06196`，平均 MSE 约 `0.000440228`，只比无变化低约 **0.15%**，12 状态仅 6 个不劣。`α=0.02` 时虽有 8 个状态不劣，平均收益仍不到 **0.1%**。这说明仅把预测压到近乎零变化，可能勉强满足宽松的数值门，却没有足够实际价值；不能把它包装为合格预测器，也不能暗改 E233/E235 原合同。

E245 改测一条不同、可以核对来源的上游路径：用官方训练来源同基因效应迁移至目标状态。其质量门和 `α` 网格在 `VALIDATION_FIRST_PROTOCOL.md` 先写明；设验证 MSE 至少改善 2% 且 8/12 状态不劣。若失败则继续停，不打开测试表达。另用元数据确认：验证 212/216、测试 220/224 任务在“每来源至少30个受扰动细胞、目标状态之外至少2个来源”的固定条件下合格；这四个各自的 abstain 都保留记录。
