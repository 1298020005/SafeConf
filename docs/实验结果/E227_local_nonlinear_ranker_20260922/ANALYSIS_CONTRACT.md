# E227：同预算非线性对照

登记日期2026-09-22；在读取本轮输出前固定。E225/E226已经查看，本轮属于后续开发，不能作为新的独立确认。

问题：E226的改善是否受限于二次岭回归；通用非线性学习器是否已能解释增益，历史项/条件项还有没有额外作用。

- 输入只用E225/E226同一SHA的8196条历史评估记录，原始数据不改。
- 固定同一研究内5个扰动组外层折、历史抽样种子11/23/47；仅用剩余组的50%训练评分器（约占全体扰动组40%）。保留全部4个研究。
- 特征四组：M；MD；MDH；MDH_condition。M是幅度百分位，D是分歧百分位，H为背景新颖度和支持稀缺的集合名，不等于E201跨背景离散度H。
- 三个固定学习器：E226同参数岭回归残差（alpha=10，lambda=0.5）；直预测误差百分位的直方图梯度提升树；预测“误差百分位−幅度百分位”并以0.5系数补回幅度的相同树。
- 树固定100轮、7叶、学习率0.05、最小叶样本20、L2=10、不开自动早停；不读取外层误差调参。四组特征使用相同训练条件。预计720次小模型拟合、4个CPU进程。
- 主要候选：直接预测的树＋MDH_condition。主要复核预算20%，10%/30%为敏感性；误差对象仍是两个预测器RMSE的均值。
- 主门：对原始幅度效用增量至少0.02、至少3/4研究为正；研究簇描述性95%区间对原始幅度、同类树M/MD/MDH、岭回归条件模型均严格大于0。所有对比都公开，不把辅助臂换成主要候选。
- 同分公平处理；无法定义的效用保留NaN并报告数量；模型训练和测试扰动组不交叉。上游预测沿用原实验，不能说整个系统均未见过这些基因。
- 本轮不读E208标签、不改E208协议。不是PertEMA的软件复现，不把720次拟合当成720个独立实验。
- 停止条件：完成预定矩阵即结束，不追加参数直到显著。通过也只选择独立确认候选，不产生期刊录用保证。
