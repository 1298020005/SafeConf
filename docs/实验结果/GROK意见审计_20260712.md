# Grok 意见审计（2026-07-12）

审读对象：`agents/grok/CODEX_READ_THIS.md`、同目录两份判断文件、周老师 2026-07-09 聊天原文，以及 E33–E77 现有证据。

## 1. 有道理的部分

1. **优先级纠偏正确。** 周老师最后明确点了小矩阵、整行整列、跨数据集。第二套面板完成后继续堆第三、第四面板，边际价值低于补齐这三类 setting。
2. **错误必须绑定 predictor。** 老师连续追问“实际预测错误用的是什么模型”。后续所有数字必须带 `predictor_name`、误差名称和训练范围。
3. **输入来源比公式形式重要。** 老师原话是“具体公式不重要，输入的东西是什么比较重要”。true effect magnitude 不能进入部署分数，predicted magnitude 可以作为基线。
4. **pair risk 与单模型风险要分开。** E74/E77 能证明 pair mean/max 的下界，不能回答同一任务上 GEARS 和 scGPT 谁错。
5. **下载不是结果，化学侧尚未闭环。** Tahoe 和 OpenProblems 完整落盘解决了数据供应，没有解决 predictor、split、误差与风险合同。

## 2. 方向对，但需要改写的部分

1. **“所有 setting 使用同一真实 predictor”过于死板。** 遗传扰动与化学扰动不适合强行使用同一模型。真正需要统一的是 PredictionRecord、目标真值隔离、误差口径、统计方法和基线；predictor 应按模态选择并明确名称。
2. **“A：四特征分诊 / B：pair-risk 二选一”是假二选一。** 更连贯的论文结构是：SafeConf 作为总的 post-hoc 分诊框架，pair-risk certificate 是无需真值的硬证据层，任务新颖性和支持度属于校准路由层。固定等权公式降为基线即可。
3. **停止重复面板的时点需要看证据。** 在 E77 之前，第二套不重叠面板有必要；E77 之后 144 个任务已给出稳定增量，继续第三面板才属于低优先级。
4. **化学侧优先 CPA/chemCPA 合理，但不是老师指定模型。** 这是依据任务适配性与投稿对照作出的研究选择。

## 3. 不能当成老师硬要求的部分

1. 25%/50%/75% 是实验设计建议，老师没有给具体比例。
2. Gate0–8 的固定顺序是项目管理方案，不是老师原话。
3. “三类 setting 做完等于稳定二区”没有依据。老师说的是“小文章应该可以了”，没有承诺分区或录用。
4. “chemical 必须 CPA”“稳定二区必须 Q7–Q9 全绿”属于投稿推导，不是会议任务原文。
5. 期刊顺序会受年份、分区口径和稿件定位变化影响，不能在实验未闭环时锁死。

## 4. 最终判断

Grok 对当前优先级的批评大体成立，尤其是停止无限面板、回到老师三类 setting。它把合理的投稿补强建议写成了绝对命令，并把“完成老师给的最小研究问题”夸大为“稳定二区门槛”。采纳其方向，不采纳绝对化表述。

本项目现在不缺更多同类数据名字，也不缺第三套未见基因面板。最关键的缺口是：在目标真值隔离的正式合同下，把子矩阵四象限、整行/整列、双未见和同族跨数据集跑成可以复核的结果；化学侧补适配 predictor；随后加入直接 uncertainty 与 risk–coverage 对照。
