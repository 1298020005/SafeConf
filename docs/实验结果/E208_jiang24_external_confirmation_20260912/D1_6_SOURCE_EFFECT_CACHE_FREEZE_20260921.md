# E208｜训练来源效应缓存冻结

登记时间：2026-09-21

登记时点：五个正式模型仍在训练；224 个外部测试任务的扰动表达读取行数为 0。

## 固定来源

- 只读取 Jiang24 官方 `train` 层。
- 扰动基因只取自已冻结的 224 任务清单，共 53 个基因；不根据表达值或测试误差选基因。
- 训练层中全部 30 个 `cell_type×treatment` 细胞状态都进入对照质心清单。
- 对每个存在的“训练状态×目标基因”组合，使用该组合的全部训练扰动细胞；
  对照质心使用该训练状态的全部对照细胞，不抽样。

来源效应为：

\[
\delta_{jg}=\operatorname{mean}(X\mid \text{train},j,g)
-\operatorname{mean}(X\mid \text{train},j,\mathrm{control}).
\]

其中 (j) 是训练细胞状态，(g) 是扰动基因。每条缓存记录还必须保留扰动细胞数、
对照细胞数和来源状态标识。

## 任务级使用规则

对外部任务 (t=(c,g))，只取同一基因 (g) 且来源状态不等于目标状态 (c) 的记录。
每个来源状态等权计算平均历史效应与跨状态离散度；来源细胞数使用这些记录的
扰动细胞数之和。若某任务排除目标状态后少于两个来源状态，该任务不补测试数据，直接记为
`ABSTAIN`。

## 完整性约束

缓存程序必须核对官方切分哈希、H5 字节数、基因轴、训练行数与任务清单哈希。
输出来源效应数组、来源清单和状态文件的 SHA-256。全过程必须记录
`test_perturbed_expression_rows_read=0`。
