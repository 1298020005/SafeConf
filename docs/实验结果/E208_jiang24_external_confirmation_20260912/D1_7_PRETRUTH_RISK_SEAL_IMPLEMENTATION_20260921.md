# E208｜真值前风险封存实现补充

登记时间：2026-09-21

本文件只固定已登记公式的数值实现细节。登记时五个正式模型未训练完，
224 个测试任务的扰动表达仍未读取。

1. 每个 `cell_type×treatment` 状态分别使用 `ddof=0` 标准化 (D,G,H,N,C)。
2. 幅度和 SafeConf 都在同一状态的全部冻结任务中使用升序平均秩；值越大，秩越大。
3. 主分数固定为 `(4*rank_magnitude + rank_safeconf)/(5*n_context_tasks)`。
4. 单向次要分数为 `m + 0.25*max(s-m, 0)`，其中 (m,s) 是除以状态任务数后的归一化秩。
5. 主异构家族权重固定为四个 LatentAdditive 各 0.125，LinearAdditive 为 0.5。
6. 家族下界的 10%–90% 阈值使用 NumPy `quantile(method="linear")`。
7. conformal 校准先对每个验证基因取跨状态最大家族误差，再取
   `ceil((n_calibration_genes+1)*0.9)` 的上取整顺序统计量；序号最大截断为 (n)。
8. 任一状态少于 10 个任务、五分量中任一个标准差为 0、某任务少于两个来源状态，
   该状态记为 `ABSTAIN`，不删单项后继续。

封存表必须包含全部 224 任务的原始分量、标准化分量、幅度、两个排序公式、
同结构分歧、异构家族下界和 conformal 上界。表、校准分数、阈值、预测数组、
训练来源缓存和代码都写入 SHA-256。只有该封存提交同步到 GitHub 和 Gitee 后，
才可以单独授权读取测试扰动真值。
