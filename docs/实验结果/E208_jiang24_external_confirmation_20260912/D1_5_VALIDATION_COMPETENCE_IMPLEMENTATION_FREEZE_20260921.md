# E208｜验证集能力门实现冻结

登记时间：2026-09-21

登记时点：五个正式模型仍在训练；外部测试集扰动表达读取行数为 0；本文件
只把 `D1_1_FAMILY_COMPETENCE_AND_OUTPUT_ADDENDUM_20260915.md` 中已冻结的能力门
落实为唯一可复算实现，不修改模型家族或外部测试端点。

## 1. 验证任务

- 只使用 Jiang24 官方 `val` 层，不使用 `test` 扰动表达。
- 纳入四个细胞系（HAP1、HT29、K562、MCF7）与三个处理状态（IFNG、INS、TGFB）
  的全部单基因验证任务，共 12 个状态、216 个任务。
- 不删除细胞数较少的两个 SOX2 任务；能力门使用官方验证层的完整任务集。
- 每个任务的验证真值质心使用该任务的全部验证细胞计算。

## 2. 固定对照输入

每个细胞系×处理状态使用同一组官方 `val` 对照细胞。数量不超过 1,000 时
全部使用；超过 1,000 时，按
`SHA256("E208-validation-control-v1\\0" + cell_id)` 升序固定选取前 1,000 个。
同一状态的所有扰动任务、全部五个模型共用这组对照，不允许每个模型重新抽样。

## 3. 模型输出与基线

对每个验证任务，模型对固定对照细胞逐个预测，然后取基因维度的平均值得到预测质心。
不变化基线（no-change）直接使用同一组对照细胞的表达质心。

任务误差为全 15,473 个共同基因上的质心均方误差：

\[
e_{mt}=\frac{1}{15473}\sum_g(\hat y_{mtg}-y_{tg})^2,
\qquad
e_{0t}=\frac{1}{15473}\sum_g(x_{0tg}-y_{tg})^2.
\]

LatentAdditive 的架构质心先对四个固定随机种子的预测质心做算术平均，
再计算误差；LinearAdditive 使用唯一登记种子。不按种子挑最好结果。

## 4. 能力门的唯一判定

先对 216 个任务等权求平均：

\[
\bar e_{\mathrm{latent}}<\bar e_0
\quad\text{且}\quad
\bar e_{\mathrm{linear}}<\bar e_0.
\]

两个架构都严格优于不变化基线时，能力门记为 `PASS`，允许五模型家族进入外部
测试预测。任一架构未通过时，记为 `FAMILY_COMPETENCE_BLOCKED`：不删弱模型，不换
误差指标，不用测试集重选家族。

同时报告每个状态的误差与相对 no-change 改善，但它们只用于说明能力边界，
不替换上述全任务平均门。

## 5. 防泄漏与产物

能力门程序必须记录：训练 checkpoint 哈希、验证任务顺序、固定对照行、
每模型预测质心、验证真值质心、不变化质心、任务级误差和总体判定。
这一步可读取官方 `val` 表达，但测试扰动表达读取行数必须继续为 0。
