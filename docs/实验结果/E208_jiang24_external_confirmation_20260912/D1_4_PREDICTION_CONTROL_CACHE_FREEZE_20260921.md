# E208｜预测对照缓存与共同输入补充冻结

登记时间：2026-09-21

登记时点：五个正式模型已经开始训练；224 项任务清单已经由 D0 元数据清单生成；测试
扰动表达读取行数仍为 0；模型正式预测、风险分数和测试真实误差均未生成。本文只固定
此前没有写明的部署对照抽样和缓存实现，不改变任务、模型、公式、权重或评价门。

## 1. 需要补充的原因

PerturBench 的预测接口默认在每次模型推理时从 93 GB H5AD 中重新抽取目标状态对照。
2026-09-21 的单任务工程 smoke 在没有读取测试扰动表达的情况下，三分钟顺序读取约
14 GB 并占用约 16 GB 内存，说明该接口会重复扫描大矩阵。五个模型分别执行会造成无
必要的 I/O，并使不同模型可能使用不同的随机对照子样本。

模型家族分歧应反映模型结构或训练随机性的差异，不能混入部署输入抽样差异。因此，
正式预测先构建一次只含测试状态未扰动对照的稀疏缓存，五个模型共享同一缓存和同一
任务顺序。

## 2. 固定对照选择

目标状态固定为 D0 的 12 个 `cell_type × treatment` 组合。每个状态只允许使用官方
`test` 层中 `condition=control` 的细胞：

- 对照数不超过 1,000 时全部保留；
- 超过 1,000 时，按
  `SHA256("E208-control-cache-v1\\0" + cell_id)` 从小到大固定选择前 1,000 个；
- 五个模型使用同一组细胞，不按模型随机种子重新抽样；
- 选择只依赖细胞 ID、官方切分和对照标签，不读取表达值或扰动结果。

元数据预检得到 7,858 个候选对照。HAP1-INS 和 HT29-INS 分别有 1,472 和 1,587
个候选，按上述规则各取 1,000；其余十个状态全部保留。因此缓存预期包含 6,799 行。

## 3. 表达与基因轴

缓存直接复制原 H5AD `X` 的选中 CSR 行，保持原 15,473 基因顺序。原始 `X` 为
float64，但正式训练流水线在模型输入前固定执行 `ToFloat`；缓存使用 float32，与模型
实际接收的数值类型一致。不得重新归一化、筛基因或根据预测结果修改缓存。

## 4. 真值隔离与产物

构建程序只读取：`obs` 中的 `condition/cell_type/treatment`、细胞 ID、官方 split、
`var_names` 和被选中的对照行。任何 `condition != control` 的测试表达行都禁止读取。
程序输出：

- `E208_TARGET_CONTROL_CACHE.npz`：共同稀疏对照矩阵与 15,473 基因轴；
- `E208_TARGET_CONTROL_ROWS.csv`：原始行号、细胞 ID 和状态；
- `E208_CONTROL_CACHE_STATUS.json`：输入身份、逐状态数量、文件哈希和零测试扰动读取声明。

大型矩阵保存在数据盘，不提交 Git；状态 JSON 和选择规则提交双远程。若行数、状态数、
基因数、对照标签或 split 对齐不满足上述合同，正式预测停止，不改为读取测试扰动细胞。
