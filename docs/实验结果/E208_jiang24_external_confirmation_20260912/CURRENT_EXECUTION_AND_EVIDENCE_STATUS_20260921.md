## 2. 当前唯一主公式

对每个目标背景的全部预登记任务分别计算幅度秩和原 SafeConf 秩：

\[
R_t=\frac{4\,r(M_t)+r(S_t)}{5N},
\qquad
S_t=\frac{z(D_t)+z(G_t)+z(H_t)+z(N_t)+z(C_t)}{5}.
\]

- (M)：四种子平均预测相对目标状态对照质心的变化幅度。
- (D)：同结构随机种子之间的预测分歧。
- (G)：模型平均预测与来源背景历史平均效应的偏离。
- (H)：同一扰动在不同来源背景中的效应离散度。
- (N)：来源扰动细胞数的稀缺度。
- (C)：来源背景覆盖的缺口。
- (r)：背景内平均秩；(N)在分母中表示该背景的全部排序任务数。

4:1 表示 80% 使用强基线幅度秩，20% 使用历史证据和稳定性组成的 SafeConf 秩。
它已在 E205 真值打开前冻结。E205 和 E208 都不允许再根据测试真值搜索新权重。
更多自适应公式可在开发数据上研究，但需要另一个未揭盲数据确认后才能升为主方法。

## 4. E208 后续已经自动化

后台监管器已经形成完整链条：

1. 等五个正式训练任务都通过 checkpoint 和零真值访问检查。
2. 五个模型在 216 个验证任务上生成质心预测。
3. LatentAdditive 四种子架构质心和 LinearAdditive 都必须严格优于 no-change。
4. 能力门通过后，五个模型对 224 个外部任务生成预测质心。
5. 由第二段程序独立复算五项证据、组合分数、校准量和证书阈值；等尺寸模拟测试的最大绝对差为
   `8.88e-16`，门槛为 `1e-10`。
6. 风险封存与独立审计先提交并推送 GitHub/Gitee，再另建一次性揭盲授权提交。
7. 两个远程都确认授权提交后，才读取测试扰动真值并运行正式评价。
8. 另一段程序再次读取 214,901 个测试细胞，独立复算三种输出空间和 5,000 次自助法；复核通过后
   才把结果推送到两个远程。

能力门失败时，监管器会停在 `FAMILY_COMPETENCE_BLOCKED`，不删掉弱模型制造有利结果。
任一封存、哈希、远程或独立复核门失败时，自动收尾程序同样停止，不根据结果改公式或阈值。

## 5. 现在可以怎样定义文章主线

当前真实支持的主线是：

> 对整背景留出的单细胞扰动预测，预测幅度是必须超越的强基线；SafeConf-M 以固定小比例
> 加入来源背景证据与预测稳定性，在跨结构家族和四个整背景上提高高误差任务的排序与固定预算复核效用。

确定性分歧下界的数学恒等式正确，但 E205 中位紧致度只有 0.0997，不满足已冻结的操作证书门。
它应作为理论边界或补充结果，不再替代已有实证支持的 SafeConf-M 风险排序主线。

## 6. Git 体积的处理决定

当前 Git pack 约 902 MiB。主要体积不是 `node_modules`，而是历史已提交的预测数组、自助法抽样表
和早期实验 CSV/NPZ。在当前分支仅删文件不会缩小远程历史；真正缩小需要改写历史，
会破坏 E205/E208 正在使用的祖先提交与哈希链。

因此当前不对活跃实验仓做历史重写。E208 封存后再生成独立轻量发布快照，只保留代码、
协议、汇总表、主图和小型复现样例；大型中间数组留在数据盘并用 SHA-256 索引，不再进 Git。
