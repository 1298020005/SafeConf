# E208｜正式评价实现冻结

登记时间：2026-09-21

登记时点：正式模型未训练完，风险表未生成，外部测试扰动真值读取行数为 0。

## 1. 主端点

在 12 个 `cell_type×treatment` 状态内分别计算 SafeConf-M 与全 15,473 基因 RMSE 的
Spearman，再对 12 个状态等权求平均。主结果是该宏平均相对预测幅度的差：

\[
\Delta_\rho=\frac1{12}\sum_c
\left[\rho_c(R_{80/20},e)-\rho_c(M,e)\right].
\]

按扰动基因作为簇进行 5,000 次有放回重抽样，随机种子固定为 `208202609`。
每次抽取与原始唯一基因数相同的基因簇，保留被重复抽中的全部状态任务。
主端点的 95% 百分位区间下限大于 0 才记为外部确认。

## 2. 20% 复核效用

每个状态选取 `ceil(0.20*n_context_tasks)` 个最高风险任务。并列使用
`SHA256("E208\\0"+task_id+"\\0"+bootstrap_occurrence)` 升序打破。归一化效用为：

\[
U=\frac{\bar e_{selected}-\bar e_{all}}
{\bar e_{oracle}-\bar e_{all}}.
\]

同时报告选中任务的误差总量占该状态全部误差总量的比例（error-mass capture）。
SafeConf-M 相对幅度的捕获率相对改善为 `(capture_scm-capture_mag)/capture_mag`。

实际效果门沿用早先登记：20% 效用差点估计至少 0.02 且簇自助法 95% 下限大于 0；
误差总量捕获率相对改善至少 5%；12 个状态中至少 9 个的 Spearman 差为正；
三个输出空间中至少两个的宏平均 Spearman 差为正。

## 3. 证书检查

异构家族误差、确定性下界、conformal 上界和九个阈值按早先证书协议复算。
逐任务恒等式残差不得超过
`max(1e-12, 1e-10*max(R_F^2, centroid_error^2+D_F^2))`，下界违反数必须为 0。
高风险证书、低风险 conformal 输出、未知和放弃按四态规则完整报告，不用任意单阈值代替预登记的曲线。

## 4. 硬性授权门

评价程序只有同时满足以下条件才可以读取测试扰动表达：

1. 预真值风险封存状态为 `PASS_AWAITING_REMOTE_SEAL`；
2. 风险表与风险状态文件已经进入预真值 Git 提交，程序会从该提交重新读取字节并核对 SHA-256；
3. 授权 JSON 另行提交；该授权提交必须是预真值提交的后代，且评价必须从该授权提交本身执行；
4. GitHub 与 Gitee 的远程分支头均等于授权提交，证明预真值封存和揭盲授权均已异地留痕；
5. 阈值表 SHA-256 与预真值风险状态中的登记一致。

任一项不成立时程序必须在打开 H5 表达矩阵前退出。

授权由 `tools/scripts/create_e208_truth_authorization.py` 生成。生成前仓库必须干净，
且预真值风险表、状态和阈值表的当前字节必须与 `HEAD` 及 GitHub/Gitee 两个远程一致。
生成的授权文件随后单独提交并推送；正式评价要求工作区仍然干净，两个远程均指向该授权提交，
输出目录为空。评价程序拒绝覆盖任何既有正式结果。
