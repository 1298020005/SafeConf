# E208｜自动收尾协议

登记时间：2026-09-21

`tools/scripts/run_e208_seal_authorize_evaluate_finalize.py` 只在预真值风险队列完成后执行，顺序固定为：

1. 核对四段冻结程序和两份评价资源的 SHA-256；
2. 独立复算预真值风险表；
3. 将风险表、阈值、校准记录和审计结果提交并推送到 GitHub/Gitee；
4. 生成独立揭盲授权，再次提交并推送到两个远程；
5. 从该授权提交执行一次正式评价，正式输出目录非空时拒绝覆盖；
6. 第二次读取 214,901 个测试扰动细胞，独立复算正式误差和统计结果；
7. 仅在复核通过后，将正式结果提交并推送到两个远程。

任何一步失败都会写入外部状态文件并停止，不会跳过门槛继续运行，也不会根据结果更换公式、删除状态或调整阈值。
