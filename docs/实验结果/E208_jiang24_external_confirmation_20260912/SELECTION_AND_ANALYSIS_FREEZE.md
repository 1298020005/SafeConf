# E208｜Jiang24 新外部遗传扰动确认

冻结时间：2026-09-12（下载完整表达矩阵之前）

证据身份：**新的外部确认候选**。Jiang24 没有参与 E201/E206 的公式开发，也没有进入 E207 的历史压力测试。当前文件只冻结选择理由和分析规则，不代表数据已通过合同，更不代表已有结果。

## 数据来源与选择理由

- PerturBench 官方仓库：<https://github.com/altoslabs/perturbench>；
- 处理后数据：<https://huggingface.co/datasets/altoslabs/perturbench/tree/main>；
- PerturBench 论文：<https://proceedings.neurips.cc/paper_files/paper/2025/hash/8aee537279a66ced96319dfca3c00002-Abstract-Datasets_and_Benchmarks_Track.html>。

公开说明显示，Jiang24 同时包含多个细胞系、处理状态和数百个遗传扰动，PerturBench 已给出跨条件切分。它比单一 K562 内部未见基因更接近 E208 要回答的问题：公式在新的生物背景和新的数据处理来源上是否仍然成立。

## 下载前冻结的问题

在上游预测已经生成、真实扰动结果仍未用于打分时，固定分数

\[
R_{\mathrm{SCM}}=\frac{4r(M)+r(S)}{5N}
\]

是否比只看预测幅度 \(M\) 更能排列任务级预测误差。\(S\) 为按来源状态计算的 SafeConf 分数；\(r\) 为测试批次内平均秩；\(N\) 为可评价任务数。公式、4∶1 权重和并列处理不在 E208 上重选。

## D0：数据合同门

下载后先完成字段和规模审计，至少要求：

1. 每个细胞都有明确的遗传扰动标签、细胞系、附加处理状态和表达矩阵；
2. 存在可识别的未扰动或非靶向对照；
3. 官方训练、验证、测试切分能够与表达行一一对齐；
4. 主分析只保留单基因扰动；组合扰动不改名并入；
5. 每个测试任务至少 30 个细胞，否则只进预先标记的灵敏度层；
6. 下载文件、解压文件和切分表逐文件记录字节数、SHA-256 与来源 URL。

任一核心字段无法恢复时写 `INCOMPATIBLE`，不靠猜测补标签。

## D1：上游预测合同

- 使用 PerturBench 官方切分，不根据 SafeConf 结果重新分组；
- 至少训练一个预先选定的上游结构的 4 个随机种子；
- 若资源允许，再加入第二结构，但两个结构分别报告；
- 训练只读取官方训练层；测试扰动表达只在预测和风险分数全部封存后用于评价；
- 同时保留同合同的简单预测基线，避免只和复杂模型内部比较。

具体模型、超参数和训练轮数须在 D0 通过后、第一次正式训练前补充冻结。不得试完测试结果再选择模型。

## D2：风险分数

在测试状态内一次性计算并封存：

1. 随机排序；
2. 预测幅度；
3. 四种子同结构分歧；
4. 原 SafeConf；
5. 固定 SafeConf-M；
6. 若第二结构存在，跨结构质心分歧。

所有风险特征只允许读取预测、对照和训练状态统计。风险表写出 SHA-256 并同步双远程后，才允许生成任务真实误差。

## D3：评价与判据

主要端点：SafeConf-M 相对预测幅度的任务级 Spearman 差值。按扰动基因做 5,000 次簇自举，95% 区间下限大于 0 才记为外部确认。

次要端点：

- 5%、10%、20%、30% 复核预算的效用与错误总量抓取率；
- 全共同基因、差异表达基因和通路活性三种输出空间；
- RMSE、相关性损失、方向错误和分布距离；
- 逐细胞系、逐处理状态和逐随机种子结果；
- 控制预测幅度后的偏 Spearman；
- 特征计算时间和内存。

次要端点不用于替换失败的主要端点。区间跨 0 写“未确认”，方向相反写“外部失败”。

## 扰动类型边界

E208 主分析只回答遗传扰动。Jiang24 中若同时存在化学或细胞因子处理，它们作为细胞状态协变量或单独分层，不与 E118 的纯药物任务合并，也不由此宣称统一适用于所有扰动。
