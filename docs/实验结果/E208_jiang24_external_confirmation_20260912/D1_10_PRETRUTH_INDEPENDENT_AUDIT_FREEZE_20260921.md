# E208｜预真值风险表独立复核冻结

登记时间：2026-09-21

登记时点：正式训练仍在运行，测试扰动真值读取行数为 0。

`tools/scripts/audit_e208_pretruth_risk_seal.py` 不调用风险表生成程序，独立完成以下复算：

1. 核对五个模型的验证集与测试集预测文件、检查点哈希、任务顺序和对照表达；
2. 用验证集真值重新计算异构家族误差、确定性下界和 90% conformal 校准量；
3. 用测试集预测重新计算预测幅度、同结构分歧、异构家族下界与上界；
4. 用训练来源效应缓存重新计算 `D/G/H/N/C` 五项证据；
5. 在 12 个状态内重新标准化和排序，复算原始 SafeConf、固定 `80/20` 主分数和单向次要分数；
6. 重新计算九个证书阈值，并逐项核对封存表。

所有数值最大绝对差必须不超过 `1e-10`，全部输入状态都必须记录测试扰动真值读取行数为 0。
复核通过后，风险表、风险状态、阈值表及独立复核结果一并进入预真值 Git 提交；未通过不得创建揭盲授权。
