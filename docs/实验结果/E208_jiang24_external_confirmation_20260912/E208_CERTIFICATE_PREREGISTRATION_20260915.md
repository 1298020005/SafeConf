# E208｜注册模型家族证书副协议

登记时间：2026-09-15

登记时点：D0 元数据清单已通过，上游正式模型尚未训练，测试扰动表达数值尚未读取，
测试真实误差尚未生成。本文件新增证书分析，不替换已经冻结的 E208 风险排序主要检验。

## 1. 分析目的

在 Jiang24 新外部数据上检验：由预先注册的异构预测器组成的家族，能否在不读取测试
扰动真值时给出有效且非退化的误差下界，并在校准靶点可用时给出目标簇同时覆盖的
边际 conformal 上界。

## 2. 注册家族

主家族固定为五个成员：

- LatentAdditive，随机种子 1、2、3、4；
- LinearAdditive，随机种子 1。

为防止同一架构通过复制随机种子获得更多权重，先给两种架构各分配 0.5 总权重，再在
LatentAdditive 的四个种子间均分。因此四个 LatentAdditive 成员各重 0.125，
LinearAdditive 成员权重为 0.5。结果出来后不删除预测较差的成员，也不改变权重。

附加报告四个 LatentAdditive 种子的等权同结构家族，作为“随机初始化分歧”对照；它
不能替代主异构家族。

所有成员必须共享同一 15,473 基因输出轴、同一标准化、同一任务顺序和同一官方切分。
任一合同不一致且无法按事前映射无损对齐时，主家族输出 `ABSTAIN`。

## 3. 确定性下界

对权重和为 1 的预测向量 \(p_i\)，定义：

\[
\bar p=\sum_iw_ip_i,\quad
D_F^2=\sum_iw_i\lVert p_i-\bar p\rVert^2,\quad
R_F^2=\sum_iw_i\lVert p_i-y\rVert^2.
\]

主要误差几何为共同基因轴上的 RMSE 范数。验证恒等式：

\[
R_F^2=\lVert\bar p-y\rVert^2+D_F^2,
\]

并使用 \(L_F=D_F\le R_F\) 作为真值无关下界。揭盲后的恒等式数值门使用 float64，
逐任务绝对残差不得超过：

\[
\max\{10^{-12},10^{-10}\max(R_F^2,\lVert\bar p-y\rVert^2+D_F^2)\}.
\]

超过门槛写 `NUMERICAL_GATE_FAIL`，不通过修改容差改判。

## 4. 允许误差阈值与证书曲线

测试预测封存后、读取测试真值前，用主家族 \(D_F\) 的 10%、20%、……、90% 分位点
固定九个 \(\tau\)。对每个阈值：

- \(D_F>\tau\)：`CERTIFIED_HIGH`；
- 其余：`UNKNOWN`，不标为安全。

揭盲后报告：真实 \(R_F>\tau\) 的任务数、被证书捕获的数量、召回率、证书覆盖任务
比例和二项区间。`CERTIFIED_HIGH` 的经验精确率用于核对实现；理论上任何精确率低于
1 都表示实现或数值门失败。

非退化 GO 门预先设为：异构家族下界紧致度 \(D_F/R_F\) 的中位数不低于 0.15；且
至少一个拥有不少于 20 个真实高误差任务的 \(\tau\) 上，证书召回率不低于 0.05。

## 5. 目标簇 conformal 上界

校准只允许使用官方验证层的受扰动表达；测试受扰动表达继续隔离。以扰动基因为独立
校准单位，对同一基因跨细胞系/处理状态的质心 RMSE 取最大值，形成一个“靶点同时”
校准分数。若合格校准基因少于 50 个，上界分析记 `CALIBRATION_BLOCKED`，下界分析
仍继续。

在校准单位不少于 50 时，用有限样本 split-conformal 的上取整秩选择 90% 分位数
\(q_{0.9}\)。对测试任务报告：

\[
U_F=\sqrt{q_{0.9}^2+D_F^2}.
\]

主要覆盖单位为测试扰动基因：只有该基因的全部正式任务均满足 \(R_F\le U_F\)，才记
该靶点被覆盖。外部上界 GO 门固定为目标簇点覆盖至少 85%，且其 95% Clopper–Pearson
区间包含 90%。这是边际覆盖检查，不解释为被选择单个任务的条件安全保证。

## 6. 比较与完整报告

同一任务、同一预测合同下同时报告：

1. 同结构四种子分歧；
2. 架构平衡异构家族下界；
3. 预测幅度；
4. 不带家族分歧的标准 centroid split-conformal 上界；
5. 原 SafeConf 与已经冻结的两个排序公式；
6. no-change 和 LinearAdditive 的上游预测误差。

报告 12 个细胞状态和全部 224 个测试任务，不因结果不利删除某个状态或基因。主分析
只限单基因遗传扰动；组合扰动和其他处理状态不补入替换失败结果。

## 7. 封存与揭盲顺序

1. 完成五个成员及 checkpoint 合同审计；
2. 生成 224 项任务的成员预测；
3. 写出成员注册表、架构权重、质心、\(D_F\)、九个 \(\tau\) 和全部风险分数；
4. 记录 SHA-256，推送 GitHub、Gitee；
5. 再单独授权评价程序读取测试扰动表达；
6. 一次性生成下界违反、数值恒等式、紧致度、证书召回和上界覆盖结果。

任何顺序违反均写入主表。E182 的历史 FAIL、E201 的数值门 FAIL 和本实验结果分别
报告，不互相改判。
