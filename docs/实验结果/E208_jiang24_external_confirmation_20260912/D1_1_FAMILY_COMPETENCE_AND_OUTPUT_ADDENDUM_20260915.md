# E208｜家族能力门与四态输出补充登记

登记时间：2026-09-15

登记时点：Jiang24 D0 元数据清单已经冻结；五个上游模型尚未正式训练；测试扰动表达
数值尚未读取；测试真实误差尚未生成。本文件补充解释注册家族是否具备实际评价意义，
并固定证书输出的语义，不修改已经登记的成员、权重、任务、误差几何和九个阈值。

## 1. 为什么增加能力门

分歧下界对任何固定家族都成立。若故意加入一个很差的模型，也可以人为增大分歧，
但这样的家族没有合理的部署含义。为了防止用弱成员制造“高风险证书”，主异构家族
必须先通过不接触测试扰动真值的能力门。

能力门只读取官方训练集和验证集：

1. LatentAdditive 四个种子和 LinearAdditive 的训练过程均产生有限损失，checkpoint
   合同全部通过；
2. 在官方验证层上，先计算每个架构的预测质心误差，再与 no-change 基线比较；
3. LatentAdditive 架构质心和 LinearAdditive 均须严格优于 no-change；
4. 能力门通过后才生成测试对照输入上的 224 项预测和家族证书。

若第 3 条失败，不删除较弱架构、不换模型，也不按测试结果重选家族。E208 主异构
证书记为 `FAMILY_COMPETENCE_BLOCKED`；四个 LatentAdditive 种子的同结构结果仍可按
原登记作为附加诊断，但不能冒充异构家族确认。

验证层只用于能力门和 conformal 校准，不用于选择公式、成员权重、测试任务或阈值。

## 2. 被保证的误差对象

确定性下界 (L_F=D_F) 对应注册家族均方根误差：

\[
R_F=\sqrt{\sum_iw_i\lVert p_i-y\rVert^2}.
\]

它不直接保证 LatentAdditive、LinearAdditive 或家族质心中的某一个预测必然错误。
当 (L_F>\tau) 时，能够确认的是：该注册家族整体的 (R_F>\tau)，因而当前任务
不满足家族一致放行条件，应停止自动放行并复核。

## 3. 每个阈值的四态输出

对九个已经登记的 \(\tau\) 逐一输出：

| 条件 | 状态 | 允许解释 |
|---|---|---|
| (L_F>\tau) | `CERTIFIED_HIGH` | 注册家族的 (R_F\) 确定大于容忍度 |
| (L_F\le\tau) 且 (U_F\le\tau) | `CONFORMAL_LOW` | 在登记的边际 conformal 条件下，误差上界不超过容忍度 |
| (L_F\le\tau<U_F) | `UNKNOWN` | 现有上下界不能作出高或低判断 |
| 成员、轴、能力、校准或数值门失败 | `ABSTAIN` | 不输出风险结论 |

因为 (U_F\ge L_F)，正常数值条件下不会同时出现 `CERTIFIED_HIGH` 与
`CONFORMAL_LOW`。如发生重叠，记为 `NUMERICAL_GATE_FAIL`。

`CONFORMAL_LOW` 只具备预先登记总体上的边际覆盖含义，不能写成每个被放行任务都以
90% 概率安全，也不能把放行子集中的经验成功比例当成新的条件覆盖定理。

## 4. 固定报告量

任务层和扰动基因簇层均报告：

- `CERTIFIED_HIGH` 数量、签发率、真实高误差召回率和错误高证书数；
- `CONFORMAL_LOW` 数量、放行率、全体单位中的错误放行质量，以及放行子集错误率
  （后者只作描述）；
- `UNKNOWN` 与 `ABSTAIN` 数量；
- 全部四态之和是否等于登记任务数；
- 下界紧致度、区间宽度和目标簇同时上界覆盖。

高风险证书出现任何错误签发，主下界实现门失败。低风险输出仍沿用
`E208_CERTIFICATE_PREREGISTRATION_20260915.md` 的目标簇覆盖门，不另挑有利阈值或
用任务级覆盖替换目标簇覆盖。

## 5. 结果边界

- 能力门通过只说明家族成员在验证层不是明显失效预测器，不保证测试层性能；
- 能力门失败属于正式负结果，不得通过删除 LinearAdditive 改判；
- 某个 \(\tau\) 没有低风险放行或没有高风险签发时，报告零，不移动阈值；
- E208 是本补充登记的第一次新外部检验；E181/E183/E211 的已释放数据只能作回顾性
  工作区间说明。
