# E269｜不使用历史效应向量的干净来源组

E266 的 `B` 同时包含跨背景真实效应稳定性/方差。为区分“公共历史的可用元数据”与“直接读取历史扰动效应”，E269 在同一套外层折上增加两组：

- `Bsafe`：扰动支持数、对照背景最大相似度、对照背景平均相似度；
- `Bsafe+E`：上述 Bsafe 加同一预测器过去折的错误历史。

`Bsafe` 不使用历史扰动效应向量，`E` 也没有使用评估行的真实误差；训练行的 E 特征逐行留一。所有结果仍是已有公开任务的回顾性开发结果。

## 当前判断

在 Cui、Lara ex vivo、Santinha 三项研究中，Bsafe 组合在逐折上普遍提供正向线索，且加入 E 后通常继续提高。这支持“当前预测 + 可获得的背景/支持信息 +（有标签时）模型错误经验”值得进入下一轮冻结协议；它不等于已经完成外部盲测，也不能把这些数字直接写成期刊录用保证。

下一步应只做一件事：从尚未用于这些公式选择的新研究/新背景中重建 Bsafe，事前固定一个小规则，真值封存后与幅度、冻结 SafeConf-M、同标签预算的监督风险基线比较。若新数据不能复现，主张应退回已验证的场景条件化排序，不再扩大历史故事。
