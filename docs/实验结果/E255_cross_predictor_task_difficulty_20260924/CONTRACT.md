# E255：跨架构共享任务难度的回顾性核验

日期：2026-09-24。结果揭晓前固定本合同；E112 真实结果早已公开，因此只属于回顾性分析，不能称为独立盲测。

## 问题与资料

网页提纲中的 0.973 来自两个简单参考预测器。这里改用 E112 的 scGPT 与 GEARS 两种不同架构，在 Lara ex vivo 和 Santinha 的同一批预测任务上比较。E112 每个数据集有五个留出背景折，预测、真实效应和误差均来自原正式记录，不重新训练上游。

## 固定指标

1. 同任务两模型的原始 RMSE Spearman 相关，整体及各任务设置分别计算。
2. 各模型 RMSE 减去同任务 no-change RMSE 后的 Spearman 相关；负值可出现。
3. 两模型 RMSE 秩在控制同任务 no-change RMSE 秩后的偏相关。no-change 使用真实效应，只是**解释性诊断**，绝不作为可部署风险特征。
4. 对原始相关按任务和按留出背景分别自助抽样 2000 次，报告 95% 分位区间。五个背景簇的区间预期宽；不得用任务级窄区间代替独立背景的证据。
5. 逐折上游能力：RMSE 均值与 no-change 相比。两模型中任一不如 no-change 时，跨模型相关不能作为“两个有效预测器共享难题”的证明。

主要结论必须区分“两个错误排序相似”与“任务难度真的可从过去预测器迁移到新模型”；本实验只检验前者。切忌把 E112 中弱于 no-change 的模型当成有用上游。

补充原始 A1 的 4584 配对任务核验：读取旧 `RELIABILITY_ALL_SCORES.csv` 的 `random` 分数行仅为去重，不使用随机分数；复算原始错误相关，并逐数据集计算错误相关和控制真实效应长度后的偏秩相关。真实效应长度同样是**事后诊断**。不同数据集的误差标度可能不同，不能把合并相关直接解释为同一数据集内部规律。

再补已完成的 E205 现代跨结构面板，不训练新的图模型：对每个任务分别平均四个 GAT seed 和四个 Exphormer seed 的 RMSE，按 `task_id` 与 E201 正式表中 `control_error`（同任务 no-change RMSE）一对一连接。对四个整背景及合并任务计算原始错误相关、各自减去 control_error 后的相关、控制 control_error 的偏秩相关，并报告两架构均值是否超过 no-change。这里四个种子不是四个独立数据集，不能用种子数扩大独立样本量。
