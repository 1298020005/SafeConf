# E237｜Nadig 新基因复制的事先分析合同

登记于 2026-09-23，`CONTRACT_STATUS.json` 和 `manifests/E237_TASK_MANIFEST.csv` 在读取本轮扰动表达、训练本轮预测器或计算本轮误差前生成。选择 Nadig 场景发生在 E139/E152 解封后，故不能称它是对“该研究适用”这一选择的完全独立检验；本轮只检验**同一研究中未用于 E139 的扰动基因**。

## 人群、模型、目标

- 从 Nadig HepG2/Jurkat 两份公开数据中，仅用细胞数、基因名称、scGPT 词表筛出每细胞系至少 50 个细胞的共同单基因 CRISPRi 目标。785 个合格基因中排除 E136 的 96 个；余下 689 个按固定哈希选择 128 个，不根据表达变化或误差挑选。两个细胞系轮流留出，共 332 个预定测试行，全部进入报告。
- 上游固定为 E112/E138 已用的 scGPT 与 GEARS 训练流程、基因面板大小和超参数；E135 冻结方向风险模型的 SHA-256 已记入合同。模型能力及无变化、训练质心比较均记录，不因结果差删除某一模型。
- 主终点：两模型方向误差的折内秩均值，方向误差使用训练受扰动表达质心为参照的 Pearson 与 cosine 定义；主统计量为两折等权 Spearman。目标是排序错误，不是重新预测表达。
- 冻结公式与四项公平对照：单独预测幅度 M、扰动新颖度 N、两模型分歧 D、同折百分位各半的 M+N。全都在相同 332 行和相同真值上比较。M+N 为主比较器；M、N、D 均完整报告。

## 判定与审计

按扰动基因整簇、同步两个折，固定随机种子 20260923 重采样 2,000 次。预定的可支持结论须同时满足：冻结公式对主终点的两折相关都为正；对 M+N 的宏平均差值大于零且簇重采样 95% 区间下限大于零。20%优先复核预算的真实方向错误捕获率，以及 Pearson/cosine 单独终点，是辅助指标；不足以单独覆盖主判定。若主比较失败，保留全部任务并记录失败，不换扰动子集、模型或公式寻找通过。

本轮沿用 E112 的预测器实现时，程序会在生成任务图时载入测试表达以供事后误差计算；因此即便方法系数和基因清单已经冻结，也**不宣称严格的“先封存预测、后首次读取测试真值”**。报告必须写明这一执行限制，直到有独立的预真值预测流程为止。E237 不用本轮真值调参，也不把同研究复制说成跨研究外部验证，更不把相关性提升直接换算为节省湿实验成本。
