# E189 结果怎么回答周老师

## 1. 实际和什么误差比较

每个任务都有 3 个 scGPT 与 3 个 GEARS 的真实 RMSE，同时计算六成员 family RMS
和 worst-member error。风险量不再和一个含糊的“模型误差”相关，而是对应这四类
明确对象。13,440 个任务实例中，family RMS 多样性下界和 worst-member 直径下界
均为 0 违例。

## 2. 预测前能否计算

16 个 prediction release 的目标真值读取数均为 0，所有 query graph 均不含 `y`。
分歧、family diameter 和 predicted magnitude 全部由六个预测向量计算，不需要
目标扰动表达。

## 3. 小矩阵、随机 pair、整行、整列和双未见

同一模型合同下，每个已见扰动只提供 1、2、3、5 个训练背景。support 从 1 增至 3
时平均误差下降，增至 5 后基本进入平台。support=5 时，六成员优于 zero-effect 的
成员比例为：

- 随机缺一格：51.70%；
- 未见背景整行：48.81%；
- 未见扰动整列：49.60%；
- 背景与扰动同时未见：47.81%。

这说明任务矩阵已经补齐，但不能据此声称预测器在困难设置中稳定有效。

## 4. 老师对“模型分歧”的质疑是成立的

分歧与 family error 的关系依赖 setting：

- 随机缺一格的 Spearman 为 0.368–0.412，置信区间均高于 0；
- 整列未见为 0.210–0.247，仍有正信号；
- 整行未见约 -0.095 至 -0.013，没有稳定正信号；
- 双未见为 -0.349 至 -0.241，方向反而为负。

因此，分歧可以在部分 setting 标出任务难度，不能当成普适的单任务置信度。小分歧
也不能推出预测安全。

## 5. 预测器本身的边界

全部任务平均 RMSE：scGPT 0.11404，GEARS 0.11848，六成员 family 0.11638，
zero-effect 0.11425。scGPT 仅比 zero-effect 低约 0.00022；GEARS 高约 0.00423，
使合并家族整体高约 0.00213。证书的确定性下界仍成立，但弱预测器家族不会因证书
成立而自动变成好预测器。

## 6. 当前结论

E189 完整回答了老师关于训练子矩阵和四种缺失方式的实验要求，也验证了老师对
disagreement 解释边界的判断。它支持的结论是“可在预测前给出严格的 family-error
下界，并明确识别适用 setting”；不支持“分歧能普遍排序任务风险”或“六模型家族
在困难泛化中稳定胜过零效应”。跨研究问题由 E190 单独检验。
