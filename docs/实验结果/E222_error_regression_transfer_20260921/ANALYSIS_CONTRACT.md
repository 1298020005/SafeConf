# E222：直接拟合误差的跨研究评分器对照

登记于 2026-09-21，运行前提交。设计依据：E220 的实际复核增量偏小，E221 的全研究
权重搜索仍有明显异质性。此次检验“优化目标是否错位”与“非线性额外信息是否有用”，
不增加上游表达预测模型，不修改 E208 冻结方案。

## 固定输入、误差和候选

只读 E153 已公开 3,465 条任务记录、8 个研究、34 个 fold。唯一输入 SHA-256：
`b75f5edae0bb585ba5ff18aecafcc2389b0f05fd5cc86b36960afb4b62e4a15a`。
任务唯一键为研究、fold、任务 ID；同一任务在不同 fold 的不同预测仍保留。
误差仍是原 CSV 的双预测器平均 RMSE，不偷换为平均预测向量误差。

两个完全同等调参权限的输入组：幅度 M；幅度 M + 历史 SafeConf S + 分歧 D。
所有输入先在各 fold 内转百分位。测试批次自身的未标记特征可用于算百分位，这是
批量排序设置，不声称支持不变的单任务在线分数。

每组预列三个候选：二次多项式 Ridge（岭回归）alpha=1、10；
HistGradientBoostingRegressor（梯度提升树）80 轮、学习率 0.05、7 叶、最小叶 30、
L2=1、early_stopping=False、随机种子 20260921。无后续扩大搜索。
这只是强学习基线及改进方向审计，不称为完整 PertEMA 复现，也不声称新的学习算法。

## 训练目标和隔离

在训练集内，把每条 RMSE 除以所在 fold 的平均 RMSE，得到相对误差；按平方损失拟合。
每个研究总权重相等，同一研究的 fold 总权重相等。不读取目标研究真值进行标准化。
按条件期望误差排序，在模型校准正确的理想条件下会最大化固定预算所包含的预期误差
总量；实际跨研究迁移不保证满足该条件，必须实测。

外层留出一个完整研究。内层对其余七个研究再次留一：用六个训练、一个验证，平均
utility@20% 选择算法；并列按候选列表顺序。随后用七个研究重新拟合，给外层研究打分。
幅度输入组与完整输入组分别执行同样流程。所有训练、验证、测试研究 ID 留存。

附加一个事先固定的保守使用规则：完整输入组的内层 utility 平均相对原幅度增量
至少 0.02，且七个验证研究至少五个增量 >0 才采用它；否则回退为原始幅度百分位。
这不提供未来研究的安全保证。

## 输出与判定

所有研究、候选、预测、选择、场景分解完整公开。主要端点为八研究等权的 utility@20%
差值，同时比较原幅度与同算法幅度输入组。次要为 Spearman、错误抓取率、剩余任务
相对误差。5,000 次配对研究重采样只描述固定外层预测在当前八研究中的差异；训练集
有重叠，区间不包含全部重训练/选模不确定性，不作独立确认性检验。

本轮开发通过标准：完整输入组相对原幅度 utility 增量 >=0.02 且描述区间下限 >0；
相对学习幅度组也有正增量且下限 >0；至少 6/8 研究相对原幅度方向为正。否则记为
开发未通过，不能按某个次要指标或删研究改判。通过后也须另有未参与开发的新数据确认。

仅用 CPU，最多 4 个外层并行、每个 BLAS/OpenMP 单线程。E208 工作目录及 GPU 队列
保持不变；不加载任意 E208 真值、模型或测试输出。
