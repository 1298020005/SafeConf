# E252｜历史证据是否减少风险评分器所需的错误标签

2026-09-24 登记，先于本轮计算。使用 E201 **已解封的旧数据**作回顾性方法开发；它不能被写成新的独立验证。外层每个目标细胞背景单独建评分器，其历史特征由 E201 原有“排除该目标背景的来源数据”生成；只允许给评分器使用该目标内少量校准扰动的真实误差。这样避免 E228 那种“其他目标的历史特征引用当前外层测试背景”的交叉泄漏。

## 固定问题

误差对象为 TxPert 四种子的 `family_rms_error`，只纳入四背景的 `primary_ge30` 单基因任务。每个背景按 SHA256(`E252:eval:` + 背景 + `:` + 基因) 排序，把前 20% **基因**作为共同评价组；其余 80% 只供抽取校准标签。若一个基因有多任务，整簇同进同出。目标背景内分别报告，不根据结果排除背景。

从校准池按预定随机种子抽取 `1%、5%、10%、20%、50%、100%` 的基因，16 次重复；“100%”仍不包含外层评价组。评估标签用于计算误差，但不能参加任何模型拟合或权重选择。这里的随机重复只是校准集敏感性分析，不是 16 个独立研究。

两套小模型使用**完全相同**的正系数岭回归（`alpha=10`），所有特征先在该目标的未标记任务全集上转为百分位，缺失仍用 E201 已冻结的插补值：

- 无历史版：`M=predicted_magnitude`、`D=family_disagreement`。
- 有历史版：同样的 `M,D` 加 `G=model_source_gap`、`H=source_delta_dispersion`、`N=negative_log_source_cells`、`C=support_context_deficit`。

两版都预测校准任务的真实家族 RMS 误差，输出评价任务风险分。单项 M、D，以及固定 `0.8 rank(M)+0.2 rank(D)`、`0.8 rank(M)+0.2 rank(H)` 同时列为不使用错误标签的对照；后者属于已用 E201 调查过的开发规则。

主要报告同一 20% 复核预算下的 oracle 归一化效用，配对比较“有历史小模型 − 无历史小模型”；还须比较有历史版与**所有无标签简单规则的最强者**，不能因为只赢 M 就称完整方法成功。Spearman 作补充。若历史在 1%/5% 有优势但在充足标签时消失，记录为待独立数据复核的“低标签假设”，不直接宣称比 PertEMA 更省标签。PertEMA 的完整软件/标签预算公平复现另立实验。

不做逐背景挑胜者；所有 4 背景×6 预算×16 抽样种子的数值及负结果入表。任何看结果后的特征、权重或误差对象变化另编号，不覆盖本轮。
