# E271｜不使用错误标签的固定 Bsafe 公式

E271 使用与 E270 相同的按扰动整体留出，但完全不训练风险模型、不读取真实错误标签。固定分数为：

`M + mean(rank(-support), rank(-context_similarity_max), rank(-context_similarity_mean))`

另列一个加入当前预测分歧的固定版本。所有权重事前相等，没有根据结果挑权重。

## 结果

`M+Bsafe` 固定公式在 Cui、Lara ex vivo 有明显正向线索，在 Santinha 下降；9 个研究×预测器组合中 6 个为正，宏平均 Utility@20 差值约 `+0.1295`。加入分歧的固定版本宏平均约 `+0.1025`，仅 4/9 组合为正。

这说明公共支持/背景信息并非无效，但固定无标签公式存在明确适用范围，不能把 Cui/Lara 的增益外推到所有研究。后续若走 training-free 主线，必须把适用范围事前定义并在新研究验证；若允许过去错误标签，则应转入 E270 的监督式风险层表述。
