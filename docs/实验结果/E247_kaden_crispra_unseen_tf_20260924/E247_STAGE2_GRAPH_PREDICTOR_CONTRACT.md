# E247 第二阶段：GO 图谱小模型的上游能力门

登记于 2026-09-24，验证扰动表达尚未读取时。此阶段的模型**预测扰动效应**，属于 SafeConf 的上游；其表现不能冒充 SafeConf 风险排序结果。

## 数据与误差对象

- 训练：物理隔离的 1,093 个扰动标签及 42,233 个对照细胞。目标为每标签平均 `log1p(CPM)` 表达与训练对照均值之差。
- 基因面板：从训练扰动效应的逐基因方差中取前 1,024 个，方差并列按基因名排序。验证/测试表达绝不参与选面板。
- 验证：冻结 376 个标签，用 SHA256(`E247:tune:` + 标签) 排序，一半用于超参数选择，一半只作能力门检查。测试 367 标签的表达直到预测及风险分封存后才允许读取。
- 主要误差：同一 1,024 基因轴上每扰动平均表达效应向量的 RMSE。无变化预测输出零效应；训练平均效应也单列。模型能力通过要求：能力门半组平均 RMSE 比无变化至少低 2%，扰动标签 bootstrap 的相对改善 95% 区间下限大于 0。

## 固定模型与选择网格

把公开 GO top-50 图限制到全部 1,836 个扰动标签，保留图权重、补自环；对每个标签生成一跳及两跳行归一化邻域向量，两跳部分乘 0.5，拼接后再做逐标签单位 L2 归一化。此图只用外部先验与已封存的标签，不碰目标扰动表达。用训练标签的图特征拟合核岭回归，目标为训练效应向量；预测时可加训练平均效应截距。

只在验证调参半组选择：核岭惩罚相对于训练核对角中位数取 `0.001/0.01/0.1/1/10`；图预测强度取 `0.25/0.5/1`；训练平均效应截距强度取 `0/0.5/1`。选择平均 RMSE 最低者，同值按更大惩罚、更小预测强度优先。能力门半组不用于调参。设备优先 GPU，只是加速矩阵求解；不能把显卡使用当成生物学贡献。

如果能力门失败，保留全部配置和误差，不解封测试；另一个不同的上游预测架构必须先登记再验证。若能力门通过，才锁定上游预测及 SafeConf 候选，在测试集一次性比较幅度、GO 图历史证据、分歧可用时的分歧和组合。单一 RPE1 背景不能检验跨背景历史质量。

本文件不预告会得到正结果，也不声称核岭模型是 GEARS 或 TxPert。
