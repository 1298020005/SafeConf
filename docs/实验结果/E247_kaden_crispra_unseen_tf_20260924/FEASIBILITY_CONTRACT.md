# E247：独立 CRISPRa 转录因子数据的未见扰动可行性门

登记日期：2026-09-24。当前只登记**资产与标签门**，尚未登记或运行正式风险评价；
不得把本文件解释成 E247 已获得正结果。

## 为什么选这一范围

E199 的正信号来自 K562 中的未见基因扰动，而 E200/E201 的整细胞背景留出显示
预测幅度可能取代模型分歧。因此下一次独立确认优先考察“细胞背景已知、目标
扰动未见”这一明确范围。Southard 等人的 RPE1 转录因子 CRISPRa 数据属于新的
研究、细胞背景和扰动机制；它不会被写成 E199 的同分布重复。它的机制差异既是
外部检验的价值，也是可能失败的原因。

数据源：scPertEval 官方处理版 `kaden25rpe1_processed_complete.h5ad`；
官方页面报告 850,225 个细胞、42,233 个对照细胞、1,836 个单扰动标签。
固定 HTTPS 来源为
`https://storage.googleapis.com/scperteval/processed/kaden25rpe1_processed_complete.h5ad`。
存储对象声明大小 5,641,728,720 字节、MD5 `bda7f3ea0173f64a0898ab6bb21a4a16`。
先校验这两个值，再检查 H5 内部结构。原始 5.6 GB 文件只留在服务器，不入 Git。

**来源质量限制**：原研究明确报告 CRISPRa guide 的 seed 相关脱靶现象；
scPertEval 精简版只保留基因级扰动标签，不能据此检查每条 guide 的脱靶或
重做 guide 级过滤。因此它可先用于独立预测基准，但若要把某些“高误差”解释
为真正的生物学模型失败，还须核对原研究 guide/QC 元数据，并另报仅限可靠
guide 的灵敏度分析；取不到元数据时不作这种更强的解释。

## 第一阶段：只读标签，不读扰动表达

脚本 `tools/scripts/audit_e247_kaden_labels.py` 只读取 `obs/perturbation` 的类别与编码、
`X` 的形状元数据和基因轴长度；不读取 `X` 的数值、真实效应或任何预测误差。
逐扰动计数小于 30 的标签事先记为不可评价，不因结果改变门槛。对合格的非
`control` 标签，使用 `sha256("kaden25rpe1:" + 标签)` 的前 64 位做固定划分：
前 60% 训练，接着 20% 验证，最后 20% 测试。标签、细胞数、分组、输入哈希
都要提交到两个远程，之后才训练上游模型。没有合格的对照或任一分组任务数
少于 100，停止，不临时重划。

2026-09-24 标签门结果：官方文件大小、MD5、850,225 细胞、42,233 对照及
1,836 扰动标签均核对通过；全部扰动至少 30 个细胞，SHA 固定划分为
训练 1,093／验证 376／测试 367，基因轴 28,907。逐标签清单见
`E247_LABEL_ONLY_SPLIT.csv`，其 SHA256 为
`3b6992bad649e4c7a12932ba016eb99fb61830209d29a3ffc7389b55c2ea09af`；
测试表达仍读取 0 行。只按图谱元数据核对的候选节点覆盖为：STRING
训练/验证/测试 `1065/367/357`，GO 为 `1033/357/350`。图谱来源哈希分别为
STRING `55d312f8d6186078eb00a7caf108ef731cd27aa08a5b48de59cd0333f0206404`
和 GO `ad469c852ba9b8b5489749c7987467687aa566598fc0706fd7232aa27edce27b`。
这些计数只说明图谱节点大多存在，不说明模型会比简单基线更准。

## 第二阶段：模型与风险候选，需要另行冻结

资产与标签门通过后，才做数据接口和一个小规模训练试跑；在任何验证/测试
扰动表达参与评估前，单独冻结：上游预测器架构、随机种子、模型选择规则、
特征和评价代码。优先检验已有实现可适配的 GEARS/TxPert，而不是把训练失败的
模型强行拿来证明 SafeConf。至少比较：无变化预测、训练集平均效应、单模型
预测幅度、模型间分歧，以及事先确定的组合。正式风险对象必须明确是单模型
误差还是注册家族的 RMS 误差，不能在结果出来后切换。

TxPert 官方 onboarding 示例不能原样套用：它会先用扰动效应过滤细胞、再在
整张矩阵上选高变基因；若在本实验的验证/测试标签上执行，就会提前使用
目标表达。scPertEval 的 `X` 已按 1e4 归一化并 `log1p`，也不能再次归一化。
适配器只能根据训练扰动及允许使用的对照建立特征轴、归一化合同和图映射；
测试扰动表达直到最终解封都不得参与过滤、选基因、训练或选模型。若缺少
真实批次字段，不伪造具有生物含义的批次校正；把单一批次假设写清楚。
当前 H5 的 `obs` 实际只有 `cell_barcode` 与 `perturbation`，也没有 TxPert 默认
配置要求的 `obsm["raw"]`；所以不能直接把它喂给原版配置运行。必须先写
专用、可审计的接口，且对验证/测试扰动的表达做物理隔离，不能仅靠程序员
承诺“虽然读到了但没用”。

训练视图构建器 `tools/scripts/build_e247_train_only_view.py` 已单独登记并通过
合成数据隔离测试。它先核对官方文件与标签清单 SHA256，再只索引训练标签和
对照的 CSR 表达区间，输出不含验证/测试扰动表达或类别的独立 H5AD。
这一步只完成数据隔离，**不是训练了 GEARS/TxPert，更不是得到风险成绩**。
生成后的视图仍须检验 AnnData 结构与行数，并把视图 SHA256 留在运行记录。

验证集先过上游能力门：相对同一批任务的无变化预测，主要误差至少改善 2%，
且改善的基因簇 bootstrap 区间下限大于 0；否则停止风险主张。风险候选必须
在验证集中超过同预算的预测幅度，才可冻结并在测试集一次性检验。正式增益
以固定 20% 人工复核预算的高错误捕获效用为主，逐任务表、随机基线、全部
训练种子和负结果都保留。测试真值只在预测与风险分双远程封存后授权读取。

最近的 PertEMA 软件同样研究预测后的可靠性。若进入投稿级比较，应在同一
Kaden 划分上用**训练集扰动的折外误差**重新拟合其监督式元评估器，再比较
相同测试任务与复核预算；不能直接拿它在 CD4 数据上冻结的示例模型测 Kaden，
也不能让 SafeConf 使用更少信息却声称无条件优于可见误差标签的方法。无法按
其公开流程公平复现时，比较表中明确标为缺失，不能写成已经战胜该方法。

这份阶段计划**不保证**模型能力门或风险增益通过；若两者失败，E247 仍给出
可复核的适用范围边界。若正向，也只支持“RPE1 转录因子 CRISPRa 未见扰动”
这一范围，不自动推广到药物、其他细胞背景或所有基因扰动。

## 当前论文候选的真实位置

| 范围 | 已有事实 | 现在的用途 |
|---|---|---|
| 已知 K562、未见单基因（E199） | 三个公开架构的分歧在 263 任务上与家族误差相关；预测幅度较弱。模型本身也明显优于简单基线。 | 正向开发证据；不是新独立研究上的确认。 |
| 整背景留出（E205 经 E220 同口径校正） | 固定组合在 20% 预算的增量约 +0.014，区间跨 0。 | 不把它写成稳定的实用复核收益。 |
| Jiang24 来源迁移（E245/E246） | 全 12 状态上游能力门失败；IFNG 局部预测略有改善，但历史离散度对幅度没有风险增益。 | 保留负结果；不拿这个局部包装 SafeConf 风险成功。 |
| Kaden RPE1 CRISPRa（E247） | 官方资产已完成大小/哈希校验；850,225 细胞、1,836 扰动标签，标签划分 1,093/376/367 已封存；尚无模型或风险结果，测试表达读取 0 行。 | 独立候选，不是已确认贡献。单背景数据不能检验跨背景历史证据。 |

若要把窄范围写成有说服力的计算方法论文，E247 测试端至少应同时满足：
上游预测确有能力；相同任务、误差对象和 20% 预算下，冻结风险规则对预测
幅度的 oracle 归一化效用增量达到 `+0.05` 且扰动基因簇 95% 区间下限大于 0；
完成与已有事后可靠性方法的同合同对照，并把不适用范围完整报告。这个门
衡量的是方法证据，**不是期刊录用概率的数学保证**。测试前如果发现设计
不可行，可以登记新实验；不能改本次已登记的划分去追求好看的数字。
