# E247 第四阶段：GEARS 架构的任务均值适配器

2026-09-24 登记于运行前。阶段二 GO 核岭和阶段三两种子图网络都未超过“训练扰动平均效应”这一更强上游基线，因而尚无可用于 SafeConf 主张的 Kaden 预测器。本阶段测试已有 GEARS 架构的**任务均值适配**，不把它冒充原版逐细胞官方 GEARS 或 SafeConf 自身的小模型。

输入只用物理隔离训练视图及已封存的 1,024 基因面板：训练扰动标签 1,093 个和训练对照均值。GO top-50 图只在全部 1,836 标签上作外部基因先验；基因图仅从训练视图的 42,233 个对照细胞计算绝对 Pearson 相关，每基因保留前 20 个且相关 ≥0.4，补自环。验证/测试扰动表达不用于建图。训练任务为同一对照均值输入、扰动标签输入，目标为训练扰动的平均表达向量。

固定 GEARS/PRESCRIBE 仓库的 `GEARS_Model` 架构，不修改其网络方程；`num_genes=1024`、`num_perts=1836`、隐藏维 64、GO/Gene 图各 1 层、解码器 16、单均值任务 MSE、Adam 学习率 0.001、batch 16、最多 100 轮、验证调参半组连续 12 轮未改善早停。种子 `31` 与 `47` 分别在两张 GPU 训练，预定主候选为两个最佳 checkpoint 的预测均值；单种子保留。最佳轮次只由 E247 原有 188 个验证调参标签决定，另外 188 个能力门标签不选模型。测试 367 标签表达继续封闭。

主能力门与阶段三一致：门半组的两种子集成平均 RMSE 同时低于无变化和训练平均效应，且相对后者的标签 bootstrap 95% 区间下限 >0。与阶段二 GO 核岭、阶段三图网络同一训练/验证标签和同一基因轴比较。若失败，不读测试真值；留下全模型、全种子的负结果，另找不同机制或数据，不能继续在同一验证门上无限调网络。

注意：PRESCRIBE fork 的 GEARS 实现把 GO 节点独立列为 `num_perts`，此处在训练前固定全标签节点映射，使未见扰动有外部图邻居；随机权重只从训练任务获得梯度。发布时需明确本阶段是可复算适配器，不引用原 GEARS 论文成绩代替本结果。
