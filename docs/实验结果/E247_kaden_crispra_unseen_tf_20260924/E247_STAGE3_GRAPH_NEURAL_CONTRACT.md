# E247 第三阶段：两个随机种子的图神经扰动预测器

2026-09-24 登记于运行前，E247 测试扰动表达仍为 0 行读取。阶段二 GO 核岭回归达到相对无变化 +2.18% 的最小能力门，但**比训练平均效应基线略差**（能力门半组平均 RMSE 0.040694 vs 0.040673）；其任务特异信息不足，不能直接当有说服力的上游模型。本阶段检验更有表达能力、但同样只使用训练标签的图预测器，不改变 E247 标签划分或 1,024 基因训练面板。

固定输入：GO top-50 图的一跳、两跳邻域（与阶段二同一固定特征轴），以及该图的行归一化邻接矩阵；不输入任何验证/测试真实表达。模型对全部 1,836 扰动标签作图特征编码，经两次邻域聚合和全连接层，输出 1,024 基因的扰动效应向量。训练标签 1,093 个；验证标签的 SHA 半组用于选每个随机种子的最佳训练轮数，另一半作为能力门。随机种子固定为 `31,47`，两个模型算术平均是预定主上游候选；单种子完整列示。两个 GPU 可并行训练，只是加速。

超参数固定：隐藏维 128、两层图聚合、dropout 0.10、AdamW 学习率 0.001、weight decay 0.0001、最多 250 轮、连续 30 轮无验证改善则早停。训练目标是训练标签平均效应向量的 MSE；每轮按验证调参半组平均 RMSE 选 checkpoint。评价时比较同任务无变化预测、训练平均效应、阶段二 GO 核岭及新模型；**实用能力要求新模型在能力门半组同时优于无变化和训练平均效应，且相对训练平均效应的标签 bootstrap 95% 区间下限大于 0**。这是比原阶段一“只超无变化”更严格的门，不能因失败而改回弱门。

若门失败，不读测试表达；保留所有训练曲线和负结果，再另行登记不同上游结构或数据。若通过，冻结两个 checkpoint、预测和候选风险分，再开启独立测试。此图模型是上游扰动预测器，不是 SafeConf 风险评分小模型，不能作为 SafeConf 的方法创新点。
