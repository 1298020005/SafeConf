## 今天最该讲的研究问题

单细胞扰动预测模型会给出“敲掉某个基因或施加药物后，细胞表达会怎样变化”的预测。
SafeConf 不重新预测，而是在预测之后回答：**哪些预测在真值未知时更值得优先复核或
做湿实验？**

这个问题必须同时满足三条：

1. 风险分数要对应一个明确预测器或明确预测器家族的真实误差；
2. 打分时只用部署时能得到的信息，不能读取 target 的扰动后表达；
3. 不能只在随机拆分上有效，要看小训练矩阵、整行/整列留出和跨数据集。

## E201：正在补的关键证据

E201 使用公开 TxPert STRING-GAT，把 K562、RPE1、HepG2、Jurkat 轮流完全留作
target；训练只能看其余三个背景的扰动数据和 target control，不能看 target 的扰动
后表达。每个 target 训练 4 个预先登记的种子，共 16 个模型。

截至本次汇报：

| 状态 | 数量 | 含义 |
|---|---:|---|
| 完成训练 | 7 / 16 | K562、RPE1、HepG2 的 seeds 1–2，Jurkat seed 1，均完成 80 epochs |
| 正在训练 | 1 / 16 | Jurkat seed 2，约第 79 / 80 轮 |
| 已排队 | 8 / 16 | seeds 3–4 的四个背景 |
| target 扰动真值访问 | 0 行 | 不允许用中间表现改模型、种子、任务或风险规则 |

完成模型的 source validation 只证明训练正常，**不是 target 测试结果**。所有 16
个模型完成后，顺序已冻结为：检查和封存 checkpoint → 零真值预测 → 封存风险量与
general baseline → 双远程 Git 留存 → 才释放 target 真值 → 正式评价。

## 对“能不能发表”的严肃回答

今天不建议问“老师，我这个能不能发论文？”然后等待一个是/否回答。更有用的问法是：

> “我现在把问题收成：对已有扰动预测做不看真值的风险审计，并在困难留出下说明何时
> 能用、何时应当 abstain。E189–E200 给出了小矩阵、跨研究、公开图模型和一个完整
> 背景留出的证据；E201 正在把完整背景留出扩成四个 target、四个种子。您觉得这个
> 问题和证据结构够不够作为一篇方法论文的主线？E201 完成后，您认为还缺哪一类独立
> 验证，才值得开始写正文？”

目前的判断：

- **有论文问题**：预测之后的风险分诊、明确的部署信息边界、困难 split 和
  fail-closed（不验证就不启用经验排序）是一个可写的问题；
- **已有可讲结果**：E189–E200 并不是只有正结果，包含 magnitude 更强、跨研究
  不稳、RPE1 `ABSTAIN` 等重要边界；
- **尚未达到“可直接投稿”的完整度**：E201 未完成，基因侧的多背景结论尚不能写；
  chemical 的强弱与 gene 不同，不能作为同一条普适主张；仍需老师确认主线是
  “可靠性审计合同/边界”还是“某个风险量优于 magnitude”；
- **最稳的预期**：E201 结果无论正、负或分 target 不同，都会决定文章到底写成
  “在何种条件下可安全路由”的方法论文，还是需要再增加一个独立验证。

## 今天汇报后应得到的三个明确决定

1. 老师是否接受“预测后风险审计 + 困难 setting + 不适用时 abstain”为主问题；
2. E201 全部评价后，是否需要一个新的独立数据集，或 E201 四背景已足以进入写作；
3. gene 与 chemical 是否分成主文与边界章节，而不是强行合并成一个统一成功结论。

如果这三个决定没有拿到，继续随意增加数据或换模型不会让论文更清楚。
