# E221：留一研究外推的自适应风险排序

登记日期：2026-09-21。E221 是 E153 八个公开研究上的后续方法审计，不修改
E201/E205/E208 的主方法或确认性协议。它回答一个窄问题：如果风险分的权重只在
其他研究上选择，再用于一个完全留出的研究，能否在固定 20% 复核预算下稳定优于
同口径预测幅度？

## 输入与隔离

- 唯一输入：`E153_ABSOLUTE_TASK_INPUT.csv`，SHA-256 固定为
  `b75f5edae0bb585ba5ff18aecafcc2389b0f05fd5cc86b36960afb4b62e4a15a`。
- 每个任务的输入特征是已有预测后的 `baseline_predicted_magnitude`、
  `safeconf_calibrated_pair_risk` 和 `risk_model_disagreement`。真实误差只用于
  训练集内选择候选公式和最终留出评价；留出研究的误差不会参与选参。
- 评分和结果均在 `dataset × fold_id` 内计算百分位，避免不同研究的尺度混入。
- 外层按完整 `dataset` 留出；内层再次按完整研究留出，在外层训练集内部选择候选。
  外层测试研究只在选择完成后读取误差。

## 事先固定的候选

候选集合在运行前固定，不根据结果增加候选：

1. 幅度百分位 `M`；
2. 固定 `0.8M + 0.2S`（当前 SafeConf-M）；
3. 单项 `S`、`D`；
4. 非负三项线性组合 `w_M M + w_S S + w_D D`，每个权重为 0、0.25、0.5、0.75 或 1，
   且三者和为 1；
5. 单向修正 `M + λ_S max(S−M,0) + λ_D max(D−M,0)`，两个 λ 取
   0、0.25、0.5、0.75、1。

候选只在内层平均 `utility@20%` 最高时被选中；并列时依次选择更简单、权重更小的
候选。该规则不看外层研究的结果。所有候选、外层选择和失败情况完整输出。

## 主要指标

- Spearman：风险排序与真实 RMSE 的秩相关；
- `utility_20`：固定复核前 20% 任务，相对于随机选择和理想选择的归一化收益；
- `capture_20`：前 20% 风险任务包含的误差总量比例；
- `remaining_error_80`：放过低风险 80% 后的平均误差。

主要汇总为八个研究等权平均，另报每个研究和每个场景；不把最高的一项改写成主
方法。研究簇 bootstrap 只用于描述当前八研究的区间，不能当成所有未来数据的保证。

## 解释边界

E221 是“需要有标签的开发期自适应分数”的外部审计，不等同于免重训、无需误差标签
的 SafeConf-M。若 E221 为正，下一步必须把选定规则冻结后在全新未参与开发的数据上
另行验证；若为负，保留负结果，主方法继续使用事先冻结的 SafeConf-M 或证书路径。
任何结果都不能通过删除研究、删任务或改真实误差来改善。
