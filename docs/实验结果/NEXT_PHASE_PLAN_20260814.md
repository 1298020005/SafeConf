## 2. 以前的思路：哪些对，哪些必须丢掉

我按 Codex 长会话、周老师原话、现有论文草稿和 E189–E201 冻结协议对过。
结论不是“全部错”或“全部对”，而是两条线被混在一起了。

### 2.1 必须保留的（和老师、和证据都对齐）

1. SafeConf 不是新预测器，是预测之后的质检。
2. 分数必须绑定具体预测器/家族和误差定义，不能说成“模型置信度”。
3. predicted magnitude 不看真值，而且必须留作强基线。
4. 随机缺一格太容易；要看小矩阵、整行整列、跨数据集。
5. 没见过的任务仍可用 control 相似度和扰动关系；没有合法输入就 abstain。
6. gene 和 chemical 分开报告，不写成一套规则普适。
7. E201 用公开 TxPert 做四个细胞背景 × 四个种子的整列留出，在 16 个模型完成前
   不看真值。这和老师的“整行整列”以及 TxPert 自己的 leave-one-cell-line-out
   是同一类问题。
8. 负结果要留：双未见失效、RPE1 `ABSTAIN`、E200 上 magnitude 更强。

### 2.2 必须丢掉的（会话里反复把项目带偏的）

1. **用“稳定二区 / 冲一区”驱动实验。** 老师原话是：三个更难 setting 都解决了，
   可以写一个小文章。分区不是实验门。
2. **把“永远优于 magnitude”当论文主主张。** E200、chemical、跨研究都有反例。
3. **旧稿 `submission/SafeConf_current/` 的主线不能当下一篇直接投稿。**
   那份稿写的是 registered-family error certificate + conformal 上界；老师要听的
   是预测后风险审计、困难 setting 和何时 abstain。两套可以互相支撑，但现在不能
   把旧摘要数字继续小修小补。
4. **7 月论文学习页里“六数据总体超过 magnitude”已经过期。**
   `docs/学习导航/04_论文创作接力说明.md` 自己也写了必须改。
5. **课程论文、考试复习、组会 HTML 和科研主线不要再搅在同一条执行队列里。**
   课程部分已归档；今天只走科研。
6. **不要为了“补到能发”再开新数据、新模型或湿实验。** 先把 E201 按冻结顺序评完。
   老师若要求独立验证，再开；现在开等于用未完成的主实验给自己加戏。

### 2.3 一句话审核

后期 Codex 把主线收成“风险审计 + 困难 setting + 不适用就 abstain”，这个收法
是对的。早期 GPT/Codex 用分区和“再跑就能赢 magnitude”推实验，这个方向是错的。
E201 本身该继续，但只能当老师要的整背景留出证据，不能当成投稿开关。

三个科学门分开判，互不替代：

2. 经验路由门：SafeConf 与 family RMS 的相关、20% 复核效用；
3. magnitude 增量门：控制幅度后是否还有增量。

四个 target 无论正负全部报告。不允许删背景、改种子、改公式。

## 4. 论文学习后的可用主张

对照现有已解盲证据，今天可以写进提纲、不能写进投稿结论的分界如下。

| 主张 | 现在能不能写 | 依据 |
|---|---|---|
| 预测后风险审计是一个可写的方法问题 | 可以写提纲 | 老师认可框架，E189–E200 有正负边界 |
| 小矩阵 / 行列 / 跨数据集都能算 | 可以 | E189、E190、E192、E84/E87/E89 |
| 这些 setting 都比 magnitude 好 | 不能 | 多处反例 |
| 公开图模型在 K562 未见扰动上有风险信号 | 可以，须写边界 | E199 |
| 整背景留出已经在多个细胞系上成立 | 不能 | 只有 E200 的 K562；E201 未开真值 |
| registered-family 下界是经典分解，不是新定理 | 可以 | 旧稿这部分数学表述可用 |
| 已经是稳定二区 / 可直接投稿 | 不能 | E201 未完成；竞品对照也未按 7 月阻断项闭合 |
| PRESCRIBE 同协议正面打赢 | 不能 | 仍是投稿前阻断项，不是当前主实验 |

旧稿里可复用的是：问题定义、ambiguity 分解、不把 disagreement 说成正确概率。
必须重写的是：摘要数字、主结果叙事、以及任何“证书已经足够投稿”的句子。
