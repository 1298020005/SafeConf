## 现在最重要的科学判断

当前证据支持“风险排序在部分轻量 reference setting 能筛出高误差任务”，不支持“固定四项等权分数在跨域场景普遍优于预测幅度”。这不是措辞问题，是 E59 和 E61 的实测结果。

E60 又补上了真实模型层面的反证：Adamson 的 24 个固定未见基因任务上，GEARS 三 seed ensemble 的分歧与真实 ensemble RMSE 的 Spearman 为 −0.091（bootstrap 95% CI [−0.475, 0.289]）；预测幅度的 ρ 也只有 0.095（CI [−0.250, 0.425]）。panel-level perturbation-specific centroid accuracy 为 2/24。也就是说，这个 setting 里，当前 seed ensemble disagreement 不能被当作可靠性分数。

E64 用同一批任务把第二预测器换成 source-only 全局效应基线，GEARS—baseline 分歧的 ρ 为 −0.243（CI [−0.649, 0.214]），top20 高误差富集为 0.608。简单独立基线也没有产生可用风险信号，因此不再重复这类 baseline disagreement。

E65 说明“第二模型必须是真正训练过的、不同模型家族的预测器”是实证问题，不是模型名称问题。旧 E29 的 forward-only scGPT 不可用；E60 的 seed 分歧无信号；E64 的全局效应基线无信号。E65 中 official-tutorial 风格微调的 scGPT 才在完全相同的 24 个未见基因、512 个共享基因、同一 true effect 下给出了任务级分歧信号。这个信号主要反映 scGPT 或双模型任务的风险，对 GEARS 单独风险还不够稳。

E66/E67 是独立 Norman 复现。E66 单看三个 GEARS seed，分歧与 GEARS error 的ρ=.331，CI [−.027,.625]，而预测幅度ρ=.611，CI [.177,.896]；seed disagreement 再次没有超过幅度。E67 把第二预测器换成正式微调的 scGPT 后，模型间分歧对 GEARS error 的ρ=.708，CI [.420,.868]，对两模型平均 error 的ρ=.589，CI [.196,.834]。两套数据共同说明：有价值的是不同模型家族在同一任务上的结构性分歧，不能用同模型 seed 抖动或简单 baseline 偏差替代。

E69 把风险校准器做了 Adamson→Norman、Norman→Adamson 冻结迁移。8 个“方向×目标误差”比较中，`magnitude + disagreement` 只有 Adamson→Norman 的 GEARS error 稳定超过 magnitude；两模型平均 error 这个预设主目标在两个方向的增量 CI 都穿 0。当前同域结果可复现，跨域独立增量尚未成立。

E71/E72 增加了第三个独立数据集 Frangieh。24 个测试扰动只按条件类型、细胞数阈值和固定随机种子选择，没有读取效应或误差。GEARS 三 seed disagreement 对 GEARS error 的ρ=.028，CI [−.382,.442]，第三次说明 seed 抖动不是可靠风险信号。正式微调 scGPT 后，GEARS–scGPT 分歧对预设平均 error 的ρ=.349，CI [−.155,.794]；点估计与 Adamson、Norman 同向，但单面板统计功效仍有限。

E73 用整数据集留一法训练 predictor-aware residual calibrator。平均 error 上，相对 source-trained magnitude baseline 的 Δρ 在 Adamson、Norman、Frangieh 分别为 +.347、+.202、+.187，三者同向，单数据集 bootstrap 区间仍跨 0。该校准器没有在所有目标域超过直接 disagreement，因此不继续在这 72 个测试任务上搜索公式或权重。

E74 给出方法层的清楚定义。对任意两个预测 $p_1,p_2$ 和未知真值 $y$，三角不等式保证平均误差与最大误差都不小于 $d(p_1,p_2)/2$；平方误差还满足精确的 bias–disagreement 分解。72/72 个真实任务通过下界核验，恒等式最大数值误差为 1.475e−17。三数据集分层分析中，模型分歧对 pair mean RMSE 的平均ρ=.477，task-bootstrap 95% CI [.268,.674]，分层置换 p=.0001；对 pair max RMSE 的ρ=.522，CI [.313,.707]。相对 magnitude mean/max 两种固定聚合，四个 Δρ 区间均高于 0。这个结果支持“模型分歧是 pair-risk 下界与排序信号”，不支持“低分歧必然安全”或“能判断哪个模型错”。

E77 用 Adamson、Norman、Frangieh 的第二套不重叠冻结面板复核 E74，共 144 个任务，数据集内两套面板任务重叠为 0。模型分歧对 pair mean RMSE 的分层ρ=.489，95% CI [.348,.617]；对 pair max RMSE 的ρ=.552，CI [.417,.670]。相对 magnitude mean/max 的四个 Δρ 区间继续全部高于 0。第二面板已经回答“一次 24-task 抽样是否偶然”的主要疑问；第三面板不再优先，资源转向小矩阵、整行/整列和跨数据集。

E81/E82 把老师点名的难 setting 放进一个化学 Cartesian 合同。E81 只按标签、细胞数和固定种子冻结 3 个细胞系、9 种 base drug、4 个剂量的 9 个子矩阵设置；整列留出时同一种药的全部剂量一起封存。E82 用两个 inductive reference predictor 生成 688 个 manifest-task/模型、1,376 条 strict PredictionRecords。描述统计显示，分歧在随机缺失 pair 象限的平均ρ=.589，高于 magnitude 的 .354；在新 context、新药和双未见象限，magnitude 分别为 .879、.528、.706，均高于分歧的 .588、.434、.321。该结果证明协议可运行，也给出明确负面边界，不能替代 CPA/chemCPA 主实验。

E82 还暴露了特征可辨识性问题：单独留出一整行时，context similarity 在该行内是常数；留出一整列新药时，历史支持全部为 0。它们可以解释跨行/跨列总体差异，不能单独在同一行或同一列内部排序。后续方法需要按 setting 使用可变化的特征，不能继续把四项机械等权相加。

E83 先用一个 manifest 做 CPA-RDKit 开发 smoke，查看测试结果后永久排除该 split，不再通过改 epoch 把它升级为正式证据。E84 固定 20 epochs、网络结构、log10-dose、细胞抽样和评价合同，在其余 8 个未查看 manifest 上正式运行 CPA-RDKit 与 inductive ridge，共 629 个 manifest-task、1,258 条 strict PredictionRecords，合同问题为 0。分歧对 pair mean error 的 manifest 平均ρ在双未见、新 context、新药和随机缺失 pair 四个象限分别为 .769、.779、.336、.738；相对 predicted magnitude 的 Δρ 分别为 +.019、−.063、−.229、+.106。只有随机缺失 pair 的增量区间稳定高于 0；新 context 和新药由 magnitude 稳定占优，双未见差异不明确。

E85 把同一批冻结分数放入 top-20%、reject-20% 和 AURC。两种分数在实际筛选收益上大多接近；新 context 与新药的 AURC 由 magnitude 稳定占优，随机缺失 pair 的 disagreement 优势很小且区间跨 0。因此 E84 的高 Spearman 不能直接写成明显节省实验资源。化学侧现在已经回答“能不能在这些 setting 上计算并排序”，尚未证明 SafeConf 相对简单幅度基线有稳定选择性增量。

E86/E87 完成了老师点名的真实跨数据集预测。基因面板只由两个数据集的 control 方差确定；CPA-RDKit 与 ridge 只用 sciPlex3 的 108 个源任务训练，OpenProblems 的 553 个 perturbed truth 在预测文件落盘后才读取。分歧对 pair mean error 的ρ=.993，表面很高，但 predicted magnitude 的ρ=.994；Δρ=−.0005，bootstrap 95% CI [−.0010,−.0001]。CPA 与 ridge 在目标域均没有任务优于零效应预测，中位误差分别为零效应基线的 5.43 倍和 8.28 倍。这个 setting 揭示的是强域偏移和预测器失准，不能包装成 SafeConf 跨域成功。

E88/E89 随后冻结同一研究系列的 sciPlex3→sciPlex4 独立批次复核：24 个源任务，28 个目标任务，两个共享药物、两个共享细胞系，16 个精确剂量与 12 个插值剂量。CPA-RDKit 与 source-dose interpolation 先落盘预测，再解封 sciPlex4 真值；56 条 strict records 无问题。分歧对 pair mean error 的ρ=.784，magnitude 的ρ=.835，Δρ=−.051，bootstrap 95% CI [−.200,.068]。插值器与 CPA 分别在 67.9% 和 35.7% 的任务上胜过零效应。该结果说明较合理的 source→target predictor 下 pair-risk 排序可复现，但相对幅度的独立增量仍未成立。

直接竞品不能回避。NeurIPS 2025 的 PRESCRIBE 已经用深度证据回归联合估计单细胞扰动的数据与模型不确定性。SafeConf 的区别应限定为：不改造原预测器的 post-hoc 质检层、可接已有异构预测器、显式审计跨模型和跨数据集失败边界。PRESCRIBE 代码已固定到 `/home/yyf/archive/external/PRESCRIBE` 的 commit `6f7264a205aaff654a9594863c5c10b656f88ebe`，后续需要同协议基线或清楚说明任务差异。

这一点和近期 benchmark 的警示一致：未见扰动预测中，简单基线或系统性变化可能得到看似漂亮的常规指标；评估需要强调扰动特异性和严格 holdout。[Systema](https://github.com/mlbio-epfl/systema) 与 [scPerturBench](https://github.com/bm2-lab/scPerturBench) 都把这类检查作为核心环节。
