# SafeConf：一区目标与二区底线的证据门槛

更新时间：2026-07-12。这里讨论的是研究证据够不够，不按“实验很多”“数据很大”判断投稿档次。分区受年份、学科和期刊口径影响，没有百分之百保证；下面的门槛用于减少明显短板。

## 周老师原话对应的六个问题

| 老师真正问的内容 | 当前证据 | 还缺什么 |
|---|---|---|
| 风险分数和哪个模型的实际预测误差相关？ | E60/E66/E71 明确是 GEARS ensemble RMSE；E65/E67/E72 分别报告 GEARS、scGPT、两模型均值和最大误差。E74 从理论上把分歧对应到 pair mean/max risk。 | 分歧不能判断具体哪个 predictor 错。论文中每个单模型风险结论仍要写清 `predictor + task + error`。 |
| 打分输入在新任务上能不能直接得到？ | E59 区分 predicted magnitude 与 true magnitude；E65/E67 的分歧、预测幅度均来自预测向量，真值只用于最后评估。 | 上下文相似度、扰动相似度、支持度也要逐项给出部署时的数据来源；任何需要目标表达真值的量只能放 oracle/diagnostic。 |
| 现在的随机 pair holdout 是否太简单？ | E81/E84 已用同一 CPA-RDKit+ridge 合同覆盖低覆盖、随机 pair、新 context、新药和双未见。 | 只有 sciPlex3 内部；新 context、新药和双未见没有稳定超过幅度。 |
| 整行、整列、小矩阵下还能不能算？ | E84 共 8 个未查看 manifest、629 个任务、1,258 条 strict records，四类 split 使用同一 predictor pair 与 error。 | 协议已跑通；有效性依 setting 变化，不能写成统一优势。 |
| 一个数据集见过，换到另一个数据集怎样？ | E86/E87 完成 sciPlex3→OpenProblems 强外推；E88/E89 完成 sciPlex3→sciPlex4 同族独立批次复核。 | 强外推中 predictor 失准；同族复核ρ=.784但未超过幅度。两个目标集均已封存，不再调参。 |
| 多几个 setting、多种数据都看看。 | 83 份 scPerturb/scPerturBench 数据已核验；Tahoe 3,388 个 raw shards 已完整落盘；Adamson/Norman/Frangieh 已有正式双模型记录。 | genetic 侧仍要补重复面板和更难 split；chemical 数据必须转成有适配 predictor、严格 split 和 task-level error 的证据。 |

周老师最后说“这三个都解决了，感觉可以写一个小文章”。这句话给出了可发表的最低问题集合，没有说明达到一区。一区还需要方法增量、强基线、跨域复现和清楚的科学发现。

## 当前论文处在什么位置

现有证据更接近一篇“严格评估 + 风险路由”研究，尚不能写成固定四项等权 SafeConf 普遍有效。

- E59/E61 表明固定等权分数在不少方向输给 predicted magnitude。
- E60/E66 表明同一模型的 seed disagreement 不稳定，Norman 上 predicted magnitude 明显更强。
- E64 表明简单全局效应 baseline 的分歧没有风险信号。
- E65/E67/E72 表明真正训练过的 GEARS 与 scGPT 产生的模型家族分歧，在三个独立数据集的预设平均误差上都是正信号。
- E74 将主目标收紧为 pair risk：模型分歧的一半是 pair mean/max RMSE 的无真值下界，平方误差下还有精确分解。首批三数据集 72 任务的分层 pair mean ρ=.477，95% CI [.268,.674]；E77 扩到两套不重叠面板 144 任务后为ρ=.489，CI [.348,.617]，相对固定 magnitude 聚合的增量区间继续为正。
- 三个数据集对“分歧主要筛出谁的错误”仍给出不同答案，说明单模型风险是 predictor-dependent；pair-risk 证书不负责定位错误模型。
- E84 把 chemical 侧接到 CPA-RDKit，在 sciPlex3 的 8 个未查看 Cartesian manifests 上覆盖随机 pair、新 context、新药和双未见。分歧在四类中均为正，但只在随机 pair 中稳定超过 magnitude；新 context 与新药由 magnitude 更强。E85 进一步显示选择性路由收益大多接近，不能把相关性直接换写成显著资源节省。
- E87 完成 sciPlex3→OpenProblems 的真实 predictor 跨数据集链路。分歧ρ=.993、幅度ρ=.994，两个 predictor 均未在任何目标任务上优于零效应预测。该结果说明强域偏移下 pair-risk 仍可计算，但高相关可以由失控的预测幅度制造，不能当成跨域方法成功。
- E89 在同族独立筛选 sciPlex3→sciPlex4 上复核：分歧ρ=.784、幅度ρ=.835，Δρ区间跨0；source-dose interpolation 在67.9%的目标任务上优于零效应。它比 E87 的 predictor 状态健康，支持 pair-risk 排序可跨批次复现，但没有补上幅度之外的独立增量。

这组结果有科学价值：它指出“多个模型不同意”只有在模型确实学到不同归纳偏置时才有意义，seed 抖动和廉价 baseline 偏差不能替代。论文主线应围绕这个发现重构，固定四项公式退到待比较基线。

## 稳定二区的最低证据

以下项目缺一项，审稿时都容易被击中：

1. 至少 3 个独立数据集，覆盖不少于两类 generalization setting；当前 Adamson、Norman、Frangieh 已达到三个 genetic 数据来源，但主要都是整列式未见基因。
2. 至少 2 个真正训练的不同模型家族，所有对照共享 task、gene order、true effect 和 split；Adamson、Norman 已达到。
3. 对 predicted magnitude 的增量价值：E73 已完成 source-trained residual-risk；E74/E77 的三数据集、两套不重叠面板 pair-risk 结果稳定超过两种固定 magnitude 聚合。这个缺口已收口。
4. random pair、低覆盖、整行、整列、双未见、跨数据集六类 split 使用统一报告字段。
5. Spearman、bootstrap CI、top-k enrichment、risk–coverage/selective error 同时报；多 split 结果给总体汇总，不挑单个方向。
6. seed disagreement、global baseline、predicted magnitude、support-only、context-only、模型家族 disagreement 全部消融。
7. 失败结果保留：McFarland、Tahoe magnitude 更强、E60/E64 无信号、E66 seed disagreement 不显著。
8. 从原始任务表到图的完整复现命令、版本、随机种子和 PredictionRecord 合同可查。

达到这些条件后，二区投稿才有较稳的技术叙事。它仍取决于期刊匹配和审稿人，不存在“百分之百”。

## 冲一区还要增加什么

一区需要把“评估做得严”提升成明确的方法与发现：

1. **方法贡献**：从等权打分升级为 predictor-aware 的风险模型。它需要显式分开任务新颖性、模型家族分歧和预测幅度，并在 source/validation 数据上学习，目标是解释 magnitude 之后的 residual error。
2. **跨域贡献**：风险校准器在 dataset A 拟合后冻结到 dataset B；随后再做 predictor 本身 A→B 的外部泛化。两者要分开报告。
3. **选择性预测**：回答“拒绝最危险的 10%、20%、30% 任务后，剩余预测误差下降多少”，并与 magnitude-only、random rejection 和模型原生 uncertainty 比较。
4. **扰动特异性**：常规平均误差之外加入 perturbation-specific 检查，避免系统性平均变化制造漂亮指标。Systema 和近期简单基线研究已经把这一问题抬到审稿门槛。
5. **双模态证据**：遗传扰动和化学扰动分别使用适合的 predictor；化学侧不能用 GEARS/scGPT 代替 CPA/chemCPA 类模型。
6. **机制解释**：高风险任务为何失败，要落到未见基因、通路、细胞状态、剂量、模型归纳偏置等可解释分组，而不只是相关系数。
7. **外部验证**：独立实验室/独立批次数据，最好再有少量湿实验或公开挑战盲测结果。没有湿实验也可投稿，但需要更强的外部 benchmark 和统计设计补足。

## 接下来的实验顺序

### E69：真实双模型风险校准跨数据集迁移（已完成）

- Adamson 24 tasks 拟合风险校准器，冻结后预测 Norman 的任务风险；再做 Norman→Adamson。
- magnitude-only 为主基线；`magnitude + disagreement` 为候选方法。
- 目标分别是 GEARS error、scGPT error、mean error、max error。
- 目标域真值只用于最终评价，不参与权重、标准化或模型选择。
- 输出 Spearman、MAE、top20 enrichment、risk–coverage curve，并报告加入 disagreement 的增量。

结果：8 个“方向×目标误差”比较中，只有 Adamson→Norman 的 GEARS error 显示 `magnitude + disagreement` 稳定超过 magnitude。预设主目标 `task_mean_rmse` 在两个方向的增量 CI 都穿 0。它连接了老师的跨数据集问题，也说明当前增量尚不稳定；迁移对象仍是风险校准器，不等同于 perturbation predictor A→B。

### E70：重复冻结面板

- Adamson、Norman 各生成至少 3 个不重叠 held-out gene panels。
- 复用完全相同的超参数，不根据 panel 结果改模型。
- 汇总 panel-level effect 与置信区间，检验 E65/E67 是否只是一次抽样运气。

### E71：第三个 genetic dataset

- 已完成 Frangieh 24 个冻结未见基因、三 seed GEARS 与正式微调 scGPT；共 72 条 GEARS seed 记录和 48 条共享双模型记录，strict issue_count 均为 0。
- E71 seed disagreement 对 GEARS error 无信号；E72 模型家族分歧对 pair mean error 为正，但单面板区间跨 0。

### E73/E74：predictor-aware 校准与理论证书（已完成）

- E73 每次留出一整个数据集，来源域分组交叉验证后冻结到目标域。pair mean error 的增量在三个目标域同向，但单域区间仍宽。
- E74 证明并核验 disagreement/2 是 pair mean/max RMSE 下界；72/72 任务成立。三数据集分层关联及相对 magnitude 的增量区间均为正。

### 直接不确定性基线

- NeurIPS 2025 PRESCRIBE 是直接竞品，联合估计 aleatoric 与 epistemic uncertainty。代码与论文已归档，下一步按可比任务合同运行或明确不可比项。
- GEARS 原生 uncertainty、seed disagreement、magnitude-only、global baseline、固定 rank aggregation 都要进入同一消融表。

### 后续化学 predictor 合同

- 从 OpenProblems/sciPlex/Tahoe 选择字段最完整的一条线。
- 使用适合药物、剂量和细胞背景的 predictor；建立 compound/context/dose holdout。
- 先比较 magnitude 与模型分歧，再决定是否加入结构相似度、历史支持和上下文新颖性。

## 现在允许写的核心结论

> 在三个独立数据集的严格未见基因任务上，同模型 seed 分歧不能稳定识别高误差任务。不同模型家族的分歧为 pair mean/max error 提供无真值下界，并在 72 个真实任务的分层分析中稳定关联 pair risk、超过固定预测幅度聚合。它不能判断具体哪个模型出错，低分歧也不构成安全保证。

## 现在不能写的结论

- SafeConf 在所有扰动预测任务上普遍有效。
- 固定四项等权分数优于简单基线。
- GEARS–scGPT disagreement 已经是概率校准好的置信度或单模型误差上界。
- 下载 Tahoe raw 数据等于完成了大规模外部验证。
- 三个 24-task panel 足以保证一区或二区录用。

## 外部方法门槛

- [scPerturBench, Nature Methods](https://www.nature.com/articles/s41592-025-02980-0)：多方法、多数据集、未见扰动/上下文评估说明单一数据切分已不够。
- [Systema, Nature Biotechnology](https://www.nature.com/articles/s41587-025-02777-8)：强调系统性变化、简单均值和扰动特异性问题。
- [简单基线审计, Nature Methods](https://www.nature.com/articles/s41592-025-02772-6)：复杂模型必须和合理简单基线在统一协议下比较。
- [scGPT 官方 perturbation tutorial](https://scgpt.readthedocs.io/en/latest/tutorial_perturbation.html)：E65/E67 的 scGPT 训练路径依据；forward-only smoke 不算正式预测器。
- [PRESCRIBE, NeurIPS 2025](https://openreview.net/forum?id=A5O41ntKjk)：直接的单细胞扰动不确定性竞品；SafeConf 必须比较或清楚区分 post-hoc 异构预测器质检与其 integrated evidential predictor。
