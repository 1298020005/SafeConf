# E239｜第三批未用基因：混合任务队列的增量检验

2026-09-23，在读取本批次扰动表达和运行预测器之前登记。E139、E237 的结果已经看到，尤其已看到 E237 的任务类型混合效应；因此这是对**事后选定的窄场景**的一次新基因检验，不宣称新研究外部验证。

## 适用范围和全部任务

对象为 Nadig HepG2/Jurkat 单基因 CRISPRi，scGPT 和 GEARS 两个预测器共同提供输出。先用细胞数、基因名和词表筛选；排除 E136、E237 的全部 224 个已用基因，再按固定哈希从 561 个剩余合格基因选 128 个。两个细胞系轮流作外层留出；每折同时包含来源细胞系内的新/已见基因测试，以及目标细胞系的所有已见/新基因测试，合计 332 行。四种任务情形都在主表报告，不因误差差或分数低而删除。

## 冻结评分、对照和终点

E135 方向风险公式和模型 SHA-256 不改；上游训练沿用 E112/E138/E237 的 scGPT/GEARS 512 基因面板和超参数。冻结评分仅使用两个预测器输出、来源训练支持、背景对照。主终点为两模型平均的 Systema-centered Pearson/cosine 方向误差折内秩均值，主统计量为两折等权 Spearman。

此次主比较器加强为：**细胞背景见过与否 + 预测幅度 M + 扰动新颖度 N**，三项分别在同一折内转百分位后等权相加。它不使用目标误差、模型训练或待测扰动表达。另完整报告只看细胞背景、只看 M、只看 N、只看模型分歧 D、M+N。主判定是冻结分数相对该强简单组合的 Spearman 差值大于零，按扰动基因整簇同步两折 bootstrap 2,000 次的 95%区间下限也大于零，且两个折的差值均为正。20%优先复核预算下的方向错误捕获率为辅助指标，不能代替主判定。

## 必须展示的适用边界

单独将两折中**目标细胞系完全留出**的行拿出来，与幅度 M 同任务比较；即使混合队列主判定通过，这个结果也不能省略，更不能把混合队列优势改写为“整细胞系留出时更好”。另报告普通未中心化效应向量 cosine error 和全基因 RMSE 的相关性，不能把 Systema-centered 指标的优势扩写为所有错误定义。

程序沿用的 E112 图构建器会提前物化测试目标向量，所以本轮可证明基因清单、公式和对照先固定，以及评分函数不使用目标方向真值；**不能称为严格的首次读取测试真值前盲测**。若主门失败，照样保留完整表，不临时换基因、模型、对照或终点。结果只支持这个公开研究中的限定任务队列，不推出期刊一定录用或已节省湿实验费用。
