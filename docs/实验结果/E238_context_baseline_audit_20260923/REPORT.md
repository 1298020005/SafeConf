因此，已经有的真实增益应写成**“来源与目标背景等多种任务情形混在同一复核队列时，对 Systema-centered 方向误差的排序增益”**。细胞背景是否见过本身就是强线索；完整公式相对这条线索、幅度和新颖度的简单组合，仍有较小但正的增量。真正只看“整个目标细胞系没见过”时，没有证据说明完整公式胜过幅度。不能把四种情形混合的 0.79 写成目标细胞系留出内部的表现。

指标也有边界：普通未中心化的预测效应 cosine error，冻结分数在 E139/E237 全任务分别与之相关 −0.083/−0.240；全基因绝对 RMSE 的相关分别为 +0.252/+0.334，而幅度为 +0.403/+0.494。符号和强弱都不能包装成“各种错误都能筛”。Systema-centered 方向误差是有明确定义的研究终点，但若论文要主张一般预测可靠性，必须补这些不利对照。

E239 已在读取其 128 个新基因的表达前把更强的“背景见过 + 幅度 + 新颖度”固定为主要比较对象；同时规定目标细胞系留出内部、普通效应 cosine error、绝对 RMSE 均单独展示。E239 即便通过，也只是同一个 Nadig 研究内第三批基因；跨研究复制仍需另外完成。
