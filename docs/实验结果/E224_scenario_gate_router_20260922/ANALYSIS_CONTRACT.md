# E224：场景门控的幅度—SafeConf 路由

## 与 E223 的关系

E223 显示，`m + max(s-m, 0)` 在四个研究中平均有益，但“仅细胞背景未见”场景出现负向结果。E224 预先把这个边界转成一个可复核假设：在 `context_unseen_row` 中只使用幅度；在扰动未见、随机缺失、细胞背景与扰动同时未见时，允许 SafeConf 补充幅度以上的部分。

## 规则与评估

候选规则在运行前固定：幅度单项、全场景 `max(m,s)`、三种场景门控（硬门、软门、半门）和固定 0.8/0.2 融合。特征仍在任务块内转为百分位。每个外层数据集由其余数据集内部留一选择规则，外层标签只在最终评估时读取。

## 约束

- 使用 E187 原始 8196 个任务，完整保留四个数据集、四种场景和四个训练比例。
- 不删除负结果、不改标签、不把外层结果用于选规则。
- 这是针对 E223 观察提出的历史开发实验；若通过，仍需在 E208 或新的独立研究上按冻结规则确认。
