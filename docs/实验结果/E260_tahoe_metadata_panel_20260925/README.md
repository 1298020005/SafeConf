# E260–E263｜Tahoe 固定面板与预真值数据准备

登记日期：2026-09-25。当前阶段：E260 元数据面板、E261 固定哈希细胞选择、E262/E262b 原始分片映射已完成；E263 仅提取训练／验证处理细胞与各细胞系可用 DMSO 对照，结果以其独立状态文件为准。

## 为什么做这一轮

本轮固定两个不同的增量：`ΔQ = Utility@20(Ridge(M,Q)) − Utility@20(Ridge(M))`，以及 `ΔH = Utility@20(Ridge(M,Q,H)) − Utility@20(Ridge(M,Q))`。两侧必须使用同一批任务、同一真实误差、同样的训练侧错误标签预算和相同 20% 复核预算。另报不使用错误标签训练的原始预测幅度 `M`，但**不能用一个有监督的 `M+Q` 去和未经同预算校准的 `M` 比，再把全部差值算成 Q 的贡献**。

`M` 是上游预测效应向量的 RMS；`Q` 只可使用训练来源数量、训练来源细胞数、训练来源 split-half 波动和预测时已有的目标背景对照数据质量；`H` 是训练来源跨背景效应离散度，所谓 `H_bio` 只是扣除估计采样波动的近似值。不能用目标扰动结果的细胞量或波动作为风险输入。

## 已锁定的 Tahoe 面板

官方原始分片在本机已有 **3,388/3,388** 个，总压缩大小约 337.6 GB，不重下全库。`obs_metadata.parquet` 共 **100,648,790** 行。E260 只读 `cell_line`、药物剂量、药名、板号及 `pass_filter`，选 `pass_filter=full` 的组合；每个细胞系／药物剂量须至少 64 个细胞，同细胞系、同板 DMSO 对照至少 64 个。对覆盖度先后尝试预置档位 `24×100 → 18×100 → 12×100 → 12×60`，没有按表达结果或模型误差择优。

第一档 `24×100` 即通过：**24 个细胞系 × 100 个药物剂量 = 2,400 个任务**，涉及 89 种药物、13 块板；每个任务至少 1,260 个合格细胞，同板对照至少 586 个。按固定哈希分为 **12 训练、6 验证、6 测试**细胞系。面板的高覆盖性质是其明示适用范围，不应外推到稀疏条件。冻结面板 `LOCKED_PANEL.csv` 随 Git 留存；完整覆盖中间表 `METADATA_COUNTS.csv`、`ELIGIBLE_PAIRS.csv` 体积较大，保留在服务器原位，按脚本与官方元数据可再生，不纳入 Git。

E261 再次只读元数据，按固定 barcode 哈希为每个训练／验证任务选择最多 128 个细胞；已经固定选择 **230,400** 个处理细胞及 **35,584** 个可用对照细胞，其中测试细胞系只包含 **8,832 个对照细胞，0 个测试扰动细胞**。E262/E262b 根据 Parquet 页脚和 `sample` 字段定位候选原始行组，没有读取表达列。E263 原始数据提取时，为取得选中细胞必须解压其所在行组，因此可能在物理 I/O 层读到同组其他细胞；代码只保留登记的 barcode，严格禁止测试处理细胞写入、汇总或评估。不能将这件事误写成“从未物理读取含测试细胞的文件”。

Tahoe 在本项目旧分析中已被使用；这个按元数据事先锁定的新面板是**同一公开研究中的新确认面板**，不是全新外部研究。测试处理效应和模型误差目前未打开；测试表达缓存只能在预测、分数、规则及其哈希固定后由单独评估环节构造。

## 接下来允许的实验与通过条件

1. E263 完整提取后，按固定基因轴和同板对照构造 train/validation 任务。验证各选中 barcode 的药物、板、细胞系一致，保存原始文件和预测文件哈希。不得一次性 dense 化整个 100M 原库。
2. 先建立不变预测、训练来源同药物剂量均值、基于已有对照背景相似度的训练来源均值。CPA 等非图上游模型使用已经存在的成熟实现与固定配置；相同任务基因轴、相同误差对象上，相对最强简单预测的验证细胞系宏平均 RMSE 改善须至少 2%，且 **6 个验证细胞系中至少 4 个胜出**，才进入主要风险分析。失败模型完整留档，不按风险结果换模型。
3. 风险模型只在训练细胞系留出折学习错误标签。验证细胞系仅用于锁定**一个**最终规则，不反复加特征/调门槛；训练侧依次比较 `Ridge(M)`、`Ridge(M,Q)`、`Ridge(M,Q,H_raw)`、`Ridge(M,Q,H_bio_approx)`。另外报告无监督 `M` 与同标签预算的 prediction-only 对照。主要效用 20%，辅助 10/30% 和 Spearman。历史是否有贡献只看 `M+Q+H` 对 `M+Q`。
4. 若上游能力门与规则锁定门通过，才封存测试预测和风险分，然后一次性读取六个测试细胞系扰动真值。按细胞系、药物剂量两层配对自助抽样报告区间。目标真实结果的 split-half 只能用于**评估真值噪声敏感性**，不能成为风险模型输入。

scPerturBench 已作为外部预测资源核对：[官方仓库](https://github.com/bm2-lab/scPerturBench)的 `Results/Cellular_context_ood` 文件是评测指标 CSV（例如列 `method`、`DataSet`、`op`、`mse_score`），[官网说明](https://bm2-lab.github.io/scPerturBench-reproducibility/Task_Usability.html)也明确“raw results”指六项指标。**这批文件不能直接充当逐基因预测向量。**之后若要使用，需按官方代码／容器生成任务级预测，并先审计其输入输出合同；不下载 40 GB 容器来制造“已获得预测”的假象。

本机预检资源：96 逻辑 CPU、125 GiB 内存、2×Quadro RTX 6000 24 GB；`/home` 可用空间约 2.5 TB。GPU 模型须等真正的数据合同和能力门具备才启动；空闲率不是科学指标。遇到原始文件不一致、测试信息混入或磁盘危险时应停，不能自动掩盖。
