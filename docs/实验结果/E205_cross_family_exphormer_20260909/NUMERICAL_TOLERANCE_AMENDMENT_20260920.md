# E205 跨架构证书数值容差修正

## 修正时点

本修正在 E205 第 16 个模型仍处于训练状态、E205 任务真值尚未授权读取时完成。它不使用 E205 的误差方向、相关性、复核效用或证书结果。

## 修正原因

E205 的预测中心向量以 float32 封存，跨架构分歧在封存前以 float64 计算。数学上的家族误差恒等式成立，但两种精度之间的序列化会产生极小的平方误差残差。

独立外部实验 E216 在相同存储方式下观察到最大绝对残差约 `3.12×10⁻¹⁰`；原 E205 判据使用 `max(10⁻¹², 10⁻¹⁰ × 误差平方尺度)`，在常见误差尺度下约为 `10⁻¹²` 至 `10⁻¹¹`，会把纯量化残差误记为恒等式失败。

## 固定修改

E205 的恒等式数值容差改为：

\[
\max\left(10^{-9},\;10^{-8}\times\text{误差平方尺度}\right).
\]

`10⁻⁹` 只用于判断浮点恒等式是否数值一致，不进入风险分数、证书下界、阈值、排序、真实误差或置信区间。下界违反检查和全部科学门槛保持不变。

## 未改变内容

- TxPert-STRING-GAT 与 TxPert-Exphormer 的八个家族成员不变；
- 两个架构各占 0.5 的权重不变；
- 1808 个任务、主要分析层、九个证书阈值不变；
- SafeConf-M 4:1、证书优先路由、20% 预算和自举方案不变；
- E205 真实答案仍未读取。
