# 周老师问题与本轮实验的对应关系

这张表用于组会解释当前工作边界。每个问题都对应一个可检查的实验步骤，不用把没有跑过的内容说成已经完成。

| 周老师关心的点 | 当前可给出的回答 | 证据或下一步 |
|---|---|---|
| 风险分数到底和谁的误差相关 | 任务级风险分数和同一任务的预测误差比较；误差来自预测质心与真实扰动表达质心的差距。预测阶段不读真实答案。 | E199/E200 已有结果；E201 完成盲预测后再释放真值。 |
| 分歧是针对某个模型还是整体任务 | 当前 E201 的四个预测器是同一 TxPert-GAT 结构的四个随机种子，因此分歧表示该任务对初始化变化的敏感程度，不能包装成跨模型架构结论。 | E201 四目标 × 四种子；若要声称跨架构稳健，另登记独立的 cross-family 实验。 |
| “幅度”从哪里来 | 幅度是预测模型自己给出的整体变化大小，只用预测向量计算，不需要先做湿实验；它和真实答案的关系只能在盲测解封后评价。 | E201 预测前特征封存。 |
| 当前切分是不是简单 | 随机任务、整列未见扰动、整行未见细胞背景、双重未见和跨数据集分别报告，不能用简单场景代表全部。 | E189–E192、E199/E200；E201 继续做四个 target。 |
| 未见任务时第四个值怎么算 | 没见过的是 target 的真实表达；预测向量、预测幅度和 source 支持度仍可计算。若没有预测结果，就不产生风险分数。 | E201 blind H5AD 和 sealed prediction runner。 |
| 三种难考法是否都解决 | 没有。整行/双重未见时已有不稳定或负结果，固定把分歧和幅度相加也会在 E200 变差。 | 保留负结果；用条件性路由和停止规则。 |
| 能否把风险信息用于训练 | 这是新增 E204：用 source-only 支持度、背景覆盖和跨背景离散度给条件加权，比较 uniform、risk_weighted、dispersion_only。 | 协议已冻结；先 smoke，再正式四 seed；target 真值解封前不调权重。 |
