# 周老师问题与当前实验对应

更新时间：2026-09-05

| 周老师关心的点 | 当前直接回答 | 证据与状态 |
| --- | --- | --- |
| 风险分数和谁的误差相关 | 每个任务的风险分数与同一任务的 family RMS error 比；误差来自四种子预测与真实扰动表达质心的差距。 | E201 已解封完成，主任务 1,808 个。 |
| 分歧是不是针对每个模型 | 不是单个模型自带的置信度。当前四个成员是同一 TxPert-GAT 的四个随机种子，分歧表示任务对初始化的敏感程度。 | E201 支持同架构 family；跨架构结论留给 E205。 |
| 幅度是否要先做实验 | 不需要。predicted magnitude 是预测向量离 target 对照质心的距离，真实扰动后表达没有参与计算。 | E199/E200/E201 均有预测前幅度特征。 |
| 以前的切分是否太简单 | 早期随机缺格确实较简单；后续已补未见基因、整背景留出、双未见和跨数据迁移。 | E189–E192、E199–E201。 |
| 没见过的格子怎样算幅度 | 没见过的是该格子的真实扰动结果。模型仍能输出预测，预测与未扰动对照之间的距离仍可计算。 | E201 盲预测链和 target read 审计。 |
| 三种难考法是否都解决 | 没有。未见基因中分歧有效；整背景留出中幅度更强；双未见中旧排序可能有害，需暂停。 | 负结果保留，不能用一个固定分覆盖所有场景。 |
| 风险排序是否有幅度之外的价值 | 有。E201 控制幅度后的 SafeConf partial Spearman 为 0.2503，95% CI 为 [0.2021, 0.2980]；但 SafeConf 单独复核收益低于幅度。 | E201 正式核心报告。 |
| 风险信息能否用于训练 | E204 正在检验。四背景一轮 profile 已全部通过，说明加权实现正确；正式 80 轮性能尚无结论。 | E204 profile acceptance；不得把工程通过写成效果提升。 |

## 当前能够自然汇报的一句话

老师上次问的预测前输入、误差对象和困难切分已经通过 E199–E201 逐项核对；结果不是所有场景都赢。E201 说明风险分仍有幅度之外的信息，E204 接着检验这份信息放进训练后能否真正改善难任务。
