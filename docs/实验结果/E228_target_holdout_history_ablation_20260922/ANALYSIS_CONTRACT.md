# E228：E201目标背景留出下的历史证据消融

登记：2026-09-22；运行前固定。使用E201正式任务表；属于历史开发/稳健性分析，不是E208新外部确认。

## 问题

固定上游TxPert预测，历史参考字段是否能在完全留出一个目标细胞背景时，为误差排序提供超出预测幅度的信息？如果做不到，不能把历史字段写成通用增益。

## 数据与切分

- 输入：E201正式`E201_TASK_METRICS.csv`，SHA由运行状态记录；2008行，目标背景K562/RPE1/hepg2/jurkat全部保留。
- 外层按`target`留一：每次用其他3个目标背景的任务误差训练，完全不使用留出目标的误差、任务标签或分数选择。
- 训练标签是`family_rms_error`在训练数据内的百分位；评价对象仍是留出任务的`family_rms_error`。
- 不输入`safeconf_e201_risk`，因为它是E201已有组合分数，避免把待检验旧结果当特征。
- 允许部署的字段：预测幅度M、家族分歧D、历史预测—来源差异、来源跨背景离散度、来源细胞量的log、来源背景覆盖缺口和离散度缺失标记。所有标准化参数只在训练目标上计算。

## 预先固定的四条线

1. M：只用预测幅度百分位；
2. MD：预测幅度＋家族分歧；
3. MDH：再加入历史参考字段；
4. 原始幅度排序作为无训练强基线。

评分器是固定正则化岭回归（alpha=10），输出训练标签百分位的预测值。没有树模型、权重扫描、场景门或按留出结果选臂。

## 主要评价与门

每个目标背景内复核预算20%，报告Spearman和归一化复核效用。主候选MDH相对M必须平均效用提高至少0.02、至少3/4目标为正，且目标簇bootstrap描述性区间下限大于0；同时公开其相对MD的差值。10%和30%只作固定敏感性分析。

如果门未通过，保留负结果；不得删除目标、换误差对象或把E201旧组合改称本实验结果。E201任务已经有真实误差，故不得把本轮叫作外部盲测或training-free。
