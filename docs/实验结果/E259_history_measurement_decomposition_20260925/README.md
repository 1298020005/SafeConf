# E259｜历史扰动信息与测量质量的拆分复核

日期：2026-09-25。范围：Feng 开发数据、已有 Cui 和 Lara ex vivo 结果、七研究资格审计、两次固定种子的非图预测器训练。此目录记录完成了什么、没有完成什么；不把旧数据开发结果写成新的独立验证。

## 这次回答的问题

现有历史扰动数据带来的风险信息，究竟是生物效应在不同背景下的差异，还是仅仅反映历史数据测量得够不够充分？固定比较是：预测幅度 `M`，加入测量质量 `Q`，再分别加入原始历史离散度 `H_raw` 和扣除估计采样波动后的剩余离散度 `H_bio_approx`。主要看同任务、同误差、同复核预算下，`M+Q+H` 比 `M+Q` 多找到多少错误。

`Q` 包括训练来源数、来源细胞数及能够重建时的来源内 split-half（将同一来源的细胞拆成两半，比较两次效应估计）波动。split-half 混有真实细胞异质性，不是纯实验噪声，因此 `H_bio_approx` 只能称作近似分解，不能声称已分离出“纯生物差异”。

## 已完成的结果

| 数据与上游预测器 | 对照 | 加入历史后的 20% 复核效用变化 | 判断 |
|---|---|---:|---|
| Feng E258，训练供体历史收缩预测，2 位已用于开发的验证供体，1,530 任务 | `M+Q` → `M+Q+H_raw` | −0.000206；按扰动基因抽样的 95% 区间 [−0.000852, +0.000951] | 未发现效用增量 |
| Feng E258，同上 | `M+Q` → `M+Q+H_bio_approx` | −0.000399；95% 区间 [−0.001199, +0.000828] | 未发现效用增量 |
| Cui，已有 ContextSimBaseline，5 折、1,253 个任务 | `M+Q_split` → `M+Q_split+H_raw` | −0.003967，非 5 折一致正向 | 未复现原先的正向线索 |
| Cui，同上 | `M+Q_split` → `M+Q_split+H_bio_approx` | −0.012826，2/5 折正向 | 未发现稳定增量 |
| Lara ex vivo，已有 GEARS，5 折、116 个历史支持任务 | `M+Q_split` → `M+Q_split+H_raw` | −0.056071，1/5 折正向 | 未发现稳定增量 |
| Lara ex vivo，同上 | `M+Q_split` → `M+Q_split+H_bio_approx` | −0.056071，1/5 折正向 | 未发现稳定增量 |

注意：Feng 的效用是高误差总量的覆盖份额；Cui 和 Lara 使用各自既有的“相对随机选择与最优选择”的标准化效用。**只能在同一行、同一研究内比较差值，不能把表中的数值跨研究求平均。**Feng 的区间条件于同两位验证供体，不代表新供体不确定性。Cui、Lara 均为已知结果上的回顾性开发，不能算外部确认。

Cui 有一个特别重要的反例：只把来源数、来源细胞数当 `Q`，ContextSimBaseline 的 `H_raw` 看起来增加 `+0.027742`；把来源内 split-half 波动补进 `Q`，同一上游、同一任务、同一风险标签预算下，差值变为 `−0.003967`。这不证明原先的正数全由噪声造成，但足以说明**未控制测量质量时的历史增益不能直接当生物历史贡献**。另两个 Cui 预测器在不完整 `Q` 下，历史增益本来就分别为 `−0.023729` 和 `−0.039914`。

Feng 的 `Z_hist` 也实现了固定诊断，但没有带来 20% 复核效用增量。这里的上游预测本身是历史平均效应的固定倍数，因此“预测—历史冲突”的分子在数学上由历史均值决定；它不是一个独立预测器与历史相互核对的证据，不能包装成新机制。

## 七研究与 GPU 资格审计

七个旧研究的原始数据与既有任务级预测/误差表都已核对，但**没有七研究统一的 `M+Q+H_bio` 成绩单**。Cui 和 Lara ex vivo 已按原有基因轴重建来源内 split-half，并核对归档效应；其余五个数据仍需逐研究对齐原任务与预处理。McFarland、SciPlex3 还需确定剂量与时间字段；Frangieh 需要对齐处理后背景定义。不能拿七个只有旧 `H`、没有同口径 `Q` 的结果拼成“七研究证实”。资格表见下列运行产物。

两张 GPU 分别运行固定种子 `202609259` 和 `202609260` 的 scGPT Transformer（不是图模型），沿用 Lara ex vivo 的 E99/E112 固定任务合同，各完成五折、345 个测试任务。两次都没有通过事先登记的上游能力门：相对不变预测的全任务 MSE 改善分别为 **−3.90%**、**−27.03%**，均为 0/5 折胜；历史支持任务相对最强简单预测的改善分别为 **−45.76%**、**−76.61%**，也均为 0/5 折胜。因此这两组输出不进入 SafeConf 风险比较，也不继续追加随机种子刷结果。模型训练完成后 GPU 空闲，是依据能力门停止无效续跑，不代表漏报了正结果。

## 本轮结论与下一步

对于“真实生物历史是否已在 `M+Q` 之外给出可重复的复核收益”，本轮判定为 **NO：当前没有证实**；这不是断言所有历史数据都不可能有用。当前旧研究仍有研究、预测器、效用定义不统一的问题，不能以它们来证明或彻底否定普遍规律。Feng 的四位最终测试供体扰动真值本轮读取 **0 行**，仍保持封存，不能为了扭转上述开发结果解封试公式。

下一步只安排能缩小这个缺口的工作：先补齐七研究逐项资格和相同口径 `Q`，再事先定义一个新研究/预测器及同任务 `M+Q` 对照；如果开发数据始终没有一致、可提前识别的历史有效条件，就停掉“生物历史独立增益”作为主张，回到已封存的场景条件化风险排序和测量质量感知审计。不要为了 GPU 占用率增加无关模型，也不要按效果删研究、删扰动或更改主要指标。
