# E116 预设分析：高风险任务与预测器失效机制

## 问题

解释 SafeConf 为什么主要筛出 GEARS 错误，并给出高风险扰动基因的可复核生物学线索。

## 冻结分析

1. 在每个外层 fold 内，计算风险组成项与 `GEARS error - scGPT error` 的 Spearman 相关；
2. 按数据集聚合扰动基因，列出 SafeConf 高风险、GEARS excess error 高和二者重叠的基因；
3. 对每个数据集 top-20% SafeConf 高风险基因做 g:Profiler 富集，背景集合限定为该数据集全部被测扰动基因；
4. 保存查询基因、背景基因、接口响应和多重检验校正结果。

## 解释边界

富集分析是机制线索，不证明因果。任何通路只在 g:SCS 校正 `p<0.05` 且交集基因不少于 2 时进入主表；无显著结果也必须保留。
