# E266｜当前预测、公共生物历史与过去模型错误历史的来源拆分

## 要回答的问题

网页 GPT 提议把 SafeConf 的证据拆成三类：当前预测、公开扰动历史、过去模型的错误经验。本实验只使用已存在的任务表，目的在于判断哪类信息在相同误差标签预算下有增量；它不是最终独立验证。

## 设计

- 数据：Cui、Lara ex vivo、Santinha 三项已经通过基础任务表对齐的研究；每项包含三种已有参考预测器。
- 切分：每个研究和预测器保留原来的五个外层测试折。每次用另外四折的错误标签训练风险评分器，留出一折评估；同一任务不会同时出现在训练和该折评估中。
- `M`：直接使用预测幅度 `prediction_l2_norm`。
- `P`：当前预测输出统计（幅度、绝对均值、已有预测器分歧）。
- `B`：公共生物/背景历史（扰动支持数、跨背景效应稳定性、效应方差、背景相似度）。其中稳定性和效应方差来自历史真实效应，不能称为纯元数据。
- `Bsafe`：只保留扰动支持数和对照背景相似度，不读取历史扰动效应向量。
- `E`：同一上游预测器在其他外层折上的历史误差均值、离散度和支持数。训练行采用逐行留一，避免把自己的误差标签放进自己的特征。
- 评分器：固定 `Ridge(alpha=10)`；另有一个预先固定的浅层 HistGradientBoosting 交互模型，不做超参数搜索。
- 指标：同一任务、同一真实误差、同一 20% 复核预算下的 Utility@20% 和 Spearman；逐研究、逐预测器、逐折报告。

## 已观察到的线索

在这三项回顾性研究中，`P+Bsafe`、`P+E` 和组合规则多次高于单独幅度；但增益很大，说明这些任务表中已有的背景/扰动结构和错误标签都携带强信息。该数值不能直接写成 SafeConf 的独立盲测收益，原因是：

1. 所有真实误差已经公开，属于开发数据；
2. B 字段沿用旧折合同，尚未由本轮风险外层重新从原始表达重建；
3. `E` 需要先有同类任务的模型错误标签，属于有监督风险估计，不是冷启动的 training-free 分数；
4. 因此下一步必须看 E267 的按扰动整体留出结果，并在新数据上冻结规则后一次验证。

完整逐折数值在 `FOLD_RESULTS.csv`，汇总在 `SUMMARY.csv`，边界记录在 `STATUS.json`。本轮没有训练新的扰动预测器或图模型。
