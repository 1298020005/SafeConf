# TxPert 成熟上游递增风险实验：执行前合同

日期：2026-09-28。用户要求立即得到“幅度 → 当前预测 → 公共历史支持 → 公共历史内容”的实际增量。此合同在运行新风险学习之前固定。范围为已发布 E201 的四个目标背景、1,808 个 ≥30 目标细胞的主任务；不读取任何仍封存的外部测试数据，不训练新的上游。

## 来源与任务

- 上游：E201 的 TxPert STRING-GAT 四种子预测质心，四个目标背景各有独立冻结上游状态。四种子只是同一架构的重复，不算四种模型。
- 风险标签：已发布 E201 `family_centroid_rmse`。运行时由预测质心、目标真值质心重算并逐任务核对；目标真值只用于标签和最终评价，不参与构造输入。
- 公共历史：E201 在目标真值释放前已经冻结的来源实验。每个目标仅使用另外三个来源背景的 train 扰动、相应 control；目标背景 treated truth 访问数为 0。新风险模型在**同一目标背景、同一上游状态内**按扰动基因五折学习和评价。每个评价扰动的标签只在该折评价时使用。该设置允许约 80% 其他目标任务的历史错误标签用于风险学习，**不是零反馈冷启动、不是新数据盲测**。
- 不跨目标背景拼风险训练集：另一个目标背景的上游可能已从当前背景的扰动表达训练，跨状态合并有回流风险。四背景仅在指标层等权汇总。

## 固定输入阶梯

| 组 | 输入 | 来源 |
|---|---|---|
| M | `predicted_magnitude`，预测效应向量的 RMS | 当前预测 |
| P | M、四种子分歧和半径；预测效应绝对均值、有符号均值、标准差、95% 绝对分位 | 当前预测 |
| P+Q | P 加来源细胞数、来源背景数、来源 batch 总数、每个来源背景最少扰动细胞数 | 公共历史支持/采样量 |
| P+Q+H | P+Q 加来源真实效应幅度、来源间效应离散度、预测与来源均值效应距离、余弦相似度 | 公共历史真实内容及其与预测的一致性 |

来源间离散度同时含生物差异和测量波动；一来源时缺失，不伪称纯生物质量。没有来源内 split-half 测量，Q 不是完整质量模型。`n_target_cells`、`n_target_batches`、目标真值、旧 SafeConf 分数、旧 z 标准化值、基因名和目标名均不进入数值输入。每个缺失值用训练折中位数填补，附缺失标记；标准化仅用训练折。

## 固定比较和输出

- Raw M 直接排序；另对 M、P、P+Q、P+Q+H 用同一 Ridge (`alpha=10`)、HistGradientBoosting (`80` 次、深度 3、7 叶、叶最少 5、学习率 .05、L2 1)、小 MLP (`input→16→8→1`，120 epoch、AdamW .005) 预测任务 RMSE。每种算法各阶梯使用相同折、标签和拟合预算；不按评价结果挑超参数，不强制残差锚定。
- 每个目标背景保存全部评价任务的折外风险。主指标是每个背景内选择风险最高 20% 任务的 oracle 归一化效用 U20，然后四背景等权平均；另报 Spearman、风险 RMSE、各背景值和 M→P、P→PQ、PQ→PQH 的配对增量。
- 用相同基因跨背景为重采样簇，固定种子做 2,000 次配对 bootstrap，报告 95% 百分位区间和四背景的增量方向；仅条件于这四个现有背景，不推广为新背景置信区间。
- 以 `raw M`、`Ridge_P` 和每种算法自己的上一阶梯为公平对照。表中所有方法完整呈现；负结果保留。Error Memory 本批不进入。
- 运行成功门：1,808/1,808 个折外记录、每目标五折基因无重叠、源支持对齐、预测与 E201 标签逐任务差 <1e-6、全部输出有限。数据是已经公开的回顾性开发，不把这批叫新独立确认。运行后停止扩模，提交表、脚本、协议和中文结论到 GitHub。
