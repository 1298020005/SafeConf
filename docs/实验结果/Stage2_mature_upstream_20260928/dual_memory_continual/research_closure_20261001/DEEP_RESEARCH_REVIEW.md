### 已完成的同估计目标对照

7173 个历史实验、615059 个允许的 train/validation treated cells，固定 543 个查询/380 个扰动簇；没有新模型拟合或上游调用。guide 等权距离为 0.711295；cell 等权距离为 0.834314，差值 +0.123019，5000 次配对簇 CI [0.056150,0.198610]。相对历史数量规则 0.827129 的差值仅 +0.007185，CI [−0.039087,0.055330]。

判定：历史内部平均方式确实影响观测误差风险排序；对齐后性能仍未证明超过数量信息。两个估计目标都可以合法，但必须明确选择并与目标一致。这是已见数据诊断，不成为旧确认认证的新主方法。已实际启动同一 cell 等权参照的五个固定 matched-support 内容置换，检查剩余增量，不扩新学习器。

后续已经完成：五次物理效应置换距离 U20 为 0.602882–0.678152，真实 cell 参照相对全部置换差值的 95% CI 均为正。这说明真实内容/对应关系对这一参照规则有作用，但不能由此推断它在数量信息之外仍有额外可预测信息；数量规则仍与它接近。

同时准确重放原 Manual Source HGB：3616 个源记录/575 簇、原标签/CDF/参数/种子，旧 query 风险必须逐值复现。只把 query 参照对齐 cell mean 后，该风险 U20 从 0.648814 降至 0.575302；对 cell 距离的差值为 −0.259012，CI [−0.371281,−0.127813]。因此平均方式问题解释了参照规则的损失，不能用来宣称源监督外部问题也解决了。停止这一修复方向的模型变体搜索。

Source 354208 个 released cells 单遍核查、187628 个主任务细胞/1808 任务的 centroid 与原冻结效应精确复算通过；在固定控制、条件 iid 假设下，treated-cell sampling MSE 约占观测 MSE 的 12%–30%。这不是完整噪声分解，不能将剩余比例自动归为模型的真实生物错误；也不能把 McFaline 的采样主导解释推广到所有 Source context。

## 后续实际结果与负责人取舍（2026-10-02，上海时间）

### 旧模型监督有信息，但不能由此跳到普遍跨研究成功

已完成全部固定预算、来源组合的 5000 次共同生物簇重采样。相同 543 个 McFaline 任务、380 个基因簇上，学习式参照风险模型的源监督从 10% 增至 100%，U20 差值为 +0.339716，95% CI [0.223499, 0.390742]；完整双来源训练相对等记录池为 +0.128708，CI [0.021106, 0.179955]。这是当前数据上真实的监督覆盖收益，值得保留。

但完整源模型的 0.695253 仍未超过同参照强距离规则 0.729672，更未超过历史数量规则 0.827129。增长同时改变合法训练标签数和 CDF 分辨率；GAT/Exphormer 仍是同家族的两种架构，不能把记录翻倍称为独立生物样本翻倍。故论文需要同时展示这些正向增长证据和强对照边界。

### “能够更新”与“更新后更好”必须分开验证

隔离的真实 Source DEV 操作重放已完成：公共记录 1047→2008，模型错误记录 1372→2038；生成新参照、重新拟合风险模型、执行预先登记的开发发布门，并重载核对实际服务版本。候选版本在新任务上 ΔU20=-0.017995，仅 3/8 分层非负，未通过发布门；新增数据保留，旧风险模型与旧服务参照继续使用。实际 registry/CURRENT 的回滚与重载演练证明旧模型、参照和风险预测可逐字节恢复。
