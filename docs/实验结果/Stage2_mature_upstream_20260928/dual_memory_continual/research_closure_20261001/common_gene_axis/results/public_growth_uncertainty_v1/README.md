# 当前2840基因合同：公共覆盖增长实际结果

这是原72小时计划P1-C的当前合同补项；旧native/512增长曲线保留，新结果不继承未触碰确认资格。使用同一Source错误监督全集、原支持加权参照、原HGB参数、5个固定哈希顺序和10/25/50/75/100%预算，275次小模型拟合已经完成；不增加上游尝试、算法候选或Orion访问。

## 完成和统计

每快照10个Source外层折风险拟合加1个Source全池→McFaline拟合，共25×11=275。公共生物学习器没有重训；每个预算变化的是整gene公共覆盖、参照特征及相应风险重拟合。Source监督和其合法训练区CDF始终为100%预算。

固定HGB评价全集：两Source方向各1808任务/575gene，McFaline543任务/380gene。五orders是设计顺序，不是独立数据集。每个重采样数据池5000次gene-block抽样，Source两方向共用抽样索引；各context内拼接OOF预测，再等context/等order平均。另单列outer-fold/context的可评价数量，不能把该统计聚合当自动论文成功门。原75个新GROWTH HGB宏点复算最大差2.22e-16；100%点与已归档主矩阵McFaline完全一致，两个Source U20约1.3e-9浮点差、Spearman和miss率一致，未替换原主矩阵数字。

## 覆盖与内容必须分开

bank按整gene加入全部既有records。每order最低预算已覆盖任务在五预算间的直接距离逐项不变；最大差严格0。五orders最低预算gene交集为0，全部25快照共同历史子集为空。不能为了得到曲线换成最好order或拼不同人群。

Source每order共同子集177–184任务；MC为50–68任务。MC低预算若干context不足20，U20保留NA；Source低预算直接规则在所有outer-fold/context均不足20。原GROWTH_DISTANCE预算曲线评价人群随覆盖变化，且原汇总可能忽略NA context，因此只作覆盖伴随表，不用其升降证明参考内容变好。`DISTANCE_COMMON_COHORT_INVARIANCE.csv`、`FOLD_CONTEXT_AVAILABILITY.csv`保留全部范围。
