# SafeConf mixed-history ranking

This is a frozen SEEN audit of the 2,993-task GWPS queue. `PublicRule_mixed` is one unified ranking: expanded public distance is used where legal history exists, and the pre-sealed amplitude CDF is used when no legal history exists. `SourceHGB_mixed` uses the corresponding frozen source-error HGB score with the same fallback. No score, threshold, or metric was chosen from cached errors in this audit; the cached error file is used only to report retrospective metrics. It is not independent confirmation.
