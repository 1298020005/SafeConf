这是“真实错误监督包含超越生物效应强弱代理的任务对应信息”的开发证据；替代标签不是预期必败的空标签，也没有排除所有更强生物难度学习器。它保留源预测输入、源生物真值和公共参照，不属于无监督或零源模型调用。

范围为1808生物任务、575基因簇、两种架构、一个模型家族；两方向共用生物真值，不翻倍计算独立样本。14464是10次拟合累计训练标签行使用量，不是14464条新增独立实验。5000次为既有保存的gene重采样；CI条件于固定训练模型，未覆盖训练重采样或诊断选择的不确定性。

各指标不是全面获胜：生物标签对照在两方向error@10点估计更低。旧错误HGB相对最强Magnitude的配对U20区间仍跨零；McFaline/Orion的跨研究主要增量尚未建立，不能用本对照代替外部确认或宣布投稿档次达标。

实际取舍：保留原CDF正式方法，不开发新gate，不扫描生物标签或温度变体；将这一信息对照纳入证据矩阵，停止本支诊断。训练与统计完成后报告表格格式依赖异常，只从已封存输出恢复报告，0重新拟合；失败回执保留。论文正文依用户当前要求暂不生成。
