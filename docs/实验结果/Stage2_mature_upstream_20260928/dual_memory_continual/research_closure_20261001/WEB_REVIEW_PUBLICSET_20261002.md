## 审核意见一：区分参照学习与风险使用，避免错误淘汰

### 保留原定评价，不临时换指标

继续报告生物重建、固定 `R_history`、辅助直接RMSE，以及已有计划允许的一次固定HGB联合评价。新网络出来前就登记各分支的触发条件、比较对象和预算。

要特别明确：**固定R_history不提升，不能单独判定整个Public＋HGB结构无效。**生物重建获得可复核改善、固定规则无改善时，在Source数据资格与预算允许的条件下，完成已规定的固定HGB评价。输入缺失属于输入未就绪，不属于算法失败。

### 原因：两步优化的量不同

在相同基因轴、归一化及非负归一权重下：

`L_bio = ||μ−y||²/G`

`R_history² = ||p−μ||²/G + Σ_i w_i||h_i−μ||²/G
            = Σ_i w_i||p−h_i||²/G`

第一项训练损失只关心均值μ；固定风险规则还包含随学习权重变化的分散度。均值改善不提供风险排序改善保证。

合成一维算例：历史为[-1,1]、真实值y=0、当前预测p=0.5。旧权重[0.25,0.75]的重建平方误差为0.25，R_history²为0.75；新权重[0.5,0.5]的重建误差降至0，R_history²却升至1.25。这只是代数示例，不证明某个方法在实际任务中更差，也不是风险排序实验。

### 采用结论分开写

- 仅重建改善：局部生物参照收益。
- 固定规则改善：该无额外源错误监督读出的风险收益。
- 仅固定HGB流程改善：公共表示与风险学习的联合收益。

联合流程须比较“新参照＋HGB”和**同样重训、同样数据与监督预算的旧参照＋HGB**。保持逐条网络、支持量和其他强简单对照。不能只测最佳种子、最佳研究，不能用新模型的完整训练结果对比旧模型的较弱缓存。

## 审核意见二：受限最佳组合不能把约束问题归咎于数据

保留已经规定的50:50受限最佳组合诊断，不增加混合比例搜索。

**受限最优仍差，只支持当前候选历史、固定混合限制与当前生物效应定义下难以重建。**它不能独自证明公共数据没有信息，或只能靠新增数据解决。

合成反例：历史为[0,2]、支持权重均为1/2、真实值为0。50:50混合使第二条历史总权重至少1/4，受限最佳参照仍为0.5；历史里其实已经存在精确答案0。故该诊断应报告“固定50:50约束下的可达误差”，不能称整个历史库的信息上限。

执行口径补充：

- 四臂采用同一登记的细胞/guide聚合目标、基因轴、对照和归一化。不得借本轮改用已见结果里最好的真值定义。
- 求解器收敛、约束可行性及误差容差须通过。没有求出可信最优时，标记未求得，不能据此判数据瓶颈。
- 没有预定义的重建误差界限时，报告连续误差和可改善空间；不要临时创造“无法重建任务比例”的成功标准。
- 保留全部合法历史原本的冲突、真实重复性、支持量和缺失标记。权重集中不等于实验质量高，K=1时加权分散度为0也不等于预测确定。
- 不因诊断结果删除难任务。没有收益时先定位权重限制、输入表示、估计目标或历史覆盖，不能立刻升级Transformer或无边界下载。

上述为解释与检查修正，不要求增加一个新算法。

## 审核意见三：隔离要覆盖整条训练链，更新遵守信息到达时间

### 防止答案经其他历史记录进入训练

对每个外层划分，建立明确的允许历史表与禁止评价实验表。外层评价实验及不允许的重复/派生数据不能作为**其他训练查询的历史**进入PCA、冲突摘要、质量统计、权重学习或风险拟合。逐查询只排除自身仍不足够。

相同基因在其他条件下、合同允许的历史实验继续保留。实验记录的使用资格与基因分组分别定义，避免把合法公共知识全部误删。

Source继续核教师checkpoint的训练暴露。缺少合格向量时，按原预算复用旧checkpoint导出合法validation预测；重新切风险表不能消除上游已见评价答案的问题。Source个别分支未就绪时，Public生物训练及其他合格工作继续。

### 自学习记录必须能还原当时知道什么

1. 真值返回前保存当时版本的预测和风险。
2. 真值返回后才追加公共实验及对应模型版本的错误记录。
3. 使用当时合法的旧/新数据训练候选，开发验证决定是否发布。
4. 未参与该次选择的后续任务用于评价更新收益。

新增25簇、10%及各反馈节点只是候选训练触发条件，不是性能或发布保证。Source新错误的触发节点也须明确写入配置，沿用既有监督预算或批次定义，不另发明实验。

历史库、预处理、Public、风险特征、源风险器及受影响目标适配器绑定一致版本。一个实验同时进入公共账本和错误账本，仍是同一个实验来源。

现有静态反馈曲线可复用，与真实后续任务上的更新收益分别报告。缺少独立后续评价时，报告回顾性更新模拟；不能把“能更新”写成已经证明持续改善。

## 小型实现验收：防止集合支路形同虚设

不改既定网络，只确认评分头 `128→64→1` 的隐藏层保留非线性。如果直接用线性评分 `v_u·u_i + v_c·c + b`，同一个集合的公共项 `v_c·c+b` 会被softmax抵消，权重并没有真正利用集合上下文。

验证B2上下文恒零、B3上下文能在非退化合成输入下影响相对权重；检查历史重排、padding、K=1及相同历史向量的输出。此验收只证明代码具有拟议能力，不能替代真实集合增量实验。

HGB的小反馈预算可能受最小叶节点样本数限制而输出常数，结果要注明；不得把固定配置的常数输出扩大成少量反馈普遍没有信息。现有参数仍保持不变。

### 运行量与预算核对

基础完整公共比较的拟合数为：

`2个生物域 × 5折 × 2个新网络 × 3个种子 × 2阶段训练 = 120次`。

若原型24次完全兼容复用，基础阶段还剩96次。这个数不含后续风险训练所需的内层Public拟合、现有HGB重拟合或反馈组合。按实际依赖展开清单并缓存合法重复计算，不把单层五折称为完整嵌套系统。

原型4 GPU-hours、后续12 GPU-hours、旧checkpoint导出2 GPU-hours均受原累计剩余额约束。只在范围内自行推进；超预算、新未授权数据或更改冻结核心时提供具体决策包，不隐性扩范围。
