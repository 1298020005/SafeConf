## 1. 通俗理解：三类信息分别做什么

- **公共生物实验**：提供“相似任务真实发生过什么”的参照；生物学习器学习哪些参照更适用。
- **旧模型错误**：教风险模型如何解释当前预测及其与公共参照的差异；这些错误进入已训练参数，当前方法不默认每次检索一条旧错误记录。
- **目标模型自身反馈**：另外训练目标专属风险模型/修正器。这是额外信息条件，不能与无目标反馈方法混称同一个预算。

主风险模型目前主要采用固定HGB；不是大型新神经网络。原源模型、冻结核心、原确认和外部结果未被覆盖。我们没有把“更换学习器”或“系统可以更新”自动认定为原创方法贡献。
