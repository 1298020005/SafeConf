此处是已开封 Orion 的 SEEN 补充统计，不是新确认、算法候选或选模依据。原13项主比较和30个目标学习器保持不变。

## 实际完成

使用原 validation control 保存的5000×144个排序基因索引，补算原先缺少的均匀、人工、学习式直接RMSE和人工加权历史距离；原学习式加权历史距离已保存。30个固定目标学习器对全部5个历史规则，保留150项对照、两个背景和宏平均、7个指标，共3150行。没有新抽样或拟合，也没有按最好基线筛选对照。

所有5000次原学习式加权距离的逐次指标均在1e-15内复现；630项原目标对加权距离的点估计/CI也在1e-15内复现。84个原始规则/背景/指标点估计复现。每项对照5000次有效抽样。保存的抽样指标数组位于服务器runtime，Git中仅包含合同、完整数字表和验证回执。

旧主评估以首次出现顺序构造基因数组，新validation control使用排序Ensembl；相同seed不保证配对。因此本次使用已有同一组索引补算，不用旧边际CI相减。独立审计见相邻 existing_validation_risk_control_v1/STRONG_SIMPLE_COMPARISON_SCOPE_AUDIT.md。
