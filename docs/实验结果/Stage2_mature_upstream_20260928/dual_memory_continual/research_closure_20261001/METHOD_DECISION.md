## 负责人实际取舍

- 保留所有冻结模型、13 个候选、失败记录和完整区间，不从次比较选新冠军。
- 当前不把“可迁移源错误监督优于强历史规则”列为已证实贡献。McFaline 和 Orion 都未建立这项跨研究主增量；它们的结果强度不同，不能称相同失败机制已经证明。
- 公共历史、数量信息和源监督之间的关系必须按研究分别报告。Orion 的数量规则为负，与 McFaline 的强数量关联不同，不能宣称统一的数量机制。
- 在同一冻结特征上检查训练分布范围、缺失状态和风险同分比例；这项实际诊断不拟合模型、不改变 TEST 比较，也不将描述性漂移认定为根因。
- 有效实验已经完成不等于方法贡献或投稿就绪已经成立。Route A/B/C 仍需按全部证据评估，不预先保证任一路线成功。
- Orion 的 2790 条 validation 误差已经用于上游能力检查。它们未参与共享风险训练，但可以支持无需新增上游调用的目标风险学习；当前固定比较没有该方法，不能宣称标签或调用成本优势。

## 实际 Source 均值预测器诊断

根据冻结特征的幅度范围差异，完成一次 Source DEV 的折外均值预测验证：5 个全局基因折、4 个背景，20 个训练均值参数，1808 个任务、575 个基因。所有预测和参数先保存哈希，再计算 Source 的折外误差；原 Source 的 101 项文件哈希前后完全一致，未拟合风险模型或 CDF，也未读取 Orion 输入或误差。耗时约 10.006 秒，CPU 增量约 8.808 秒，峰值 RSS 567353344 bytes。

Source 均值预测幅度中位数为 K562 0.0241、RPE1 0.0713、hepg2 0.0428、jurkat 0.0343，全部落在对应旧模型范围内，未提供原范围之外的低幅度样本。因此“补一个训练均值预测器即可填补低幅度范围”这一具体思路未获支持，停止该修复方向。其错误排序与旧模型相关性约 0.45–0.79，只说明当前 Source 数据中存在不同错误模式，不证明外部增量或新的独立模型家族。本轮实际新上游尝试计数为 2；不滚动增加第三个候选来救当前 TEST。

## 实际 Source 幅度压力测试与停止决定

已完成固定1/.1/.05三尺度、两种旧架构、四个背景的零拟合诊断，耗时9.998秒；原始特征、风险预测及误差在尺度1逐字节复现。预测先封存，再计算改变后的 Source 误差；无 Orion 访问或新 CDF。最终风险模型在这些 Source 记录上训练过，必须标为样本内诊断。

在缩到5%时，GAT/Exphormer 的 P-only HGB 宏U20降至0.0084/−0.0009，公共历史 HGB 仍为0.7332/0.7418，历史距离为0.7620/0.7621。两种上游、两个缩小尺度均在三个背景上出现 HGB 相对距离的U20优势反转，但公共历史 HGB 没有失去全部区分能力，其低风险10%平均误差在全部四个缩放宏比较中仍优于距离。真实误差排序也随干预改变。

负责人决定：这一干预支持“当前预测特征树模型对低输出范围敏感”，不能据此认定 Orion 根因、重新写入外部主结果或自动批准新修复。粗方向门满足不等于拟议方法有效；ECDF 锚点的饱和缺陷仍未解决。停止此诊断的变体和额外重采样。所有结果及独立科学判断见 `orion_preparation/source_counterfactual_scale_stress_v2/`。
