# Author fields for the TCBB submission draft

The manuscript and cover letter contain visible placeholders. The following facts require author-supplied wording:

| Field | Location | Required author input |
|---|---|---|
| Authors and ordering | `PAPER.md`, generated `main.tex` | Full names and approved order |
| Affiliations | Title block and cover letter | Departments, institutions, cities, countries |
| Corresponding author | Title block and cover letter | Name, email and postal address |
| Contributions | Declarations | Author-approved contributions |
| Funding | Declarations | Funder and grant numbers, or confirmed absence |
| Competing interests | Declarations and cover letter | Actual declaration |
| Ethics and dataset use | Declarations | Institutional and dataset-specific statement |
| Originality and related work dissemination | Cover letter | Author-confirmed submission declaration and any related manuscripts |
| Exclusive submission and all-author approval | Cover letter | Author-confirmed statement |
| Reproducible release | Availability statement | Final submission commit and checkpoint/data access instructions |

The target journal is IEEE Transactions on Computational Biology and Bioinformatics. The existing IEEEtran mirror is a review draft; the final journal-specific submission layout can be chosen after author completion.
