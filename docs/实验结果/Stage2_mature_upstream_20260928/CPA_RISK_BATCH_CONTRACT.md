# CPA 化学扰动风险压力线：执行合同

使用已发布 E84 sciPlex3 八个固定划分，逐划分保留 test 任务，来源只使用该划分 role=train 的同药物同剂量记录；不把目标 treated truth 作为输入。每个划分内部按药物分组五折学习风险，避免同药物不同剂量跨折泄漏。比较原始 prediction magnitude、Ridge M、P、P+Q、P+Q+H；Q 是来源细胞/背景/batch 支持，H 是来源真实效应幅度、离散度、模型—来源距离和方向一致性。

该线是化学模态压力测试，不会把 CPA 当前版本包装成合格上游：先前 E84 八种设置的 CPA 平均 RMSE 均高于零效应或来源均值。结果只回答“即使上游较弱，风险学习能否识别其失败任务”，不替代化学上游能力验证。报告按八个 manifest 等权平均，并给出 manifest bootstrap 区间；失败和负增量完整保留。
