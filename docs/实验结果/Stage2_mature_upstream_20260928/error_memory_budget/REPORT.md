# SafeConf：同模型错误反馈预算实验

**完成时间：2026-09-28｜TxPert GAT + Exphormer｜3,616 条预测记录｜按基因五折留出**

## 实验目的

这一批实验回答一个具体问题：当 SafeConf 已经有当前预测信息和公共历史支持度时，需要多少同一上游模型的真实错误反馈，才能让风险排序稳定改善？

实验把 GAT 和 Exphormer 的记录合并，但每个背景内按基因分组做五折。每个测试基因的任何记录都不进入风险训练。反馈预算只从训练折中抽取 0%、10%、25%、50%、75%、100% 的基因错误标签；上游预测器不重训，风险学习器固定为 Ridge(P+Q)。因此这是一项**同模型反馈样本效率实验**，不是把随机五折结果包装成在线学习。

## 判断

1. **Error Memory 有价值，但不是冷启动必需品。** 没有反馈时，幅度已经提供可用排序；10% 的反馈量在两个上游都不稳定，不能把少量反馈宣传成确定收益。
2. **反馈收益随上游而异。** GAT 在 75–100% 训练基因反馈后超过幅度基线；Exphormer 在 50–75% 达到平台。该差异本身支持“反馈记忆服务于具体上游模型”的设计。
3. **当前论文主模型仍是 Ridge(P+Q)。** Error Memory 应作为部署后定期重训的可选扩展：新真实结果回流后按批次更新，而不是在线逐样本改参数。
4. **这批实验不能声称已经完成在线自学习。** 它证明了严格基因留出下的反馈样本效率和方向，真正的在线验证需要按时间登记的新预测—真实结果批次。
