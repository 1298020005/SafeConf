# SafeConf 导师汇报结果（2026-09-30）

## 一、当前结论

SafeConf 已经从“方法构想和开发实验”推进到一条可以组织成计算机方向方法论文的 **Route A 主线**：

> 冻结上游扰动预测器后，SafeConf 统一提取当前预测证据，并用合法历史实验的 Support 与 Relevance 修正任务级风险；嵌套 evidence shrinkage 决定历史修正的使用强度。方法在开发数据上冻结后，在此前未查看结果的 E170 四面板上一次性通过预注册 Gate A。

最终主方法保持为 `V2_nested_evidence_shrinkage`，确认后没有改模型、改阈值或将 V1 事后换成主方法。

## 二、确认实验的核心结果

E170 confirmation 包含：

- 4 个完整面板；
- 1 个 held-out donor；
- 800 个新 perturbation cluster；
- 3 个细胞状态；
- 2,400 个 task；
- 12 个预注册 panel × state strata；
- 冻结的 6-member scGPT + GEARS 上游 ensemble。

| 方法 | Utility@20 | Spearman | AURC | risk@20 | 高风险漏检率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Magnitude | 0.1655 | 0.1734 | 0.1161 | 0.1121 | 0.7125 |
| Frozen V1 | 0.2010 | 0.1897 | 0.1137 | 0.1087 | 0.6979 |
| Final V2 | **0.2159** | 0.1890 | 0.1140 | 0.1089 | **0.6938** |

预注册 Gate A 结果：

- `ΔUtility@20(V2−Magnitude) = +0.0504`；
- 12 个 strata 中 10 个方向非负；
- risk@10、risk@20、AURC、高风险漏检率均没有触发退化；
- risk@50 相对恶化 0.60%，低于预注册的 5% 上限；
- 有效 strata 为 12/12；
- **Gate A = PASS**。

成对 target-cluster bootstrap 的 ΔU20 95% CI 为 `[-0.0266, +0.1136]`。因此论文会同时报告“预注册实用性门通过”和“统计区间仍宽”，不把它包装成传统显著性结论。

## 三、历史证据真正在哪些任务上有效

| 任务类型 | n | Magnitude U20 | V1 U20 | V2 U20 |
| --- | ---: | ---: | ---: | ---: |
| 有合法两供体历史（held-out donor） | 1,920 | 0.2383 | 0.2718 | **0.2857** |
| 无该 perturbation 历史（column-unseen） | 480 | 0.0011 | -0.0137 | 0.0038 |

这组结果支持两个同时成立的结论：

1. 有相关、合法历史时，SafeConf 在强幅度基线之上继续提高风险排序；
2. 完全无历史时，当前 prediction-only 信息不足，SafeConf 也接近无信息，不能声称已经解决零历史风险估计。

第二条作为方法边界保留在主文或补充材料，不删除这 480 个任务。

## 五、跨模型家族结果

E190 GEARS 是能力合格的独立家族开发压力线：

- 692 tasks；
- 47 gene clusters；
- Adamson → Replogle 跨 study 历史；
- GEARS 相对最强简单上游基线误差差仅 +0.115%，通过预注册 2% competence gate。

结果为：Magnitude `0.2348`，V1 `0.3035`，加入 conflict/content 后最佳点估计 `0.3894`；冻结 V2 为 `-0.0114`。这说明 V1 的历史信号跨 family 存在，但低样本 gate 不稳定。该结果作为跨 family 开发与失败边界，不冒充外部确认，也不反向修改最终 V2。

## 六、Error Memory 与化学压力线

### Error Memory

同模型反馈按 gene cluster 从 outer-train 逐步提供，评价基因保持完全留出：

- GAT：零反馈 U20 `0.7615`；75%/100% 反馈为 `0.7699/0.7759`；
- Exphormer：零反馈 U20 `0.7514`；50%/75% 反馈为 `0.7688/0.7681`；
- 10% 反馈在两个上游都下降。

因此 Error Memory 被定义为部署后的周期性增强：真实结果积累到一定规模后批量重训风险层，不采用逐样本在线改参数，也不把少量反馈描述成稳定收益。

### 化学扰动

CPA 八个固定 sciPlex3 划分上，Magnitude / P+Q / P+Q+H 的 U20 为 `0.5816 / 0.5396 / 0.6069`。P+Q+H 相对幅度点增量为 `+0.0253`，95% CI `[-0.0952,+0.1590]`。CPA 上游没有通过能力门，因此它承担统一接口与失败边界的 chemical stress test，不进入主确认。

## 七、方法贡献如何表述

当前最稳妥的计算机方法贡献是：

1. **统一的黑盒后置接口。** Direct-effect 与 treated-state 上游均转换为受版本控制的 PredictionRecord 和 Prediction/Error Contract。
2. **强基线之上的历史风险建模。** 把 prediction magnitude 作为必须击败的强基线，进一步使用合法历史的 Support 和 Relevance。
3. **Evidence-aware shrinkage。** 历史修正不被无条件使用，V2 在严格 nested/cross-fitted 条件下学习收缩强度。
4. **Fail-closed 实验治理。** 上游不通过能力门时不生成漂亮但无部署意义的风险结论；confirmation 在方法冻结后一次性打开。
5. **Selective review 目标。** 输出 task-level risk score，用于有限实验复核预算下的优先级排序。

当前不写成已证明的内容：Quality-aware、广泛化学扰动通用性、广泛 external-study confirmation、完全零历史泛化。
