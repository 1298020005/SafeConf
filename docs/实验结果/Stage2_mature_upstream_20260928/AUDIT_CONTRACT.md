## 可读资产与隔离边界

- 1764 候选任务：使用原始七研究旧公开产物的 split 元数据、训练来源缓存、val 预测与 val 误差。原始 heldout 清单在 `input/HELDOUT_PAIR_SPLITS.csv`；第一批仅检查 `tables/` 的缺失结论不完整，本轮明确更正。
- 只验证候选的 val 记录。训练来源仅按该原始 fold 的 train 清单索引，当前 val 任务不在来源内；不解析旧 test 记录的误差作为审计标签。
- E112/E253、E84/E87/E89、E201/E205 已经发布的预测和评价产物允许做回顾性开发审计。不能重新称为未见最终测试。E208/Jiang24、Feng 最终封存 donor 等不读取。
- 同一个生物任务的不同原始 fold、种子、predictor 是不同 prediction record，不是独立 task。不同 upstream 状态不能混成一个冻结模型或同模型 Error Memory。

## 来源恢复接受标准

1. 源表 val 角色与原始 split 清单完全一致；任务在相应上游 train 中不存在。
2. V0/ContextSim 的 val 预测向量能用允许 train 的效应/对照和现有确定性规则复建；逐任务绝对最大向量偏差 ≤1e-5、误差偏差 ≤1e-5。PertMean 以允许 train 复建并检查误差及幅度。偏差失败如实隔离，不为通过而调整阈值。
3. 复建是来源核验，不改变旧预测，也不训练深度上游；它不是对历史 wall-clock 顺序的密码学证明。
4. 恢复的记录只能在同一原始模型状态内做后续风险折。跨原始 folds 合并时可能出现目标真值通过别的上游训练集合回流，未解决前不混合训练。
5. 旧全局 H/Q 暂不继承“合法恢复”：记录恢复与特征恢复分别判定。Error Memory 仍不进入本轮正式结果。

## 成熟上游资产优先级

固定优先检查：GEARS/scGPT 的 E112 Lara、CPA 的 E84 内部化学划分；TxPert E201/E205 为额外基因资产，CPA E87/E89 为旧外部能力边界。优先级依资产完整性和已有来源记录，不根据本轮风险学习得分选择。

仅有架构名/权重不等于能力合格。先汇报既有预测相对零效应和可用简单上游的 RMSE。能力描述阈值：平均 RMSE 比零效应至少降低 2%；未达到仍保留为失败/压力案例，不宣传为强上游确认。不同模型版本、数据组、设置分别报告，不通过挑选部分任务使模型达标。

审计结束再冻结第二批特征、切分和固定模型参数，然后运行。保持 raw magnitude、Ridge、HGB、小 MLP；不预设最终方法，不强制幅度残差分支，不按中途结果调参。
