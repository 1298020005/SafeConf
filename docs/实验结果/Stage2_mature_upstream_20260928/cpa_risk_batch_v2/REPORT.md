# SafeConf｜CPA 化学扰动压力线

**完成时间：2026-09-28｜8 个固定划分｜629 条 CPA 预测记录｜103 个真实化学任务键的公开效应归档**

| 方法 | 八划分宏 U20 | 八划分宏 Spearman |
|---|---:|---:|
| 原始预测幅度 M | 0.5816 | 0.5906 |
| Ridge P+Q | 0.5396 | 0.5568 |
| **Ridge P+Q+H** | **0.6069** | **0.6122** |

Ridge P+Q+H 相对原始幅度的点增量为 U20 `+0.0253`、Spearman `+0.0216`。按八个划分等权重采样的 95% 区间分别为 `[-0.0952,+0.1590]` 和 `[-0.0707,+0.1285]`，所以化学线目前是支持性压力结果，不能写成独立确认。P+Q+H 相对 P+Q 的 U20 增量为 `+0.0673`，区间 `[-0.0006,+0.1655]`；Spearman 增量 `+0.0554`，区间 `[+0.0016,+0.1279]`。

八个划分中，P+Q+H 相对原始幅度只有 3 个划分正向；它在 R3/P50、R3/P75 上明显改善，在其他划分可能下降。这个异质性说明药物历史内容强烈依赖任务覆盖和划分，支持将 H 作为可选扩展，而不是统一模型的硬结构。

CPA 本身在上游能力审计中没有稳定胜过零效应或同药同剂量来源均值，因此这条线不能承担“成熟化学上游已确认”的主张。它的论文作用是展示 SafeConf 能对化学预测失败进行风险排序，并暴露公共历史质量和剂量覆盖不足的边界。
