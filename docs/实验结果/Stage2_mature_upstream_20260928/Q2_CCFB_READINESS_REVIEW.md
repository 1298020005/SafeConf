# SafeConf：面向二区 / CCF-B 的独立判断

日期：2026-09-28。本文件不是网页意见的转述，而是根据当前三条实验线和跨上游迁移结果作出的项目判断。

## 判断

**可以按二区 / CCF-B 方向继续收敛，当前还不适合把论文写成已完成投稿稿。**

原因不是风险模型太小。23 参数 Ridge 完全可以成为方法论文的组件。真正的贡献是：在冻结的扰动预测器之后，用同一个任务接口融合当前预测证据和公共实验支持度，输出任务级风险，并在不同上游结构上迁移。当前跨上游、按基因完全留出的结果已经支持这个方向：

- GAT：Ridge(P+Q) 相对幅度 `+0.0068`，4/4 背景正向；
- Exphormer：Ridge(P+Q) 相对幅度 `+0.0177`，4/4 背景正向；
- 两个上游联合训练后再按基因留出，增量仍然保留。

这使论文不再是“手工特征加 Ridge”，而是一个有跨上游迁移证据的**预测后可靠性审计框架**。

## 对网页版本的修正

网页版本提出的三层结构是对的：Prediction Evidence、Public Experimental Evidence、Model Feedback Evidence。但当前完成度不同：

1. Prediction Evidence：已经完成，幅度是强基线，当前预测形状和结构分歧有额外信息。
2. Public Experimental Evidence：Q（支持/覆盖）在 GAT、Exphormer 和化学压力线上可以运行；H（生物历史内容）在 GAT 上有收益，在 Exphormer 上不稳定，因此不能写成必选双历史。
3. Model Feedback Evidence：还没有严格的时间顺序 Error Memory。当前风险学习使用折外历史错误标签，能证明“有反馈标签时可以学习风险”，不能直接写成在线自学习。新增预算实验量化了反馈量：10% 在两个 TxPert 结构上都不稳定；GAT 约在 75% 训练基因反馈后、Exphormer 约在 50%–75% 后达到平台。因此 Error Memory 有论文实验价值，但应作为部署后的周期性增强，不应在冷启动主模型中强行加入。

因此最终架构图可以保留三条证据通道，但 Error Memory 必须画成虚线可选通道，并把它标为后续反馈扩展，不能放在当前主结果标题里。

## 当前主方法

```text
冻结上游预测
      ├── 当前预测证据 P：幅度、形状、分歧
      ├── 公共历史支持 Q：来源数、背景数、细胞和 batch 支持
      └── 可选历史内容 H：来源效应、离散度、预测—历史一致性
                    ↓
             小型风险学习器
             Ridge(P+Q) 主版本
             HGB / MLP 对照
                    ↓
             task-level risk
                    ↓
             复核排序、优先实验、风险覆盖曲线
```

第一版统一模型固定为 Ridge(P+Q)，23 个参数。P+Q+H 为 31 参数的扩展版本，用于判断历史内容在特定模型/模态下是否值得启用。显式 magnitude residual 结构不再作为必需设计，因为前批和跨结构结果都没有支持它必须存在。

## 距离论文收口还缺什么

- **化学主验证**：当前 CPA 能运行风险线，但上游预测能力弱，不能承担“成熟化学上游确认”。需要一个预测能力合格的化学模型或将论文实证范围明确写成“基因主验证 + 化学压力测试”。
- **反馈学习**：反馈预算曲线已经完成；下一步只需用真实时间批次替换模拟抽样，验证周期性重训是否保持该趋势。
- **独立确认**：当前 GAT 和 Exphormer共享 1808 个任务；跨上游迁移已通过基因留出，但仍需新背景或新数据集确认。
- **风险覆盖图**：补齐 coverage、selective risk、拒绝/复核曲线，使 U20 不成为唯一指标。

不需要做的事：继续增大网络、堆更多同类随机种子、为了占满 GPU 重训表现不合格的 CPA/GEARS、把 H 强行塞进主模型。

## 最终投稿判断

当前成果已经达到“可写成方法论文雏形、可用于开题和进展汇报”的程度；跨上游迁移和反馈预算曲线让它具备 CCF-B/二区方向的研究骨架。正式投稿前仍需合格化学上游或明确化学压力测试定位，以及真正按时间登记的反馈批次。当前最稳的实证表述是“基因扰动预测的模型无关风险审计，向化学扰动扩展并通过压力线验证接口”，而不是把弱 CPA 结果包装成已完成的通用药物确认。
