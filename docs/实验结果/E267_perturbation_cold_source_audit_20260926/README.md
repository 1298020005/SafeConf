# E267｜按扰动整体留出的来源复核

E266 仍可能利用同一扰动在不同折中的过去错误标签。E267 用固定的 `blake2b(E267:<perturbation>) mod 5` 将每个扰动整体放进一个桶；每次把一个桶作为评估集，训练集中完全没有这些扰动的模型错误标签。

比较内容与 E266 相同：`M`、当前预测 `P`、公共历史 `B`、模型错误历史 `E` 及其组合和固定浅层交互模型。每个研究、预测器和桶均报告，不按结果删掉研究或扰动。

## 解释

- 如果 `E` 的增益在 E267 中消失，说明它主要依赖同一扰动的过去错误标签，不能宣称跨新扰动泛化。
- 如果 `Bsafe` 仍有增益，说明支持数/背景相似度这类部署前信息值得在新研究中重新盲测。
- 由于 B 字段仍来自已有折合同，E267 是更严格的回顾性开发检查，仍不是独立测试。

完整逐桶结果见 `FOLD_RESULTS.csv`，汇总见 `SUMMARY.csv`，状态与限制见 `STATUS.json`。
