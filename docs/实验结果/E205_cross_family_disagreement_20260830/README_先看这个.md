# E205 先看这个

E205 已完成，不再处于训练或等待阶段。它在与 E201 相同的四个整细胞背景留出合同下，
新增了 TxPert-Exphormer 预测家族，用于检验跨模型结构风险信号能否在揭示目标真值之前完成计算，
并在揭盲后改善高误差任务排序。

## 当前状态

- 16 个 Exphormer 正式模型全部完成：四个目标细胞背景，每个背景四个随机种子。
- 2008 个任务的预测、风险输入和公式先封存并提交，之后才授权读取目标真值。
- 主分析包含 1808 个至少有 30 个目标细胞的任务；四个背景全部保留。
- 正式评价和 5000 次扰动条件簇自助法已经完成。
- 独立复算已通过：任务无重复，封存前后 38 个共享字段无变化，公式和区间均可复现。

## 当前结论

固定 SafeConf-M 的 Spearman 为 0.6935，预测幅度为 0.6010；二者差值为
0.0925，95% 区间为 [0.0817, 0.1052]。在 20% 复核预算下，SafeConf-M
效用为 0.6724，预测幅度为 0.5771；差值为 0.0954，95% 区间为
[0.0577, 0.1209]。四个细胞背景的相关性增量均为正；K562 的 20% 复核
效用差约为 -0.001，属于接近零的边界结果，不能描述成四个背景的复核效用都提高。

确定性下界没有发生数学违反，但紧致度中位数只有 0.0997，未达到预先规定的 0.15。
因此“下界恒等式正确”可以保留，“证书已有足够实际筛查能力”不能主张。证书优先路由同样
没有提高复核效用，不能作为性能主线。
