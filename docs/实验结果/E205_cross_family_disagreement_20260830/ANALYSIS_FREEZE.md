# E205 冻结协议：跨模型家族的分歧是否仍然有用

冻结日期：2026-08-30
状态：候选补充实验，排在 E201 真值评价之后

## 动机

当前 E201 的四个预测器使用相同的 TxPert-GAT 结构，只改变随机种子。因此 family disagreement 能回答“同一模型家族对初始化是否敏感”，不能回答“不同模型结构是否给出一致预测”。周老师问到“实际预测用的是什么模型”时，这个边界必须说清楚。

## 设计

固定 E201 的四个 target、任务切分、输入视图、训练轮数和评价指标，增加一个结构不同且输入输出契约一致的预测器家族（优先选择仓库中可以复现实验的图模型变体；若无法保持相同接口，登记为工程失败，不用手工拼结果）。每个家族使用四个预先登记的随机种子。

预测完成后计算三种分歧：

1. 同家族、跨种子分歧；
2. 跨家族预测质心分歧；
3. 两者组合后的分歧。

风险分数在 target 真值释放前只使用这些预测和 source-only 特征。每个家族单独报告 RMSE、Pearson delta、rank 和高风险 20% 复核收益；不能把多个家族的错误平均后隐藏掉。

## 预先裁决

- 若跨家族分歧在控制预测幅度后仍能稳定区分错误任务，SafeConf 的“模型不确定性”解释更有说服力；
- 若只在同家族跨种子有效，结论改为“初始化敏感性指标”，不写成通用模型分歧；
- 若不同家族方向相反，保留冲突并把路由设为停止，不能挑选有利家族。

该实验不改变 E201 主结果，也不回溯调整 E204 的权重公式。它的作用是补齐模型身份这一条证据链，不能替代多数据集和湿实验验证。
