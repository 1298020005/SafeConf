# E205 真值前增补：架构感知单向路由确认

登记时间：2026-09-20  
状态：E205 目标真值尚未授权；正式训练完成 15/16 时登记

## 为什么增补

E212 已显示同一修正系数不能同时适用于 E153 跨结构模型对和 E201 同结构随机种子。
E217 在已释放历史数据上重新检查参数地形后发现：跨结构模型对允许较强的 SafeConf
修正和较弱的分歧修正；把同样强度用于同结构种子会在 E201 产生过度调整。

该分析在 E205 目标真值打开之前完成。E217 是开发证据，E205 是一次性确认。

## 冻结公式

在每个目标细胞背景内，把以下三个量转换为百分位：

- \(m\)：STRING-GAT 与 Exphormer 注册家族质心的预测幅度；
- \(s\)：E205 SafeConf 风险分；
- \(d\)：STRING-GAT 与 Exphormer 两个家族质心之间的分歧。

混合缺失场景的开发公式为：

\[
R_{arch}=m+0.50\max(s-m,0)+0.125\max(d-m,0).
\]

E205 的部署设置固定为整个细胞背景未见。只在 E153 的整背景留出子场景中重新计算
批次百分位并按相同规则选参后，E205 的首要确认公式冻结为：

\[
R_{context}=m+0.125\max(s-m,0)+0.125\max(d-m,0).
\]

SafeConf 或分歧低于幅度时不降低原有风险，只在其给出更高风险时向上修正。

## 固定评价

- 结局：八成员注册家族的均方根误差；
- 基线：注册家族预测幅度；
- 指标：逐目标与 pooled Spearman，5%、10%、20%、30% 复核效用；
- 首要确认量：\(R_{context}\) 的 20% 复核效用相对幅度的 perturbation-cluster bootstrap 差值；
- \(R_{arch}\) 作为混合场景公式的次要比较，不能替换首要判据；
- 通过：差值 95% 区间下限大于 0；
- 四个目标全部报告，不根据结果删除目标、任务或随机种子。

证书有效也不能替代排序效用。
