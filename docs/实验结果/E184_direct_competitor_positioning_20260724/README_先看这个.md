本轮不改公式、不读取新的评价真值，也不把不同预测器的相关系数拼成胜负表。它解决的是投稿前的定义问题：哪些数学成分已有明确来源，哪些方法与 SafeConf 只是在名称上相似，稿件应该怎样陈述贡献才经得住审稿。

结论：SafeConf 的平方误差恒等式、三角不等式和 split-conformal 不是独立的新基础定理。可 defend（可辩护）的贡献是面向单细胞扰动预测的注册家族证书、参考质心上界搬移、靶点簇校准、fail-closed 真值访问和四项研究验证。
