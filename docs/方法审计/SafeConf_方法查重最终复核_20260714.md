# SafeConf 方法查重最终复核

生成日期：2026-07-14

审计范围：Qoder 方法查重报告、其二次评估，以及 SafeConf 当前正式方法与 E60、E108、E114、E117、E132、E153、E158/E159 结果

审计性质：文献与仓库证据复核，不修改既有实验结论

## 一、最终结论

两份外部报告都不能原样作为论文的新颖性结论。

- Qoder 第一份报告的组件拆解有用，但漏掉了最直接的领域先例，整体明显偏乐观。
- 第二份报告正确指出 PRESCRIBE 是直接竞品，却把不同的不确定性信号错误地一一等同，并误把 GEARS-Ens 这个比较基线算进 PRESCRIBE 方法本身。
- SafeConf 可以成立的贡献是“外部、异构双预测器、任务级风险路由及其严格跨研究审计”，不能宣称“首个逐预测置信度方法”“首个后预测不确定性方法”或“已经优于 PRESCRIBE”。

截至 E153 和 E159，最稳妥的结果判断是：SafeConf 在研究内 fold-macro 分析中，相对单独的模型分歧表现出更稳定的错误排序关联；相对 predicted magnitude 的跨研究增量优势尚未得到确认，PRESCRIBE 的正式头对头比较也因 E158 分数退化而不可估计。

## 二、两份查重报告的最终判定

### 2.1 Qoder 第一份：覆盖面较广，核心结论过度

| 组件 | 最终判定 | 论文中的安全处理 |
|---|---|---|
| C1 异构模型分歧 | “分歧反映不确定性”早已存在；具体使用 scGPT–GEARS 分歧值得研究，但不能宣称首创。 | 写成“在统一任务合同下实例化并检验跨架构分歧”。 |
| C2 后预测置信度 | “扰动预测领域没有逐预测置信度”错误。PRESCRIBE、CPA、chemCPA、GEARS 均构成不同程度的直接先例。 | 强调 predictor-external task-risk routing，不写 first confidence method。 |
| C3 上下文相似度与支持度 | 距离训练域、训练覆盖度均不新；CPA 和 chemCPA 已在单细胞扰动场景使用条件距离或邻域不确定性。 | 把具体组合视为框架设计，不作为单独原理首创。 |
| C4 AURC、top-k、reject | 都属于已有选择性预测或富集评估思想。 | 作为系统评价设计，不写成算法创新。 |
| C5 conformal 上界 | split conformal 不新；高维扰动 RMSE 只是应用对象变化，且当前结果偏保守、shift-aware 版本失败。 | 作为独立补充分析，保留可交换性前提。 |
| C6 task/predictor 方差分解 | 方差分解方法不新；93.6% 是本项目经验发现，而且只基于两个简单预测器。 | 作为研究动机，不推广到所有深度预测器。 |
| C7 predicted magnitude | 不是创新点，而是必须保留的强基线；当前主 SafeConf 分数本身也使用 magnitude。 | 报告相对 magnitude 的增量，不能只报告自身相关为正。 |

以下说法缺乏足够证据，应从最终报告和论文中删除：

- “三个特征在任何领域均无先例”；
- “AURC、oracle AURC、normalized AURC 或 top-k enrichment 首次用于生物学”；
- “首次给高维扰动预测提供 conformal RMSE 上界”；
- “首次进行 task-vs-predictor 方差分解”；
- “首次发现 predicted magnitude 可以预测误差”。

即使检索暂时没有找到完全相同的实现，也只能写“我们使用”“我们系统评价”，不能把未检出先例等同于证明首创。

### 2.2 第二份报告：正确识别 PRESCRIBE，但对应关系不准确

第二份报告正确指出：PRESCRIBE 已在单细胞扰动预测中提供逐预测 confidence score，并通过过滤低置信度任务改善保留结果。因此，“扰动预测领域没有逐预测置信度方法”已经被直接证伪。[PRESCRIBE 官方摘要](https://papers.nips.cc/paper_files/paper/2025/hash/d6383e7643415842b48a5077a1b09c98-Abstract-Conference.html)、[PRESCRIBE 官方论文](https://papers.nips.cc/paper_files/paper/2025/file/d6383e7643415842b48a5077a1b09c98-Paper-Conference.pdf)

但以下三组等同关系不成立：

1. PRESCRIBE 的 epistemic signal 来自学习到的扰动潜空间密度和 posterior evidence；SafeConf 的 context novelty 来自目标细胞背景 control 表达与训练背景 control 表达的余弦距离。二者都涉及训练域覆盖，计算对象和生物含义并不相同。
2. PRESCRIBE 的 aleatoric signal 来自预测分布熵，不等同于 SafeConf 的 exact-perturbation training support count。
3. GEARS-Ens 是 PRESCRIBE 论文中的比较基线，不是 PRESCRIBE pseudo E-distance 的组成部分，不能据此说 PRESCRIBE 已经同时使用异构模型分歧。

第二份报告称“post-hoc 是 SafeConf 唯一剩余区别”也过于绝对：

- CPA 已提供查询条件与训练条件嵌入之间的 cosine/Euclidean distance uncertainty。[CPA 原论文](https://www.embopress.org/doi/pdf/10.15252%2Fmsb.202211517)、[CPA 官方 uncertainty API](https://cpa-tools.readthedocs.io/en/stable/api/reference/cpa.ComPertAPI.compute_uncertainty.html)、[CPA 官方代码](https://github.com/facebookresearch/CPA)
- chemCPA 对未见药物使用药物嵌入邻域距离、MoA/pathway 熵估计不确定性。[chemCPA 官方摘要](https://proceedings.neurips.cc/paper_files/paper/2022/hash/aa933b5abc1be30baece1d230ec575a7-Abstract-Conference.html)、[chemCPA 官方论文](https://proceedings.neurips.cc/paper_files/paper/2022/file/aa933b5abc1be30baece1d230ec575a7-Paper-Conference.pdf)
- GEARS 可学习基因级 Gaussian log-variance，并有官方 uncertainty 用法。[GEARS 论文](https://www.nature.com/articles/s41587-023-01905-6)、[GEARS 官方代码](https://github.com/snap-stanford/GEARS)

SafeConf 更准确的区别是：它在预测器之外，联合两个冻结且架构异构的预测器输出和可部署元数据，对统一任务合同下的失败风险进行排序。

## 三、当前 SafeConf 的真实方法定义

Qoder 报告将当前方法写成简单的“context similarity + log-support − disagreement”三项 z-score，这已经不符合正式实现。

当前 E108 实现中：

- context novelty 是目标背景 control 与训练背景 control 最大余弦相似度的缩放距离；
- perturbation novelty 是 `1 / (1 + training_support_count)`；
- frozen pair score 为 disagreement z-score、context novelty 和 perturbation novelty 之和；
- 当前主 calibrated score 先在 validation 上用非负 Ridge 拟合 disagreement 与 predicted magnitude，再加入结构 novelty。

代码证据：

- [结构特征定义](../../tools/scripts/run_e108_formal_dual_model_risk_audit.py#L85)
- [同一任务下的双模型分歧、预测幅度与误差端点](../../tools/scripts/run_e108_formal_dual_model_risk_audit.py#L127)
- [冻结分数与 validation-only 校准](../../tools/scripts/run_e108_formal_dual_model_risk_audit.py#L190)

这带来两个必须修正的写作口径：

1. predicted magnitude 已是当前主分数的组成部分，不能再只写成外部比较器。
2. 当前输出是风险排序分数，不是校准后的“预测正确概率”。在未完成概率校准前，应称 `risk score` 或 `risk ranking`，不称 confidence probability。

## 四、可以安全宣称的创新点

### 4.1 推荐的主定位

> SafeConf 研究冻结的单细胞扰动预测器在部署后的任务级失败路由问题。它在统一的任务、基因面板和效应定义下，联合异构预测器分歧、预测幅度、细胞背景相对训练域的新颖度及扰动训练覆盖信息，在不重新训练原预测器的情况下对任务风险进行排序，并通过严格的预测记录、真值隔离和跨研究分析检验该排序在哪些场景有效、在哪些场景失效。

### 4.2 可作为论文贡献的内容

- 预测器外部的 heterogeneous multi-predictor task-risk routing；
- scGPT 与 GEARS 在共享任务、基因顺序、效应定义和归一化合同下的正式对齐；
- PredictionRecord、分数冻结、测试真值隔离和完整 provenance；
- 多研究中风险信号的迁移性、异质性和失败边界；
- 对 PRESCRIBE 严格适配失败和数值饱和的完整保留；
- 将 risk-coverage、top-risk capture 和 reject utility 组织成统一的部署评价体系。

上述贡献的核心价值来自“具体系统组合、严格合同和跨研究证据”，不是来自每个组成指标的单独首创。

### 4.3 推荐的英文摘要级表述

> Rather than proposing a new intrinsic uncertainty estimator, SafeConf studies whether deployable metadata and outputs from frozen heterogeneous perturbation predictors can support post-hoc task-level failure routing across single-cell perturbation studies.

可以使用 `we introduce and evaluate`、`we study` 或 `to our knowledge, few studies have systematically evaluated`。在未完成系统综述和直接竞品实验前不使用 `the first`。

## 五、绝不能写的主张

- 首个单细胞扰动逐预测置信度方法；
- 首个 post-hoc 扰动不确定性方法；
- 首个模型无关不确定性方法；
- 首次在生物学使用 AURC、oracle AURC 或 top-k enrichment；
- 首个高维 conformal RMSE 保证；
- 首个 task-vs-predictor 方差分解；
- 首次发现 predicted magnitude 可预测误差；
- SafeConf 分解了 epistemic 与 aleatoric uncertainty；
- SafeConf 输出经过校准的正确概率；
- SafeConf 优于 predicted magnitude；
- SafeConf 优于 PRESCRIBE；
- 异构模型分歧一定优于同模型 seed 分歧；
- E114 在任意 OOD shift 下都有 90% 覆盖；
- SafeConf 对任意黑盒预测器都 model-agnostic；
- 已经证明可稳定推广到未来数据集、稳定录用二区或冲入一区。

“model-agnostic”也需要谨慎。当前 SafeConf 依赖共享任务、共享基因面板、统一效应向量和至少两个可比预测器输出，更准确的术语是 `predictor-external`，不是“适用于任意模型而无需适配”。

## 六、当前仓库证据支持到什么程度

### 6.1 E108：正式双模型结果仍有设置差异

E108 使用 837 个测试任务和 1674 条 PredictionRecord，预测、风险分数和 q80 阈值在读取测试扰动表达前冻结。全部设置 pooled 时 SafeConf ρ=0.253，高于 magnitude 0.148 和 disagreement 0.137；但 context-unseen row 中 SafeConf ρ=0.155，低于 magnitude 0.218 和 disagreement 0.210。三个配对差值区间均跨零。

证据：[E108 正式报告](../实验结果/E108_formal_dual_model_risk_audit_20260713/reports/E108_REPORT.md#L3)

### 6.2 E153：八研究结果支持“相对 disagreement”，不支持“稳定胜过 magnitude”

E153 是 E152 解封后的八研究扩展元分析，不是新的预注册独立 gate。主分析结果为：

- SafeConf 相对 disagreement 的随机效应 Fisher-z 差值为 0.1397，95% CI `[0.0704, 0.2089]`，但未来研究 prediction interval 为 `[-0.0190, 0.2983]`；
- SafeConf 相对 predicted magnitude 的差值为 0.0613，95% CI `[-0.0582, 0.1808]`，prediction interval 为 `[-0.2657, 0.3883]`；
- Nadig、Replogle、Shifrut 中 magnitude 高于 SafeConf；
- pooled-median 敏感性中，SafeConf 相对 disagreement 和 magnitude 均为负且不显著。该敏感性包含 fold-specific scale 混排和 Replogle Simpson reversal，不能覆盖主分析，也不能被隐藏。

证据：

- [E153 分研究结果](../实验结果/E153_eight_study_formal_meta_20260714/reports/E153_REPORT.md#L22)
- [E153 八研究随机效应](../实验结果/E153_eight_study_formal_meta_20260714/reports/E153_REPORT.md#L58)
- [E153 pooled-median 敏感性及尺度复核](../实验结果/E153_eight_study_formal_meta_20260714/reports/E153_REPORT.md#L98)

当前最稳妥的论文结果表述是：

> SafeConf 在研究内 fold-macro 分析中，比单独的异构模型分歧表现出更稳定的错误排序关联；但相对 predicted magnitude 的跨研究增量优势尚未得到确认，且结果随研究和汇总尺度而变化。

### 6.3 E132：分诊效用为弱增益，不能只展示方向

E132 中 SafeConf normalized AURC 为 0.9814，top-20% enrichment 为 1.0693，reject 20% 后总体误差降低约 1.78%。除 AURC 相对 disagreement 的区间外，多数相对比较区间跨零。

证据：[E132 分诊效用报告](../实验结果/E132_six_dataset_triage_utility_20260714/reports/E132_REPORT.md#L3)

因此，AURC 和 top-k 可以证明框架完成了部署评价，当前数值不能支持“显著改善科研资源分配”的强结论。

### 6.4 E60：seed disagreement 的负结果不能证明异构分歧因果更优

E60 仅覆盖 Adamson 的 24 个 held-out 单基因任务、三个 GEARS seeds。seed disagreement ρ=-0.091，95% CI `[-0.475, 0.289]`；支持度在全部任务中恒为 0。

证据：[E60 GEARS 固定面板报告](../实验结果/E60_gears_fixed_panel_formal_20260711/reports/E60_GEARS_FIXED_PANEL_REPORT.md#L3)

E60 与 E153 使用不同数据、任务规模和实验协议，不能据此写“seed disagreement 无效，而异构模型分歧有效”。需要同一面板上的受控比较。

### 6.5 task-vs-predictor 方差只能作为旧主线动机

旧审计在 4584 个 V0StrongBaseline 与 ContextSimBaseline 配对任务上得到 task variance fraction=0.936267、predictor fraction=0.001060。

证据：

- [A1 方差分解表](../实验结果/Task_risk_audit_20260611/tables/A1_task_vs_predictor_variance_summary.csv)
- [C3 适用范围边界](../实验结果/Task_risk_audit_20260611/tables/C3_scope_boundary_table.csv)

表中已明确写出：该结论只适用于已测试的简单预测器，不得推广为所有深度预测器都由 task difficulty 主导。

## 七、E158/E159 负结果的正确影响

E158 不能解释为“PRESCRIBE 不如 SafeConf”，也不能解释为“PRESCRIBE 在 OOD 上普遍失败”。

本次 Norman P3/P4 严格适配中：

- raw `log_prob` 在每个面板各有 24 个不同值；
- 预注册 epistemic、aleatoric、official combined 和 predicted magnitude 在面板内全部成为常数；
- 十个预测 PCA 坐标全部为常数；
- 因而主相关统计不可估计，E158 预注册 gate 失败；
- raw log-density 的事后结果依赖评价端点，不能用于挽救 E158。

数值链表明，`log_prob + 10` 全部被截到 -30；随后 float32 中的证据比例发生饱和，posterior 退回 prior。即使把计算改成数值更稳定的形式，也无法恢复被 clamp 抹掉的任务顺序，更不能在测试真值解封后改写主结果。

证据：[E159 PRESCRIBE 饱和取证报告](../实验结果/E159_prescribe_saturation_forensics_20260714/E159_事后饱和取证报告.md#L3)

这个负结果的实际影响是：

- 增强项目的审计可信度和失败边界；
- 暂时削弱论文的直接竞品证据；
- 明确禁止声称 SafeConf 已经胜过 PRESCRIBE；
- 要求下一次使用未解封的新数据、预先冻结的新适配版本和解封前非退化门槛。

E158 `attempt_001` 应永久保留，不能删除、覆盖或用同一批已解封数据重新调参后称为独立验证。

## 八、conformal 结果的边界

E114 的 split-conformal 上界只有在 calibration tasks 与未来任务可交换时才具有有限样本边际覆盖保证。row、column 和 double shift 不必满足可交换性。当前 pooled empirical coverage 为 0.980，但平均上界 0.1014，约为平均真实误差 0.0546 的 1.86 倍，明显偏保守。

证据：[E114 split-conformal 报告](../实验结果/E114_split_conformal_error_bounds_20260713/reports/E114_REPORT.md#L3)

E117 尝试匹配困难 setting 后，上界缩短，但 pooled coverage 降为 0.726，预设 gate 已失败；即使未来版本通过，也不能声称任意分布偏移下无条件覆盖。

证据：[E117 shift-aware conformal 报告](../实验结果/E117_shift_aware_conformal_20260713/reports/E117_REPORT.md#L3)

conformal 应与主风险排序方法分开陈述，作为风险兜底与失败实验，不作为 SafeConf 的主要新颖性支柱。

## 九、完成实验闭环前必须新增的对比与消融

### P0：直接决定论文主张的实验

1. **正式竞品对照**
   在相同任务、split、endpoint 和测试真值冻结规则下，对比 SafeConf、GEARS native variance、GEARS-Drop/seed ensemble、CPA cosine/Euclidean condition distance、chemCPA uncertainty 和 PRESCRIBE official pseudo E-distance。chemCPA 只在适用的 chemical perturbation 数据上比较。

2. **相对 magnitude 的增量消融**
   在 validation 内嵌套冻结 magnitude、disagreement、context、coverage、magnitude+disagreement、full SafeConf，以及逐项 leave-one-feature-out。主检验必须是 full 相对 magnitude 的增量，而不是只检验 SafeConf 自身相关是否大于零。

3. **独立 PRESCRIBE 重复**
   使用新的未解封数据。在打开测试真值前检查每个分数的 `nunique`、标准差、clamp 比例、预测坐标动态范围。非退化检查不通过就停止，不得解封测试真值。

4. **Systema 端点评价**
   加入 perturbed-centroid reference、centroid accuracy 和扰动特异性，排除 control-reference RMSE 被系统性效应和预测幅度主导的可能。[Systema](https://www.nature.com/articles/s41587-025-02777-8)、[简单基线研究](https://www.nature.com/articles/s41592-025-02772-6)

### P1：决定跨研究稳健性的实验

5. **同质与异构分歧的受控比较**
   在同一数据、同一测试面板、相同训练预算下训练多个 scGPT seeds 和多个 GEARS seeds，再构造同家族与全部跨家族 pair。只有这样才能检验跨架构分歧是否真正提供增量。

6. **跨研究部署验证**
   做 leave-one-study-out 或完全固定校准器迁移到新实验室、新细胞系和新测序技术，报告 study-level prediction interval，不只报告已有研究均值。

7. **端点拆分**
   分别评价 scGPT error、GEARS error、两者 mean error、max error 和 ensemble error，避免只优化“两模型平均 RMSE”后泛称所有预测器风险。

8. **训练覆盖特征修订只能走新预注册**
   exact-label support 在完全未见基因设置中常为常数零。可以开发基因嵌入邻域覆盖、通路覆盖或训练扰动相似度，但必须作为新版本预先冻结，不能回写旧实验。

### P2：部署与解释增强

9. **如果继续使用 confidence 一词，需要增加校准**
   评价高错误事件的 calibration curve、Brier score 或明确的误差区间；否则全篇统一称 risk score/ranking。

10. **成本敏感分诊**
    除 AURC 和 top-20% 外，给出不同人工复核或湿实验预算下的错误捕获数、漏检代价和净效用。选择性预测和 risk-coverage 是已有方法，不构成算法首创。[Selective Classification, NeurIPS 2017](https://papers.neurips.cc/paper_files/paper/2017/hash/4a8423d5e91fda00bb7e46540e2b0cf1-Abstract.html)、[SCROSS, AAAI 2023](https://ojs.aaai.org/index.php/AAAI/article/view/26133)、[AUCROSS, AISTATS 2023](https://proceedings.mlr.press/v206/pugnana23a.html)

## 十、直接竞品与概念先例的优先级

论文 Related Work 的优先级应调整为：

1. **PRESCRIBE**：同一任务层级的逐预测 confidence 与 filtering，是最直接竞品；
2. **CPA / chemCPA**：条件或药物层面的训练域距离与不确定性；
3. **GEARS native uncertainty / GEARS ensemble**：预测器内在方差和同模型集合；
4. **Systema 与简单基线研究**：评价端点、系统性变化和 magnitude confounding；
5. **通用 selective prediction、deep ensembles、applicability domain**：概念来源；
6. **mLLMCelltype、popV 等单细胞标注共识方法**：跨任务旁证，不是最直接威胁。

PRESCRIBE 的优先级高于 mLLMCelltype，因为它与 SafeConf 都处理扰动预测可靠性；mLLMCelltype 处理的是细胞类型标注。

## 十一、对投稿成熟度的最终判断

新颖性查重本身不能证明“稳定二区”或“冲一区”。当前证据支持一篇谨慎定位的风险审计与评价方法论文，但尚缺两项决定性证据：

1. SafeConf 相对 predicted magnitude 的可靠增量；
2. 与 PRESCRIBE、CPA、chemCPA 和 GEARS 原生不确定性的同合同直接比较。

在上述证据完成前，最安全的总体判断是：

> SafeConf 不是“首个扰动预测置信度方法”，但可以发展为一个严谨的“冻结异构预测器外部任务风险路由与失败审计框架”。当前最强证据是它相对单独 disagreement 的跨研究增益；相对 predicted magnitude 的增量和相对已有领域方法的优势仍需正式验证。

不能根据当前结果保证未来期刊录用、分区或湿实验机制价值。E153 本身也已经在审计边界中明确说明这一点：[E153 审计边界](../实验结果/E153_eight_study_formal_meta_20260714/reports/E153_REPORT.md#L157)。
