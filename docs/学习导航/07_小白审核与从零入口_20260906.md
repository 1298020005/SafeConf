## 2. 现在可以当真说的话

用考试来理解。TxPert 是答题的学生，SafeConf 是还没对答案时先给试卷打的“这题可能错”标记。

1. **SafeConf 不是再做一遍预测。** 它读已经生成的预测，再结合训练时见过的细胞背景，给每个任务打风险分。
2. **在四种整套细胞背景都没见过的考试里，这个风险分和真实误差同方向。** 四个细胞系都为正，合并相关 0.408。
3. **它不是最强的单一线索。** 模型自己预测的变化有多大（`predicted magnitude`，预测幅度）相关 0.619，固定只检查 20% 任务时也更会抓到错题。
4. **它也不是幅度的重复。** 先拿掉幅度能解释的部分，还剩 0.250 的相关。四个细胞系的区间下限都大于 0。
5. **同一套线索换一种考法会翻转。** 基因没见过时，模型之间吵得凶更有用；整套细胞背景没见过时，幅度更有用。
6. **训练加权的程序已经体检通过。** 四个背景都完成一轮完整训练检查：权重能对上、对照细胞权重保持 1、没偷看目标细胞的扰动答案。

## 3. 现在不能写、不能对外保证的话

1. SafeConf 单独排序超过预测幅度。数字方向相反。
2. 四个随机种子等于四种不同模型。E201 里它们是同一套 TxPert-GAT 换了四次初始状态。
3. E204 已经让模型变准。目前只证明程序正确。
4. 已经稳定一区或二区。筛错有证据，训练收益、跨架构分歧、真正新的外部确认都还缺。
5. 对化学药、所有数据集、双未见任务都通用。这些边界里已有失败或未闭环的结果。
6. E201 报告封面写的“相对 magnitude 的增量 SUPPORTED”。这个门通过，是因为控制幅度后仍有正的偏相关；不是因为 SafeConf 打赢了幅度。

## 6. 从零：用一道真题看懂整个项目

### 6.1 一个细胞是一行数字

`single-cell RNA sequencing`（单细胞 RNA 测序）给每个细胞记下一长串数字。每一列是一个基因，数字表示这个基因被读到多少。E201 里每个细胞有 3,352 个基因。

原始单细胞噪声大，评价时会把同一条件下的许多细胞先平均，得到 `centroid`（质心，也就是这道题的平均答案）。

### 6.2 扰动是故意改细胞

当前主线使用 `CRISPRi`（CRISPR interference，CRISPR 干扰）：把某个基因的表达压低，再看其他基因怎么变。

`AARS+ctrl` 读成：敲低 AARS，另一个位置放无效对照。

### 6.3 一道题叫 task

项目里的 `task`（任务）通常是：

```text
一个细胞背景  ×  一个扰动条件
```

`K562::AARS+ctrl` 的意思是：K562 这种细胞里，敲低 AARS 以后，那 3,352 个基因会怎么变。

K562、RPE1、HepG2、Jurkat 是四种可以长期培养的实验细胞，不是四位病人。代码里后两个写成 `hepg2`、`jurkat`。

### 6.4 两种角色

`TxPert` 是答题的模型。它看到：

- 目标细胞没被扰动时的基础状态；
- 被敲低的基因，以及基因之间的关系图；

然后输出扰动后的 3,352 维预测。

`SafeConf` 不重新答题。它在还没对答案时，根据几件事给这道题打风险分：几个模型是不是互相吵、预测变化大不大、训练时见过的三种细胞里这件事稳不稳、证据多不多。

### 6.5 三种“没见过”难度完全不同

把细胞背景当成行，扰动当成列：

| 考法 | 通俗理解 | 对应实验 |
| --- | --- | --- |
| 随机缺一格 | 这种细胞见过，这个基因也见过，只是这个组合没见过 | 早期较容易的切分 |
| 整列留出 | 这个基因在训练扰动里完全没出现 | E199 |
| 整行留出 | 这种细胞的任何扰动后答案都没给模型看过 | E200、E201 |
| 双未见 | 细胞和基因都没见过 | 已有失败，现有规则应暂停 |

周老师说的更难的 `general task`，主要指整行留出。

### 6.6 打开 `K562::AARS+ctrl` 这一行

主表：[E201_TASK_METRICS.csv](../实验结果/E201_txpert_multitarget_retraining_20260802/formal_core_evaluation/tables/E201_TASK_METRICS.csv)

| 你看到的字段 | 这一行 | 人话 |
| --- | ---: | --- |
| n_target_cells | 38 | 用来对答案的 K562 细胞有 38 个 |
| n_source_cells | 161 | 另外三种细胞里，同一扰动一共有 161 个细胞 |
| n_source_contexts | 3 | 三种训练用细胞都见过这个扰动 |
| family_disagreement | 0.01035 | 四个 TxPert 种子互相差多少 |
| predicted_magnitude | 0.10173 | 模型认为这次变化有多大 |
| safeconf_e201_risk | 0.11790 | 五个标准化线索的等权平均 |
| family_rms_error | 0.08909 | 对完答案后，这组模型总体错多少 |

左边的风险分可以在对答案前算出来。右边的误差必须等真实扰动结果解封。E201 的做法是：先把预测和风险分推到 GitHub、Gitee 存档，再打开答案。这是为了防止先看对错、再挑对自己有利的规则。

### 6.7 这道题背后的统计数字怎么读

`Spearman`（斯皮尔曼秩相关）只问一件事：风险排名高的题，真实误差排名是不是也高。

- 1 表示完全同方向；
- 0 表示没排序能力；
- 小于 0 表示越标高风险，反而越容易对，这种排序可能有害。

`95% CI`（95% 置信区间）是把扰动条件抽出重放 5,000 次后，这个数字大概落在哪。区间跨过 0，就还不能稳定说方向。

E201 主结果：SafeConf 0.408，幅度 0.619。两个都比随机抽查好，幅度更强。把幅度能解释的部分拿掉以后，SafeConf 还剩 0.250。当前结论是：有独立风险信息，但尚未证明合在一起能提高复核效用。不要写成「幅度先排序、SafeConf 做补充」已经成立。完整四句见教学包 [00_当前能说什么_记忆提纲.md](./20260906_论文审核与从零教学/00_当前能说什么_记忆提纲.md)。
