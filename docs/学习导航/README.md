## 推荐学习顺序

1. 先读 07，确认哪些结论能当真，并用一道真题建立全局；
2. 再读 00 的第 0–3 节，能讲清研究问题和三种留出；
3. 读第 4–7 节，能解释五个风险成分、幅度和 Spearman；
4. 读第 8–12 节，对照真实结果和代码；
5. 回答第 18 节十道题；
6. 再打开正式脚本逐段学习。
