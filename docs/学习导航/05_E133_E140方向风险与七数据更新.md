## 为什么新增方向风险

Systema 指出 RMSE 对共同参考平移不敏感，Pearson/cosine 等方向指标则依赖参考状态。E133/E134 检查后发现：原 SafeConf 能排 absolute RMSE，不能直接排 perturbed-centroid centered direction error。

E135 随后用同样四个部署特征探索五类低复杂度模型。Ridge(alpha=10) 在六数据 LODO 中 Pearson ρ=0.346、cosine ρ=0.336，但这一步看过候选结果，只算探索。

E136 先冻结 Ridge 系数、文件哈希与 Nadig HepG2/Jurkat 两细胞系合同；E137 构建表达资产；E138 正式训练 scGPT/GEARS；E139 先落盘风险，再评价方向真值。第七数据 Pearson ρ=0.748、cosine ρ=0.757，复合方向终点 cluster-bootstrap 95% CI `[0.693, 0.801]`，预注册 gate 通过。

## 七数据 absolute 结果

E140 加入 Nadig 后：

- 原 SafeConf 相对 disagreement Δρ=0.133，dataset-population CI `[0.045, 0.223]`；
- 相对 magnitude Δρ=0.071，CI `[-0.056, 0.186]`；
- Nadig absolute RMSE 上 magnitude ρ=0.403，SafeConf ρ=0.231。

因此 absolute 上只能写稳定超过 disagreement，不能写稳定超过 magnitude。

## 三个名字不要混

| 名称 | 排序目标 | 当前证据 |
|---|---|---|
| calibrated SafeConf | absolute RMSE | 七数据总体超过 disagreement；对 magnitude 区间跨 0 |
| frozen SafeConf | absolute RMSE | 固定规则对照 |
| Directional-SafeConf | centered Pearson/cosine error | 六数据探索后冻结；Nadig 第七数据确认通过 |

## 论文当前主张

SafeConf 是 metric-aware（评价目标感知）的任务风险路由系统。absolute 和 direction 是两个风险头，共享部署特征，但不能用同一组固定系数冒充对所有误差普适。
