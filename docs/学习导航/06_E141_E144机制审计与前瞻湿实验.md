# E141–E144：机制审计与前瞻湿实验

## 先记住结论

新增工作没有把 SafeConf 包装成“已经找到生物机制”。E141 得到一条较弱的通路误差证据；E142 和 E144 分别否定了跨蛋白确认、靶基因自身恢复和 STRING 知识距离三个过强故事。真正能提高证据等级的下一步是 E143：在全新细胞背景中，先冻结风险，再做盲法 CRISPRi 验证。

## 四项工作的关系

```text
既有七数据 RNA 预测
  ├─ E141：投影到 PROGENy 通路活动 → 弱正结果
  ├─ E142：Frangieh 同批 CITE-seq 蛋白 → decoder 质控失败，不能确认
  ├─ E144：STRING 距离 + 被扰动基因自身误差 → 主 gate 失败
  └─ E143：把失败边界转成全新背景的前瞻、盲法湿实验
```

## E141：PROGENy 通路忠实度

- 7 数据、3,209 个任务；PROGENy 资源和风险分数先冻结。
- 原 SafeConf 与通路 activity RMSE 的七数据等权 Spearman ρ=0.117。
- 分层整簇 bootstrap 95% CI `[0.029, 0.206]`。
- 相对 predicted magnitude 的 Δρ 95% CI 跨 0。
- 允许写：风险与通路层预测误差存在较弱稳定联系。
- 不允许写：稳定优于幅度、证明通路激活、证明因果机制。

入口：[E141 报告](../实验结果/E141_progeny_pathway_fidelity_20260714/reports/E141_REPORT.md)

## E142：Frangieh RNA–蛋白正交审计

- 218,331 个同批细胞、20 个生物蛋白、837 个正式测试任务。
- SafeConf 与 protein RMSE/cosine error 呈正相关。
- 但是 train-only RNA→protein decoder 输入真实 RNA 时仍比训练蛋白均值基线更差，预注册 gate 失败。
- 因此相关性不能解释成跨模态确认；decoder 本身没有证明蛋白误差可被 RNA 可靠恢复。

入口：[E142 报告](../实验结果/E142_frangieh_cite_orthogonal_20260714/reports/E142_REPORT.md)

## E144：STRING 与靶基因自身失败

- STRING v12.0，human，combined score≥700；19,699 个蛋白、473,860 条高置信边。
- 3,170/3,209 个任务的扰动靶点同时映射到 512 预测面板和 STRING。
- SafeConf 与被扰动基因自身 absolute error 的 ρ=0.015，95% CI `[-0.065, 0.099]`，主 gate 失败。
- 训练未见目标中，STRING 到训练目标的距离与全向量 RMSE 反而为负相关 ρ=-0.095；标签置换 P=0.008。
- 该结果不支持“离训练网络越远越难”的预期，也不支持 SafeConf 专门抓靶基因自身下调失败。

入口：[E144 报告](../实验结果/E144_string_target_failure_20260714/reports/E144_REPORT.md)

## E143：前瞻湿实验

服务器端已经完成：

- 48 个正式候选槽位；
- 24 基因 Nadig 技术预实验面板；
- 相关性功效与最低基因数；
- 2 个背景×3 个独立批次，共 6 个 10x 文库；
- 2 条 guide/基因、6 条 non-targeting guide；
- 盲法样本布局、QC、排除规则、预注册主 gate；
- 正式候选匹配和私有 codebook 冻结程序。

ρ=0.40、双侧 α=0.05、80% 功效的 Fisher 近似需要 47 个独立基因，所以主方案采用 48 个。细胞数只降低每个 pseudobulk 的测量噪声，不能替代独立扰动数。

物理实验尚未执行。必须先从实验室取得：新细胞背景、dCas9-KRAB 条件、生物安全许可、平台、预算、时间、负责人和三批 baseline。Nadig 24 基因只能调流程，不能算新增独立确认。

入口：[E143 交接](../实验结果/E143_prospective_wetlab_validation_20260714/reports/E143_DECISION_AND_HANDOFF.md)

## 给后续 Codex 的执行顺序

1. 不再用 E142/E144 调分数或换阈值挽救失败。
2. 先与实验室确认 E143 交接文档列出的九项输入。
3. 获取三批新背景 baseline，只用 perturbation 前信息生成预测和风险。
4. 填写 `E143_prospective_wetlab_validation_20260714/templates/FORMAL_CANDIDATE_INPUT.csv`。
5. 运行 `tools/scripts/freeze_e143_formal_wetlab_candidates.py`；私有风险 codebook 不提交 Git。
6. 完成 QC 和 pseudobulk 锁定报告后才解盲。

## 当前投稿含义

E141 增加了解释层，但效应弱；E142/E144 增加了可信边界，不增加正向主张。现阶段仍是较强二区投稿基础，冲一区最关键的缺口是 E143 的真实前瞻新背景验证，以及随后由结果触发、带 rescue 的两基因机制闭环。
