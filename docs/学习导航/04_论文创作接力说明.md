## 2. 当前论文建议定位

> SafeConf is a post-prediction task-risk routing framework for single-cell perturbation models. It ranks which predictions are more likely to fail and supports selective verification under limited experimental budgets.

中文：SafeConf 是单细胞扰动预测后的任务风险路由框架，用于排序哪些预测更可能失败，并支持有限实验预算下的优先复核。

不要定位成：

- 新的单细胞扰动预测器；
- 对所有模型通用的置信度；
- 跨 gene、chemical 和 cytokine 全模态成功的方法；
- 已经保证固定预算显著节省湿实验的方法。

## 3. 新正文建议结构

### Introduction

1. 扰动预测模型输出很多预测，但用户缺少逐任务可靠性信息。
2. 模型分歧和预测幅度是强基线，却不能完全描述任务风险。
3. SafeConf 的贡献是预测后风险排序、严格数据合同和可审计边界，而不是替代预测器。

### Methods

1. 六数据集、context × perturbation 任务矩阵和四类 held-out setting。
2. scGPT 与 GEARS 的相同输入、gene panel 和 task-scoped true effect 合同。
3. PredictionRecord schema、训练/验证/测试隔离和风险先冻结再解封真值。
4. calibrated pair risk、frozen pair risk、disagreement 和 predicted magnitude 的定义。
5. 外层 fold、source validation 校准、cluster bootstrap 和 dataset-population bootstrap。
6. risk–coverage、normalized AURC、top-20% capture 和 conformal 上界。

### Results

1. 正式合同和 5,906 条 strict PredictionRecord 全部通过。
2. E131 六数据集主结果及异质性。
3. calibrated 与 frozen 的关系，不夸大校准增益。
4. E111/E116：风险对 GEARS 更敏感，背景新颖度是主要失效来源。
5. E132：AURC 改善成立，固定 top-20% 增益有限。
6. E114/E117：保守上界成功、紧上界失败。
7. E118/E130：chemical 和学习型路由器负结果构成边界。

### Discussion

1. 任务风险路由的实际用途和当前绝对收益大小。
2. predictor-specific 而非无条件 predictor-agnostic。
3. 五套生物背景数据加一套技术批次数据的覆盖与限制。
4. chemical、Santinha、Shifrut、机制和 conformal 的边界。
5. 下一步应是独立新数据或湿实验验证，而非当前真值上的事后调参。
