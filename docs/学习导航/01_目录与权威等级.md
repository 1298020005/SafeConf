冲突处理规则：

```text
L0 > L1 > L2 > L3 > L4
日期更晚不自动更权威；必须确认它是否是正式 gate 或正式结果。
```

## 5. Git 与同步边界

- 公开代码、稳定文档和 compact 结果表进入 Git。
- 大型运行输出放服务器 runtime，不把缓存和模型权重随意提交。
- `.ssh`、`.codex`、`.claude`、`.qoder`、token、key、credential 不进入仓库。
- 本地有未提交内容时，先 stash 或建立回滚点，再执行 fast-forward 同步。
- 不从 archive 反向覆盖当前目录；需要恢复时先做差异审计。
