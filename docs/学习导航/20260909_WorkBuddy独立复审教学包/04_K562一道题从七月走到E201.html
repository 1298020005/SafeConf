只用一道题：从 7 月那些 CSV，走到现在的 TxPert / E201

给完全小白。目标口径：计算机一区 / CCF 期刊或会议，不是生物一区。
贯穿例子永远是：K562::AARS+ctrl＝在 K562 这种血癌细胞里，把 AARS 这个基因调低，猜三千多个基因会怎么变。
先改口：你要发的是计算机方向的顶刊或顶会（比如 CCF-A 的 Bioinformatics 期刊，或 NeurIPS 这类会议）。PRESCRIBE 发的 NeurIPS 2025 就是计算机顶会，和你同一把尺子。下面不再拿「生物 1 区」说事。

第 0 步：你到底卖什么（先钉死）

领域里大家都在做：细胞 + 扰动 → 猜基因怎么变。

你这篇不重新猜。别人已经猜完了。你给这道猜打一个「可能错」的分，按分数从高到低排，好决定先核对哪几道。排序就是排序。

选修（现在没成绩、可以先不看）：下次让答题程序重新学习时，难题多练。那叫训练加权。主关不必从头再训一个新模型。

第 1 步：把这道题写成一行表（CSV 长这样）

CSV 就是 Excel 能打开的表格。一行一道题。7 月和现在，表头精神是一样的：

列人话这道题填什么
题号哪次考试K562::AARS+ctrl
细胞在谁身上考K562
扰动做了什么把 AARS 调低
学生猜的变化有多大幅度（猜的，不是实验室测的）现在 E201 里这题是 0.10173
几个学生吵不吵分歧现在 E201 里这题是 0.01035
你的风险分SafeConf 盖的章现在 E201 里这题是 0.11790
对完答案才有的错多少真实误差现在 E201 里这题是 0.08909

7 月那些「很多 CSV、很多公式」，就是对成百上千行这样的表算：风险分高的题，误差是不是也高。

第 2 步：7 月那种考法（具体细胞）

还是 K562。练习册和考场可以是同一类细胞。老师后来说这种太简单：每个基因都见过一点、每种细胞也见过一点，只是某个组合没见过。像：语文、数学都复习过，只是「这两科合在一张卷」没做过。

当时的学生可以是 scGPT、GEARS（两个别人的答题程序）。同一道题他们各猜一份。你们不算新答案，只拿他们的猜测算表、算相关。

步骤（7 月）：

  1. 选好几套公开数据（不止 K562 一套）。
  2. scGPT、GEARS 已经或当场给出每格的猜测。
  3. 把每格写成 CSV 一行：幅度、分歧、风险分。
  4. 对答案，算「分高的是不是更错」。
  5. 得到的是统计质检：很多表、很多公式。不是「你们发明了 scGPT」。

第 3 步：老师说太简单之后（还是这道 K562 题）

老师原话大意：你现在每个药见过一些细胞、每个细胞也见过一些药，这是更简单的 task。

后来主考改成：考 K562 时，K562 整行的答案全部藏起来。 练习册只许看 RPE1、HepG2、Jurkat 三种细胞。K562 上包括 AARS+ctrl 在内的所有题，练习时都不能看答案。

答题学生换成公开的 TxPert（当前这一场指定的学生）。同一套 TxPert 用四个不同的随机起点各猜一遍，得到四份猜测。

步骤（现在 E201，只盯 K562 这一行）：

  1. 练习册 = RPE1 + HepG2 + Jurkat 的答案。TxPert 在这里学习。
  2. 考试 = K562 全部题。其中包括 AARS。
  3. TxPert 对 K562 的每一题猜 3352 个数。四个随机起点各猜一份，共四份。
  4. 对答案之前就算：四份吵不吵、幅度多大、练习册里 AARS 的证据多少。合成风险分 0.11790。
  5. 指纹锁死，交到 GitHub / Gitee（交卷，不是网上训练）。
  6. 再打开 K562 的真答案。这题误差 0.08909。
  7. 1808 道题都这么干，看「分高的是不是更错」。总成绩：你的分 0.4082，笨办法幅度 0.6189。
7 月和现在差在哪，就三句话： 1. 还是质检和排序，不是改行当。
2. 考法更难：从「抠几格」变成「一种细胞整行当考场」。
3. 指定学生换成 TxPert。以前的 CSV 还在仓库，对外讲主成绩用 E201。

第 4 步：幅度还用这道题算一遍

TxPert 猜完，每个基因有一个「我猜会变多少」。把这些数平方、加起来、开根号，得到一个正数。这题是 0.10173。对答案前就能算。实验室还没测。

1808 道题都有这样一个数。按这个数从大到小排队，和「真的错多少」排得有多齐，就是 0.6189。按你的风险分排，是 0.4082。所以笨排队目前更齐。

PRESCRIBE 能发顶会，是因为它做了「自己猜 + 自己报把握」并给出过滤后精度提升。你做的是猜完之后排序。同一领域、同一把计算机尺子，货不同。不是「他能做模型所以你不能」；是你这篇主关没做成新猜题模型。
