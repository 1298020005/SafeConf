1. 这件事在干什么

实验室把 K562（一种长期培养的血癌细胞）里的 AARS 基因调低，然后测序，看三千多个基因各自升高还是降低。真做一遍贵、慢。

公开模型 TxPert 先输出 3352 个猜测。当前主结果用的就是它。它不是唯一能用的模型：7 月那张正式表用的是 scGPT 和 GEARS。

SafeConf 不输出这 3352 个数。TxPert 猜完之后，在还没有打开「K562 压低 AARS」这组真实测序之前，SafeConf 给一个风险分。风险分高，表示这组猜测更可能偏。使用者按风险分从高到低排，预算只够核对一部分时，先做高风险的那些。这是质检，也是排序。

四个随机起点 = 同一套 TxPert STRING-GAT，换四个启动值。不是四种结构。三种不同结构（GAT / Exphormer / Exphormer-MG）出现在 E199，那是另一张表，263 组，不要和 E201 的四个起点混谈。

4. 幅度 0.10173 怎么来的

TxPert 对每个基因输出「我猜会变多少」。把 3352 个数每个平方，相加，再开根号，得到一个正数。表里叫 predicted_magnitude。

幅度大，往往绝对误差也大：猜的变化本身就多，差一点点也会在平方和里显出来。所以幅度经常能把「误差大的组」排到前面。这不是 SafeConf 的功劳，是幅度自己的性质。E201 里幅度必须单独拿出来比，而且它更强。

6. 风险分 0.11790 怎么平均出来

五个量先在 K562 主分析 566 组内部做标准分：减去这 566 组的均值，再除以这 566 组的总体标准差。然后五个标准分相加，除以 5。事先规定各占 1/5，没有用 K562 的真实误差去学权重。

幅度不进这五个。幅度是拿来对比的强基线。

风险分可以是负数，因为它是标准分的平均，不是 0 到 1 的概率。不能读成「百分之多少会错」。

12. 只能核对 20% 时

合并 1808 组，20% 是 362 组。K562 566 组的 20% 是 114 组。下面有两列，不要合成一个数。

抓取比例 high_error_capture：真实误差最高的那一批里，有多大比例被你挑去核对了。随机乱挑，期望就是 362÷1808=0.2002。

效用 oracle_normalized_utility：如果全知道谁最错，挑 362 组能达到的平均误差是上限；乱挑是下限。你的排法相对乱挑，往「全知道」挪了多少。0 等于乱挑，1 等于全知道。

组合「幅度 + SafeConf」有没有更好用，E201 没有给出已证明的效用提升。不能写已经合在一起更好。
