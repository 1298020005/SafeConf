## 1. 一句话结论

SafeConf 是已有单细胞扰动预测模型之后的可靠性审计层。当前主线不生成扰动预测，也不依赖排序优势；它用冻结预测家族的几何关系给出确定性误差下界，并用独立校准数据给出可搬移的经验上界。

当前研究已经形成六套正式 scGPT–GEARS 证据闭环，但结论必须限定在当前 gene perturbation（基因扰动）合同、当前预测器和当前数据分布内。

因此可以写“六数据集总体上超过两个强基线”，但不能写“每个数据集都稳定获胜”或“校准版必然优于 frozen”。

## 3. 三个 SafeConf 版本必须分开

| 名称 | 含义 | 论文中的位置 |
|---|---|---|
| `safeconf_calibrated_pair_risk` | 只使用 fold 内 source validation pair 校准的任务风险 | 当前六数据集主结果，需要完整写明校准数据需求 |
| `safeconf_frozen_pair_risk` | 预先固定、可解释的规则 | 固定协议基线和稳健性对照 |
| learned router / reliability layer | 后续学习型风险模型 | 补充或负结果；不能反向修改 frozen 成功率 |

E126 的跨数据集 Ridge 和 E130 的 Tian 确认性高错误路由器都没有通过预设门槛。已经解封真值的数据集不能继续事后更换模型硬救。

## 6. 当前边界

- `predictor-agnostic`（预测器无关）不能作为无条件结论；风险信号对 GEARS 明显强于 scGPT。
- Santinha 信号弱，Shifrut 未超过 magnitude，Tian 含负 fold。
- normalized AURC 有稳定改善，但 top-20% 总错误捕获增量很小且区间跨 0。
- 90% split-conformal 经验覆盖 98%，但平均上界约为真实误差 1.86 倍。
- chemical 统一合同没有证明 SafeConf 超过 magnitude。
- 高风险基因通路没有通过预设显著性门槛。
- 研究具备投稿竞争力，不等于任何期刊保证录用。

## 7. 当前还缺什么

对较强二区稿件，首要缺口是把最新证据写成统一 manuscript，而不是继续堆同类实验。

对更高门槛稿件，最有价值的是新的真正未见数据、独立合作或湿实验验证；在当前六数据上继续调风险模型的确认价值很低。
