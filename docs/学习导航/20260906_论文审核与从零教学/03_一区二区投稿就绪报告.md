## 3. 还缺什么：在这些闭合前，二区都谈不上“一定”

### 3.1 正式 E204（最高优先级）

需要新增 16 个 risk_weighted 模型和 16 个 dispersion_only 模型，各 80 轮，与 E201 的 16 个 uniform 模型按同一 target、同一 seed 成对比较。主判断已冻结：高难任务 RMSE 是否下降，全体 RMSE 恶化是否不超过 5%。

现状：只有 profile / smoke。没有正式效果表。

### 3.2 E205 跨架构

E201 的四个成员是同一 GAT 的四个种子。没有 E205，就不能把分歧写成跨模型不确定性。

现状：只有 `ANALYSIS_FREEZE.md`，结果表 0 张。

### 3.3 冻结后的新外部确认

Frangieh、Lara、Santinha、Replogle 已参与过方法开发或历史判断，不能再包装成全新确认。需要：在看真值前写死策略、阈值、基线和停止规则，然后在一个未参与开发的数据集或新模型家族上一次性评价。

### 3.4 可执行复核策略，而不是“二选一谁更好”

E201 已经表明幅度更强、SafeConf 有独立信息。下一版应是“幅度主排序 + SafeConf 补充”，并在新数据上冻结评价。现在还停在相关和 20% 效用。

## 5. “二区一定能发”为什么现在不能说

二区应用方法论文，审稿人通常会问四件事：问题清不清、评价严不严、相对最强基线有没有增量、失败边界有没有写。

当前：问题清楚，评价有封存纪律，四个 target 都报了，失败也留下了。卡住的是增量叙事——单独排序输给幅度；训练介入没有正式结果；外部确认还是旧数据。把这样的状态写成“一定能发”，是把审稿人最可能问的洞，说成已经补上。

什么时候才“可以认真讨论二区投稿”，而不是“一定能发”：

1. E204 正式比较完成，难任务改善，全体恶化不超过 5%，或诚实改写成训练取舍；
2. 复核策略冻结，并在未参与开发的数据或模型上一次性评价；
3. E205 至少补一个结构不同的家族，或把主张改成“初始化敏感性指标”；
4. 主文定位改成“预测后任务风险审计 + 幅度强基线 + 有限独立信息”，不写成通用置信度。

即使这四条都满足，录用仍取决于期刊、审稿人和写作。本报告不把任何分区写成保证。
