# 2026-09-26｜网页方案的实验审查与当前判断

## 这版方案哪里对

把 SafeConf 研究问题拆成当前预测证据、公共生物历史和过去模型错误历史，是一个合理的实验问题。它能避免把 `historical_residual_risk` 误说成“过去模型错了”：源码中该字段实际是训练来源真实效应的跨背景外推误差；过去模型错误只能作为风险模型的监督标签。

## 本轮已经执行

1. E264b 修正了目标背景排除合同，确认三项研究能做基础质量复核，Lara in vivo 仍因来源不足被拒绝。
2. E266 在三项研究、三种参考预测器和五个外层折上比较 `M`、当前预测 `P`、公共历史 `B`、模型错误历史 `E` 及组合。
3. E267 将每个扰动整体放入一个固定桶，测试扰动不向风险训练器提供过去错误标签。
4. E269 把历史效应稳定性/方差从 `B` 中拿掉，只保留支持数和背景相似度，检验更干净的公共信息。
5. E270 将 `Bsafe` 放进按扰动整体留出的严格回顾性检查；E271 用不读取错误标签的固定等权公式复核同一问题。

## 当前结果怎么读

E269 的 `Bsafe` 与 `Bsafe+E` 在三项回顾性研究中均出现正向线索；E270 的按扰动整体留出也保留了监督式组合的方向。E271 同时给出一个必要的负边界：固定无标签公式在 Santinha 下降，说明不能把一个等权公式普遍化。这说明支持数、背景相似度和可用的过去错误经验值得进入下一轮研究设计，但二者必须分开写。

这些结果仍不能直接作为外部盲测或投稿主结果，原因是任务真值已经公开，B 字段沿用旧折合同，E 需要已有错误标签，且尚未在一套全新的研究/背景上冻结后验证。它们的作用是缩小最终实验空间，而不是替代最终验证。

## 下一步固定为一个问题

在新研究中，先只使用 `Bsafe`（扰动支持数、对照背景相似度）和当前预测输出，事前固定一个小风险规则；有足够历史错误标签时再作为独立的监督增强组。真值封存后，与幅度、已冻结 SafeConf-M 和同标签预算的监督基线同场比较。若新研究不复现，历史增强不作为主线；若复现，再报告适用范围和增量。
