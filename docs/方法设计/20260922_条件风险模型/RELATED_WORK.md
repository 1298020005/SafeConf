## 哪些说法现在不能写

- 首次用AI预测的输出评价其可靠性。
- 首次在单细胞扰动预测中估计置信度或拒绝不可靠预测。
- 新增门控/残差/保形三个名词，就有了新的理论。
- 另一个项目没有正式论文，所以它的公开算法不需要引用。
- 初步在历史数据上超过一个弱基线，就达到CCF-B录用标准。

## 值得继续验证的差异

以下是候选贡献，不是已证明的新颖性：

1. **不同历史覆盖条件下的稳定增量。** 在新背景、新扰动、双未见等条件中，利用可用证据决定补充幅度的程度；与固定融合及通用小评分器做同预算对照。
2. **对新研究校准依赖的量化。** 明确零目标标签、少量目标校准、充分目标校准三种设置。不能让自己的方法用目标验证误差，而对照只用原始幅度。
3. **历史参考库的作用被单独验证。** 固定上游预测，控制背景数量、扰动支持量和缺失机制；排除只是扩大了预测模型训练数据的解释。
4. **风险对象与证书一致。** 单模型、平均预测和家族误差分开；跨结构方法验证后才能讨论兼容性。

## 当前四类问题的回答

| 用户的判断分类 | 现在的回答 |
|---|---|
| 已有人做，所以发不了？ | 大方向有人做，而且有近邻；不能据此断言发不了。必须证明与近邻不同且有用的增量 |
| 没有意义/价值？ | 可靠性问题有价值，文献已经说明需求。特定SafeConf方案的增量价值仍需实验证明 |
| 有意义但没实现？ | 完整条件小模型、历史库容量对照、近邻同合同复现尚未全部完成 |
| 有意义且已实现？ | 特征、历史底表、评分与审计链已实现；“已完整验证、可保证录用”尚不成立 |

当前属于“已有实现与开发证据，关键增量尚待完整验证”。这是具体状态判断，不使用虚构的完成百分比。
