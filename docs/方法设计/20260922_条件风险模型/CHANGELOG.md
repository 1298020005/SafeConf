# 本轮沉淀记录

日期：2026-09-22

## 做了什么

1. 把“有人做过、有没有价值、已经做到哪一步”放进同一份记录。检索了单细胞扰动预测可靠性、PRESCRIBE、GPerturb、TISSUE、PertEMA和选择性预测文献；明确SafeConf的差异不能靠“第一次做置信度”来说明。
2. 将流程固定成：上游预测器输出预测表达 → 只用预测时可得到的幅度/分歧和允许的历史证据 → 任务级风险排序或停止放行。输出是风险和顺序，不是新的表达预测，也不是错误概率。
3. 增加四张白底统一字体的设计/结果图，PNG、SVG、PDF同时保留；绘图脚本只读已完成CSV，不改真实数字。
4. 完成四轮登记实验：E225跨研究原始证据、E226同研究本地历史误差、E227固定非线性对照、E228 E201目标背景留出。所有研究、目标和不利结果均保留。
5. 复查原有E223/E224口径：旧`s`已经含幅度和研究内验证误差校准；场景门控来自看过E223后的开发分析；8196行只有1083个去重条件。因此把`D16`从确定性结论改为带来源的历史候选。
6. 修复单任务块指标的除0路径：剩余任务数为0时返回缺失，不把它改成0。旧E225主要结果没有被重算或改判；新增测试覆盖该情况。

## 三轮实际结果

| 实验 | 设计 | 20%复核效用（相对幅度） | 结果 |
|---|---|---:|---|
| E225 | 不输入旧目标校准分数，比较M/MD/MDH/条件模型 | −0.000685，区间[−0.033003,+0.018641] | 预定门未通过 |
| E226 | 同研究其他扰动组误差，50%可用组校准 | +0.010737，区间[+0.002222,+0.021261] | 有开发信号，但未达+0.02，不能归因给单一模块 |
| E227 | 相同历史预算，固定参数梯度提升树对照 | −0.014885，区间[−0.075011,+0.020086] | 复杂直接预测不如幅度，预定门未通过 |
| E228 | E201四目标背景轮留，其他三目标误差训练 | +0.017608，区间[−0.015783,+0.054148]，2/4目标正向 | 有方向但未达门，不能写跨背景稳定增益 |

E226与E227同一岭回归臂的汇总复算一致；240个历史分组记录均无校准/测试扰动重叠。E225预测文件不含外层误差字段。四轮共1852次小模型拟合，但这不是1852个独立生物学实验。

## 没有做的事

- 没有修改原始CSV、真实误差、任务选择或E208协议。
- 没有把E208训练进度写成外部结果；截至本记录，测试真实表达读取仍为0。
- 没有把E225/E226/E227改名成PertEMA复现；PertEMA只按公开README作为最接近的软件方法记录。
- 没有用失败结果选择一个更好看的公式，也没有把“相对幅度为正”写成录用或CCF-B保证。

## 下一步如何继续而不重复调参

优先做固定上游预测下的历史库覆盖/数量实验：分别改变来源背景数量、每背景细胞数量、来源研究数，并记录缺失标记；先登记候选与停止门，再运行。与此同时准备PertEMA同合同对照和E208独立确认。若外部确认不支持，主线应收窄为风险审计、证书和明确的ABSTAIN边界，不继续在同一测试表上循环调权重。
