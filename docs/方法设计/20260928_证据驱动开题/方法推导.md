# 从实验规律到 SafeConf 条件风险模型

日期：2026-09-28。状态：研究设计与推导；本文提出的估计器尚未训练或确认。

## 1. 先固定问题与学习目标

对任务 q 和冻结预测器 m，令 p 是预测效应、y 是实测效应，均在相同预处理及 G 个基因的固定轴上。当前主要评价对象为：

\[
e=\frac{\|p-y\|_2}{\sqrt G},\qquad M=\frac{\|p\|_2}{\sqrt G}.
\]

SafeConf 学习 \(\mathbb E[e\mid\text{预测时证据}]\)。这里 e 是相对实测效应的 RMSE，包含测量不确定性的影响；不能称作不可观测的“纯生物预测错误”。

预测时允许知道当前任务的细胞背景、处理条件、对照，以及合法的训练来源实验和已经返回的历史反馈。当前任务的处理后表达、真实效应大小、测试 DE 基因列表和实际处理后细胞量都不得成为输入。历史 Q 指来源实验的可用信息，不能偷换为当前测试实验的质量。

第一轮在每个已对齐的数据集/上游内学习和评价 e；跨类型汇总使用组内的复核效用。若后续联合训练原始 expected error，须先冻结跨数据集误差单位、基因轴和仅训练侧尺度映射，不能直接混合不同 RMSE 单位。

## 2. 为什么可以从幅度出发，但不能把它当定理

令 \(T=\|y\|_2/\sqrt G\)，当两个范数非零时令 \(c=\langle p,y\rangle/(\|p\|\|y\|)\)。有恒等式：

\[
e^2=M^2+T^2-2MTc.
\]

当范数为零时直接使用内积形式。这个恒等式解释了风险的几何来源：预测尺度、真实响应尺度、预测方向与真实方向的匹配。M 是预测时可用的尺度项；T 和 c 依赖未知真值。

但 M 大并不必然 e 大：完美预测时 p=y，无论 M 多大，e=0。幅度成为锚点的经验依据是 E201 中的强关联，几何关系只是帮助解释。不能把 M 写成误差下界，不能据此强制所有域共享单调风险函数。

**最小比较**：原始 M 排序、仅 M 的正则化样条/低自由度回归、相同模型加其他预测特征 P。若单调校准 M，通常只改变数值不改变排序（平台会引入并列），因此不能把单调校准称为排序创新。

E201 的偏秩相关 0.2503 是剩余关联线索。偏相关不是完整条件独立检验，更不是对 H 分支的因果识别；旧分数混合了多类证据。

## 3. 核心形式：逐级增加信息，估计条件误差

令 Z 表示在所有比较中固定的合法任务元数据和尺度约定。用嵌套信息集合：

\[
\mathcal F_0=\sigma(Z,M),\quad
\mathcal F_1=\sigma(Z,M,Q),\quad
\mathcal F_2=\sigma(Z,M,Q,H),\quad
\mathcal F_3=\sigma(Z,M,Q,H,E).
\]

记真实但未知的最优风险函数为 \(\mu_k=\mathbb E[e\mid\mathcal F_k]\)。定义：

\[
\Delta_Q=\mu_1-\mu_0,\quad
\Delta_H=\mu_2-\mu_1,\quad
\Delta_E=\mu_3-\mu_2.
\]

于是有：

\[
\mu_3=\mu_0+\Delta_Q+\Delta_H+\Delta_E.
\]

这把用户提出的设计顺序变成了明确的估计目标：每一级修正只描述新信息带来的条件均值变化。P 可作为扩展锚点加入所有 \(\mathcal F_k\)，并通过单独的 M→P 对照核算其收益。

### 命题 1：理想条件风险的增量恒等式

若 \(e\in L^2\)，对每一级有：

\[
\mathbb E[(e-\mu_{k-1})^2]-\mathbb E[(e-\mu_k)^2]
=\mathbb E[(\mu_k-\mu_{k-1})^2]\ge0.
\]

证明：令 \(d_k=\mu_k-\mu_{k-1}\)，则 \(e-\mu_{k-1}=(e-\mu_k)+d_k\)。由于 \(d_k\) 对 \(\mathcal F_k\) 可测，且 \(\mathbb E[e-\mu_k\mid\mathcal F_k]=0\)，展开平方后的交叉项为零。

另有 \(\mathbb E[d_k\mid\mathcal F_{k-1}]=0\)。若新证据不改变条件均值，则 \(d_k=0\) 几乎处处，增加这个分支不会改善理想均方估计。

**设计含义**：H 若只重复 Q 的信息，理想修正应接近零。这支持“先质量、后内容”的分解。

**边界**：这是条件期望投影的标准性质，不是 SafeConf 新定理。它适用于理想函数和固定分布；有限样本估计器可能因为方差、错设或分布变化而变差。它也不等价于相关性或 Utility@20 必然提高。

### 顺序与归因

顺序改变会改变各分支归因，但相同完整信息的理想条件均值不变。Q 先行来自 E259 的混杂控制问题；H 与 E 要额外交换加入顺序，测量彼此的条件增量。E273 中 H 在 E 后只有 3/7 组正向，正说明不能把两个来源的边际收益相加。

如果 H 的增量为零、E 有增量，则最终模型可以是 \(\mu_0+\Delta_Q+\Delta_E\)。这仍回答原研究问题。

## 4. Q 与 H 为什么要分开

将历史来源 s 的实测效应写成 \(\tilde h_s=\theta_s+\varepsilon_s\)。在零均值、来源独立测量扰动等简化条件下，来源间观测差异包含真实响应异质性和测量波动两部分。有限细胞估计、批次及共享对照会破坏简化独立性。

类似地，对固定预测 p 与带噪目标 \(\tilde y=y^*+\varepsilon\)，若条件均值为零且交叉项消失：

\[
\mathbb E[\|p-\tilde y\|^2/G\mid p,y^*]
=\|p-y^*\|^2/G+\operatorname{tr}(\Sigma_\varepsilon)/G.
\]

这个关系仅用于解释 MSE 测量混杂；不能对 RMSE 直接相加分解。若预测与真值共享带噪对照，需要显式保留协方差项。split-half 只能提供稳定性代理。

因此将证据定义为：

| 来源 | 最小字段 | 可做的解释 |
|---|---|---|
| Q | 来源数、来源处理/对照细胞数、重复数、split-half 波动、缺失标志 | 观测支持、测量稳定性 |
| H | 历史中心、来源差异、预测—历史距离；保持剂量/时间和基因轴一致 | 控制 Q 后仍有用的历史效应内容 |
| Z/P | 预测尺度/形状、可用的上游不确定性、合法控制状态 | 当前预测及任务结构 |

历史中心距离要防止数学冗余：如果上游预测只是历史均值乘固定系数，其距离可能已经由 M 决定。E258 的历史收缩预测器出现过这种情况，必须报告该退化条件。

## 5. 提出的可实现估计器

第一版用低复杂度、逐层冻结的回归函数：

\[
\hat e_q=\max\{0,\ b(M_q,Z_q)+g_Q(M_q,Z_q,Q_q)
+a_Hg_H(M_q,Z_q,Q_q,H_q)+a_Ec_E(q)\}.
\]

- b：只从幅度和预定元数据估计基础误差，比较线性/低自由度样条与原始 M。
- g_Q：用前级折外残差拟合质量修正，默认岭回归；不强行假设细胞数越多风险就越低。
- g_H：可选、正则化的内容修正。a_H 为开发阶段选择后冻结的全局/预定类型开关，不用最终测试决定。
- c_E：模型特有的历史残差校正，见下一节。a_E=0 表示缺少合法反馈。
- 最后的非负投影与 e≥0 一致；各修正本身允许正负。

优先把 b+g_Q 与普通同特征 Ridge/GBDT 比较。分层结构相对拼接的潜在价值是解释与反馈适应，不预设它一定提高准确率。

没有 H 时 g_H=0；没有 E 时 c_E=0。缺少 H/E 的模型仍有经验误差风险，不能输出“安全保证”。只有校准合同成立后才另行提供区间；缺证据时保留 support 状态。

## 6. 误差记忆应记住什么

过去任务的原始错误 \(e_j\) 同时包含幅度、背景难度和模型额外偏差。若直接平均它，可能只是重复学习“大幅度任务或某个背景通常更难”。

提出保存前级模型的折外残差：

\[
r_j=e_j-\hat b_{\mathrm{pre}}^{(-j)}(x_j),
\]

其中前级包含已经接受的幅度/质量/历史修正；\((-j)\) 要排除 j 所属的整个任务簇及其标签衍生特征。每条 memory 附有上游 checkpoint、训练 split、风险层折号、历史池版本和反馈到达时间。

对当前 q，按不依赖其未知误差的合法相似条件形成权重 \(w_j\ge0\)，定义：

\[
\bar r_q=\frac{\sum_jw_jr_j}{\sum_jw_j},\qquad
n_{\mathrm{eff},q}=\frac{(\sum_jw_j)^2}{\sum_jw_j^2}.
\]

同一湿实验来源、同一扰动的重复记录先按簇聚合；种子、细胞及重复导出行不能直接增加独立反馈量。来源相关时该公式只是名义有效样本量，应按独立簇控制、检验敏感性。

第一版使用可审计的相同模型版本/类型与固定条件相似性，不训练检索器。对无匹配任务的 fallback 单独记录全局残差来源，并把 `n_exact_support=0` 保留；不能把全局池数量伪装为“该扰动的历史支持数”。

## 7. 从小样本问题推导收缩，而非预先设置门控

### 命题 2：简化随机效应下的反馈收缩

假设某一可比反馈组的额外偏差为 \(\theta\sim N(0,\tau^2)\)，历史折外残差满足 \(r_j=\theta+\epsilon_j\)，\(\epsilon_j\overset{iid}{\sim}N(0,\sigma^2)\)，且组划分与误差无事后选择。

后验均值为：

\[
\hat\theta=\frac{n\tau^2}{\sigma^2+n\tau^2}\bar r
=\frac{n}{n+\kappa}\bar r,\qquad \kappa=\sigma^2/\tau^2.
\]

也可直接最小化线性收缩 \(w\bar r\) 的均方误差：

\[
\mathbb E[(\theta-w\bar r)^2]=(1-w)^2\tau^2+w^2\sigma^2/n.
\]

对 w 求导即得同一最优权重。n=0 时采用先验均值 0；\(\tau^2=0\) 时也不修正。

**设计含义**：少量反馈和高噪声时缩小校正，反馈增加且有可重复偏差时加大校正。与用户要求的“先有残余风险，再加入 Error Correction”一致。

在加权、异方差场景中，若每条残差有已知独立方差 \(v_j\)，后验均值为
\(\sum_jr_j/v_j\,/\,(\tau^{-2}+\sum_j1/v_j)\)。实际 split-half 不能直接当 \(v_j\) 的精确真值。第一版使用预定有效簇数量与训练侧 κ，作为受检验的近似。

**理论边界**：这是标准高斯收缩思想。实际 memory 的相关性、残差估计误差、概念漂移及数据驱动相似度会改变结论。不能把上述 Bayes 风险最优性写成对所有目标任务的无条件不劣保证。

**真正的方法问题**：质量分解后的残差反馈是否比原始错误记忆更省反馈、更不易被背景难度混杂；收益是否跨基因与化学成立。这需要实验回答。

## 8. 训练算法与两层泄漏

上游折外与风险层折外是不同条件：

1. 上游预测任务 j 时，没有在上游拟合中使用其被留出的任务/背景真值。
2. 风险器预测任务 j 时，没有用 j 的误差拟合自身或构造任一标签衍生特征。

E273 的风险层扰动冷桶只验证了第二层的一部分，不能自动证明第一层。

```text
输入：冻结上游预测、允许的公共历史、合法误差标签、任务簇划分。
外层：固定 evaluator T，其标签只在最后使用。
内层：D = 允许开发/拟合部分，按任务簇交叉拟合。
  1. 每个内层训练分片重建自己的归一化、历史池、质量及记忆。
  2. 在未参与拟合的内层任务上生成 b 的预测与残差。
  3. 拟合 gQ，再为 gH 生成完整前级的折外残差。
  4. 对所有拟作 E 的记录，交叉拟合整个前级流水线得到 r_j。
  5. 仅内层评价选择正则化、κ、是否保留 H，以及固定回退规则。
  6. 外层评估前封存方法/预测/历史池哈希。
评价：T 的真实误差只用于配对指标；各类型、背景、预测器完整报告。
```

对第 3–4 步，仅预存一次含全 D 标签的上游特征再切内层仍可能泄漏，必须在相应内层重新生成所有标签依赖项。工程上可用明确 A/B/C 角色分片降低嵌套成本，再用角色轮换利用样本；轮换不能穿越最终外层评价簇。

公共实验历史与错误 memory 的允许范围要按场景定义：已知扰动的新 context 可以用其他允许 context 的同扰动历史；真正未见扰动没有这样的来源，不可仍称为同一“冷启动”任务。

## 9. 为什么期望误差对应复核优先级

### 命题 3：固定成本预算下的选择

若复核 k 个任务的收益定义为所捕获的总真实误差，且每个任务成本相等，当前全部可见证据记为 \(\mathcal X\)，则：

\[
\mathbb E[\sum_{i\in S}e_i\mid\mathcal X]
=\sum_{i\in S}\mathbb E[e_i\mid\mathcal X].
\]

因此，选择条件期望误差最高的 k 个任务最大化该目标；不要求任务误差互相独立。如果所有估计误差满足 \(|\hat\mu_i-\mu_i|\le\epsilon\)，相对最优集合的条件期望总误差捕获差至多 \(2k\epsilon\)。证明由加入并减去所选/最优集合的估计总和得到。

**实用含义**：学习 expected error 有明确复核目标。有限样本均方误差改善不保证 top-k 排序改善，因此两个指标均应报告。任务成本不同或价值取决于湿实验发现时，需另立收益定义；当前不能声称节省实际实验费用或找到更多生物发现。

E273 的学习目标是训练集内误差百分位，属于风险排序分数。它没有直接拟合上述 expected error；新方法需独立评价，不能借用 E273 的数值。

## 10. 四种冷启动/更新合同

| 场景 | 允许使用的信息 | 必须怎样评价 |
|---|---|---|
| 同模型，新任务，无 E 特征 | 仍可能已用该模型其他误差训练风险器 | 叫“无记忆特征”，不能称零标签 |
| 新模型，零目标反馈 | base 仅从允许的其他模型/研究训练，目标模型误差预算为 0 | leave-one-model/version-out；只用合法公共历史 |
| 固定风险器，追加 memory | b/gQ/gH 固定；记录逐渐到达 | 固定独立 query set；每个预算相同排序、相同记录子集 |
| 周期性重新拟合 | 只用截至该时点已返回的标签 | 与普通 Ridge/GBDT 同反馈数、同调参预算比较 |

E274 对应“监督风险器重拟合 + 记忆特征稀疏化”，不是后两类的证据。新实验需同时记录 `n_risk_training_labels` 与 `n_memory_labels`，并按二者并集计费。

## 11. 基因/化学的统一设计

第一版共享任务与误差语义、幅度—质量—残差处理流程、同一训练程序；分别估计必要参数并报告结果。在有效记录足够后，比较完全分线、共享小主干+类型字段、完全共享三种版本。

基因特有字段：KO/CRISPRi/CRISPRa/OE、靶基因、组合成员、guide（可用才用）。化学特有字段：compound、dose、time、vehicle。未记载的字段带 mask；同名 perturbation 不等于同条件任务。

**“统一方法”首先指共享估计原则与接口；一个共同 checkpoint 的跨类型增益是后续实验证明的更强主张。**

## 12. 与既有证书路线及创新性的关系

旧证书的 \(R_F^2=\|\bar p-y\|^2+D_F^2\) 描述注册家族 RMS 误差；本文描述指定冻结预测器的任务误差。证书可作为独立已有成果或可选附录，不能给本文单模型风险器提供确定性安全保证。

本轮拟贡献是由 E201→E259→E273/E274 推出的可检验估计结构：幅度基础风险、质量控制、可关闭的历史内容、合法反馈的残差收缩。若它仅等同普通 Ridge/GBDT，方法贡献需要收缩；研究报告仍可完整陈述风险来源与边界，但不能靠把标准恒等式命名为新理论来弥补。
