# 面向单细胞扰动预测的证据感知后置风险审计方法研究

**开题报告与研究进展确认版｜2026-09-30**

用途：2026 年 9 月 30 日导师/学校汇报。文中分别标明开发结果、一次性确认结果和仍需扩展的证据；SafeConf v4 已在方法冻结后完成 E170 四面板确认。

## 一、研究背景与问题

单细胞扰动预测模型尝试回答：改变某个基因，或对特定细胞施加一种药物后，基因表达会如何变化。实际使用时，预测模型会同时给出大量候选结果，而真实实验验证的预算有限。因此，除了提高表达预测精度，还需要判断哪些预测更可能出错、应优先复核。

本研究把已经训练好的扰动预测模型视为冻结的上游模型，以“任务—模型”为风险评价单位。一个任务包括细胞背景、扰动对象、扰动类型、剂量/时间等条件及匹配对照。SafeConf 接收其预测结果和预测时可获得的证据，估计任务级真实误差并分配复核优先级。

核心问题为：**在预测幅度已经解释相当部分误差的情况下，其他证据还能提供多少有效信息，怎样利用这些增量而避免质量混杂、重复计数和反馈泄漏？**

选择这个问题的依据来自已有实验。E201 显示预测幅度与误差存在强关联；E258/E259 显示历史效应的关联可能由测量质量解释；E273/E274 则提示模型历史反馈可能提供进一步线索。上述结果形成一个由已知规律逐步增加研究问题的过程。

## 二、国内外研究与本课题位置

现有相关方法可分为四种。

1. **扰动响应预测与内生不确定性。** PRESCRIBE 在扰动预测框架内联合处理模型与数据不确定性，主要针对未见基因扰动。它说明预测可靠性是明确的研究问题，但本课题关注冻结上游输出上的风险估计。[正式论文](https://papers.nips.cc/paper_files/paper/2025/hash/d6383e7643415842b48a5077a1b09c98-Abstract-Conference.html)
2. **后置误差估计。** PertEMA 的公开软件使用预测时特征、折外误差、梯度提升模型及后置校准。这使“用一个小模型预测另一个模型的误差”成为必须比较的近邻基线；其仓库说明跨新 screen 需重新拟合，且尚无配套论文。[官方软件](https://github.com/OfficialBishal/PertEMA)
3. **历史误差与校准。** HopCPT 在时间序列中检索相似历史误差状态并形成预测区间。由此，本课题的差异需要落实到扰动场景下的质量控制、残差反馈与冷启动验证。[正式论文](https://papers.neurips.cc/paper_files/paper/2023/hash/aef75887979ae1287b5deb54a1e3cbda-Abstract-Conference.html)
4. **测量质量与评测混杂。** Systema 提醒扰动预测评价需分离系统性变化；2026 年扰动可靠性预印本进一步讨论实测数据质量对模型比较的影响。SafeConf 需要把预测器的错误、目标测量误差和历史测量支持分开。[Systema](https://www.nature.com/articles/s41587-025-02777-8)、[可靠性预印本](https://www.biorxiv.org/content/10.64898/2026.08.11.744177v1)

本课题解决的具体缺口是：**在幅度强基线、历史证据相关性差异和有限反馈同时存在时，如何构造能逐项识别证据增量、历史不足时收缩的后置风险估计器。**本轮已完成开发冻结与一次性确认；残差学习、经验贝叶斯和条件期望分解本身属于理论基础，不单独包装为创新。

## 三、研究目标和拟回答的问题

### 3.1 总体目标

建立作用于冻结扰动预测器输出的证据感知风险审计方法，在固定复核预算下识别更多高误差预测，并明确历史证据有效、无效和缺失的条件。基因扰动承担主验证，化学扰动承担当前压力测试。

### 3.2 三个研究问题

- **RQ1：幅度之外还剩什么？** 建立幅度基础风险后，支持度、测量稳定性和公共历史内容各自具有多大条件增量？
- **RQ2：如何从少量反馈学习剩余错误？** 用模型过去的合法预测错误修正幅度与历史仍未解释的部分，能否以较少反馈达到稳定的复核收益？
- **RQ3：这些规律能否跨类型成立？** 共享风险语义和处理流程，在基因与化学数据、不同上游模型和不同留出方式下检验增量，而非只看混合均值。

## 四、已有研究基础：证据怎样推出方法

### 4.1 E201：幅度决定基础风险的起点

**已完成结果。** 四背景、1,808 个主任务中，旧 SafeConf 与真实误差的 Spearman 相关为 0.4082，预测幅度为 0.6189；控制幅度后，旧分数的偏相关为 0.2503，95% 区间 [0.2021, 0.2980]。固定 20% 复核预算下，旧分数效用为 0.3200，幅度为 0.5943。

**中间结论。** 幅度是必须保留的强基线。其他证据有剩余关联，但直接混合可能损害排序。因此先估计幅度基础风险，再学习剩余误差。

**不能推出。** 幅度在所有模型和场景中必然单调决定误差；旧 SafeConf 已优于幅度；剩余关联必然是公共生物历史的独立作用。

依据：[E201 正式报告](../../实验结果/E201_txpert_multitarget_retraining_20260802/formal_core_evaluation/reports/E201_CORE_REPORT.md)。

### 4.2 E230/E234：历史值得检验，复杂结构尚无充分依据

**已完成结果。** E230 固定预测并改变历史细胞/来源覆盖，完整历史组合相对幅度效用增加 0.011995，但预定开发门未通过。E234 的简单 M+H 增加 0.013928，基因簇区间 [−0.010165, 0.056283]；复杂历史候选 E232 比 M+H 只高 0.002832，区间同样跨零。

**中间结论。** 历史数量和内容需要分别检验；当前优先做简单可解释修正。M+H 的正点估计是候选线索。

**下一实验。** 在相同任务、误差、标签预算和历史池上，比较幅度、质量控制与历史内容修正，避免由来源数量带来表面收益。

依据：[E230](../../实验结果/E230_history_capacity_20260922/REPORT.md)、[E234](../../实验结果/E234_fair_simple_baselines_20260923/REPORT.md)。E201 的 pooled 效用与 E234 的背景宏平均不可直接横向比较。

### 4.3 E258/E259：质量 Q 必须先于历史内容 H

**已完成结果。** Feng 开发数据中，原始历史离散度控制幅度后的宏偏相关为 0.572；增加来源细胞量控制后为 0.169；分半近似扣噪后为 0.008。E259 中，Feng 加入 H_raw 的效用增量为 −0.000206；Cui 加入完整 Q_split 后为 −0.003967；Lara ex vivo 为 −0.056071。

**中间结论。** 历史效应的原始相关不能被直接解释为生物信息。方法必须分别记录历史测量质量与效应内容，H 仅拟合在 M+Q 后的剩余误差。

**机制边界。** split-half 包含采样波动和细胞异质性，属于测量稳定性代理，不等于精确识别纯技术噪声。Feng 与 Cui/Lara 的效用定义不同，以上差值不能跨研究平均。

依据：[E258 开发报告](../../实验结果/E258_feng2025_independent_confirmation_20260924/DEV_REPORT_20260925_历史何时有用.md)、[E259](../../实验结果/E259_history_measurement_decomposition_20260925/README.md)。

### 4.5 E274：反馈有价值的线索，冷启动需要独立定义

**已完成结果。** 模拟 E 记忆比例从 0% 到 100% 时，开发效用从 0.6795 到 0.7493；5% 和 10% 之间并不单调。GPU 重复表明小风险器可运行，但尚未证明新结构的独立收益。

**本轮代码核对。** 每个记忆预算都使用全部 fit 误差标签重新拟合风险器。所以该曲线衡量的是“完整监督下记忆特征稀疏化”，不是新模型零标签冷启动，也不是固定风险器只追加外部 memory。

**架构选择。** 提出对模型历史误差先去掉已解释成分，再按合法反馈数量向零收缩的校正。另做真正同反馈预算实验，才能把“反馈越多逐步适应”写成贡献。

依据：[E274 报告](../../实验结果/E274_six_pm_queue_20260927/E274_RESULT_SUMMARY.md)、[E274 代码](../../../tools/scripts/run_e274_error_memory_curve_cpu.py)。

### 4.6 SafeConf v4：开发冻结、竞争比较与一次性确认

**开发与冻结。** 在 TxPert GAT/Exphormer 各 1,808 个任务上，Magnitude 的 Utility@20 分别为 0.7682/0.7587，V1 为 0.7864/0.7823，nested V2 为 0.7963/0.7918。V2 相对 V1 的开发宏增量为 +0.0097，8 个评价 strata 中 7 个非负，预注册安全退化门全部通过，因此在打开 confirmation 前冻结 V2。

**PertEMA 同合同比较。** 在相同任务、gene-disjoint outer split 和错误标签预算下，PertEMA 官方算法适配的 U20 为 0.7237/0.7181，SafeConf V2 为 0.7963/0.7918；差值为 +0.0656/+0.0688，两组 target-cluster bootstrap 区间下限均大于 0。

**一次性确认。** E170 全部四面板在冻结与远端授权后同时打开，包含 2,400 个 task、800 个新 perturbation cluster、1 个 held-out donor 和 12 个 panel×state strata。Magnitude/V1/V2 的 U20 为 0.1655/0.2010/0.2159；V2 相对 Magnitude 增加 +0.0504，10/12 strata 非负，risk@10/20、AURC 和高风险漏检率均未退化，预注册 Gate A 通过。配对簇自举 95% CI 为 [−0.0266,+0.1136]，说明点增量和实用性门成立，但统计区间仍宽。

**适用边界。** 有合法两供体历史的 1,920 个任务中，Magnitude/V1/V2 U20 为 0.2383/0.2718/0.2857；无该 perturbation 历史的 480 个任务三者均接近无信息。E190 独立 GEARS family 中 V1 点增量为正而 V2 失败，说明低 cluster 数下 gate 不稳定。CPA 化学上游未通过能力门，只保留为压力测试。

依据：[完整结果包](../../实验结果/Stage2_mature_upstream_20260928/PAPER_RESULT_TABLES.md)、[E170 confirmation](../../实验结果/Stage2_mature_upstream_20260928/confirmation/e170_primary_cd4_four_panel/REPORT.md)、[导师汇报结果](../../实验结果/Stage2_mature_upstream_20260928/SAFEConf_导师汇报结果_20260930.md)。

## 五、最终候选方法

### 5.1 统一输入与误差对象

每个上游通过 PredictionRecord 接口输出任务、背景、扰动类型、条件、基因轴、预测效应、归一化与 provenance。上游可直接输出 effect，也可由 treated state 与匹配 control 转换；不同 output contract 的原始 RMSE 不强行混合。

任务 q 的冻结预测效应为 p_q，真实效应为 y_q，共同基因轴为 G。主要误差为 e_q = ||p_q − y_q||₂/√G，幅度为 M_q = ||p_q||₂/√G。真实效应仅作为 outer-train 风险监督、合法部署反馈和最终评价，不能进入当前任务的输入或历史库。

### 5.2 两类基础风险器

Universal Prediction Evidence 包含 magnitude、绝对均值、有符号均值、标准差、绝对 q95 和稀疏/形状统计，不使用 dataset/model ID，也不让 optional-field missingness 编码模型身份。

```text
rP  = Ridge(Universal P)
rPQ = Ridge(Universal P + Support + Relevance + Conflict + Content)
```

公共历史分为 Support、Relevance、Quality、Conflict 和 Content。当前正式字段具有 Support/Relevance/Conflict/Content；Quality 因缺少满足覆盖门的 replicate consistency 或 split-half 字段而不进入确认模型。

### 5.3 Evidence-aware shrinkage

V2 不假设历史恒定有效。它在 inner OOF 上把 rP 与 rPQ 校准到相同误差尺度，再由低容量单调 gate 决定历史修正强度：

```text
w = sigmoid(b + aS·Support + aR·Relevance
              + aQ·Quality − aC·Conflict − aM·Missingness)

rV2 = calibrated_rP + w × (calibrated_rPQ − calibrated_rP)
```

所有标准化、阈值、匹配、校准和 gate 均只由 outer-train 决定，outer-test 只执行冻结变换。最终输出称 task-level risk score，主要服务 Utility@20、risk-coverage 与选择性复核，不把排序分数过度解释为已校准的绝对期望误差。

### 5.4 历史资格与上游能力门

History Eligibility Contract 排除当前 task、同 experimental unit/replicate group、当前 truth 派生统计和 outer-test 全局统计。历史分为同 study 的合法 outer-train history 与独立 study external history，论文按来源分开表述。

上游在进入主验证前必须相对预指定最强简单基线通过 2% non-inferiority、至少 60% strata 非劣与 paired cluster bootstrap 稳定性门。该门使弱 CPA/E208/E247/E258 不能依靠“风险模型涨得好看”进入主结果。

### 5.5 Error Memory 部署扩展

公共历史描述生物实验过去发生过什么；Error Memory 描述同一冻结上游过去在哪里出错。反馈预算实验表明 10% 反馈不稳定，GAT 在 75–100%、Exphormer 在 50–75% 后形成更稳定增量。因此部署采用批次积累、周期重训，不逐样本在线改参数。

条件风险分解与收缩关系用于解释设计依据；实证有效范围以冻结 confirmation、能力门和失败边界为准。主要推导与反例见[方法推导](方法推导.md)。

## 六、拟创新点及对应验证

| 贡献 | 具体内容 | 当前证据 |
|---|---|---|
| 证据感知历史收缩 | 将预测证据与历史 Support/Relevance/Conflict/Missingness 分开，学习何时使用历史修正 | TxPert 开发冻结；E170 Gate A PASS；no-history 边界完整保留 |
| 可审计黑盒接口 | 统一 direct-effect/treated-state 输出、gene space、error contract、history eligibility 和 competence gate | Prediction/Error Contract；E208/E247/E258 fail-closed；E170 字节级授权与一次性打开 |
| 冷启动到反馈适应 | 冷启动依赖预测和公共历史，部署后以同模型 Error Memory 周期重训 | gene-disjoint 0/10/25/50/75/100% 反馈预算曲线；少量反馈负结果保留 |

单独的 Ridge、sigmoid gate、模型数量和标准恒等式不作为创新；贡献来自问题合同、证据可靠性机制和冻结验证链。

## 七、研究基础、可行性与主要风险

已有数据和实验已支撑开题及第一版方法稿：TxPert 两架构承担开发，E170 四面板承担一次性同研究确认，E190 GEARS 承担跨 family 压力，CPA 承担化学压力，E208/E216/E247/E258 记录能力门边界。

现有证据已经整理为统一主表、确认表、主图、Claim–Evidence Matrix 和复现哈希。投稿增强项是 external-study/独立 family confirmation 与成熟化学上游，不再反向修改本版方法。

主要风险及处理：E170 自举区间较宽，完整报告；无历史任务接近无信息，界定适用范围；E190 的 V2 gate 未复现，跨 family 只作开发证据；CPA 上游未过门，化学不作主确认；Quality coverage 为 0，不使用 Quality-aware 主张。

“二区”需要区分学校采用的中科院分区或 JCR 分类、年份与大小类；本报告不把 CCF-B 自动换算为二区。正式投稿准备程度以方法增量、比较公平性和验证完整性评估，录用由审稿决定。

## 九、汇报结论

SafeConf 已从证据驱动的研究问题收敛为冻结方法：在强 magnitude 基线之上，用合法历史 Support/Relevance 构造风险，并用 nested evidence shrinkage 控制历史修正。该方法在 TxPert 两结构完成开发，在同合同 PertEMA 比较中取得正增量，并在 E170 新 perturbation/held-out donor 上一次性通过 Gate A。

当前论文路线确定为 Route A。正文同时呈现 bootstrap 不确定性、无历史失败、跨 family gate 失效和弱化学上游等边界。后续增强面向 external-study 与成熟化学上游，不再改变本版 Final Candidate。
