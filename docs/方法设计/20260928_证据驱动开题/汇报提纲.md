# SafeConf 开题与进展：12 页汇报提纲

建议时长：12–15 分钟。每页只讲一个结论；页脚给结果来源。以下是可制作幻灯片的内容提纲，本轮未生成 PPT 文件。

## 1｜题目与研究问题

**面向单细胞扰动预测的幅度锚定与证据增量风险评估方法研究。**

口述：上游模型给出大量表达预测，我研究在实验预算有限时如何识别更可能出错的预测，并量化哪些证据真正提供了新增判断信息。

## 2｜实际使用场景

展示一条基因任务和一条药物任务：细胞背景、扰动对象、条件、冻结模型预测、匹配对照；真实处理后表达尚未知。

输出是任务误差风险和复核排序。当前目标是捕获更多预测错误，尚未直接检验湿实验成本节省。

## 3｜已有基础与数据角色

E201：正式四背景规律；E230/E234：历史候选；E258/E259：质量混杂；E273/E274：风险学习与反馈开发。

七个数据集组不等于七个独立基因研究；旧数据、开发数据和封存确认数据在图中分开标记。

## 4｜第一条发现：幅度是强基线

E201：rho(M,e)=0.6189，rho(旧 SafeConf,e)=0.4082；控制 M 后剩余偏相关 0.2503。

口述：这把研究起点定为幅度基础风险；额外证据应解释幅度未解释的部分。旧分数的复核效用弱于幅度，需要改变组合方式。

## 5｜第二条发现：历史原始相关混合了质量

E258 的 H 偏相关：控制 M 时 0.572，控制细胞量后 0.169，分半近似校正后 0.008。

口述：Q 必须先于 H。分半并不等于纯技术噪声，我们研究的是可观测的测量稳定性控制。

## 6｜第三条发现：证据增量具有条件性

使用 [E273 复算图](复算结果/EVIDENCE_INCREMENT.png)。突出 Q 增量 +0.1253、H|PQ +0.0281、E|PQH +0.0759。

口述：这些是开发结果。H 在已有 E 后只在 3/7 组改善，完整双历史未必是最终最优结构。

## 7｜三个研究问题

RQ1：控制幅度和质量后，历史内容还有什么？

RQ2：有限模型反馈怎样修正剩余误差？

RQ3：这一风险学习原则能否在基因和化学、不同上游上成立？

## 8｜由证据得到的模型

画出：b(M) → +ΔQ → +可选ΔH → +残差反馈ΔE。

口述：每一层拟合前一级的折外残差，没有贡献的分支关闭。锚点保留，纠正量可增可减。

## 9｜理论依据与可实现创新

条件期望增量解释为什么只看新增信息；高斯收缩解释少反馈时缩小校正。

```text
ΔE = n_eff/(n_eff+κ) × 历史折外残差均值
```

口述：这些统计关系是已知基础。拟贡献是它们如何解决本场景的质量混杂、重复风险与有限反馈问题，以及能否被公平实验支持。

## 10｜怎样检验它

同信息、同标签预算：M、M+Q、M+Q+H、M+Q+E、完整拼接、本方法。

补 context 平均难度、原始错误 memory、残差 memory、收缩开关。任务簇/上游谱系与风险层都隔离；gene/chemical 单独报告。

## 11｜当前完成、下一步与风险

已完成：原结果审查、配对复算、理论和算法设计。

待完成：完整 Q、合法 E、最终估计器性能、外部确认。

E274 的 0% memory 用过 fit 标签，真实零目标反馈要另做。该差别主动说明，避免导师把现有曲线理解成已完成冷启动。

## 12｜预期成果与目标渠道

产出：计算方法、分类型验证、可复算软件。按 TCBB 计算方法稿建设，BIBM 为会议备选。CCF-B 与二区分开核定。

收束口述：现有实验已经把方法的起点和关键混杂因素找出来。接下来用统一合同验证残差修正和反馈效率，把这些规律落成可复现的风险估计方法。

## 导师可能追问的问题

**问：是不是把几个特征送进回归器？**

答：普通拼接是必须击败或达到更低反馈成本的对照。拟研究点是质量控制后的条件残差和反馈收缩；如果结构无额外价值，最终方法就采用简单实现，不能靠命名扩大贡献。

**问：H 已经出现负结果，为何还研究？**

答：负结果说明 H 的原始增量混有质量/反馈的重复信息。保留的是“检验 H 是否必要”的问题，最终 H 可以被删除；质量和反馈主问题仍然成立。

**问：幅度大等于不可靠吗？**

答：不等于。完美的大效应预测仍然误差为零。M 是由现有结果支持的基础风险变量，其适用范围需要跨模型、跨类型验证。

**问：为什么不再加更多数据集和深度网络？**

答：当前最关键的是同信息、同反馈预算和完整 Q 的方法比较。先利用已有材料闭合这项证据，再由缺口决定是否增加数据或模型。

**问：三十号能保证什么？**

答：能交付有原始依据的进展、明确的研究问题、数学模型和实验方案。正式效果和期刊录用需要后续验证与审稿，开题中如实标记。

**问：旧证书是不是不要了？**

答：保留为已完成研究基础。证书针对注册模型家族误差，本课题风险器针对指定预测器，二者可以互补，但不混用保证对象。
