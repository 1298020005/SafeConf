# SafeConf 开题与进展：12 页汇报提纲

建议时长：12–15 分钟。每页只讲一个结论，结果来源统一指向 Stage2 v4 论文包。

## 1｜问题与使用场景

**面向单细胞扰动预测的证据感知后置风险审计。**

口述：冻结上游一次会给出大量基因表达预测；SafeConf 不改上游，而是在真实实验预算有限时判断哪些任务更可能错、应优先复核。

## 2｜为什么需要单独的风险模型

- 上游平均误差无法告诉我们单个任务是否可靠；
- prediction magnitude 与误差相关，是必须击败的强基线；
- 公共历史可能有用，也可能稀疏、无关或冲突；
- 当前任务 truth 在推理时不可见。

输出统一称 task-level risk score，主要评价 Utility@20 与 risk-coverage。

## 3｜数据与证据角色

- DEV：TxPert GAT/Exphormer，各 1,808 tasks；
- SEEN：E190 GEARS 692-task 跨 family 压力线；
- SEALED：E170 四面板，2,400 tasks，在候选冻结后一次性打开；
- Stress：CPA 八个化学划分；
- Fail-closed：E208/E216/E247/E258。

口述：上游先过能力门，再做风险验证；不根据 SafeConf 涨幅挑上游。

## 4｜从旧实验推出新方法

- E201：幅度是强风险信号；
- E258/E259：历史相关会被支持量和测量噪声混杂；
- E273/E274：预测证据、公共历史和同模型反馈必须分开；
- 结论：先建立 prediction-only 风险，再根据历史证据可靠性决定是否修正。

## 5｜统一 Prediction/Error Contract

画出两条 adapter：

```text
direct effect ───────────────┐
treated state − control ─────┼→ aligned effect vector → task RMSE
                             └→ Universal Prediction Evidence
```

强调 gene space、normalization、control source、provenance 和 History Eligibility 都有版本记录。

## 6｜SafeConf V1 与最终 V2

```text
rP  = risk from Universal P
rPQ = risk from P + historical evidence

w = f(Support, Relevance, Conflict, Missingness)
rV2 = calibrated rP + w × (calibrated rPQ − calibrated rP)
```

口述：历史可信时使用修正；无关、冲突或缺失时收缩。rP/rPQ/gate 全部 nested/cross-fitted。

## 7｜开发结果与模型冻结

| 上游 | Magnitude | V1 | V2 |
| --- | ---: | ---: | ---: |
| TxPert GAT | 0.7682 | 0.7864 | **0.7963** |
| TxPert Exphormer | 0.7587 | 0.7823 | **0.7918** |

V2−V1 宏增量 +0.0097；7/8 strata 非负；安全门通过。此时冻结 V2，之后才打开 E170。

## 8｜与 PertEMA 的公平比较

| 上游 | PertEMA* | SafeConf V2 | 差值 |
| --- | ---: | ---: | ---: |
| GAT | 0.7237 | 0.7963 | +0.0656 |
| Exphormer | 0.7181 | 0.7918 | +0.0688 |

两组 bootstrap CI 下限均为正。PertEMA* 是官方算法/超参数在同任务、同 split、同错误标签预算下的适配。

## 9｜一次性 confirmation

E170：四面板、held-out donor、800 新 perturbation clusters、2,400 tasks、12 strata。

| Magnitude | Frozen V1 | Final V2 |
| ---: | ---: | ---: |
| 0.1655 | 0.2010 | **0.2159** |

- V2−Magnitude = +0.0504；
- 10/12 strata 非负；
- 风险退化护栏全部通过；
- **Gate A PASS**；
- bootstrap CI 跨 0，完整报告统计不确定性。

## 10｜边界与负结果

- 有历史的 1,920 tasks：0.2383 → 0.2857；
- 无历史的 480 tasks：所有方法接近无信息；
- E190 GEARS：V1 有正点增量，V2 gate 在少量 clusters 下失败；
- CPA：接口可运行，但上游未过能力门；
- Quality：合法 coverage 为 0，不声称 Quality-aware。

口述：这些结果界定方法适用范围，也说明能力门与收缩机制为什么必要。

## 11｜部署增强：Error Memory

- GAT：零反馈 0.7615；75%/100% 为 0.7699/0.7759；
- Exphormer：零反馈 0.7514；50%/75% 为 0.7688/0.7681；
- 10% 反馈不稳定。

部署方案：积累同一冻结上游的合法反馈，按批次周期重训风险层；不宣传逐样本在线学习。

## 导师可能追问

**问：是不是几个特征加 Ridge？**

答：Ridge 是低方差实现。方法贡献在统一误差合同、历史资格、能力门、nested evidence shrinkage 和冻结确认；HGB/MLP 同预算没有更稳定。

**问：确认是否真正独立？**

答：E170 的 test 结果、字段分布和 truth 在候选冻结前没有读取，四面板经远端授权后一并打开。它是同研究新 perturbation/held-out donor confirmation，不包装成 external-study。

**问：为什么 bootstrap CI 跨 0 仍说 Gate A 通过？**

答：Gate A 是结果前登记的实用性与安全性标准，要求 ΔU20≥0.005、至少 60% strata 非负和风险护栏。它通过；bootstrap CI 说明有限 clusters 下估计仍不精确，两者同时报告。

**问：化学扰动是否完成？**

答：统一接口与压力测试完成；当前 CPA 上游能力不足，因此不承担主确认。论文以基因扰动为主验证，化学作为压力边界，后续补成熟化学上游。

**问：为什么不是大型网络？**

答：当前 task 数量下 Ridge 更稳定，MLP 明显落后。方法的计算问题是证据可靠性与安全退化，不需要用大模型掩盖样本限制。
