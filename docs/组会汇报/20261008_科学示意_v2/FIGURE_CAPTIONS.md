# 科学示意图图注与计算对应

## 方法概览（METHOD_OVERVIEW）

**a，新预测器和未知结果。**冻结扰动预测器 C 产生生物效应向量，当前任务的真实扰动响应尚未获得。图中的细胞、剪切和热图条用于表示任务与输出，不代表新训练了任何预测器。

**b，公共参照支持的风险判断。**合法历史实验提供响应向量 h_i。固定支持权重 w_i 得到 μ=Σw_i h_i；当前预测与均值的距离为 D=RMSE(预测,μ)，历史分散度为 V=Σw_i mean((h_i−μ)²)。公共规则的分数为 √(D²+V)，等于预测到合法历史的加权均方距离。图中的 Δ 标记局部效应差，D 在完整共同基因轴上计算。绿色曲线与阴影是参考响应及历史变化的示意，不是测得数据或校准区间。

蓝色侧路表示使用其他预测器合法留出预测、公共特征和错误训练共享风险学习器。历史错误被用于训练模型参数；推理时学习器读取当前预测和公共特征。当前实现使用固定 HGB，误差 CDF、训练权重和完整嵌套过程继续由原配置负责；这些细节不塞进概念图。

橙色侧路表示 C 获得登记预算内真实错误后训练目标风险候选；当前比较包括 HGB、小样本 HGB 和官方 XGBoost 配方的 PertEMA 输入适配。组合 Shared 分数时采用合格折外结果。当前默认与监督候选是不同配置，图中箭头不表示分数直接相加。全量排序的缺失处理和分数尺度按原冻结规则；无历史时保留幅度回退。

**c，有限复核和后续更新。**对同一队列输出一组风险排序，固定复核 ceil(0.2n) 项。获得的合法错误可用于下一批预测的个性化候选；发布检查使用训练/开发侧证据。永久评价池不因此进入更新训练。筛查收益没有改写上游模型的预测向量。

**灰色独立线。**已注册预测家族的分歧 D_F 给出该家族 RMS 误差 E_F 的确定性下界。它独立于当前经验排序，未给任意单模型提供概率保证，也未被强制加入 PublicRule。

## 实验驱动的转折图（EVIDENCE_DRIVEN_EVOLUTION）

**a，E189。**3 scGPT 与 3 GEARS 的分歧和家族 RMS 误差关系随留出方式改变。线段来自 support=1/2/3/5 的相关范围，不是 CI。该旧模型家族预测能力偏弱，结果用于解释适用边界。

**b，E201。**同一 1,808 任务中，旧固定分数与四个 GAT 种子的家族 RMS 误差相关为 0.408；预测幅度为 0.619；控制幅度后的旧分 partial ρ 为 0.250。边际相关和条件相关分别标示。固定复核 U20 同时记录为旧分 0.320、幅度 0.594。

**c，SafeConf-M。**9 月开发候选 0.8Q(M)+0.2Q(S) 的 context 宏平均相关增量为 0.0183，95% CI [0.0091,0.0271]；U20 增量为 0.0134，CI [-0.0139,0.0520]。两个指标分别验收；该历史候选不等于当前默认。

**d，PertEMA 核对后的问题。**自身 OOF 错误的后置学习已有直接近邻，当前研究进一步区分公共实验、其他预测器错误和当前预测器反馈的可用信息。图展示问题的重定位，不声明这些组件首次出现或全部有效。
