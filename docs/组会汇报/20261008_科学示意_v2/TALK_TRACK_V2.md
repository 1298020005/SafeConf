# 给周老师的汇报 v2：沿着问题讲演变，再讲真实效果

建议主体五页、约 10—12 分钟；E201 和困难设置作追问时的备份。以下是口头表达，不是论文正文。各数字对应的文件列在 EVIDENCE_BINDINGS.csv。

## 1. 研究怎样演变到现在（约 3 分钟）

**放图：EVIDENCE_DRIVEN_EVOLUTION。**

老师，上次您问了几件很具体的事：风险和哪个预测模型的误差比较；几个模型的分歧，是在判断某一个模型，还是在判断这项任务本身难；幅度等输入是不是必须把实验测出来才知道；以及小矩阵、整行、整列和跨数据集的设置。

我后面沿着这些问题做了验证。最早的想法是把支持、背景相似性、模型分歧等信息合成固定风险分，希望能排序预测错误。随后明确了每组结果的误差对象，并把容易的随机缺格扩展到背景、扰动和两者同时留出。

困难设置给了一个具体结论：模型分歧的意义随设置变化。E189 的六模型家族中，分歧与 family RMS 在随机缺格为正，整列未见仍有正信号；整行未见没有稳定正信号，双未见甚至反向。所以这条分歧信息能识别部分任务难度，但小分歧不能直接解释为当前模型预测安全。这个结论来自当时较弱的模型家族，后续也继续做了能力更合格的预测器验证。

这里也有正结果：更早的 E90 在六个未见基因面板、144 个任务中，分歧相对幅度的池化相关增量为 0.120，区间 [0.007, 0.238]。因此收缩的是普适排序主张，已有特定设置里的正信号仍保留。

另一个转折是强简单起点。E172 的新靶点没有确认固定分数超过幅度。E201 中，1,808 个四背景留出任务，旧分和四个 GAT 种子 family RMS 的 Spearman 为 0.408，预测幅度为 0.619；控制幅度以后旧分仍有 0.250 的条件关联。实际只复核 20% 时，旧分 U20 为 0.320，幅度 0.594。也就是说旧分包含额外信息，但当时使用这份信息的方式没有带来更好的复核排序。

这以后我把幅度放到起点。9 月做过明确的 SafeConf-M 候选：80% 幅度秩加 20% 原风险秩。E201 留背景开发里，context 宏平均相关增量是 0.0183，区间 [0.0091, 0.0271]；20% 复核增量 0.0134 的区间仍跨零。这一步保留了幅度，也进一步表明相关改善和实际复核改善要分别验收。

还有一条一直并行的家族证书线，7 月已经开展，时间上早于 E201。它回答事先注册家族的误差下界，E181 两类下界在 2,393 个任务上零违例；外部上界未过门的 E182 仍保留 FAIL。它和经验排序是两个研究对象，证书不直接给每个新模型一个可靠概率。

**转到 PertEMA。**后来核对 PertEMA，我意识到当前模型自身 OOF 错误的后置学习已经有直接近邻。于是进一步明确三个信息条件：公共真实实验提供什么参照；其他预测器 A/B 的错误能否迁移给尚无自身错误监督的 C；C 有了反馈后还能改善多少。这一步接续了原来关于风险规律能否迁移的问题。

## 2. 当前架构具体怎样计算（约 2 分钟）

**放图：METHOD_OVERVIEW_ZH。**

这张图以当前结果未知的新预测为中心：公共真实响应形成参照，共享与目标学习器提供经验证后可以启用的风险判断，最终进入同一复核队列。

公共模块读合法的真实实验。对当前任务排除自身实验、禁止重复，统一 effect、对照与基因轴，得到支持加权均值 μ 和历史效应分散度 V。当前预测 ŷ 和 μ 的距离是 D，直接公共规则用 √(D²+V)。它是到合法历史实验的加权均方距离，不需要预测器错误标签。

Source 模块使用其他冻结预测器在合法留出任务上的错误。CDF 只用对应训练区和预算，把不同模型及背景的原始误差分组处理；公共训练特征也经过内部留出。它训练风险模型参数，推理时输入 C 的预测特征和公共证据。C 推理时没有逐条读取 A/B 的错误数据库，也没有使用当前任务的真值。

Target 模块使用登记预算内 C 自己的错误。HGB、小样本 HGB、官方 XGBoost 配方适配都比较过；要组合 Shared 分数时用折外输出。算法选择、CDF 和融合用过的 C 错误全部计入信息成本。零反馈配置没有 Target 通道。

最后在开发侧选定完整评分配置。没有历史时退回幅度，有历史时用对应公共规则或通过验收的风险学习器；不同通道的尺度只在训练侧固定。每条任务输出一个分数、信息状态和版本。新记录进库后训练候选，验收后更新，失败时数据留存而参数保留旧版。

**目前的采用很具体：McFaline 用 PublicRule；TxPert 同体系 Source DEV 有明确正结果；Target 仍是候选。**这三条在图中并列，不要求串成三次修正。

新架构也实际试过。公共内容聚合统一以后，逐条小网络与 DeepSets 没有稳定通过采用门；背景映射和可靠性候选也没有稳定改善最终风险排序。因此保留了更有效的公共方案，没有为了保留某个网络去继续扩大结构。

## 3. Source 的正结果在哪里、边界在哪里（约 2 分钟）

**放图：03_SOURCE_RESULT，原三 panel 中的 A。**

这里用同一批 1,808 个任务、575 个扰动簇做五个外层 gene folds。Exphormer 的错误训练、GAT 评价，公共秩通道 U20 是 0.577，Source HGB 是 0.780；反向为 0.557 和 0.786。配对增量分别为 0.202，区间 [0.149, 0.269]，以及 0.229，区间 [0.158, 0.280]。

五个整扰动簇错误标签置乱对照，始终 Source 的平均值下降到约 0.168 和 0.149。特征、训练行、权重和 CDF 相同，打乱的是标签与任务的关系。所以这里的真实错误对应关系确实提供了信息，能在未见扰动风险折和另一种架构上改善判断。

条件 gate 这次也修正了通道尺度，并对真实与置乱流程重新做了开发选择，但结果弱于始终 Source。我保留了 Source 的实际增量，没有额外采用 gate。

这里还要直接对强幅度基线：同一合同里，幅度分别为 0.749 和 0.746，Source 的额外点增量为 0.031、0.040，95% 区间分别 [-0.016, 0.059]、[-0.001, 0.076]。它明确超过公共通道和置乱，而超过幅度的稳定额外收益尚未建立。原图保留，强对照另表展示。

这个结果的范围是 TxPert 两种架构的同体系迁移。跨 family 已经跑过 SAMS 与 DecoderOnly，不是还没有做：真实错误优于置乱，但仍未稳定超过强公共规则。SAMS 已通过登记的操作性可用门，但相对强简单预测器的误差改善很小、区间跨零；它不同于此前能力门失败的 scGPT/GEARS 压力批次。另一些研究的公共或 Source 迁移也有负结果。因此下一项要查的是哪些可提前计算的条件支持额外迁移，不能只把模型名称增加当成进步。

## 4. PertEMA 之后，我们增加的信息带来了什么（约 1.5 分钟）

**放图：04_TARGET_RESULT，原三 panel 中的 B。**

这组是在当前 McFaline 真值、同一 212 个评价任务和 152 个基因簇上重新比较。Native61 包括预测时可获得的控制特征、control-only embedding 和训练相似性，使用官方树配方；另一组只增加相同公共信息，反馈记录和权重一致。

50% 反馈时，三个种子平均 U20 从 0.053 提高到 0.733；100% 时从 0.203 提高到 0.764。五个预算的主种子配对区间都支持加入公共信息的正增量。

无反馈 PublicRule 为 0.838，仍然更强。这里证明的是公共实验能够增强这份较完整的预测时特征适配，尚没有证明这个反馈学习器值得取代公共规则。Native61 属于 McFaline 输入适配，训练目标改为当前 RMSE/CDF；完整官方校准和 conformal 流程没有复现，所以汇报时把适配范围写清楚。

此前 37 条反馈训练记录、HGB 叶子至少 20 导致无法分裂，确实是实现设置限制。修正小样本叶子后恢复了学习；随后仍没有稳定超过强公共规则，这才是当前采用决定的依据。固定 TabPFN 替换也跑了，没有通过升级门。一次替换结果用于判断这一配置，不用于排除所有学习器。

## 5. 最终配置的实际用途，以及下一步研究选择（约 1.5 分钟）

**放图：05_REVIEW_RESULT，原三 panel 中的 C。**

现在用同一 212 个任务做一次全局排序，每种方法都复核 43 项。公共规则命中真实误差最大的 43 项中的 22 项，幅度命中 4 项，多发现 18 项。去掉这 43 项后，剩余平均误差相对幅度复核方案降低 7.07%。Native＋Public 的 50% 反馈版本在固定首种子命中 19 项。这说明当前采用公共规则有实际理由。

另一个强起点是历史支持量规则：同一 212 个任务上的 U20 为 0.795，公共规则为 0.838。所以公共历史整体确实有用，但这里面生物内容、实验支持和测量因素的贡献仍需分别解释，不能把全部增益都归为生物内容。

这个收益是筛查能力，上游模型预测值没有被改好。图 B 的主指标按 context 宏平均，这一页是全局 20% 复核，两个统计对象分别报告。另一组 2,993 个有历史 / 无历史混合任务已完成回顾性评价，公共方案相对幅度多命中 33 项；它是另一任务合同，不拼到这组图里。

目前我的研究判断是：公共真实实验作为风险参照有明确用途；旧模型错误在同体系里有清楚的额外价值；换研究和预测机制以后，Source 的额外价值需要针对条件验证。Target 学习器加入公共信息有收益，但反馈本身没有稳定优于无需反馈的强起点。

接下来我会先把 SAMS 双向结果和同体系结果按同样任务、公共特征及监督账本对齐，查错误模式与参照偏差在哪些条件下共同变化；从已登记资产中核准一个预测能力合格、未参与当前选择的验证队列。资产身份先核准，方法只在开发数据上定，完整配置冻结后才读确认成绩。这次组会材料没有启动新训练或打开封存 TEST。

**可以以一句具体的问题结束：**我现在要进一步解决的是，哪些已有真实实验可以作为新预测器的风险参照，以及其他模型的错误经验在什么条件下确实超过这个参照。当前结果已经把有效范围和下一项验证缺口分开了。

## 讨论时备用：几个区别要保持

| 老师可能接着追问 | 对应说明 |
|---|---|
| 现在风险到底对应谁？ | 当前每条结果绑定目标冻结预测器的误差；E201 的历史结果是四 GAT 种子 family RMS。两种目标分别记录。 |
| 幅度或公共参照要看当前答案吗？ | 幅度从冻结预测计算；公共库资格排除当前实验及禁止派生记录；当前真值只用于评分。历史本身的生物真值是合法额外信息，单独计账。 |
| Source 是任务难度还是模型特有信息？ | 留出扰动、换架构、真实与置乱标签证据支持当前迁移范围；尚需进一步用共同困难任务与跨 family 比较区分共同难度和模型特异成分。 |
| 公共参照更准确就必然识别错误吗？ | 不必然。令 a=ŷ−y，b=μ−y，D²=e²+mean(b²)−2mean(a·b)。参照偏差的大小与共同方向都会影响距离。含真值项只作开发诊断，不作推理特征。 |
| 证书现在在哪？ | 固定、事前注册家族的下界是独立线。它没有被塞进当前 PublicRule，也不等于单模型可靠概率。 |
| 方法版本为什么一直改？ | 学习目标逐渐明确，强起点和信息预算变严格；固定总分、SafeConf-M、Public / Source / Target 是有实验依据的不同阶段。旧实验和失败门保留。 |
| 当前做得最扎实的是什么？ | Public 的实际复核用途、同体系 Source 的标签对应关系增量，以及较完整 PertEMA 输入适配增加 Public 的公平比较。 |
