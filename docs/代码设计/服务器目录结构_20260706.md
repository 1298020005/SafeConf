# SafeConf 服务器目录结构

更新日期：2026-07-07

SafeConf 在服务器上使用以下唯一路径边界：

| 服务器路径 | 用途 | 是否进 Git |
|---|---|---|
| `/home/yyf/proj` | 当前代码、稳定文档、实验证据索引和汇报 | 是 |
| `/home/yyf/data` | 原始数据集和外部 benchmark | 否 |
| `/home/yyf/safeconf_runtime` | 大型数组、预测向量与完整运行产物 | 否 |
| `/home/yyf/tool` | 服务器通用工具和代理脚本 | 否 |
| `/home/yyf/out` | 短期交付中转区 | 否 |
| `/home/yyf/archive` | 所有旧项目、课程、备份和历史现场的唯一归档根 | 否 |

项目内部的 `docs/实验结果/` 保留可审计的正式表、图、协议和结论；与之对应的大型原始运行产物保留在 `/home/yyf/safeconf_runtime/outputs/`。

旧项目已从 home 顶层收入 `/home/yyf/archive/projects/`；SafeConf 项目内部原有的 `_archive`、`docs/_archive`和`workspace/_archive`也已迁往 `/home/yyf/archive/safeconf/`。Git 工作区不再保留分散归档目录。
