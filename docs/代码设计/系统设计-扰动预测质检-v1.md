## 0. 一句话（组会可念）

> 预测器已经给出「扰动后细胞怎么变」；我们设计一套 **可复现的质检系统**，给每一次预测打 **可信度分**，并用「高分是否对应低误差」来验收。

**不是**：再造一个比 GEARS/V0 更准的深度模型。

## 1. 系统长什么样（总览）

```text
                    ┌─────────────────────────────────────┐
                    │  公开单细胞扰动数据（已在服务器）      │
                    └─────────────────┬───────────────────┘
                                      ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ ① 协议层（Protocol）                                                      │
│    · 定义 effect、control、eligible (context, perturbation) pair          │
│    · held-out pair 切分 + 泄漏检查（L1–L4）                               │
│    · gene_main / chem_robust 分线；发布 splits/*.json                     │
└─────────────────────────────────┬────────────────────────────────────────┘
                                  ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ ② 预测层（Predictor，黑盒，不训练新深度模型）                            │
│    · V0、ContextSim（现成）→ 每条 task 输出 predicted_effect              │
│    · 后期 GEARS：读 checkpoint / 预计算 npz（predictor-agnostic 证明）    │
└─────────────────────────────────┬────────────────────────────────────────┘
                                  ▼
                    PredictionRecord（一行 = 一次预测）
                                  ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ ③ 打分层（Scoring）                                                       │
│    · 从 train 折统计算特征（禁止偷看 test 真值）                          │
│    · 输出 confidence_score（越大越可信）                                  │
│    · 主方法：family-aware 组合分（v0.2 公式，见 §4）                      │
└─────────────────────────────────┬────────────────────────────────────────┘
                                  ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ ④ 评估层（Evaluation）                                                    │
│    · Spearman(confidence, RMSE)，按数据集分别报                           │
│    · risk-coverage@80%、高低分组 ΔRMSE                                    │
│    · 主表、图、RUN_REPORT → 论文 Results                                  │
└──────────────────────────────────────────────────────────────────────────┘
```

**你要写的代码 = 上面四层里的 ①③④ + ②的薄封装**，不是第五个「大神经网络」。

## 2. 三类代码（对应 Codex 口径）

| 类 | 干什么 | 包内模块 | 论文里叫什么 |
|:---|:-------|:---------|:-------------|
| **协议代码** | 数据怎么切、什么叫 test、怎么防泄漏 | `split/`, `data/tasks.py`, `config/datasets/*.yaml` | Methods: split protocol |
| **打分代码** | 每次预测一个 confidence | `features/`, `scoring/` | Methods: confidence features |
| **评估代码** | 分数有没有用 | `eval/` | Results: correlation & RC |

**预测器代码**（V0/ContextSim）已有，放在 `predictors/`，只做 **adapter**，不重写算法。

## 3. 评估单元：PredictionRecord

**一行记录 = 一次预测**，字段核心：

| 字段 | 含义 |
|:-----|:-----|
| `dataset`, `fold`, `split` | 哪次实验、哪折、train/val/test |
| `context`, `perturbation` | 目标细胞背景、扰动 |
| `predictor_name` | V0 / ContextSim / GEARS |
| `predicted_effect`, `true_effect` | 向量存 NPZ，表里只存指针 |
| `true_error_rmse` | **主 ground truth**（与 confidence 比） |
| `confidence_score` | 方法输出（越大越可信） |

`n_genes = 5000`（写死在 config，禁止 silent 改成 1000）。

## 4. 协议 v0.2（拟冻结内容）

### 4.1 数据集分线

| 族 | 数据集 | 论文角色 | 当前状态 |
|:---|:-------|:---------|:---------|
| **gene_main** | Haber, Parekh, Norman, Adamson | 主文 Table | 前 2 个已跑；后 2 个 **blind** |
| **chem_robust** | KaggleCrossCell, KaggleCrossPatient | 附表 / 稳健性 | KCC 已跑 |
| external | Papalexi / Frangieh | 冲一区可选 | 后期 |

**硬规则**：禁止 gene + chem **pooled** 成一个 Spearman 当唯一 headline。

### 4.2 Split：held-out (context, perturbation) pair

- 划分单位是 **(c,p) 组合**，不是单独新 context 或新 perturbation。
- 默认 5-fold（极小集 3-fold）；val = trainval 的 10%。
- 自动断言 L1–L4（见 `PROTOCOL.md` §4.3）。
- 发布：`splits/{dataset}/fold_{k}.json`。

### 4.3 主分数公式（v0.2 实验已验证，待写入 PROTOCOL.md）

在 **fold train 上 z-score 各特征** 后，**val 上选权重（若需要）**，**test 只打分**：

| 族 | 主分数名 | 公式（概念） |
|:---|:---------|:-------------|
| **gene_main** | `protocol_v0_2_family_confidence` | `z(context_similarity) + z(log_support) − z(model_disagreement)` |
| **chem_robust** | 同上 | `z(log_support) − z(model_disagreement)`（**stability 权重 = 0**） |

**对照 / ablation**（主文或附录）：`model_disagreement` 单独、`historical_residual`、`random`、同 fold `learned_histgb`（**不当 headline**）。

### 4.4 主指标

| 指标 | 方向 | 报告方式 |
|:-----|:-----|:---------|
| aligned Spearman(score, RMSE) | 越高越好 | **每个数据集一行** |
| risk-coverage@80% | 保留高置信后 RMSE 是否下降 | per dataset |
| high-low ΔRMSE | 最高 vs 最低 20% 置信 | 补充 |

## 5. 特征字典（打分层设计）

所有特征 **只用当前 fold 的 train 统计**（+ 可选 val 调权重），**禁止**用 test 的 `true_effect`。

| 特征 | 直觉（人话） | 基因线 | 化学线 |
|:-----|:-------------|:------:|:------:|
| `context_similarity` | 目标背景和训练里见过的像不像 | ✓ | 可选 |
| `log_support` | 这个 (c,p) 在训练里证据多不多 | ✓ | ✓ |
| `perturbation_stability` | 同一扰动在别的 context 稳不稳 | ✓ | **权重 0**（KCC 缺失多） |
| `model_disagreement` | V0 和 ContextSim 意见是否一致 | ✓ | ✓ |
| `prediction_magnitude` | 预测效应是否离谱 | 辅助 | 辅助 |
| `ood_distance` | 是否离训练分布太远 | 辅助 | 辅助 |
| `historical_residual` | 历史误差模式 | baseline | baseline |

**诚实记录**：Parekh 上单独 `model_disagreement` 可比组合更强 → 主文写 **可解释组合 + 跨集稳健**，不写「组合永远最强」。

## 9. 和文献的关系（设计定位，不是空白领域）

| 工作 | 他们 | 我们 |
|:-----|:-----|:-----|
| scPerturBench / PerturBench / scArchon | 比 **谁预测更准** | 比 **这次预测信不信** |
| PRESCRIBE (NeurIPS 2025) | **新模型** 内置 uncertainty | **任意 predictor** 外挂同一协议 |
| Selective prediction | 通用 risk-coverage 理论 | 落到 perturbation + cross-context |

**投稿句子（Introduction 用）：**

> Existing benchmarks focus on predictive accuracy or model-internal uncertainty; we provide a **predictor-agnostic protocol** to score whether each **cross-context** perturbation prediction is reliable under **held-out (context, perturbation) pairs**.
