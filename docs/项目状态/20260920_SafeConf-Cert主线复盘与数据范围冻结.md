# SafeConf-Cert 主线复盘与数据范围冻结

更新时间：2026-09-20  
性质：研究范围与证据口径冻结；不是投稿承诺，也不是正式实验结果

## 一、先把 SafeConf-Cert 说清楚

SafeConf-Cert 不预测扰动后的基因表达。上游模型先完成预测，SafeConf-Cert 只检查一组不同结构的上游模型在同一任务上分歧有多大。

设第 \(m\) 个模型的预测向量为 \(\hat y_m\)，模型家族的平衡质心为 \(\bar y\)，尚未打开的真实表达变化为 \(y\)。定义：

\[
D_F^2=\sum_m w_m\lVert \hat y_m-\bar y\rVert^2,
\]

\[
R_F^2=\sum_m w_m\lVert \hat y_m-y\rVert^2.
\]

由平方误差的分解恒等式：

\[
R_F^2=\lVert \bar y-y\rVert^2+D_F^2 \ge D_F^2,
\qquad R_F\ge D_F.
\]

其中：

- \(D_F\)：不同结构模型之间的分歧，只用预测就能计算；
- \(R_F\)：整个注册模型家族相对真实答案的均方根误差；
- \(w_m\)：模型权重，先按架构或谱系平衡，再在同一架构内部平分，避免复制多个相似模型人为放大票数；
- \(\tau\)：使用者预先规定的最大可容忍误差。

如果 \(D_F>\tau\)，那么在不读取真实答案的情况下，可以确定 \(R_F>\tau\)。系统输出 `CERTIFIED_HIGH`，停止自动放行并要求复核。

如果 \(D_F\le\tau\)，系统只能输出 `UNKNOWN`，不能说预测安全，也不能保证任何单个模型正确。

一个数值例子：若两类不同结构模型的平衡分歧为 0.12，而允许误差上限为 0.10，则模型家族的真实均方根误差至少为 0.12，任务应停止放行。若分歧只有 0.06，结论只是证据不足，不能据此放行。

## 二、为什么主线发生过变化

此前同时探索过四条路线，后续实验逐步排除了其中三条作为主线的可能性。这不是四套方法同时成立，也不能把失败结果隐去。

| 路线 | 已有证据 | 当前地位 |
|---|---|---|
| 原始风险排序 | E201 中风险分与误差的宏平均 Spearman 为 0.4082，但预测幅度为 0.6189；控制幅度后仍有 0.2503 的剩余关联 | 保留为辅助分析，不能写成最强排序器 |
| 幅度与 SafeConf 融合 | E206 内部开发有小幅提升；E216 新外部数据上固定组合未通过，复核效用下降 | 不作为主张，只保留完整消融和负结果 |
| 训练加权 | E204 只完成工程验收，没有正式科学效果 | 暂停，不进入当前论文主线 |
| 确定性高误差证书 | 数学下界成立；E211 回顾性数据无下界违例；E194 支持架构平衡与防复制；E216 能在明显失效的外部模型家族上提前停止 | 唯一候选主线，仍需 E205 证明对正常可用的跨结构模型家族具有实际覆盖率 |

因此，当前准确表述不是“SafeConf-Cert 已经达到目标期刊水平”，而是“它是现有证据中逻辑最完整、最值得完成验证的候选主线”。E205 结果出来前，不得写成已经完成的方法论文。

## 三、数据范围怎样收束才合理

### 3.1 主分析的预先限定范围

当前主问题固定为：遗传扰动条件下，面对没有目标真值的新任务，能否利用真正不同结构的预测模型给出可验证的高误差下界，并据此停止自动放行。

主分析数据必须同时满足：

1. 遗传扰动（CRISPR、CRISPRi 或相同数据合同的基因干预）；
2. 有匹配对照，可构造统一的基因表达变化向量；
3. 同一任务至少有两条不同模型架构或谱系的预测；
4. 模型家族、权重、阈值和误差对象在打开目标真值前登记；
5. 所有符合这些条件的任务一并报告，不能因结果不好事后删除；
6. 每个分组样本量不足时只作描述，不作稳定性结论。

### 3.2 不纳入主结论、但不能销毁的内容

- Tahoe 等化学扰动：扰动机制、剂量和数据合同不同，现有结果也显示 magnitude 更强。它们可作为适用边界或补充材料，不与遗传扰动合并计算主结果。
- 只有单个模型或同一架构复制的任务：无法形成跨结构证书，可用于普通风险排序，不能冒充 SafeConf-Cert 主验证。
- E216 Jiang24：上游模型明显弱于 no-change 基线，因此保留为“失效模型家族能否被提前关停”的压力测试，不能包装成正常模型上的正面性能验证。
- 原始风险排序、固定融合和训练加权的失败或未完成结果：保留在补充材料和项目记录中，不删除、不改数。

上述限定根据方法问题和输入合同制定，属于合理收束。反过来，如果某个遗传扰动数据集完全符合主分析条件，仅因为结果差而删除，就是结果导向筛选，不能执行。

## 四、可以怎样突出结果，不能怎样处理结果

可以做的：

- 标题、摘要和主图只回答已经冻结的遗传扰动证书问题；
- 主图展示预先定义的主要终点，其他扰动类型和次要指标放补充材料；
- 清楚区分“正常可用模型家族”和“明显失效模型家族”两个应用状态；
- 使用公开、事先声明的模拟压力测试解释共同偏差、复制攻击和证书失效边界；
- 对失败结果作边界说明，不把它写成主要贡献。

不能做的：

- 修改真实标签、误差、置信区间或任务数量；
- 看完 E205 真值后再换 family、权重、阈值或主要指标；
- 只保留表现好的细胞系、基因、随机种子或数据集；
- 用合成数据冒充生物实验；
- 把“家族误差有下界”改写成“某个指定模型一定错误”；
- 把 `UNKNOWN` 改写成“低风险”或“安全”。

## 五、E205 出来后只按一套规则裁决

E205 使用 TxPert STRING-GAT 与 Exphormer 两类结构，在 K562、RPE1、HepG2、Jurkat 四个目标上各训练四个随机种子。当前 15/16 个训练完成，最后一个 Jurkat 模型仍在训练，目标真值为 `NOT_AUTHORIZED`。

结果解封后固定报告：

1. 下界是否存在违例；
2. 证书紧致度，即 \(D_F/R_F\)；
3. 固定 \(\tau\) 下的覆盖率、真实高误差任务召回率和错误证书数；
4. 四个目标分别的结果，而不是只报宏平均；
5. 架构平衡与成员平铺的对照；
6. 复制同类模型时证书是否被操纵；
7. 计算时间和显存开销；
8. 上游模型相对 no-change 基线的能力检查。

裁决分三种：

- 下界无违例且固定阈值有实际覆盖率：SafeConf-Cert 主线成立，继续整理为计算生物信息学方法论文；
- 下界无违例但覆盖率接近零：数学结论成立，实用贡献不足，需要增加另一个合格的跨结构模型家族，不能直接宣称论文已经够格；
- 上游模型本身不合格：E205 只能作为压力测试，不得当作正常应用验证。

## 六、截至本次冻结的最终判断

SafeConf-Cert 解决的是一个明确而有限的问题：当不同结构预测器的分歧已经大到足以证明注册模型家族总体误差超过容忍度时，系统拒绝自动放行。它不提供“低误差保证”，也不替代预测模型。

这条主线在理论对象、输入、输出和失败动作上已经闭合；现有证据还缺 E205 对正常可用跨结构模型家族的实际覆盖率。只有该证据通过，才能讨论匹配的计算方法期刊。任何期刊分区或录用都不能由当前结果预先保证。

自本文件起，E205 解封前不再新增论文主线，不再按局部结果改写数据范围。后续实验只补齐本文件列出的证据链。
